# WLD-LIFE-FAUNA · 动物与生活痕迹

> **范围**：本文规定全校的动物（含夜间、季节与雨中的状态，以及对玩家身体作出反应的猫、鸽群和水禽）、室外生活痕迹，以及它们和街道家具共用的随时段、季节、天气的显隐做法。
> **不在本文**：停着的车、街道家具及其碰撞（WLD-LIFE-STREET）；动物与布料的动作节奏（SYS-MOTION）；室内痕迹（WLD-INTERIORS-BUILD §4，图书馆与博物馆见 MAP-QSH-LIBRARY）；发声（SYS-AUDIO）；动物的生成器、容器与动画写法（`game/gen/fauna/`、`traces/`）。
> **查阅**：先读 §0；动物看 §1、§1.1；单车、晾晒、季节与雨天痕迹看 §2；显隐看 §3；待验证看 §4

## 0 结论

1. **动物**：种类、数量、位置、季节和夜间状态以 §1 表为准，夜间指太阳低于 −6°；下雨时鸟回巢、猫躲到檐下；黄昏的乌鸦只是 2–3 只一组的静止剪影；不画成群飞过的鸟、喜鹊和鸳鸯。
2. **反应动物**：学知苑的黑猫和时间广场一带的鸽群（6–12 只）只对行走模式的玩家身体作出反应；水禽对游泳的身体缓慢让开；动物不推玩家、不挡路；反应不进存档（§1.1）。
3. **生活痕迹**：单车、电动车、晾晒随时段增减；季节痕迹只在当季出现，不留残件；雨天痕迹按天气出没（§2）。
4. **不凭空出现或消失**：日夜、季节、天气的切换只在不在视野里或快进、换季雾幕时进行；街道家具和车里随时段、季节、天气变的物件同此（§3）。

### 0.1 接入要点

- **做随时段、季节、天气显隐的物件（含 WP-52 的室内痕迹）**：沿用变体掩码与锁存，只在这组不在视野里或快进、拨时间环、换季雾幕时切；不用全局参数切日夜和天气（§3）
- **区域包写宿舍晾晒、毕业季横幅**：晾晒比例按 §2 的表，衣物不出栏板外沿；横幅位置和文字由 MAP-QSH-NORTH 定
- **行走控制器（WP-42）**：不读动物位置、不推开动物；每个物理步发布感知快照（§1.1）
- **栖地（WP-44、WP-08、区域包）**：活动面、退避点、避雨点由栖地数据给出；学知苑猫栖地归 WP-20，鸽群栖点归 WP-16（§1.1）
- **音频（WP-53）**：动物发声器的位置与小动作时刻由 WP-25 提供，部件声音经 `IPartDef.Sounds()` 给出

### 1.1 反应动物：猫、鸽群与水禽

行走模式下玩家有身体。猫和鸽群对行走的身体作出反应，水面上的水禽对游泳的身体缓慢让开；其余动物照 §1 作息。

| 动物 | 反应 |
| --- | --- |
| 学知苑黑猫 | 平时待机、坐卧、理毛、小范围踱步；玩家走近时注意；跑近或下一步会撞上时让路、退到安全点；玩家静止或蹲下满 3 s 后可短暂好奇地靠近，不跟随，玩家一动就让开；随后平静，回到常态 |
| 鸽群（6–12 只） | 普通接近时就地让开，再回来啄食；跑近或地面没有退路时局部惊飞：起飞、沿有界航线飞一小段、在合法栖点落下、恢复 |
| 水禽（黑天鹅、小天鹅、小䴙䴘、白眼潜鸭） | 只对游泳的身体：缓慢让开，保持 4 m 以上，只改航向和速度；不惊飞、不潜逃、不发警示声；身体离开后回到平时的航线 |

- **只感知行走身体**：读同一份感知快照（位置、实际速度、姿态、支撑层），不读相机、按键和声音设置；旁观模式不被察觉，没有例外；隔着楼层或桥面不算靠近；静音不改变反应。
- **鸽群局部惊飞**是 SYS-MOTION §2.3 的定向例外：影响半径不超过 30 m，同一群冷却不少于 60 s（冷却期间改为地面让开），惊飞后回到合法栖点，不做全校群飞，不穿墙、树冠、桥底和身体。
- **不推玩家、不挡路**：动物不参与碰撞，自己让路；高速或瞬移避不开时允许不超过 0.3 s 的短暂穿插，绝不推玩家、不挡门。传送与回位后按合法落点重建动物的位置，不在视野里瞬移。
- **不做**：跟随、蹭腿、鸟主动落到身边；喂食、好感、收集、按键互动、名字条和奖励提示。猫不追出栖地，鸽群不离开自己的一带。"减少动态"打开时惊飞改为步行让开。
- **不是偶发事件，不进存档**：反应是常态行为，不写 `incidents.json`；读档、切图、传送后按栖地和当前世界状态重建，不重播旧的惊飞声。
- **栖地**由栖地数据给出，桥面、地面、台基、水面和室内层分开识别；契约以源码为准（contract-22）。

## 2 生活痕迹

人只以远处、听不清、来自看不见的地方的声音出现（SYS-AUDIO §4）；痕迹道具本身不发声。

- **共享单车（陈设）**：与停放点里可借的车同一款匿名共享单车（WLD-LIFE-STREET §1），陈设的不能借。默认状态（秋 17:30）停在图书馆前和各宿舍组团外（组团内不能停）。车筐落物按季节换：秋落叶，春樱花瓣，冬一撮雪，夏空着。上课时段（约 08:00–17:00）宿舍外的单车聚到品学楼、立人楼等教学楼前，傍晚和夜里回到宿舍组团外和图书馆前；两套停放位都建好，按 §3 切换。
- **电动车**：宿舍组团外红色透水砖车场的白线框里停满，颜色杂而低饱和，白天空出约三成。**私人自行车**：四号科研楼前露天停放，车棚里带前筐的通勤自行车整齐码一排，车色低彩度。
- **晾晒物**：宿舍阳台晾衣杆上挂衬衫、毛巾和浅色被子，被子也可平整搭在栏杆上拍晒（晒被子的阳台里约三分之一，每床两只晒被夹）；衣物是新的、颜色低饱和，只挂在阳台内的晾衣杆上，不出栏板外沿，不挂在窗外、空调格栅或护窗栏上（ART-RENOVATION）。挂东西的阳台比例：默认（秋傍晚）10%–20%；白天（太阳高于约 10°）30%–50%，一半晒被子；冬季雪后初晴的白天 60%–80%（"一见太阳全楼晒被子"，厚被为主）；雨后初晴的白天 40%；夜间（太阳低于 −6°）5%–10%，被亮着的窗从背后照透；雨雪天 0%–5%，只剩檐下的几件毛巾。

- **其他**：北部生活区服务点前的水站（蓝色桶装水加红色电动三轮车）；可选的小细节各出现一次（罚球线旁的篮球、长椅扶手上收起的伞、单车上的车锁）；门前成排盆栽，成簇、簇外留白；仅夏季挂在 3–5 扇宿舍窗的风铃。
- **季节痕迹**（SYS-TIME-LOOK §2）：只在当季出现，按季节权重出没（SYS-MOTION-ENV §6），换季时在雾幕里换上，季节以外完全隐藏，不留残件。春：花瓣落在樱花林附近单车的车筐里。夏：毕业季阳台挂横幅（纯色布面加简体中文短句，由 MAP-QSH-NORTH 定）、楼下一排行李箱；空调外机滴水只在地面留一小块深色湿斑；银杏大道和湖边树干上离地 1.2–2 m 的蝉蜕，全校 5–8 处。秋：校庆道旗（可选，WLD-LIFE-STREET §2）。冬：2–3 个雪人（组团门口、图书馆前草坪）；雪地上预先摆好的脚印和车辙贴花，不跟随观者；考试周图书馆通宵亮灯（灯光归 MAP-QSH-LIBRARY）。
- **雨天痕迹**（SYS-WEATHER §2）：按天气出没，规则同日夜两套；雨停后在雨后初晴里换成"晾伞"，再随湿润干掉慢慢收起。

雨天：宿舍楼、图书馆正门、食堂和教学楼门口檐下每处 1–3 把撑开的伞（低彩度 `umbrella.*`，约一半是乳白磨砂透明伞）；约三成组团外和图书馆前的共享单车套浅灰白塑料袋；图书馆正门、食堂、宿舍大堂门口各一块黄色"小心地滑"A 字牌（`sign.wetFloor`）。雨后初晴：门口台阶边晾开的伞（比雨天少一半）、单车座套还套着、黄牌、阳台晒被子。下雪：只有黄牌，不出伞和塑料袋。这些痕迹放在檐下或门口，不挡路；长椅扶手上那把收起的伞四季照常。
- **室内痕迹**归 WLD-INTERIORS-BUILD §4 和 WP-52，图书馆与博物馆归 MAP-QSH-LIBRARY。

## 3 显隐：随时段、季节、天气的做法

几何在 `build()` 里一次建好，不读世界状态（ENG-BUDGET-RULES §1）；变化只改可见性，且只在物件不在视野里，或改时间快进、拨时间环、换季雾幕的过程中进行（SYS-MOTION §3），镜头盯着时不凭空出现或消失。四种做法：

| 情形 | 例子 | 做法 |
| --- | --- | --- |
| 按季节换外观 | 车筐落叶、长椅座面、车顶覆雪 | 直接读全局 `season` 和 `snow` 在着色器里按阈值换；季节只在换季转场里变，切换落在雾幕里 |
| 季节专属物件 | 季节痕迹、白眼潜鸭、涉禽、家燕、道旗 | 同一季的物件成一组，在换季转场的落定段整组切换，季节以外整组隐藏，不留残件 |
| 日夜两套与天气 | 动物两套位置、黄昏乌鸦、单车两套停放位、电动车满与空、雨中的动物、伞、黄牌、座套塑料袋、晾晒收起 | 每组记一个"已生效状态"，目标状态（钟点、季节、天气维：晴、雨、雨后）变了以后，等这组不在视野里或正在快进、换季雾幕时才切（约 4 Hz 检查）。下雪时动物按"雨"，伞和塑料袋不出 |
| 部件级显隐与按比例变 | 座套塑料袋、晾晒 0%–80%、电动车空出约三成 | 实例带稳定哈希阈值和部件变体位，组的 `state_bits`、`show_ratio` 由 C# 按已生效状态锁存，只在这组不在视野里时更新 |

- **不用全局参数切日夜和天气**：全局参数一变，视野里的物件会同时变；湿润、积水这类慢慢长出来的连续变化照常读全局参数（SYS-WEATHER §6）。
- 目标状态只取决于钟点、季节和天气，镜头一离开每组都收敛到目标状态；室内痕迹用同一套变体掩码，每个房间单独锁存（WLD-INTERIORS-BUILD §4）。容器、动物小动作与发声器的写法见 `game/gen/fauna/`、`furniture/`、`traces/`，颜色一律按色名读调色板。

## 4 待验证（P0）

- **天气维的判定阈值**：降水量多大算"雨"、湿润多高算"雨后"；WP-25 在 P0 定。
- **黄昏乌鸦的组数与停处、栏杆晒被比例**：P0 看图，WP-25、区包；初值见正文。
- **反应动物的模型、动画承载与预算**：自生成的枢轴部件还是许可合规的骨骼资产，鸽群用独立实例、合批还是顶点动画；P0 原型实测，WP-25、WP-26。初值：待机沿用枢轴小动作，鸽群先用独立实例。
- **栖地与相对扫掠**：桥面桥下、台基台阶、池岸、室内层和闭门处的支撑与连通，玩家最快接近时动物能否及时让开；P0 原型，WP-25、WP-44、WP-43。
