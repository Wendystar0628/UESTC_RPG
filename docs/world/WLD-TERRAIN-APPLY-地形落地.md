# WLD-TERRAIN-APPLY · 地形落地

> **范围**：本文规定不分图的地形落地规则：地形的表达与合成，贴地与楼宇垫层，可走性与碰撞，地面着色取舍。
> **不在本文**：地形的设计原则、分层、竖直落差、水位与岸型（WLD-TERRAIN-SHAPE）；清水河各层的分布、骨架、地标丘、各水体的常水位与各区的地形操作（MAP-QSH-TERRAIN）；水面的画法（WLD-WATER）；驳岸、桥、亲水台阶等构筑物的外观（各区 MAP-QSH 文档）；控制器参数（SYS-WALK）；地形接口与操作字段（`game/contracts/`）；性能份额（ENG-BUDGET）。
> **查阅**：先读 §0；地形表达与合成看 §1；贴地与楼宇看 §2；可走性看 §3；着色看 §4；待验证看 §5

## 0 结论

1. **表达**：地形写成按区的矢量操作，每条带 ID 和理由，不画高度图；合成为确定性纯函数 H(x, z)，所有包都读它（§1）。
2. **贴地**：部件照平地生成再统一贴地；地形迁就路；楼坐在垫层上，勒脚顶线水平（§2）。
3. **可走性**：坡度分类见 WLD-TERRAIN-SHAPE §2.3，`WalkClass.Steep` 是坡度 > 26.6°；墙段与栏杆的碰撞带取两侧地面的极值（§3）。
4. **着色**：坡度 < 1:6 的面着色法线恒向上，设计土坡用分面平法线，冠线与脚线做硬边，土坡不描线，不新增色名（§4）。

### 0.1 接入要点

- **读地面高度（任何包）**：读 `IWorldModel.Terrain`，不写死 y = 0，不自己算坡度（§1）
- **生成贴地几何（WP-15（地表、道路、铺装）、各区包、部件包）**：照平地生成，再过贴地工具（§2.1）
- **放楼（WP-14（通用建筑生成器）、各区包）**：楼坐在 `PadY` 上，地坪 = PadY + 0.15 m，勒脚顶线水平（§2.3）
- **放树、道具、落点**：y 取地面高度减埋深；坡度 > 25% 不种树；小实体底面下沉、落点周围大体平缓（§2.4）
- **做碰撞、判可走（WP-43（碰撞代理生成与流式加载）、WP-44（可行走范围、边界与安全点））**：碰撞高度场与可见网格同源；墙段、栏杆的 Y0、Y1 取两侧 ±3 m 带内地面的最低、最高值（§3）
- **改地形（各区包）**：只写本区的地形文件，ID 以 `design:terrain:` 开头并写理由，影响不越出本区；标高判据按 2 cm（§1）

## 1 地形的表达与合成

- **只用矢量操作**：地形写在按区的地形覆盖层 `world/<区>.terrain.json` 里，一个文件只归一个区包。操作类型与字段以 `game/contracts/` 的 `TerrainOp` 与 `terrain.schema.json` 为准（台地、丘与盆、斜面、退台、渠、湖、垫层、走廊）。不画高度图；覆盖层是地形唯一保存源。
- **平面归世界文件，地形只加竖向**：操作按 ID 引用 `world/<区>.json` 里的楼、路、水体记录（STD-CONVENTIONS §3.1）；记录被删，或路的中线挪开使手写锚点不再落在路上，加载报错，同批改地形文件。
- **每条操作带三样东西**：`design:terrain:` 开头且本图唯一的 ID、写明理由的 `reason`（取 WLD-TERRAIN-SHAPE §1.2 第 1 条的五类，并说明服务的镜头、路线或功能）、所属的区。标高是绝对世界 y，坡比写成 `1:n`。
- **合成顺序固定**，与操作在文件里的先后无关：底层 B = 0 → 区域类（台地、丘、盆、多边形斜面、退台）→ 线状类（渠、折线斜面）→ 强约束类（水体、楼宇垫层、道路走廊）→ 夹到 −5…+10 m；后作用的覆盖或衰减之前的结果，同类内按优先级再按 ID 排。**地形迁就路，不是路迁就地形**：装饰性起伏在走廊、垫层附近衰减。
- **坡度由构造保证**：每个操作自带坡度上限，用包络而不是噪声。台地、垫层、走廊与水体在区域内取约束标高，区域外按填、挖坡度衰减；冠与脚做圆角，合并处平滑。走廊的桥段不钳制高度场（桥面是部件，桥下取河床），暗涵段照常钳制。
- **退台**：高度场只放平均坡面（不陡于 1:2），台阶本体是部件。
- **水体分段**：每个恒水位段用独立水体 ID，一个 ID 只有一个水位；阶降规则见 WLD-TERRAIN-SHAPE §4.3，连续两级跌水时三段各自是独立水体。干沟不登记水位。
- **道路走廊**：纵断面默认恒 0，需要坡度的路写若干 (s, y) 锚点，求解后圆顺；按坡度上限做不到时报错，加长或改台阶，不静默拉陡。一条路可分到几个区的文件里，按整路一次求解，接缝处标高与横坡连续。
- **自动默认**：每栋楼生成垫层，每条道路生成走廊，湖与河渠生成默认剖面（参数以 `map.json` 的 `terrainDefaults` 为准），手写操作替换默认值。
- **确定性**：求值是纯函数，gen 与本机烘焙同机同输入同输出（D-165、D-232），只依赖世界坐标和操作表，与格子划分无关；不加噪声。
- **读取**：地面网格、碰撞、地面查询、行走分类、落点搜索都读同一个地形接口（`game/contracts/Foundation/Terrain.cs`）。
- **校验（G5）**：违反本文的硬规则，或缺 `reason`、ID 重复、影响范围越出本区，报错。判据按看得出的量级（WF-RULE §15）：标高"恒为""同标高""一致"一类的规则差 2 cm 以内算满足，坡度超上限不到 1 个百分点不算违反，影响范围只算高度变化超过 2 cm 的地方。

## 2 贴地

### 2.1 先平后贴

部件（路缘、铺装、标线、栏杆、长椅……）照平地生成，再统一过贴地工具。

| 几何类别 | 贴法 |
| --- | --- |
| 面状：路面、铺装、草面、球场 | 平地不细分，坡面按地面网格的格距（约 2 m，ENG-BUDGET）细分，顶点 y 取格点面高加偏移 |
| 贴面几何：标线、落叶堆 | 同面状，再用深度偏移或沿法线外推约 1 cm |
| 线状：路缘、栏杆、绿篱、矮墙 | 沿线每 ≤ 4 m 一段取地面高度；立柱竖直，扶手平行于坡面 |
| 点状与小实体：灯杆、树、垃圾箱、长椅、花池、汀步 | 按 §2.4 |

路缘、单级踏步、铺装缝这类 1 m 以下的竖向细节不进高度场，由部件给出。

### 2.2 道路与铺装

- **横坡**：步道、广场做单面微坡；机动车道做微拱，拱形只进几何、不进着色，路中线不会在低太阳下出一条明暗缝。
- **纵坡**：主网步行面 ≤ 5%；5–8.33% 按坡道做并设平台；> 8.33% 改台阶；机动车道 ≤ 6%。
- **节点与路肩**：交于一点的中心线在节点处同标高。走廊外 0.5–1.0 m 路肩（≤ 5%），再以 1:3 边坡接回；边坡水平宽 > 6 m 或高差 > 1.2 m 时改台缘带或退台。
- **桥与涵**：桥面标高等于两端路面，引道 ≤ 5%；暗涵上方取路面。

### 2.3 楼宇：垫层、勒脚与入口

- **垫层 `PadY`**：默认取楼脚印内地形高度的中位数，按 0.05 m 取整；覆盖层可以覆盖。
- **散水与整地带**：脚印外 0.8 m 散水带内恒为 PadY；再往外一圈 ≤ 6 m 的整地带，以不陡于 1:4 接回。放不下（> 6 m 或 ΔH > 1.2 m）时在垫层外缘加台缘带或退台，并声明。
- **地坪**：楼面 F = PadY + 室内外高差，默认 0.15 m；首层架高的楼由楼自己定，垫层不为架高去抬。墙体从 PadY − 0.3 m 起。
- **勒脚**：0.3–0.9 m（ART-FIDELITY-DETAIL §1.1），翻新楼 0.6 m 勒脚加 0.8 m 散水（WLD-RENOVATION）。勒脚顶线水平，可见高 = clamp(顶线 − 立面各点地面, 0.3, 0.9)；超出 0.9 m 说明地形没整好，回到垫层调整。
- **入口**：门槛 = F。室外落点与 F 的差按 WLD-TERRAIN-SHAPE §3.1 连接。
- **大平台与台基**（图书馆大台阶、体育馆大平台）是建筑体，高度场在它们脚下是平的，四周用台阶、坡道接回。开放室内首层楼面以本楼 `PadY` 为基准，y 读室内索引，不假设 0。

### 2.4 树与道具落地

- **点状**（树、灯杆、垃圾箱）：y = 地面高度 − 0.05…0.3 m；坡度 > 25% 处不种树、不立杆。线状的行道树列、绿篱沿线每点取地面高度，绿篱顶线平行于坡面。
- **小实体**（长椅、花池、石台、汀步）：底面取脚印内最大值再下沉约 0.1 m，侧面延伸到脚印内最低点。**大实体**（亭、车棚、导览亭）必须在垫层上。
- 草叶、落叶等实例的法线取地面类别法线；坡度 > 30% 草叶减半。
- **落点**（点位、传送落点）：脚下与周围 2 m 大体平缓。

## 3 可走性与碰撞

- **坡度分级**见 WLD-TERRAIN-SHAPE §2.3。`WalkClass.Steep` = 坡度 > 26.6°（1:2），由 WP-44（可行走范围、边界与安全点） 按地形接口标进可行走遮罩；Steep 处不放安全点和落点。
- **与控制器的配合**：高度场处处 ≤ 45°，在控制器的 `FloorMaxAngle` 以内，登阶层只在真墙面上触发（路缘、单级踏步、台缘带前壁），路缘与踏步不进高度场。冠、脚做圆角。
- **碰撞带**：墙段与栏杆的 Y1 = 沿线两侧 ±3 m 带内地面最大值 + max(视觉高度, 1.5 m)，Y0 = 同一带内最小值 − 1.0 m，站在上坡一侧也翻不过去；楼体墙段 Y0 = 脚印外 3 m 带内最低地面 − 2 m；树干圆柱 Y0 取脚印内最低地面 − 0.1 m；台缘带顶面可站、前壁是墙。
- **碰撞与可见同源**：碰撞高度场与可见地面读同一份高度数据，差几厘米可以接受（WF-RULE §15，D-230）。
- **不卡脚、不穿地**：墙下过渡带被台缘带实体盖住；回位兜底的"地面"取地面高度，水体范围内取河床；可达性检查（SYS-WALK-BOUNDS §2 第 5 条）计入地形，栏杆碰撞顶 − 己方地面 < 1.5 m 即报错，新增的台缘、坐阶、花池都进跳跃链。
- **其他读地面高度的地方**（旁观速度律、落点搜索、小地图缩放、飘落池、介质判地下）都读地形接口；点位、锚点、门外落点的 y 由地形给出，审查视角按新地形复核。

## 4 地面着色与描线

两阶明暗在一处一刀切（ART-STYLE），低太阳下着色法线若跟着真实坡度走，缓坡上就会出碎影（理由见 ART-MODELING §1.6）。所以：

| 编号 | 规则 |
| --- | --- |
| S1 | **坡度 < 1:6 的面**（含 WLD-TERRAIN-SHAPE §2.3 的平面类与缓草坡）着色法线恒向上，几何照常起伏 |
| S2 | **设计土坡**（丘、堤、台地边坡）不缓于 1:6，用**分面平法线**，由操作的解析式算，整面一起翻 |
| S3 | S1 的面与分面平法线的坡面的交界（冠线、脚线）做**硬边**：拆顶点，法线突变 |
| S4 | 曲面（丘的圆顶）用软边，法线取解析梯度 |
| S5 | 8.3–16.7% 的设计坡不作"要读出起伏的面"，按 S1 着色，靠轮廓与高光读 |
| S6 | 地面材质去掉掠射乘子，保留 −0.03 ± 0.02 的一阶（ENG-PERF 的例外，待 P0 验证） |
| S7 | 冠线、脚线按顶点属性里的有符号距离取阈值，不按三角形的边 |
| S8 | 不新增色名：坡面与平面同一个色名，靠明暗阶读起伏 |

- 地形类别取接口的 `Class`：`Flat` 用 S1，`Slope` 用 S2–S4，`Transition` 在实体里看不见，按 `Slope` 处理。
- **描线**：平地 ↔ 土坡（≤ 1:2）不出线，靠明暗阶和冠脚硬边读出；台缘带前壁、压顶、地面各用自己的材质 ID，所以前壁 ↔ 地面、压顶 ↔ 前壁出线（压顶 0.75 px）；草坡 ↔ 步道要强调时用混凝土收边条自己的 ID，不用地面描线。
- **季节与光照**：积雪按法线覆盖，分面法线让陡坡上的雪自然变薄；退光线按世界高度判，不需改动；地面不投影（图层 2），台缘带、挡墙实体照常投影（图层 1）。
- 换级时粗级法线照同一条类别规则，不由粗网格重算，避免远近亮度跳变。格距、LOD、裙边与三角形份额由 ENG-BUDGET 与 ENG-PERF 规定；顶点量化范围固定取全图 −5…+10 m。
