# WLD-INTERIORS-BUILD · 室内制作：加载、生成器、风格、痕迹、楼梯与碰撞

> **范围**：本文规定不分图的室内制作规则：室内加载与进楼衔接，生成器的设计原则，室内风格与生活痕迹，楼梯、门洞与碰撞。
> **不在本文**：开放原则、门、关着的楼、新开一栋楼（WLD-INTERIORS-ACCESS）；清水河各楼的陈设（MAP-QSH-LIBRARY）；各楼外观（各区 MAP-QSH 文档）；行走控制器（SYS-WALK）；楼内介质（SYS-VIEW）；声音（SYS-AUDIO）；契约（`game/contracts/`）；室内预算（ENG-BUDGET）。
> **查阅**：先读 §0；加载看 §1；生成器看 §2；风格与痕迹看 §3、§4；楼梯与碰撞看 §5；待验证看 §6

## 0 结论

1. **加载**：离开放入口 25 m 整体加载，当前层全精度，上下层只留墙、楼板、楼梯和灯；门槛前软停只作兜底（§1）。
2. **生成器**：走廊、普通房间、楼梯间由共用平面内核生成，地标空间手工做（§2）。
3. **风格**：暖影、窗格光柱和光斑把室内灌满光；夜间不死黑（§3）。
4. **楼梯**是一整块斜面，26–34°；可走路线上的单扇门门洞 1.1 m；可走性与时刻无关（§5）。

### 0.1 接入要点

- **随钟点、季节、天气变的东西**：门、卷帘、封口和烘焙碰撞都不变，营业状态只用灯光、店招和门帘透光表现（§5）
- **点位跳转到室内**：`Entry = Door`，从最近的开放入口进门（§1.2）
- **写室内碰撞**：斜面、齐平、埋深、登阶层、封口顶高按 §5；碰撞体都填 `Foot`
- **加家具、痕迹或绘制量**：用 WP-52（室内家具与生活痕迹） 的部件与房间模板，痕迹不参与碰撞、不出现"人还在"；额度见 ENG-BUDGET 的楼内视角额度（§4）

## 1 加载与进楼衔接

### 1.1 整体加载、按层显示

开放部分一般 1–4 层，所以整体加载、按层显示：镜头所在层全精度（IF：壳、家具、痕迹、灯）；相邻层只留墙、楼板、吊顶、楼梯、灯片和门（IS）；镜头在楼梯间或中庭里时相邻两层都用 IF；中庭和场馆按提供者声明的"中庭可见层"用 IS；其余开放层隐藏，切换只改可见性；不开放的层用简化室内或 I0。

室内包和碰撞包是本机烘焙产物，进本机缓存，不随安装包发（D-165）。出门后保留约 20 s 或离楼 40 m 再淘汰，同时最多驻留 2 栋。

### 1.2 触发

- **行走**：离任一开放入口 ≤ 25 m 时预取全部 IF、IS 和碰撞，步行约 7 s 才到门口，总来得及。
- **门口软停**（兜底）：下一步要跨进的室内层 IF 或碰撞没就绪，就在门槛前 1 m 内把水平速度线性降到 0，就绪后恢复；不撞墙、不出提示，目标是触发次数为 0。
- **旁观**：镜头 1 s 内进楼则预取入楼高度所在层 ±1；速度超过 15 m/s 只显示 I0 加雾。
- **传送与点位**：目的地在室内时按"已知目的地"预取，未就绪则雾幕多停，最多 1.2 s；电梯站定即预取目的站。

### 1.3 进楼与出楼，以及衔接保证（ENG-PERF-STREAM §1.2 第 6 条）

- 介质切到 `Interior`，天气雾、雨、雪换成室内值（SYS-VIEW-MEDIUM §1）。
- **室内遮挡体**随室内包加载，进楼时隐藏本楼的外包遮挡体，楼内不关遮挡剔除。
- **剖切**：当前层与 ±1 层的室内壳一律用剖切变体，旁观切进隔墙不会透视到隔壁。
- **阴影**：主光阴影第一级范围缩到 8–12 m，0.5 s 内过渡，出楼恢复；阴影方向的抬高见 ART-SKYLIGHT §3.1。
- **保证**：镜头在任何楼体里至少显示这栋楼的 I0 兜底层；行走跨进开放室内楼层前 IF 与碰撞必须就绪，否则门槛前软停；旁观切行走要等当前层楼板碰撞就绪才落地（SYS-WALK §4）。

## 2 平面生成器与类型库

- **生成链**：世界文件里的轮廓与层数 → 楼型 → 柱网与开间（与立面共用开间网格）→ 交通核（按疏散距离放楼梯）→ 走廊脊 → 房间带 → 房间模板（家具、灯位、痕迹槽）。隔墙只落在开间分界线上，不会切到窗；外墙以玻璃面为界，立面包管外皮、室内包管内侧。
- **同一内核服务所有精度**：简化室内、I0、立面开间网格与开放后的完整室内由同一个内核按同一套楼型骨架生成，开放前后墙、楼板、楼梯、窗洞位置不变，只是细节级升高。内核是共享层，不引用世界模型；种子由世界种子、featureId、用途、层、房间键派生，遍历按稳定键排序。
- **楼型与房间类型**：楼型共用"柱网 → 走廊脊 → 交通核 → 房间带"骨架，涵盖教学、科研、宿舍、食堂、场馆、商业、会堂、门诊、办公、托幼与设备用房；每个房间的底线是踢脚线、门牌、开关面板、至少一样设备、至少 3 件家具和 1 个主痕迹。清单、尺寸和部件以 `game/gen/interior/`、`interior-props/` 为准。
- **规范值**：以现行全文强制通用规范为准，风格化只改"非人体尺度"的构件，踏步、扶手、栏杆、门高、座面按真实值（ART-MODELING-PROPORTION §2）。楼梯踏步教学类 0.30 × 0.15、宿舍 0.28 × 0.164、办公 0.26 × 0.175；栏杆视觉 ≥ 1.10 m（临开敞中庭 1.20 m）。
- **部件**：每个部件至少 3 个外观变体由房间哈希选，颜色只引用色名。
- **不做**：垃圾堆、污渍霉斑、酒瓶、真实商标，以及任何会被认成人的东西（人形大衣、坐着的玩偶、镜子里的人影）。

## 3 风格

结构与细节的取舍按 INV-9：室内的结构指楼层、平面、入口、交通核；难看的东西的删减见 MAP-QSH-ADDITIONS §5。

### 3.1 明暗与暖影

室内与室外用同一个 `toon.gdshaderinc`，明暗分阶同 ART-STYLE-SHADING §1.1，没有接触影；室内的影取调色板第 2 行（比同材质室外影的 L 高 0.02–0.08、偏暖），受光取第 3 行。窗光斑边缘硬、灯池边缘软："硬的是太阳，软的是灯"。**房间灯不用点光**：生成器把灯照权重烘进顶点，着色器读灯光通道判断亮灭。

### 3.2 窗光斑与光（最重要的室内画面）

1. **窗形光斑**：主光穿过窗洞，在地面、桌面、墙上投下带窗格的光斑；外壳、窗框、竖梃投影，玻璃不投影，家具和踢脚不投影。默认状态（秋 17:30）的教室和走廊是一条条橙金色长光斑横过地面、爬上墙。
2. **反射与倒影**：光斑落在抛光表面时，在天花板或对面墙加一块模糊、淡到 25% 的同形贴花；抛光地面按窗位画竖向拉长的平涂亮块，不用屏幕空间反射。
3. **窗帘透光**：薄窗帘受主光整块变成暖亮色，遮光帘只在帘缝漏一条光（ART-STYLE-SHADING §3.5）。
4. **光柱与细尘**：每块受光窗格一根棱柱，按哈希大部分不出柱；近镜淡入规则见 ART-SKYLIGHT §4 第 5 条；每间房一组，同屏组数有上限（§6）。
5. **窗外**：镜头在室内时窗外是真实的校园，白天比室内亮一阶以上，窗框成剪影。

### 3.3 色名、识别要素与夜间

- **色名**：室内色名约 22 个，与室外分开计数，只登记固有色，登记进 `game/style/palette/ext/` 的扩展色板。一间房最多 4 个大面积色；跳色只来自生活痕迹，面积不超过画面的 5%；饱和色只有安全出口绿、消防红、洁净室琥珀三处；界面的清蓝不进室内材质。这条只约束固有色，光造成的颜色不受限。
- **中国高校识别要素**：每类房间至少用 2 个：矿棉板格栅顶、推拉黑板加投影幕、水磨石或抛光砖、绿或灰墙裙、不锈钢扶手、"安全出口 EXIT"绿灯、红框消火栓箱、吊扇、上床下桌、电开水器、锦旗与档案盒等。日式元素边界以 ART-STYLE §3.1 为准，室内不得替代这些要素。可以加楼门口鞋柜、教室后墙储物格、成组售货机（WLD-LIFE-STREET §2）；不要教室推拉门、横贯前墙的大黑板和长条讲坛、"非常口"诱导灯、日式消火栓、榻榻米与和室宿舍、定食托盘、保健室、体育馆一端的舞台、屋顶天台场景。字一律简体中文。
- **夜间不死黑**：光源层级由亮到暗：亮灯房间 → 走廊灯 → 屏幕与台灯 → 出口绿灯、应急灯、设备指示灯 → 窗外月光光斑 → 夜空。关灯的房间至少有后三层里的两样，暗部不低于 SYS-TIME-LOOK §1.4 的下限；楼梯间夜里的主光是出口绿灯，墙上留半径 0.4 m 的平涂绿晕。

## 4 生活痕迹规则

- **结构**：房间性格（按哈希选，让痕迹互相呼应）→ 槽位 → 物件。1 个主痕迹必出且从门口一眼能看到，2–5 个次痕迹，杂物成簇并留约 40% 空白。
- **确定性**：出现与否由实体、层、房间、槽位的哈希决定，同一栋楼同一世界状态下每次进去都一样。
- **状态**：季节学期（春学期中段、夏期末与毕业季、秋开学季、冬考试周）× 时段 × 天气；主痕迹的物件集合随状态换（宿舍冬季是台灯下的复习资料，夏季是打包到一半的行李箱）。每个房间单独锁存，只在房间不在视野里或快进、换季雾幕时更新，做法沿用 WLD-LIFE-FAUNA §3。
- **不随世界状态变**：家具位置、门的静止状态、烘焙碰撞都在 `build()` 时定死（INV-8）；痕迹不参与碰撞（WLD-LIFE-STREET §3）。
- **"没有人"的边界**（INV-6）：允许"人刚离开"（摊开的书、冒热气的杯、推开的椅子、亮着的屏幕）；不允许"人还在"（流水的水龙头、转动的转椅、被子里的人形、床帘上的人影、桌下一双鞋）；"马上回来"便条每层最多 1 处。书里不夹银杏叶。
- **展陈与门牌**：展陈不出现人物肖像，换成实物、文献、模型、风景照、铭牌和文字；楼层一级的单位用真实名称，房间一级用通用名称，房号按"区-层-序号"生成，不出现真实人名；不画真实商标图形，店招只画店名（MAP-QSH-NORTH §3.3）。

## 5 楼梯、门洞与碰撞

**楼梯**：

1. 3 级以上的梯段做一整块斜面（`RampCollider`，表面类型 `Stair`），过全部踏步前缘，坡度 26–34°，门禁上限 40°；平台是平盒；斜面厚度取梯段板厚，从下面跳起会撞到。
2. **斜面顶边与上平台上表面相差 ≤ 3 cm，且不高出**（外伸或高出会卡住上下楼）。
3. **斜面底边埋进下层地面 ≥ 0.2 m**。
4. **SYS-WALK §5 的登阶层必须开**，否则平底圆柱在"坡顶接平台"的折线就卡死。
5. **梯井**：宽度 ≤ 0.2 m 做一道整面竖墙（`Barrier`），到上层楼面再加 1.5 m；> 0.2 m（敞开楼梯、中庭楼梯、光井）用斜顶薄墙 `SlopedWallCollider`，顶面取踏步前缘线以上 1.5 m；靠墙一侧的扶手不做碰撞。

**门洞**：可走路线上的单扇门门洞 1.1 m（门扇贴门吸会吃掉约 0.1 m，保证净宽 ≥ 1.0 m），双扇门 1.5–1.8 m，不进的房门 0.95 m 且锁着；门框做 0.05 m 碰撞倒角。

**其他碰撞**：楼板用凸块；隔墙、书架、玻璃隔断用薄墙；各类栏杆顶取 max(视觉高度, 1.5 m)，缝 < 0.5 m；封口顶 ≥ 1.5 m；课桌椅按排合成一个盒（顶 0.75–0.8 m，可跳上），排间走道 ≥ 0.6 m；实验台、会议桌、机床顶取 1.5 m 不让站上去；高柜和书架当墙，不留净空 1.25–1.8 m 的可站面；小件、椅子、痕迹不做碰撞；泳池池岸不设墙，池边台阶登记为出口。楼梯、楼板、门扇、栏杆的碰撞体都填 `Foot`（SYS-AUDIO），楼板按地面材质拆块。

**可走性与时刻无关**（强约束）：门开不开、卷帘拉不拉、封口在哪都不随钟点、季节、天气变；时间只向前，按钟点锁门会把人关在楼里（SYS-TIME §0 第 2 条）。

**落点**：旁观切行走时，镜头在开放楼内就落到下方最近的楼板，在不开放的楼内就落到最近入口门外；落点在封口外或未登记的屋顶时，沿导航图找同层最近走廊节点，用 0.3 s 雾幕移过去。
