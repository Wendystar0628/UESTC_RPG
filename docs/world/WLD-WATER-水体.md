# WLD-WATER · 水体

> **范围**：本文规定全校水面的动画式画法（底色与色带、波纹线、反光带、泡沫线、倒影、四季与天气），涉水与开放泳区的规则入口，水体系统的规则。
> **不在本文**：某张图各水体的具体水面和开放泳区名单（清水河见 MAP-QSH-WATER）；截面水柱的画法（WLD-OUTSKIRTS-DIORAMA §3）；驳岸、栈桥、拱桥、亭子（各区 MAP-QSH 文档）；游泳的控制器与进出阈值（SYS-WALK-BOUNDS §4）；岸型与水深剖面、常水位（WLD-TERRAIN、MAP-QSH-TERRAIN）；水边的动物（WLD-LIFE）；荷和水生植物（WLD-VEGETATION）；水的动态节奏（SYS-MOTION）；路面积水（SYS-WEATHER，WP-45b（降水与湿润））；水下的介质呈现（SYS-VIEW）；水声（SYS-AUDIO）；水面材质、倒影视口、数据通道的写法与份额（ENG-PERF 的水面部分，`game/systems/water/`）。
> **查阅**：先读 §0；水面通用画法与硬质驳岸的接水看 §1；反光带与倒影看 §2；四季与天气看 §3；涉水与开放泳区看 §4；系统规则看 §5；待定参数看 §6；各图水体的具体水面看各图水体文档（清水河是 MAP-QSH-WATER）

## 0 结论

1. **动画式画法**：所有水面都是硬边波纹线、带断口的泡沫线和按到岸距离分的三道硬边色带，不做写实的法线波；颜色读调色板，随关键帧自动变化（§1）。
2. **主光反光带**：画在主光的倒影方向，太阳和月亮由同一盏主光轮流担任；强度随太阳升高减弱，乘 (1 − 阴度)，满阴时关掉；白天波纹亮线上有四芒星闪点，同屏零星几十个以内（§2.1）。
3. **倒影**：玩家身体进倒影时，与反射宿主用同一份最终 pose 绑定；每帧只给屏幕上面积最大的那个湖做平面反射，是风格底线，不能关；其余湖、河渠和池水走解析天空加灯条；倒影切成碎片，明度分 5 级（§2.3）。
4. **灯的竖条倒影**：全场共用一张灯条表，水面和湿地面同用，亮度按岸上灯光通道自动同步（§2.2）。
5. **四季与天气不改几何**（INV-8）：冬季不结冰，泡沫线变宽变白；雨天波纹线换成雨点环，阴雨天关反光带，太阳雨时两者同在（§3）。
6. **各水体**：湖、河渠、池水、喷泉和截面水柱用同一个水面着色器和同一套画法，各自的样子见各图水体文档（清水河是 MAP-QSH-WATER）。
7. **开放泳区**：只有地图登记的湖面主水面，只在水面游泳、不下潜；清水河的名单见 MAP-QSH-WATER §5，进出规则见 SYS-WALK-BOUNDS §4（§4）。
8. **涟漪与水花**：涉水与游泳都不画；入水、出水各一声（§4）。

### 0.1 接入要点

- **湿地面或积水要画倒影（WP-45b（降水与湿润））**：读共用灯条表，复用本文的解析天空与灯条函数，不另建灯表，不做平面反射（§2.2、§5）
- **改灯光通道或偶发事件的提亮（WP-39（夜景灯光与时刻表）、SYS-MOTION）**：水面和湿地面的灯条按灯光通道和开灯阈值自己算亮度，CPU 不写，亮灭自动与岸上一致（§2.2）
- **行走踩进涉水区或游泳（WP-42（行走控制器与模式切换））**：涉水每步落脚发落脚事件，游泳入水、出水各发一次水声；不画水面反馈（§4）
- **地标、岸树、荷要出现在倒影里（区域包、WP-23（植被系统））**：倒影世界里只放平涂的代理，复用已有资源，与本体同格加载；地标不超过 10 个（§2.3）
- **地图数据声明倒影候选湖（SYS-MAPS）**：写在本图 `map.json` 的 `env.reflectLakes`，列表顺序就是湖号（§2.3）
- **画面设置（WP-32（设备分档、画面设置与自适应））**：倒影不能关，刷新间隔见 §2.3
- **定水位、做岸或湖底（WP-08（世界模型与世界数据）、各区包、WP-28（滨水与桥））**：水面高一律读 `ITerrain.WaterY`，岸线与水体多边形重合；水体 ID 稳定，同一个 ID 供水面、水域查询和倒影共用（§5）

## 1 水面的通用画法

水面的底色、波纹线和倒影都读调色板，自动跟随关键帧；本文描述的是默认状态（秋 17:30）的样子，其他时段与季节由 WP-37（日相与季节调色板） 按天色推导。

### 1.1 底色与色带

- **底色**取天空的倒影再压暗；视线越平越映出天空，视线越陡越透出下面的青绿（夏季占比加大，夜间不透）。夜间水面映着夜空，要比岸上的建筑亮，剪影才看得清，暗部不低于明度下限。
- **三道硬边色带**：水的深浅不读真实深度，按到岸距离换算成"伪深度"：1.5 m、4 m、9 m 三条硬边分带——近岸带（透出色 L +0.10）、中带（透出色）、远带（天空倒影色），9 m 那条边再分出更深的湖心一档；菲涅耳的倒影照旧叠在上面。
- **白天格**（上午到午后）的透出色提亮成清透的青，由浅到深分带，取值由 WP-37（日相与季节调色板） 按天色推导；默认格的主色不变，仍以天空倒影为主。

### 1.2 波纹线与泡沫线

- **波纹线**：阈值化的噪声做硬边的波纹线，不要柔和的法线波。亮线、暗线读调色板，暗线按影色规则推导（水面影比岸上浅），夜间亮线是月光银白。线是固定在世界空间的细长横向短段，转镜头时不游移，越远越密越细。
- **泡沫线**：沿岸一圈白色细泡沫，宽约 0.3–0.5 m，有断口；冬季加宽到 0.5–0.9 m，断口变少，更白。泡沫线读到岸距离，断口用沿岸噪声。
- **阴影里的水面**：楼影或树影里的水面影色按 ART-STYLE 推导，波纹线照样画但亮线变暗；夜间月影很浅，明暗差也相应减小。

### 1.3 硬质驳岸的接水

适用于所有常年接水的石砌或混凝土驳岸（D-205）：岸墙用 `ground.concrete`，常水位以上画一条淡湿带 `ground.bankWet`，沿岸均匀连续，草坡岸和天气湿痕不用它；岸顶压顶用 `ground.curb`；湿带、压顶、踏步的尺寸以 `game/gen/zones/design-waterfront/WaterfrontTune.cs` 的 `Bank*` 常量为准。沿岸约每 150 m 一处宽 3 m 的亲水台阶，优先正对楼门或广场轴线，不足 150 m 的一段放一处在段中点；已有涉水口的地方岸墙断开，不另加台阶；出口两侧 1 m 不长草丛。

## 2 反光带、灯条与倒影

### 2.1 主光反光带

- **默认状态**：落日正下方是一条断续的竖向碎金带，由横向的亮短段堆成，只在镜头朝西、能看到太阳倒影的方向出现，大水面上最明显。
- **其他时段**：反光带始终画在主光的倒影方向，颜色取主光色；强度随太阳升高减弱，乘 max(0, 1 − h/60°)，正午几乎没有，只剩波纹亮线上零星的白点；冬季正午太阳低，还留着一条淡金带。
- **四芒星闪点**：太阳较高时，波纹亮线上零星的白点画成四芒星，被柔光晕开一点；同屏零星几十个以内，阴度 > 0.5 时为 0；和湿面闪点是同一种语言，撑起"正午太平"的画面。
- **夜间**：主光换成月亮后画成月光银带，强度约为日落碎金带的一半；蓝调里金带淡出、银带淡入，与主光交接同步。
- **阴雨天关掉**：反光带和银带都乘 (1 − 阴度)，满阴时完全关掉；雾天只剩一条被雾冲淡的淡带；多云时云影扫过的那一段随之断开；雨后初晴恢复，云隙光扫过时跟着亮起。

### 2.2 灯的竖条倒影

天黑以后，岸边最亮的灯源（路灯、地标的窗灯和钟面）在水面上拉出暖色的竖向断续短条：先取一级灯与钟面，再取二级灯，再取临水楼的亮窗（外轮廓离水面 60 m 以内的楼，地图准备时按这条算出，不另列名单），同一级按离相机近的先取，取满为止。灯条用全场共用的灯条表（最多 16 条，水面和雨天的湿地面共用）；亮度由着色器按灯光通道和开灯阈值自己算，所以亮灭、偶发事件的提亮自动与岸上一致；阴雨天灯按有效太阳高度提前亮，灯条也提前出现。灯条是从灯在水面的投影点朝相机方向拉长的竖向短条，断成几截，截长不等、断口不齐，边缘柔开，越远越淡越窄；亮度不超过灯下光斑的一半，要读成水里的倒影，不能读成路面标线；湿地面上长度减半。灯条表只由夜景灯光一处生成，读同一份灯位与开灯表，不另建第二张。

### 2.3 倒影

- **平面反射**：每帧只给屏幕上面积最大的那个湖做，候选湖写在 `map.json` 的 `env.reflectLakes`（清水河见 MAP-QSH-WATER §6）；反射里只画远景、不超过 10 个地标、树冠替身和荷，不画天空，天空由水面解析补出。刷新间隔由画面设置决定（每 2 / 3 / 4 帧），分辨率固定每轴 1/4，倒影是风格底线，不能关。其他湖、河渠、池水和路面积水不做平面反射，走解析天空加灯条。镜头在地下或水下时停用。
- **碎片化与色块化**：波纹扰动把倒影切成一片片，碎片之间 1 px 水色细缝比水色暗 0.04 L；倒影的明度量化成 5 级，再与水色按 0.58 : 0.42 混合，保住 55–60% 的原色相；两步都在"压暗一阶"之前做，平面倒影和解析天空一视同仁。
- **主要倒影按时段**：各图各时段的主要倒影写在各图水体文档（清水河见 MAP-QSH-WATER §6）。

## 3 四季与天气的水面

季节与天气变化只走调色板、全局参数和阈值，不改水面几何（INV-8）。

| 季 | 水面 |
| --- | --- |
| 春 | 开花的树临水处漂一层稀疏的花瓣 |
| 夏 | 水色偏绿：透出的青绿占比加大；荷区之间的水面更暗 |
| 秋（默认） | 水面漂几片落叶，叶形随岸边的树种 |
| 冬 | 不结冰；泡沫线变宽变白；水色偏灰青；登记的浅滩露出（清水河见 MAP-QSH-WATER §2） |

湖面漂的花瓣和落叶画在水面着色器里：按格子哈希贴叶形，季节权重做阈值，凑近仍是完整的叶形和瓣形，不建实例。

| 天气 | 水面 |
| --- | --- |
| 少云、多云 | 云影扫过的那一片降一阶明度，波纹亮线变暗 |
| 阴 | 水色随天色偏珍珠粉紫（不发灰）；反光带关掉；波纹线照常 |
| 雾 | 湖面贴一层湖雾，倒影、波纹线和反光带随雾淡去；夜雾里岸灯光晕半径 ×2，灯条变短变淡 |
| 雨 | 波纹线换成雨点环；反光带关掉；夜里灯条照常且更显眼；水面不画溅落 |
| 雷雨 | 同大雨，雨点环更密；闪光帧水面随 toon 一起翻到受光色 |
| 雨后初晴 | 雨点环几秒内停下，波纹线恢复；倒影映洗过的蓝天；云隙光扫过时反光带亮起 |
| 太阳雨 | 雨点环还在、随降水量变稀，太阳已出来所以反光带同时亮起：一条被雨点环打碎的碎金带，映着西边的落金和东边的暗云 |
| 雪 | 雪花落到水面就消失，不画雨点环；泡沫线和水色照冬季；倒影映薰衣草灰的天 |

- **雨点环**：硬边同心环，每个小格按哈希定出现时刻和位置，环在约 0.5 s 内扩开；有环的格子占比随降水量；远处并成细碎亮点，再远交给雾。桥下、亭下、栈桥下没有环，荷叶盖住的地方不画环。河渠同样画，环心随流向平移。
- 雨落在水面上的声音见 SYS-AUDIO-AMBIENCE §2。

## 4 涉水与开放泳区

- **涉水**：行走踩进涉水区（亲水台阶最下一级、登记的卵石滩）只有减速和涉水脚步声，不画涟漪，不留脚印。
- **开放泳区**：只有地图登记的湖面主水面，只在水面游泳，没有体力和氧气，不下潜；清水河的名单与不开放的水域见 MAP-QSH-WATER §5，进出水深、速度与眼位以 SYS-WALK-BOUNDS §4 为准。不开放的水域由可行走遮罩的边界挡住。
- **出水**：水变浅就上岸，没有出口登记；硬质驳岸、栏杆和湿地栈桥岸照常挡住，游不上去就换方向；岸型要求见 WLD-TERRAIN-SHAPE §4.2。
- **水面反馈**：入水、出水各一声（SYS-AUDIO）；水花、涟漪、尾迹不画。

## 5 水体系统的规则

- **水面默认不透明**：不读深度和屏幕纹理，接收阴影，从水下能看到水面的背面（浅色的"水下天花板"），自身不投影；透明变体默认不启用，只有需要真实的物体交界泡沫（荷梗、桥墩）时才给那一块换，由 P0 原型决定。所有水面用同一个水面着色器。
- **水面高读常水位**：每个水体（每个湖、每段河渠、池水）读 `ITerrain.WaterY`，不写死；水面高度、倒影镜面、冬季浅滩顶面、截面水柱上缘都读它；河渠水位的阶降规则见 WLD-TERRAIN-SHAPE §4.3。
- **颜色全读调色板**：夜间自动换成月光与夜空；阴天水色、雨夜的暖紫天色由调色板的天气修正层给出，水面不另读天气。
- **水下**：镜头进入水下时按介质呈现处理，本文提供水下的颜色与能见度（5–10 m）；水面仍是不透明的，交界由介质呈现处理，不靠把水面换成透明。从水面以上看，水草剪影和鱼影都画在不透明水面的着色里。
- **多地图**：水面系统的节点跨图常驻，换图时在雾幕全黑的帧里重建水面网格、河渠中线和倒影代理；全图纹理按 `map_rect` 采样，不写死"全校"的原点和尺寸。
- 倒影视口、灯条表、喷泉数据通道的写法与份额见 ENG-PERF 的水面部分与 ENG-BUDGET。
