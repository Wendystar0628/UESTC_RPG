# WLD-WATER · 水体：动画式水面、西湖、东湖、河渠、喷泉

> **范围**：本文规定全校水面的动画式画法（底色与色带、波纹线、反光带、泡沫线、倒影、四季与天气），涉水与游泳的水面反馈，开放泳区，西湖、东湖、河渠、主楼水池、截面水柱、游泳池池水和品学楼叠水喷泉的水面。
> **不在本文**：驳岸、栈桥、拱桥、亭子（各区 MAP-QSH 文档）；游泳的控制器与进出阈值（SYS-WALK）；岸型与水深剖面、常水位（WLD-TERRAIN、MAP-QSH-TERRAIN）；水边的动物（WLD-LIFE）；荷和水生植物（WLD-VEGETATION）；水的动态节奏（SYS-MOTION）；路面积水（SYS-WEATHER，WP-45b）；水下的介质呈现（SYS-VIEW）；水声（SYS-AUDIO）；水面材质、倒影视口、数据通道的写法与额度（ENG-PERF 的水面部分，`game/systems/water/`）。
> **查阅**：先读 WLD-WATER §0；水面通用画法看 WLD-WATER §1；反光带与倒影看 WLD-WATER §2；四季与天气看 WLD-WATER §3；涉水、泳区与游泳反馈看 WLD-WATER §4；西湖与喷泉看 WLD-WATER §5；东湖看 WLD-WATER §6；河渠看 WLD-WATER §7；池水、叠水喷泉与截面水柱看 WLD-WATER §8；系统规则看 WLD-WATER §9；待定参数看 WLD-WATER §10

## 0 结论

1. **动画式画法**：所有水面都是硬边波纹线、带断口的泡沫线和按到岸距离分的三道硬边色带，不做写实的法线波；颜色读调色板，随关键帧自动变化（WLD-WATER §1）。
2. **主光反光带**：画在主光的倒影方向，太阳和月亮由同一盏主光轮流担任；强度随太阳升高减弱，乘 (1 − 阴度)，满阴时关掉；白天波纹亮线上有四芒星闪点，同屏不超过 40 个（WLD-WATER §2.1）。
3. **倒影**：每帧只给屏幕上面积最大的那个湖做平面反射，是风格底线，不能关；其余湖、河渠和池水走解析天空加灯条；倒影切成碎片，明度分 5 级（WLD-WATER §2.3）。
4. **灯的竖条倒影**：全场共用一张灯条表，水面和湿地面同用，最多 16 条，亮度按岸上灯光通道自动同步（WLD-WATER §2.2）。
5. **四季与天气不改几何、不重编译**：冬季不结冰，泡沫线变宽变白；雨天波纹线换成雨点环，阴雨天关反光带，太阳雨时两者同在（WLD-WATER §3）。
6. **各水体**：西湖有水下森林的剪影和按时段换形态的扇形喷泉；东湖映着宣邦楼，荷区留暗色空隙，冬季一角露出浅滩；河渠流向统一设定，流速约 0.45 m/s，暗涵段不画水面，漂浮物截到校界格栅前（WLD-WATER §5–§7）。
7. **开放泳区**：游泳馆室内池、西湖与东湖的主水面可以下水游泳；湿地、芦苇带、栈道下方、箱涵口周边 10 m、河渠、室外泳池和冬季浅滩不开放；出口只有软岸、台阶岸与可走的池边台阶（WLD-WATER §4.2）。
8. **涟漪与水下**：涉水涟漪、游泳的入水与划水涟漪都由物理事件驱动，画面和声音不各自判定（WLD-WATER §4）。
9. **池水与叠水喷泉**：用同一个水面材质，不新增着色器，不做平面反射（WLD-WATER §8）。

### 0.1 接入要点

- **湿地面或积水要画倒影（WP-45b）**：读共用灯条表，复用本文的解析天空与灯条函数，不另建灯表，不做平面反射（WLD-WATER §2.2、§9）
- **改灯光通道或偶发事件的提亮（WP-39、SYS-MOTION）**：水面和湿地面的灯条按灯光通道和开灯阈值自己算亮度，CPU 不写，亮灭自动与岸上一致（WLD-WATER §2.2）
- **行走踩进涉水区或游泳（WP-42）**：涉水每步落脚发落脚事件，游泳的入水、出水、划水各发一个边沿事件，带水体 ID 与接触点；画面和声音不各自判定，身体动画不另发入水事件（WLD-WATER §4）
- **登记开放泳区与出口（WP-16、WP-18、WP-31a）**：西湖、东湖由所在区包、游泳馆池由 WP-31a 登记泳区与出口；岸型按 WLD-TERRAIN（§4.2）
- **地标、岸树、荷要出现在倒影里（区域包、WP-23）**：倒影世界里只放平涂的代理，复用已有资源，与本体同格加载；地标不超过 10 个（WLD-WATER §2.3）
- **地图数据声明倒影候选湖（SYS-MAPS）**：写在本图 `map.json` 的 `env.reflectLakes`，列表顺序就是湖号（WLD-WATER §2.3）
- **画面设置（WP-32）**：倒影刷新每 2 / 3 / 4 帧，不能关，分辨率固定（WLD-WATER §2.3）
- **音频（WP-53）**：河渠中线、西湖喷泉时段表、叠水喷泉位置在 CPU 侧可读；本文不另发声音事件（WLD-WATER §5.2、§7、§8.2）
- **驱动漂浮物和喷泉（SYS-MOTION）**：本文提供波纹相位、流速、喷泉高度和每条河按 1 m 重采样的中线；漂浮物中线截到校界格栅前 2 m（WLD-WATER §7）
- **做驳岸、桥、亭、格栅、喷泉石台（区域包、WP-21、WP-30）**：只做岸上和水中的结构，水面和落水归本文（WLD-WATER §8.2）
- **定水位、做岸或湖底（WP-08、各区包、WP-28）**：水面高一律读 `ITerrain.WaterY`，岸线与 OSM 水体多边形重合；水体 ID 稳定，同一个 ID 供水面、水域查询和倒影共用（WLD-WATER §9）

## 1 水面的通用画法

水面的底色、波纹线和倒影都读调色板，自动跟随关键帧；本文给的色值是默认状态（秋 17:30）的值，其他时段与季节由 WP-37 按天色推导。

### 1.1 底色与色带

- **底色**取天空的倒影再压暗，默认基准色 #5B6FA8；视线越平越映出天空，视线越陡越透出下面的青绿 #4E7A6A（夏季占比加大，夜间不透）。夜间水面映着夜空，要比岸上的建筑亮，剪影才看得清，暗部不低于明度下限。
- **三道硬边色带**：水的深浅不读真实深度，按到岸距离换算成"伪深度"：1.5 m、4 m、9 m 三条硬边分带——近岸带（透出色 L +0.10）、中带（透出色）、远带（天空倒影色），9 m 那条边再分出更深的湖心一档；菲涅耳的倒影照旧叠在上面。
- **白天格**（上午到午后）的透出色提亮成清透的青，由浅到深约 #C4EBE1、#9AD8CB、#74C8C0、#3F97A3，正式值由 WP-37 按天色推导；默认格的主色不变，仍以天空倒影为主。

### 1.2 波纹线与泡沫线

- **波纹线**：阈值化的噪声做硬边的波纹线，不要柔和的法线波。默认亮线 #CBD6F0，暗线按影色规则推导（水面影比岸上浅，参考 #3E4A7A），夜间亮线是月光银白。线是固定在世界空间的细长横向短段，转镜头时不游移，越远越密越细。
- **泡沫线**：沿岸一圈白色细泡沫，宽约 0.3–0.5 m，有断口；冬季加宽到 0.5–0.9 m，断口变少，更白。泡沫线读到岸距离，断口用沿岸噪声。
- **阴影里的水面**：楼影或树影里的水面影色按 ART-STYLE 推导，波纹线照样画但亮线变暗；夜间月影很浅，明暗差也相应减小。

## 2 反光带、灯条与倒影

### 2.1 主光反光带

- **默认状态**：落日正下方是一条断续的竖向碎金带 #FFF0C0，由横向的亮短段堆成，只在镜头朝西、能看到太阳倒影的方向出现，西湖上最明显。
- **其他时段**：反光带始终画在主光的倒影方向，颜色取主光色；强度随太阳升高减弱，乘 max(0, 1 − h/60°)，正午几乎没有，只剩波纹亮线上零星的白点；冬季正午太阳低，还留着一条淡金带。
- **四芒星闪点**：太阳较高时，波纹亮线上零星的白点画成四芒星，HDR 2.0–2.8 倍，被柔光晕开一点；同屏不超过 40 个，阴度 > 0.5 时为 0；和湿面闪点是同一种语言，撑起"正午太平"的画面。
- **夜间**：主光换成月亮后画成月光银带，强度约为日落碎金带的一半；蓝调里金带淡出、银带淡入，与主光交接同步。
- **阴雨天关掉**：反光带和银带都乘 (1 − 阴度)，满阴时完全关掉；雾天只剩一条被雾冲淡的淡带；多云时云影扫过的那一段随之断开；雨后初晴恢复，云隙光扫过时跟着亮起。

### 2.2 灯的竖条倒影

天黑以后，岸边最亮的灯源（路灯、图书馆的窗灯、宣邦楼的钟面）在水面上拉出暖色的竖向断续短条，按亮度和距离挑选。灯条用全场共用的灯条表（最多 16 条，水面和雨天的湿地面共用）；亮度由着色器按灯光通道和开灯阈值自己算，所以亮灭、偶发事件的提亮自动与岸上一致；阴雨天灯按有效太阳高度提前亮，灯条也提前出现。

### 2.3 倒影

- **平面反射**：每帧只给屏幕上面积最大的那个湖做，候选湖写在 `map.json` 的 `env.reflectLakes`，清水河列西湖和东湖两个；反射里只画远景、不超过 10 个地标、树冠替身和荷，不画天空，天空由水面解析补出。刷新间隔由画面设置决定（每 2 / 3 / 4 帧），分辨率固定每轴 1/4，倒影是风格底线，不能关。其他湖、河渠、池水和路面积水不做平面反射，走解析天空加灯条。镜头在地下或水下时停用。
- **碎片化与色块化**：波纹扰动把倒影切成一片片，碎片之间 1 px 水色细缝比水色暗 0.04 L；倒影的明度量化成 5 级，再与水色按 0.58 : 0.42 混合，保住 55–60% 的原色相；两步都在"压暗一阶"之前做，平面倒影和解析天空一视同仁。
- **主要倒影按时段**：

| 时段 | 主要倒影 |
| --- | --- |
| 默认（秋 17:30） | 图书馆亮灯的穹顶；晚霞；锈红的水杉；宣邦楼的电子管穹顶 |
| 清晨、日出 | 粉金色的天；宣邦楼穹顶最先受光的一点；晨雾里的岸树剪影 |
| 上午到午后 | 蓝天和积云；受光的穹顶；岸边树冠，随季节 |
| 蓝调、入夜 | 洋红到蓝的天；图书馆的窗灯和采光顶；灯的竖条倒影；满月 |
| 深夜 | 月亮和银带；还亮着的窗；路灯的竖条倒影 |
| 阴、雨 | 珍珠粉紫的云盖和亮缝；没有反光带；雨点环打碎倒影；夜雨里灯条更显眼 |
| 雾 | 倒影随雾淡去，只剩近岸树和露出雾面的地标的淡剪影 |
| 雨后初晴 | 洗过的蓝天和向东退去的碎云；水面重新平静 |

## 3 四季与天气的水面

季节与天气变化只走调色板、全局参数和阈值，不改水面几何，不重编译。

| 季 | 水面 |
| --- | --- |
| 春 | 樱花林、粉带临水处漂一层稀疏的花瓣 |
| 夏 | 水色偏绿：透出的青绿占比加大；荷区之间的水面更暗 |
| 秋（默认） | 水面漂几片落叶，叶形随岸边的树，银杏临水处才是银杏叶 |
| 冬 | 不结冰；泡沫线变宽变白；水色偏灰青；东湖一角露出浅滩 |

湖面漂的花瓣和落叶画在水面着色器里：按格子哈希贴叶形，季节权重做阈值，凑近仍是完整的叶形和瓣形，不建实例。

| 天气 | 水面 |
| --- | --- |
| 少云、多云 | 云影扫过的那一片降一阶明度，波纹亮线变暗 |
| 阴 | 水色随天色偏珍珠粉紫（不发灰）；反光带关掉；波纹线照常 |
| 雾 | 湖面贴一层湖雾，倒影、波纹线和反光带随雾淡去；夜雾里岸灯光晕半径 ×2，灯条变短变淡 |
| 雨 | 波纹线换成雨点环；反光带关掉；夜里灯条照常且更显眼；水面不画溅落 |
| 雷雨 | 同大雨，雨点环更密；闪光帧水面随 toon 一起翻到受光色 |
| 雨后初晴 | 雨点环几秒内停下，波纹线恢复；倒影映洗过的蓝天；云隙光扫过时反光带亮起 |
| 太阳雨 | 雨点环还在、随降水量变稀，太阳已出来所以反光带同时亮起：一条被雨点环打碎的碎金带，映着西边的落金和东边的暗云 |
| 雪 | 雪花落到水面就消失，不画雨点环；泡沫线和水色照冬季；倒影映薰衣草灰的天 |

- **雨点环**：硬边同心环，每个小格按哈希定出现时刻和位置，环在约 0.5 s 内扩到半径约 0.35 m；有环的格子占比随降水量，小雨约 15%、大雨约 60%；60 m 以外并成细碎亮点，再远交给雾。桥下、亭下、栈桥下没有环，荷叶盖住的地方不画环。河渠同样画，环心随流向平移。
- 雨落在水面上的声音由 WP-53 按落点表面分层，读同一个天气向量，不另发事件。

## 4 涉水、开放泳区与游泳反馈

### 4.1 涉水涟漪

行走时踩进涉水区（亲水台阶最下一级、登记的卵石滩）或开放泳区的浅水，每一步在落脚处画 2–3 圈硬边同心环，0.6 s 内扩到半径约 1.2 m，然后断开、消失；环的颜色同亮线、暗线，环心取事件里的落脚点，不取相机下方；不留脚印。每一圈涟漪都配同一步、同一时刻的涉水脚步声，画面和声音不各自判定。不开放的水域在涉水区外沿挡住；开放泳区里往深处走，进入游泳。

### 4.2 开放泳区与出口

- **开放泳区只有三处**：游泳馆室内池（整池）、西湖的主水面、东湖的主水面。没有体力和氧气，只做水面游泳。
- **不开放**：湿地、芦苇带、栈道下方、箱涵口周边 10 m；三条河渠（断面窄、岸陡、有暗涵，只保留涉水带）；东湖冬季浅滩那一角；室外游泳池；其余水面。它们由可行走遮罩的边界挡住。
- **出口**：只有已登记的出口能出水，包括软岸、最下一级没入常水位 0.10–0.15 m 的台阶岸、泳池的软岸或可走池边台阶；硬质驳岸和湿地栈桥岸不做出口；湖心岛能看不能进，岛岸不做出口。岸型要求见 WLD-TERRAIN。
- **登记**：泳区多边形与出口由所在区包登记：西湖归 WP-16，东湖归 WP-18，游泳馆池归 WP-31a。水域查询带稳定的水体 ID、常水位、有效的垂直范围、泳区许可与出口；进出游泳的水深阈值以 SYS-WALK 为准。

### 4.3 游泳的水面反馈

- **只由物理事件触发**：入水、出水、划水都来自 WP-42 的游泳遥测，带水体 ID 和接触点；本文不凭相机或身体动画另判，同一个事件只消费一次。
- **入水**：从岸上跳入、从高处落入或从旁观直接落到水面时，接触点出一次水花和一组涟漪；走入只出涟漪；在水面上下抖动不重复出水花；传送、读档的落点不出。
- **划水**：游泳时每一划在接触点出一组涟漪，与划水声同一个事件；停在水面不划时不出。
- **有效范围**：水花和涟漪只画在这个水体的有效水面里：岸、岛、池沿、涵口和让出的冬季浅滩都不画。
- 尾迹与离水滴水主线不画，列在细节阶段。减少动态时不画装饰性飞溅，入水与出水的涟漪和声音照常保留。传送、回位、切图、读档、切到旁观时清掉未消费的事件和在播的水花，不补播。

## 5 西湖

### 5.1 水下森林与反光带

- 湖底有沉水植物：近岸 5–15 m 的浅水里能透过水面看到几团暗绿色的水草剪影（#2F5A4A），随波纹线轻轻错动；夏季最茂、近岸连成片，冬季稀疏、只剩零散几团；夜间水面不透光，看不到剪影。水面不透明，剪影是水面着色画出来的；水下的实体水草只在镜头进入水下时可见。
- 图书馆在湖的东侧，太阳在西南偏西：从图书馆一侧朝西看有落日反光带，从湖西岸朝东看，湖面映着亮灯的图书馆和满月，两种方向都要成立。白天没有碎金带，西岸朝东看映着蓝天、云和受光的穹顶；夜间从西岸朝东是月光银带加图书馆窗灯的竖条倒影，从东侧朝西是夜空和对岸的路灯竖条。
- 湖西部箱涵两侧的水面颜色可以略有不同：渠水一侧更浑一点，偏黄绿。

### 5.2 扇形喷泉

湖中央的扇形多柱喷泉，形态按 MAP-QSH-CORE 的时段表对齐，SYS-AUDIO 的喷泉声也按那张表切换；时段以 MAP-QSH-CORE 与 SYS-TIME 的灯光时刻表为准，本节只管形态。

- **默认状态**（及太阳 10° 到 −4° 的黄昏段）：只喷低低的一排，水柱高 1.5–2.5 m，白色平涂，顶端散成几点白色小块，底部一圈细小的同心波纹，喷泉灯不开。
- **白天**（9:00 到黄昏段）：扇形全开，中间最高约 5 m，向两侧递减，同心波纹随之放大。
- **入夜到 22:00**：低排之上，中间 3 柱升到约 4 m；喷泉灯打开，水柱由下往上被照亮，灯色只用暖白（电子蓝仍只用于旗面、校车和单车）。
- **22:00 到次日 9:00**：停喷，水面恢复平静，留给图书馆和月亮的倒影。**下雪时**停喷，只留水柱根部的暖白灯点，水面不结冰。
- 形态之间切换用 3–5 s 平滑过渡，不硬切；喷泉时段表在 CPU 侧开放给 WP-53。

## 6 东湖

- **倒影**：宣邦楼在东岸，默认状态下从西岸看过去，湖面映着塔楼、钟楼和受光的电子管穹顶；蓝调以后映出亮起的钟面（"交班的钟"）和钟面的竖条倒影。
- **荷区的水面**：荷之间要留出暗色空隙，四季不同：春，小荷钱贴在水面，空隙大，波纹线照常；夏，荷叶盖住荷区约六成，空隙暗而碎，粉色荷花映出模糊倒影；秋（默认），残荷之间留出暗色空隙；冬，只剩枯梗，水面开阔平静，波纹线变稀，干梗和它的倒影连成三角形。荷由 WLD-VEGETATION 负责。
- **锦鲤**（可选）：从亲水平台边俯视，水面可以透出两三条模糊的橙白色鱼影；夏季最清楚，冬季更淡更模糊，夜间看不到。鱼影画在水面着色里，不靠透过水面看实体。
- **冬季浅滩**：冬季东湖枯水，北岸与荷区分开的一角（约 300–500 m²，由 WP-18 定）露出浅滩，滩上有涉禽。不改变水位，浅滩的几何四季都在，顶面比常水位低约 5 cm；冬季水面按季节阈值让出浅滩，露出湿泥，边缘绕一圈泡沫线，和地面覆盖一样阈值生长，不硬切。浅滩不可行走，也不在开放泳区里。

## 7 河渠

流向都没有核实，按下表统一设定，全片一致。流速约 0.45 m/s：一片落叶漂过 14 m 的桥大约要 30 秒。各河渠的实体与常水位以地形文件和 MAP-QSH-TERRAIN 为准。

| 河渠 | 设定流向 | 说明 |
| --- | --- | --- |
| 走马河 | 从西北流向东南 | 有多段暗涵，暗涵段不画水面；银杏大道跨过它 |
| 红光右支渠 | 从北流向南 | 笔直的人工渠，穿过湿地，在西湖段走箱涵 |
| 磨底河 | 从北流向南 | 沿东缘 |

- **河面**：用 WLD-WATER §1 的画法，但波纹线拉长，顺着流向；不做平面反射；雨天画雨点环，夜里读共用灯条表画灯条。0.45 m/s 的缓流几乎无声，有声的是桥墩、暗涵口、堰这些扰流处（SYS-AUDIO），发声器从本文的河渠中线生成。
- **漂浮物**：数量稀疏，每 20–30 m 河道一两片，随流移动，由 SYS-MOTION 驱动，跟随季节权重，换季时在雾幕里替换：秋是落叶（银杏大道跨走马河一带是银杏叶，其余是其他落叶），春是樱花和美人梅的花瓣（每处两三片），夏基本没有，冬零星枯叶。
- **外围明渠与校界格栅**：走马河、红光右支渠、磨底河穿出校界处各有一道竖条钢格栅或节制闸（WP-30），格栅前水面照常流动；漂浮物的中线截到格栅前 2 m，越过终点的缩到 0，不穿过格栅。O0 里露出的明渠段按校内标准画，护岸由 WP-28 延续；O1 的明渠只画底色、色带、波纹线和泡沫线，不做倒影和漂浮物，没有水下内容。外围明渠的到岸距离与流向由水面生成器从外围数据算出。
- **硬质驳岸的接水**（D-205，取值是初值，样板同位姿定）：常年接水的石砌或混凝土驳岸，在常水位以上画一条约 0.12 m 高的湿带，只压明度（比驳岸本色暗约 0.06 L），沿岸均匀连续，草坡岸和天气湿痕不用它；岸顶有压顶收边，沿岸每隔一段有亲水台阶或出入口，出口两侧 1 m 不长草丛。样板段先做走马河图书馆北侧段，过评审后再铺到其他硬岸。

## 8 池水、叠水喷泉与截面水柱

### 8.1 游泳馆与室外游泳池

游泳馆是第一批开放的室内之一，整池是开放泳区；东区的室外游泳池不是。两处池水都用本文的水面材质。

- **样子**：静水，透出浅青的池底瓷砖色，分道线和池底深色标线透出来；伪深度只按池深分浅水区、深水区两道色带；波纹线比湖面稀、细、慢；池边一圈细白线代替泡沫线，没有断口。
- **倒影**：不做平面反射。室外泳池走解析天空加灯条；室内池水不映天空，把天空换成顶棚色，夜间叠池顶灯的亮点。碎片化与色块化照 WLD-WATER §2.3。
- **夜间**：游泳馆穹顶下沿的玻璃带透出池水的青光（`water.poolGlow`），随场馆灯的时刻表亮灭；池水在场馆灯下比湖面亮。
- **水下**：介质另给一套池水参数，颜色更清偏青，能见度约 15–20 m。
- 游泳反馈照 WLD-WATER §4.3，只在池沿以内；室外泳池照 WLD-WATER §3 画雨点环，室内池水无雨。

### 8.2 品学楼门前叠水喷泉

三层叠水喷泉，直径约 6 m，在品学楼门框正前方。石台、池沿和碰撞归 WP-21，三层池面和层间落水归本文。

- **池面**：三层各一块小水面，静水略动，只留一道池沿的暗边，中间透出深色花岗岩池底；波纹线比湖面细密，以落水点为心画同心波纹；池沿一圈细白线。
- **落水**：每层池沿溢出一圈薄水帘，白色平涂、带竖向亮纹，亮纹下移，节奏同水柱；水帘落进下一层处加一圈白色碎点，底层落进承水槽，不溅出石台。
- **倒影**：不做平面反射，走解析天空加灯条；夜里架空通道的筒灯在池面上成断续的短竖条；门框轮廓烘一块暗色遮罩投到池面，读得出"映着门框"。
- **时段与季节**：全天常流，没有时段表；水帘亮纹白天取主光色，夜里由筒灯照亮。冬季不结冰，石台顶一线雪；春季池面漂几片花瓣，秋季漂落叶；雨天池面画雨点环。
- **声音**：细碎落水声，约 10 m 内听得到，全天常流；喷泉位置与"常流"标记在 CPU 侧开放给 WP-53。

### 8.3 主楼水池与截面水柱

- **主楼前圆形浅水池**（可选）：水面完全静止，不画波纹线；默认状态映着落日和主楼门廊，夜间映着主楼泛光，冬季也不结冰；静水，不发声。
- **截面水柱的水色**（WLD-DIORAMA）：上层浅青绿 #7FB8B0，下层深青绿 #2F5C5E，分层处一条略亮的细线，侧面像玻璃，边缘一道白色高光竖线；其他时段由 WP-37 推导，夜间不低于暗部下限。河渠与截面线的每个交点一个水柱，交点由外围管线求出；河渠穿出校界的地方不画水柱，做格栅或节制闸。可选的分级色带默认不开，P0 看图决定。

## 9 水体系统的规则

- **水面默认不透明**：不读深度和屏幕纹理，接收阴影，从水下能看到水面的背面（浅色的"水下天花板"），自身不投影；透明变体默认不启用，只有需要真实的物体交界泡沫（荷梗、桥墩）时才给那一块换，由 P0 原型决定。
- **水面按内容格产出**，所有水面用同一个水面着色器；到岸距离与流向逐顶点写进水面网格，不做全图岸线遮罩，也没有按湖的遮罩贴图。荷区、水草剪影、冬季浅滩这类细节标记也由生成器随顶点给。
- **水面高读常水位**：每个水体（每个湖、每段河渠、池水）读 `ITerrain.WaterY`，不写死；水面高度、倒影镜面、冬季浅滩顶面、截面水柱上缘都读它；河渠每段水位恒定，只在堰、闸、涵口阶降。
- **颜色全读调色板**：夜间自动换成月光与夜空；阴天水色、雨夜的暖紫天色由调色板的天气修正层给出，水面不另读天气。
- **水下**：镜头进入水下时按介质呈现处理，本文提供水下的颜色与能见度（5–10 m）；游泳时镜头可停在水面、半入水或水下，水面仍是不透明的，交界由介质呈现处理，不靠把水面换成透明。从水面以上看，水草剪影和鱼影都画在不透明水面的着色里。
- **多地图**：水面系统的节点跨图常驻，换图时在雾幕全黑的帧里重建水面网格、河渠中线和倒影代理；全图纹理按 `map_rect` 采样，不写死"全校"的原点和尺寸。
- **性能**：倒影视口、灯条表、涟漪数组、喷泉数据通道的写法与额度见 ENG-PERF 的水面部分与 ENG-BUDGET；涟漪数组、喷泉底部同心波纹是细节阶段的待办，主线版不画涉水与游泳涟漪、喷泉底部的同心波纹。

## 10 待验证

- **主光反光带乘不乘光的衰减**：P0 在默认状态的西湖视角看西岸树影是否把碎金带切掉；初值不乘（WP-24）。
- **四芒星闪点同屏上限**：P0 在白天格西湖视角计数，确认随距离收紧的哈希阈值能保证 ≤ 40 个（WP-24）。
- **透明变体、截面水柱分级色带**：P0 原型在荷区、桥墩、截面近景看图决定，初值都不启用（WP-24）。
- **游泳反馈的容量**：入水水花小池的容量，划水涟漪与涉水涟漪共用的槽数够不够；P0 样板里连续划水、贴岸来回各测一次，初值共用 8 个槽、槽满先丢划水涟漪（WP-24）。
- **水面交界**：半入水时水面线是否连续、有无一帧全屏跳变；P0 在全视场角范围、贴岸与池壁处看图（WP-07、WP-24）。
