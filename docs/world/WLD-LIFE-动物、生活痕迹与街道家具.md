# WLD-LIFE · 动物、生活痕迹与街道家具

> **范围**：本文规定动物、室外生活痕迹、停着的车和街道家具共同遵守的底线、艺术化处理和随时段、季节、天气的显隐做法，并说明分哪两块、各自什么时候读。
> **不在本文**：动物与布料的动作节奏（SYS-MOTION）；图书馆与博物馆室内的道具（MAP-QSH-INTERIORS-LIBRARY）；其余开放室内的家具与痕迹（WLD-INTERIORS）；路灯亮度曲线（ART-COLORSCRIPT §3）；导览亭与导览桩的外观与放置（SYS-ATLAS-TRAVEL §2）；发声（SYS-AUDIO）。
> **查阅**：先读 §0；显隐做法看 §1；动物与生活痕迹看 WLD-LIFE-FAUNA；停着的车、街道家具、碰撞看 WLD-LIFE-STREET

## 0 结论

1. **不画人**：NPC 和他人只以痕迹和远处听不清的声音出现；玩家自己的角色是唯一例外，只在行走模式下出现（INV-6）。
2. **物件真实、状态全新**：生活感靠干净整齐的痕迹，不靠磨损、污渍和杂物（INV-11）；车和家具上不画可辨认的品牌标志（同 MAP-QSH-NORTH §3.3 店招）。
3. **艺术化处理**：照片和资料只定结构与分布，颜色、涂装、标识和疏密按画面需要处理（INV-9）；可以删现实里有但难看的东西（临时围挡、刺眼广告、贴满小广告的灯杆和电箱、过多的指示牌、成堆的废弃单车）。
4. **随时段、季节、天气显隐**：几何一次建好，变化只改可见性，且只在物件不在视野里或快进、换季起雾时进行；动物、痕迹、街道家具、车和室内痕迹都按 §1 做。
5. **分两块**：动物与痕迹归 FAUNA，车与家具归 STREET。

### 0.1 接入要点

- **做随时段、季节、天气显隐的物件（含 WP-52（室内家具与生活痕迹） 的室内痕迹）**：沿用变体掩码与锁存，只在这组不在视野里或快进、拨时间环、换季起雾时切；不用全局参数切日夜和天气（§1）
- 其余对外要求在子文档的接入要点。

## 1 显隐：随时段、季节、天气的做法

几何在 `build()` 里一次建好，不读世界状态（ENG-BUDGET-RULES §1）；变化只改可见性，且只在物件不在视野里，或改时间快进、拨时间环、换季起雾的过程中进行（SYS-MOTION §3），镜头盯着时不凭空出现或消失。四种做法：

- **按季节换外观**（车筐落叶、长椅座面、车顶覆雪）：直接读全局 `season` 和 `snow` 在着色器里按阈值换，切换落在起雾里。
- **季节专属物件**（季节痕迹、白眼潜鸭、涉禽、家燕、道旗）：同一季的物件成一组，在换季转场的落定段整组切换，季节以外整组隐藏，不留残件。
- **日夜两套与天气**（动物两套位置、黄昏乌鸦、单车两套停放位、电动车满与空、雨中的动物、伞、黄牌、座套塑料袋、晾晒收起）：每组记一个"已生效状态"，目标状态（钟点、季节、天气维：晴、雨、雨后）变了以后，等这组不在视野里或正在快进、换季起雾时才切。下雪时动物按"雨"，伞和塑料袋不出。
- **部件级显隐与按比例变**（座套塑料袋、晾晒 0%–80%、电动车空出约三成）：实例带稳定哈希阈值和变体位，显隐状态与比例按已生效状态锁存，只在这组不在视野里时更新。

**不用全局参数切日夜和天气**：全局参数一变，视野里的物件会同时变；湿润、积水这类慢慢长出来的连续变化照常读全局参数（SYS-WEATHER §6）。

目标状态只取决于钟点、季节和天气，镜头一离开每组都收敛到目标状态；室内痕迹用同一套变体掩码，每个房间单独锁存（WLD-INTERIORS-BUILD §4）。容器、动物小动作与发声器的写法见 `game/gen/fauna/`、`furniture/`、`traces/`，颜色一律按色名读调色板。
