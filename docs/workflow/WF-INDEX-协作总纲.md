# WF-INDEX · 协作总纲

> **范围**：本文是协作域的入口：本域管两个指挥和子代理怎么干活：入口、守则、施工边界、流程、通信、角色、模型与队列；列出本域通用的原则和本域全部文档的上下级。
> **不在本文**：各主题的规则与设计（在下面列出的文档里）；全项目的顶层规则与信息地图（CORE-INDEX）。
> **查阅**：先读 §0；要找文档看 §1，按标题挑要读的那份，再读它的 §0 与接入要点

## 0 结论

1. **全员守则在 WF-RULE**，是顶层规则的细则；各角色的入口在 WF-ENTRY，由钩子注入。
2. **活和状态只看施工队列**（WF-STATUS），沟通走 `.collab/notes/`（WF-COMMS）；此刻的状态和进度不写进本域文档。
3. **本域写的是谁做什么、怎么交接**：读者是主会话、Codex 主线和子代理；某个系统或画面怎么设计，在各自的域。

### 0.1 接入要点

- **改协作规则**：先改 WF-RULE 或对应文档，再改顶层规则（CORE-INDEX §3）里的那一句。
- **在本域新增文档**：主题文档在 §1 加一行、文件头写 `parent: WF-INDEX`；子文档写 `parent: <主题文档编码>`，列进主题文档的 §0 和本总纲的 §1 对应主题下（STD-DOC §5.1、§7）。
