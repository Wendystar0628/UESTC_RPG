# MouseButton

命名空间 `Godot`；enum

## 枚举值

- `None = 0`：Enum value which doesn't correspond to any mouse button.
- `Left = 1`：Primary mouse button, usually assigned to the left button.
- `Right = 2`：Secondary mouse button, usually assigned to the right button.
- `Middle = 3`：Middle mouse button.
- `WheelUp = 4`：Mouse wheel scrolling up.
- `WheelDown = 5`：Mouse wheel scrolling down.
- `WheelLeft = 6`：Mouse wheel left button (only present on some mice).
- `WheelRight = 7`：Mouse wheel right button (only present on some mice).
- `Xbutton1 = 8`：Extra mouse button 1.
- `Xbutton2 = 9`：Extra mouse button 2.
