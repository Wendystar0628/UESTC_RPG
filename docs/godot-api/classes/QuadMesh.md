# QuadMesh

命名空间 `Godot`；class；继承 [`PlaneMesh`](PlaneMesh.md) → [`PrimitiveMesh`](PrimitiveMesh.md) → [`Mesh`](Mesh.md) → [`Resource`](Resource.md) → [`RefCounted`](RefCounted.md) → [`GodotObject`](GodotObject.md)

Class representing a square [`PrimitiveMesh`](PrimitiveMesh.md). This flat mesh does not have a thickness. By default, this mesh is aligned on the X and Y axes; this rotation is more suited for use with billboarded materials. A `QuadMesh` is equivalent to a [`PlaneMesh`](PlaneMesh.md) except its default [`PlaneMesh.Orientation`](PlaneMesh.md) is [`PlaneMesh.OrientationEnum.Z`](PlaneMesh.md).
