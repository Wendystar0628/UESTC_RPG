# StandardMaterial3D

`StandardMaterial3D`'s properties are inherited from [`BaseMaterial3D`](BaseMaterial3D.md). `StandardMaterial3D` uses separate textures for ambient occlusion, roughness and metallic maps. To use a single ORM map for all 3 textures, use an [`OrmMaterial3D`](OrmMaterial3D.md) instead.
