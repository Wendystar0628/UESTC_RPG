# AudioEffectHighPassFilter

命名空间 `Godot`；class；继承 [`AudioEffectFilter`](AudioEffectFilter.md) → [`AudioEffect`](AudioEffect.md) → [`Resource`](Resource.md) → [`RefCounted`](RefCounted.md) → [`GodotObject`](GodotObject.md)

A "high-pass" filter attenuates frequencies lower than [`AudioEffectFilter.CutoffHz`](AudioEffectFilter.md) and allows higher frequencies to pass unchanged.

This filter can be used to remove "strength" from a sound, and give low-end space for basses and impact sounds.
