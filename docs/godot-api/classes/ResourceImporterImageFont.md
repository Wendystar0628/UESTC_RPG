# ResourceImporterImageFont

命名空间 `Godot`；class；继承 [`ResourceImporter`](ResourceImporter.md) → [`RefCounted`](RefCounted.md) → [`GodotObject`](GodotObject.md)；仅编辑器（GodotSharpEditor）

This image-based workflow can be easier to use than [`ResourceImporterBMFont`](ResourceImporterBMFont.md), but it requires all glyphs to have the same width and height, glyph advances and drawing offsets can be customized. This makes `ResourceImporterImageFont` most suited to fixed-width fonts.

See also [`ResourceImporterDynamicFont`](ResourceImporterDynamicFont.md).
