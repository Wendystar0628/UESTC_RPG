# Node3DGizmo

命名空间 `Godot`；class；继承 [`RefCounted`](RefCounted.md) → [`GodotObject`](GodotObject.md)

This abstract class helps connect the [`Node3D`](Node3D.md) scene with the editor-specific `EditorNode3DGizmo` class.

`Node3DGizmo` by itself has no exposed API, refer to [`Node3D.AddGizmo`](Node3D.md) and pass it an `EditorNode3DGizmo` instance.
