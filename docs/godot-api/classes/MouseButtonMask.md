# MouseButtonMask

命名空间 `Godot`；enum

## 枚举值

- `Left = 1`：Primary mouse button mask, usually for the left button.
- `Right = 2`：Secondary mouse button mask, usually for the right button.
- `Middle = 4`：Middle mouse button mask.
- `MbXbutton1 = 128`：Extra mouse button 1 mask.
- `MbXbutton2 = 256`：Extra mouse button 2 mask.
