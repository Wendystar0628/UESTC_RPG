# JoyAxis

命名空间 `Godot`；enum

## 枚举值

- `Invalid = -1`：An invalid game controller axis.
- `LeftX = 0`：Game controller left joystick x-axis.
- `LeftY = 1`：Game controller left joystick y-axis.
- `RightX = 2`：Game controller right joystick x-axis.
- `RightY = 3`：Game controller right joystick y-axis.
- `TriggerLeft = 4`：Game controller left trigger axis.
- `TriggerRight = 5`：Game controller right trigger axis.
- `SdlMax = 6`：The number of SDL game controller axes.
- `Max = 10`：The maximum number of game controller axes: OpenVR supports up to 5 Joysticks making a total of 10 axes.
