# MethodFlags

命名空间 `Godot`；enum

## 枚举值

- `Normal = 1`：Flag for a normal method.
- `Editor = 2`：Flag for an editor method.
- `Const = 4`：Flag for a constant method.
- `Virtual = 8`：Flag for a virtual method.
- `Vararg = 16`：Flag for a method with a variable number of arguments.
- `Static = 32`：Flag for a static method.
- `ObjectCore = 64`：Used internally.
- `VirtualRequired = 128`：Flag for a virtual method that is required.
- `Default = 1`：Default method flags (normal).
