# ResourceImporterScene

命名空间 `Godot`；class；继承 [`ResourceImporter`](ResourceImporter.md) → [`RefCounted`](RefCounted.md) → [`GodotObject`](GodotObject.md)；仅编辑器（GodotSharpEditor）

See also [`ResourceImporterObj`](ResourceImporterObj.md), which is used for OBJ models that can be imported as an independent [`Mesh`](Mesh.md) or a scene.

Additional options (such as extracting individual meshes or materials to files) are available in the **Advanced Import Settings** dialog. This dialog can be accessed by double-clicking a 3D scene in the FileSystem dock or by selecting a 3D scene in the FileSystem dock, going to the Import dock and choosing **Advanced**.

**Note:** `ResourceImporterScene` is *not* used for [`PackedScene`](PackedScene.md)s, such as `.tscn` and `.scn` files.
