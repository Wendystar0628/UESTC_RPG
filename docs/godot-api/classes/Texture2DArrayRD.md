# Texture2DArrayRD

This texture array class allows you to use a 2D array texture created directly on the [`RenderingDevice`](RenderingDevice.md) as a texture for materials, meshes, etc.

**Note:** `Texture2DArrayRD` is intended for low-level usage with [`RenderingDevice`](RenderingDevice.md). For most use cases, use [`Texture2DArray`](Texture2DArray.md) instead.
