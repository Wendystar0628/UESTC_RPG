# AudioEffectLowShelfFilter

命名空间 `Godot`；class；继承 [`AudioEffectFilter`](AudioEffectFilter.md) → [`AudioEffect`](AudioEffect.md) → [`Resource`](Resource.md) → [`RefCounted`](RefCounted.md) → [`GodotObject`](GodotObject.md)

A "low-shelf" filter controls the gain of all frequencies below [`AudioEffectFilter.CutoffHz`](AudioEffectFilter.md).

This filter can be used to adjust the "strength" of a sound, by increasing or decreasing its low-end.
