命名空间 `Godot`；class；继承 [`RefCounted`](RefCounted.md) → [`GodotObject`](GodotObject.md)；仅编辑器（GodotSharpEditor）

### _Generate

```csharp
public virtual Texture2D _Generate(Resource resource, Vector2I size, Dictionary metadata)
```

引擎名：`_generate`

Generate a preview from a given resource with the specified size. This must always be implemented.

Returning `null` is an OK way to fail and let another generator take care.

Care must be taken because this function is always called from a thread (not the main thread).

`metadata` dictionary can be modified to store file-specific metadata that can be used in [`EditorResourceTooltipPlugin._MakeTooltipForPath()`](EditorResourceTooltipPlugin.md) (like image size, sample length etc.).

### _GenerateFromPath

```csharp
public virtual Texture2D _GenerateFromPath(string path, Vector2I size, Dictionary metadata)
```

引擎名：`_generate_from_path`

Generate a preview directly from a path with the specified size. Implementing this is optional, as default code will load and call `_Generate()`.

Returning `null` is an OK way to fail and let another generator take care.

Care must be taken because this function is always called from a thread (not the main thread).

`metadata` dictionary can be modified to store file-specific metadata that can be used in [`EditorResourceTooltipPlugin._MakeTooltipForPath()`](EditorResourceTooltipPlugin.md) (like image size, sample length etc.).
