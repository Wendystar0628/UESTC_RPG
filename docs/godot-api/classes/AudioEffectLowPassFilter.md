# AudioEffectLowPassFilter

A "low-pass" filter attenuates frequencies higher than [`AudioEffectFilter.CutoffHz`](AudioEffectFilter.md) and allows lower frequencies to pass unchanged.

This filter can be used to muffle sounds.
