# VideoStreamTheora

命名空间 `Godot`；class；继承 [`VideoStream`](VideoStream.md) → [`Resource`](Resource.md) → [`RefCounted`](RefCounted.md) → [`GodotObject`](GodotObject.md)

[`VideoStream`](VideoStream.md) resource handling the [Ogg Theora](https://www.theora.org/) video format with `.ogv` extension. The Theora codec is decoded on the CPU.

**Note:** While Ogg Theora videos can also have a `.ogg` extension, you will have to rename the extension to `.ogv` to use those videos within Godot.
