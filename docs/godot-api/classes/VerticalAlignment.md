# VerticalAlignment

## 枚举值

- `Top = 0`：Vertical top alignment, usually for text-derived classes.
- `Center = 1`：Vertical center alignment, usually for text-derived classes.
- `Bottom = 2`：Vertical bottom alignment, usually for text-derived classes.
