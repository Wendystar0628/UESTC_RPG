# KeyLocation

命名空间 `Godot`；enum

## 枚举值

- `Unspecified = 0`：Used for keys which only appear once, or when a comparison doesn't need to differentiate the `LEFT` and `RIGHT` versions.
- `Left = 1`：A key which is to the left of its twin.
- `Right = 2`：A key which is to the right of its twin.
