# PLAN-INDEX · 计划总纲

> **范围**：本文是计划域的入口：本域管工作包、阶段与主线闸口；列出本域通用的原则和本域全部文档的上下级。
> **不在本文**：各主题的规则与设计（在下面列出的文档里）；全项目的核心准则与信息地图（CORE-INDEX）。
> **查阅**：先读 §0；要找文档看 §1，按标题挑要读的那份，再读它的 §0 与接入要点

## 0 结论

1. **这里只写划分与阶段**：每个包做什么、依赖谁、主线版交什么；施工状态与队列在 WF-STATUS 和 `.collab/`；契约冻结、版本与插件、清单审批、预算核账这些工程维护事项归各自的工程与世界文档，不在本域。
2. **主线闸口之前只交包表"主线版"列写的东西**；写"主线之后"的现在不施工，闸口通过后再做（PLAN-WP §1，D-233）。
3. **阶段名 P0–P3**：P0 骨架与原型，P1 到主线闸口，P2 闸口之后，P3 收尾（PLAN-WP §1）；文档里"待验证（P0）"的数是初值。

### 0.1 接入要点

- **加或拆工作包**：同批改 PLAN-WP-LIST 和 `ownership.json`。
- **在本域新增文档**：主题文档写 `parent: PLAN-INDEX`，列进本总纲 §1；子文档写 `parent: <主题文档编码>`，列进主题文档 §0，并列进本总纲 §1 那个主题下（STD-DOC §5.1、§7）。
