# MAP-QSH-WEST-WALK · 西区与西北区行走与声音：主网、挡路物、开放入口、点位与锚点、声音

> **范围**：本文规定西区与西北区的行走主网、能看不能进的挡路物、可进入的室内与开放入口的门口表现、涉水区、点位、节奏与锚点、声音要点。
> **不在本文**：各楼的外观（MAP-QSH-WEST）；四季昼夜与天气（MAP-QSH-WEST-SEASONS）；开放楼的室内内容（MAP-QSH-INTERIORS §2、WLD-INTERIORS）；校界与闸机的通用做法（WLD-OUTSKIRTS-BORDER §1、SYS-WALK-BOUNDS §2）；点位与锚点的坐标（`waypoints.json`、`world/atlas.json`）；发声器的生成（SYS-AUDIO）。
> **查阅**：先读 §0；主网、挡路物与可进入的室内看 §1；开放入口的门口表现看 §2；点位、节奏与锚点看 §3；声音看 §4；待验证看 §5

## 0 结论

1. **开放**：六号科研楼 C 区东门 → 公式台阶门厅 → 2F 室外连廊；研究院大楼正门或暗室入口 → 工训车间 → 控制室；托幼园和其余楼都不开放（§2）。
2. **行走**：R1–R5 不经过本区，观者经 P05、P10、P11、P20 和 R11 进来，主网重点是水杉路和湿地栈道；临水栏杆按 SYS-WALK-BOUNDS §2；涉水区只有湿地一处卵石滩和红光右支渠亲水台阶的最下一级（§1）。
3. **门口表现**：开放入口的通用做法按 WLD-INTERIORS-ACCESS §2，本区逐处负责的门口表现写在 §2。
4. **声音**：本区只填 `Sounds()` 插座和 `Foot`（栈道是木板、石桥是石材）（§4）。

### 0.1 接入要点

- **WP-36（点位与跳转） 定 P05、P10、P11、P20 时**：P05 落点前的水杉留空档，P10 同位，P11 在栈道；P20 在六号门厅，`Entry = Door`；坐标以 `waypoints.json` 为准（§3）
- **WP-48c（标记、锚点）、WP-44（可行走范围、边界与安全点） 登记导览桩 A08–A10 时**：坐标以 `world/atlas.json` 为准；A08 不进 P10 的前景，A10 的暖色小灯不照进萤火虫的暗处（§3）
- **WP-31b 做六号门厅和研究院室内时**：开放范围按 §2；门洞、门口表现和外立面与门厅的对位归本区，楼板、楼梯与碰撞归 WP-31b（§1）
- **WP-30（校界与门）、WP-47（外围环境带） 做西侧校门和门外时**：校界碰撞记 `Boundary`；红光右支渠北段穿出校界处的格栅两端，交点落在本区时由本区接上护岸和栏杆（MAP-QSH-WEST §10.4、MAP-QSH-WEST-WALK §1）
- **WP-16（核心区） 定 R3 栈桥对岸落点时**：落点在水杉路一侧的话，本区开护岸栏杆口、做接口铺装（§1）
- **WP-25（动物与生活痕迹） 放白鹭时**：白鹭站的浅滩放在涉水区以外、隔着深水，行走走不到（§1）

## 1 行走：主网、挡路物与开放入口（主线之后）

来这里多半是为了隔湖看图书馆、看校训石和湿地，重点是水杉路和湿地栈道；R11 西区科研线和 P20 公式台阶也在本区，六号科研楼和研究院大楼可以走进去。

**主网**：湿地栈道全程（向南接石桥，向北接西门桥头）；水杉路全程（P05 落点在路面上，临西湖一侧栏杆连续）；六号科研楼（含校训石广场）、创新中心、经管楼东侧宾诺咖啡、四号科研楼三个入口、研究院大楼、荟文楼的门前 10–15 m；西门桥头的车行桥人行道、候车亭、停车场边人行道；四号外圈环路、渠岸步道。本区重点补水杉路人行道和湿地栈道的走廊细节。

**能看不能进**：

| 地方 | 用什么挡 | 站在边界能看到 |
| --- | --- | --- |
| 托幼园 | 一圈深灰透空栏杆，内侧方整绿篱降到 1.8 m，让键盘立面露出来；园门关着，门卫室亮灯；园门开在能看全键盘立面的一侧 | 键盘立面和游戏场 |
| 关着的楼（经管楼、创新中心、四号与五号科研楼、核磁共振中心、荟文楼、孤儿楼 6151/6154，以及六号、研究院的其余入口） | 玻璃地弹门关着：地锁、读卡器红点、"请刷卡进入"贴纸；门玻璃里是门厅卡（`DoorClosed`，SYS-WALK-BOUNDS §2） | 门厅灯、人脸闸机待机绿灯、楼层索引牌 |
| 开放楼里的"到此为止"（六号门厅一侧报告厅、电梯厅、2F 深处防火门；研究院暗室屏蔽门、中庭报告厅） | 封口，碰撞按 SYS-WALK-BOUNDS §2 | 隔着门玻璃或观察窗看到里面 |
| 楼顶 | 楼梯通到屋顶门，门锁着；本区没有开放的屋顶 | — |
| 红光右支渠、走马河湿地段水面 | 护岸和栈道装栏杆（SYS-WALK-BOUNDS §2） | 水面、对岸、白鹭 |
| 西门、西二门、西北门（校界） | 扫码闸机关着、抬杆放下，`Boundary`（WLD-OUTSKIRTS-BORDER §1） | 门外的天润路、蓉 2 号线与对街，能看不能进 |
| 光伏车棚顶 | 棚檐 2.6 m，跳不上去；紧贴车棚的石笼墙顶到棚檐的高差超过跳跃上限（SYS-WALK-BOUNDS §2） | — |

**可进入的室内**：六号科研楼（C 区东门 → 公式台阶门厅 → 2F 室外连廊）；电子科学技术研究院大楼（正门或西二门一侧暗室入口 → 一楼大厅、工训车间、暗室设备厅 → 控制室观察窗）。西湖东岸的电子科技博物馆（MAP-QSH-CORE §5）也开放。R3 西湖跨湖的折线栈桥若对岸落点在水杉路一侧，接口处护岸栏杆的开口和铺装由本区配合 WP-16（核心区） 做。

**涉水区**：湿地登记一处卵石滩（石桥下游、栈道转弯处，长 10–15 m，水深不到 0.3 m，速度降到 0.6 倍）；红光右支渠亲水台阶的最下一级。白鹭站的浅滩放在涉水区以外、隔着深水的一侧，保证角色走不到。其余岸线不能下水；涉水区外沿不设墙，往深处走沉下去再回到岸上。

## 2 开放入口与门口表现（主线之后）

开放范围见 MAP-QSH-INTERIORS §2；门口表现、门洞净宽和门外传送落点按 WLD-INTERIORS-ACCESS §2。室内由 WP-31b（西区与中东区精选室内） 实现，本区逐处负责：

- **六号科研楼**：C 区东门（朝校训石广场）的门口表现、底层退后玻璃幕墙与门厅的对位、2F 连廊的外观与 B–C 连接体的门洞；回程走 C 区一部封闭楼梯（1F–2F）。台阶踢面上的白字公式、连廊的玻璃栏杆与彩色壁画可参考照片，按画面处理；晨光从东面玻璃幕斜照，木台阶的白字一级级亮起来（P20，春 08:00）。
- **电子科学技术研究院大楼**：两个开放入口，正门和西二门一侧直通设备厅的暗室入口，都做门口表现。暗室的红框屏蔽门关着，只能隔窗看（旁观可以飞进去）；观察窗里满墙的吸波尖劈用调色板色名（灰蓝、炭黑），车间机床颜色、吊牌可参考。门牌按 WLD-INTERIORS-BUILD §4：楼层一级的单位用真实名称（"微波暗室 Microwave Anechoic Chamber"），房间一级用通用名称。

点位的行走落点以 `game/data/maps/qingshuihe/waypoints.json` 为准：

| 点位 | 推荐状态 | 落点处要保证的 |

| P10 校训石 · 六号楼 | 春 07:20 雨后初晴（英雄帧 9） | 在 1.62 m 眼高下，校训石、六号楼和背后雪山仍叠在一起；导览桩 A08 不进前景 |

| P20 六号楼 · 公式台阶 | 春 08:00，晴 | 门厅里，`Entry = Door`，从 C 区东门走进去；朝 270° 看台阶，东面玻璃幕晨光斜照 |

**节奏**：水杉路（约 690 m）的大拍从南往北是校训石广场（P10）→ 经管楼东侧亮着窗口的宾诺咖啡 → 托幼园的键盘立面和门外口袋绿地，大拍相距一两百米；中间每隔几十米一个小拍：P05 的隔湖空档、创新中心的书法招牌、光伏车棚旁石笼墙座位、树牌、长椅上合着的书。湿地栈道到西门桥头的大拍是石桥（水面忽然打开）和西门桥头（车行桥、候车亭、国防科技园石刻），小拍是解说牌、涉水卵石滩、白鹭。R11 西区科研线（冬 17:20 雪后初晴）：校训石 → 六号东门 → 公式台阶 → 2F 连廊 → 水杉路 → 宾诺咖啡门前 → 研究院正门 → 工训车间 → 暗室控制室 → 西二门一侧出；大拍是公式台阶、连廊外豁然打开的草坡、控制室的观察窗（室内段锚点由 WP-31b（西区与中东区精选室内） 登记）。

**锚点**：三根导览桩，补西区的空档，本区没有导览亭：A08 校训石（六号科研楼前，朝校训石与雪山方向）、A09 研究院（经管楼与研究院之间，离路缘 1.5 m 以上，不挡研究院正门人流）、A10 湿地（栈道南口，朝芦苇荡）；位置以 `world/atlas.json` 为准。

**地标可见**：水杉路隔着西湖望得见图书馆穹顶；湿地栈道往南的视线也要能露出穹顶，沿线树冠不要把它全挡住（WP-44（可行走范围、边界与安全点） 的可见性检查，§5）。

## 4 声音要点（主线之后）

声音由 WP-53（音频） 实现，本区填 `Foot`（栈道是木板、石桥是石材）。本区的特别点：

1. **湿地公园**：芦苇、芒草的风声音色，夏夜是蛙的分区之一；渠缓流几乎无声，只在暗涵口、石桥下有水声。
2. **六号科研楼**：公式木台阶是 `WoodFloor` 的楼梯；门厅 Hall，2F 室外连廊 Canopy；门厅里是空调和远处机房通宵的嗡声。
3. **研究院**：工训车间 Hall，环氧地坪；微波暗室只隔观察窗看，控制室里只有风扇，暗室本身是吸声的寂静，是全作最"干"的一处。
4. **西门**：栏杆外的街不出车声，远处城市声从雾里来；闸机被挡住只有一声翼板轻碰。
