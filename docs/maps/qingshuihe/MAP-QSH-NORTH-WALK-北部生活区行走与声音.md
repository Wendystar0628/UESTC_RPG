# MAP-QSH-NORTH-WALK · 北部生活区行走与声音

> **范围**：本文规定北部生活区的行走主网、能看不能进的挡路物、开放入口的门口表现、涉水区、北门校界、点位、节奏与锚点、地标可见、声音要点。
> **不在本文**：各楼的外观（MAP-QSH-NORTH）；四季昼夜与天气（MAP-QSH-NORTH-SEASONS）；开放楼的室内内容（MAP-QSH-INTERIORS §3、WLD-INTERIORS）；校界与闸机的通用做法（SYS-BORDER §1、SYS-WALK-BOUNDS §2）；点位与锚点的坐标（`waypoints.json`、`world/atlas.json`）；发声器的生成（SYS-AUDIO）。
> **查阅**：先读 §0；主网、挡路物与涉水区看 §1；开放入口的门口表现看 §2；点位、节奏与锚点看 §3；声音看 §4

## 0 结论

1. **开放**：学知一组团闸机开着、中庭可走；学知苑 1 栋、银杏苑、学生活动中心与成电会堂、商业街一层两家店、朝阳餐厅一楼可进，其余组团闸机和楼门关着（§1）。
2. **行走**：R4 生活区晚归、R12、R13 和 P12、P13、P21、P22 在本区；北门是校界；朝阳外楼梯和思学苑扶梯的起步处锁着，可达性检查不能从这里连到屋顶或二楼平台（§1、§3）。
3. **门口表现**：开放入口的通用做法按 WLD-INTERIORS-ACCESS §2，本区逐处负责的门口表现写在 §2。
4. **声音**：宿舍夜床跟窗灯曲线，23:30 同步陡降（§4）。

### 0.1 接入要点

- **WP-36（点位与跳转） 定 P12、P13、P21、P22 时**：P12 在商业街北端街口外侧；P13 在学知一组团闸机外；P21、P22 是室内点，`Entry = Door`（§3）
- **WP-48c（标记、锚点）、WP-44（可行走范围、边界与安全点） 登记锚点 A05、A11、A12 时**：坐标以 `world/atlas.json` 为准；A05 不落在红光右支渠水面上（MAP-QSH-TERRAIN-CHECKS §3）；锚点侧前方约 2 m 的落点不放挡路物（§3）
- **WP-31c（北区精选室内） 做开放室内时**：门洞、门帘、门口表现、扶梯外观和学知一组团闸机的开放表现归本区，楼板、楼梯与家具归 WP-31c（§2、§1）
- **WP-47、WP-30（校界与门） 做北门与门外时**：北门闸机、抬杆和门口隐形墙段记 `Boundary`；门外的天润路和蓉 2 号线归 WP-47（§1）
- **WP-21（中部与东区） 做银杏大道北段时**：它从本区东侧穿过，属 MAP-QSH-CENTER-EAST 的主网（§1）

## 1 行走：主网、挡路物与开放入口（主线之后）

本区是行走的重点之一，最常看到的是一层店面、组团门口和食堂门前，按 SYS-WALK-BOUNDS §5 的细节优先级做足；商业街一层和组团门口是 ART-FIDELITY §5.2 点名要重点补的两处。

**主网**：商业街两端街口外的人行道和拱顶下的一层步行街；丹桂路全程；三处食堂门前的台阶广场和外摆区；风雨连廊；学生活动中心门前；各组团门口 10–15 m；学知一组团门口到 1 栋门前（经过中庭）；北门内广场到闸机为止；以及连接它们的道路。银杏大道北段属 MAP-QSH-CENTER-EAST 的主网。

**能看不能进**：通则见 SYS-WALK-BOUNDS §2、SYS-BORDER §1、WLD-INTERIORS-ACCESS §2–§3；北门是校界，门外是天润路和蓉 2 号线。本区独有的挡路物：

| 地方 | 用什么挡 | 站在边界能看到 |
| --- | --- | --- |
| 学知一组团以外的组团中庭 | 刷脸闸机关着，其余边界 2.2 m 透空栏杆加 1.2 m 绿篱，车行门抬杆放下 | 晾衣架、休憩平台、乒乓台；售货机和外卖挂架在闸机外 |
| 关着的宿舍楼（1 栋 3 层以上与其余全部） | 楼门关着，门玻璃里是门厅卡 | 门厅灯、闸机待机绿灯、楼层索引牌 |
| 商业街其余店和二、三层 | 卷帘半落或玻璃门关着（`W-SHOP`）；楼梯口伸缩门锁着 | 橱窗货架、超市吊旗 |
| 思学苑、西北餐厅、朝阳二楼 | 门帘后 0.5 m 是关着的玻璃门；朝阳外楼梯底部铁栅门锁着 | 门帘透出的光条 |
| 校医院 | 隔河；商业街一侧护岸装栏杆；便门扫码闸机关着 | 院名灯牌、驳岸柳树 |
| 风雨连廊顶、充电棚顶 | 连廊顶 3.2 m、充电棚檐 2.6 m，旁边可站的矮物到棚顶的高差超过跳跃上限 | — |

**开放室内**范围见 MAP-QSH-INTERIORS §3；其余餐厅的主入口也挂可拨开的门帘，但帘后是关着的玻璃门。

**涉水区**：本区没有。商业街与校医院之间的河是红光右支渠北段，两岸石砌驳岸，主网一侧装栏杆。

## 2 开放入口的门口表现（主线之后）

门洞、门扇、门口灯、地垫、开放牌、门前台阶和门外传送落点的通用做法按 WLD-INTERIORS-ACCESS §2，房门自动推开与闭门器按 SYS-WALK-BOUNDS §3；开放范围见 MAP-QSH-INTERIORS §3。室内由 WP-31c（北区精选室内） 实现，本区逐处负责：

- **学生活动中心与成电会堂**：玻璃门廊的外观、门洞和门前台阶；玻璃门固定敞开。
- **学知苑 1 栋**：楼门的门口表现，门前台阶 6–8 级、楼面约 1.0 m；学知一组团闸机的开放表现（MAP-QSH-NORTH §4.7）。2F 那间 4 人间净高 3.0 m，阳台进深 1.5–1.8 m，门洞 1.1 m，家具木色、窗帘颜色按画面处理。
- **商业街**：两端街口、两家开着的店（茶饮店、快递驿站）的门口表现：门开、灯箱亮、门口外摆；关着的店门和卷帘。店里桌椅可溢到街上，外摆桌椅、风扇、招牌按画面处理。
- **银杏苑**：银桦的 PVC 门帘、门洞和门前台阶；室外罩棚扶梯是 R13 的一段。窗口、灯箱、桌椅颜色按画面处理。
- **朝阳餐厅**：一楼的门洞、PVC 门帘和门前台阶；直跑外楼梯底部的铁栅门锁着，只能看。
- **思学苑的室外扶梯**：只能看，起步处拉一道锁着的不锈钢伸缩门。

## 3 行走：点位、节奏与锚点（主线之后）

点位的行走落点以 `game/data/maps/qingshuihe/waypoints.json` 为准：

| 点位或路线 | 要保证的 |
| --- | --- |
| P12 商业街 · 落雪（冬 18:20 下雪） | 北端街口外侧；1.62 m 眼高下街口外的雪落在店招前，街内暖光，三层店招都在画面里 |
| P13 学知苑 · 灯火（冬 19:00 雪） | 学知一组团闸机外；抬头看得到 1 栋窗灯一格格亮着；值班室暖光与月光冷墙形成冷暖对照 |
| P21 银杏苑 · 芙蓉窗边（秋 17:30） | 窗外满树粉白木芙蓉，远处赭红圆鼓 |
| P22 学知苑 · 学习外廊（秋 19:00） | 推开玻璃门，对面楼一格格亮窗，中庭晾衣架 |
| R4 生活区晚归（冬 18:30 雪） | 北门 → 商业街一层 → 学知一组团门口 → 芙蓉餐厅 → 学生活动中心，0.8 km，全程不卡 |
| R12 宿舍熄灯（秋 23:24 起步） | 学知一组团 → 中庭 → 1 栋 → 2F 走廊 → 学习外廊 → 等 23:30，门缝的光一条条灭掉 |
| R13 食堂到会堂（秋 17:30） | 银杏苑银桦 → 室外扶梯 → 紫荆 → 芙蓉窗边 → 学生活动中心 → 会堂座席 → 排练厅；扶梯、门帘、门廊三处进出不卡 |

**节奏**：大约一两百米一个看点。R4 的大拍是北门内广场 → 商业街三层店招与拱顶下的亮街、街口外的落雪 → 硕丰一组团门口 → 银杏苑台阶广场与芙蓉餐厅的豆沙粉墙 → 学生活动中心的赭红圆鼓。小拍：桶装水和红色三轮车、驿站货架、坝坝茶角、隔河望见的院名灯牌、外卖挂架、充电棚桩灯、微型消防站、山墙楼号、风雨连廊、门帘光条、组团门口的猫、开放入口的门口灯；北门内的导览亭 A05 是 R4 的头一拍。收与放：商业街是店招夹出的一条亮街，走出来到组团门口一下子安静；风雨连廊再收一次，到食堂台阶广场放开。

**锚点**：A05 北门 · 商业街（导览亭）、A11 银杏苑（导览桩，避开宿舍下台的台缘）、A12 思学苑（导览桩，避开宿舍上台南缘的退台），位置以 `world/atlas.json` 为准；锚点侧前方约 2 m 的落点和它面向的广场上不放挡路物。

**地标可见**：本区离图书馆穹顶、宣邦楼钟楼、主楼都最远，楼又密。丹桂路南段朝南望，图书馆穹顶大致在路的尽头，这段路尽头不种挡视线的大树；可见性不达标的路段报给 WP-00（契约、桩与拆除）。

## 4 声音要点（主线之后）

本区的特别点（通则见 SYS-AUDIO-FOLEY）：

1. **宿舍组团**：夜床（空调外机群、楼里微弱的生活声）跟宿舍窗灯曲线，23:30 熄灯时同步陡降；远处的关门、水管、拖鞋、吹风机一律远、听不清；售货机压缩机嗡声只在 4 m 内。
2. **学知苑 1 栋**：楼道 Corridor、楼梯 Stair、4 人间 SmallRoom，是"窄处脚步更明显"的典型；21:30–23:30 楼上的关门声和隔门的吹风机；房门自动推开、闭门器带上时有开关门声。
3. **食堂**：Canteen 类；后厨炒锅、蒸汽、餐盘只在饭点、隔着玻璃；PVC 门帘有摆动才有拍打声；银杏苑扶梯罩棚下有雨鼓点。
4. **商业街**（Arcade 类）：冷柜、灯箱镇流器、店里极闷的背景音乐；雨打玻璃拱顶；店招时刻表之外只剩冷柜。
5. **学生活动中心与会堂**：会堂 Auditorium 类，底噪极低；隔墙练琴声可选（19:00–21:30）；夜里组团门口的猫偶尔轻叫一声，只在做小动作时。
6. **北门**：校门外街声按 SYS-AUDIO-AMBIENCE §1.6；闸机被挡住时只有翼板一声轻碰，不出电子提示音。
