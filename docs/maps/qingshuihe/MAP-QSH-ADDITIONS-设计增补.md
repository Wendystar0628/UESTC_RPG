# MAP-QSH-ADDITIONS · 设计增补：通用规则与区文档共同口径

> **范围**：本文规定校园里原本没有设计感的地方怎么补设计的通用规则，让常被近看的地方放大后都有看头、其余地方不粗糙：以中国校园的景观和建筑细部为底，掺入日式日常街景物件，用日式动画背景的画法来画。含增补物的登记与用色、默认状态规则与作用代号、大片空地的整理、参照与转译、禁做清单、新颜色、行走分类，以及五个区文档共用的身份特征、近景与四季昼夜口径。
> **不在本文**：按场地分类的增补词汇和楼宇设计规则（MAP-QSH-ADDITIONS-VOCAB）；夜间灯光与雨天增补（MAP-QSH-ADDITIONS-ATMOSPHERE）；各区的主体建筑与景观（本区的楼归本区文档）；老楼翻新（ART-RENOVATION、MAP-QSH-RENOVATION）；日式街景物件的目录与画法（ART-AMBIENCE）；树种与季相（WLD-VEGETATION）；灯光曲线（SYS-TIME-LOOK §3）和逐盏调度（`lighting-schedule.json`）；天气数值（SYS-WEATHER）；室内陈设（WLD-INTERIORS）；外围增补（WLD-OUTSKIRTS-BAND §4）；钟声与广播（SYS-AUDIO-AMBIENCE §3）。
> **查阅**：先读 §0；登记与用色、默认状态、空地、转译看 §1–§4，禁做 §5，新颜色 §6，行走分类 §7，区文档共同口径看 §8；增补词汇与楼宇规则看 MAP-QSH-ADDITIONS-VOCAB，夜间灯光与雨天看 MAP-QSH-ADDITIONS-ATMOSPHERE

## 0 结论

1. **增补要登记**：每个增补物是覆盖层的 `add`，ID 以 `design:` 开头并写明理由；删掉现实里有、放进画面难看的东西登记为 `hide`（§1）。
2. **默认状态规则**：秋 17:30 太阳方位 241°、高度 5.5°；增补物的主面朝西（落日方向）才受光，细杆阵列大致南北排开才有长影，每件至少有一个能接住落叶、花瓣、积雪的水平面（§2）。
3. **大空地要有游戏设计**：两个方向都在约 40 m 以上的草坪，先归为功能开敞面或过渡绿地（§3）。
4. **参照与转译**：氛围靠物件不靠地标，场景里的字一律简体中文，日式物件不替代中国的识别物件（§4）。
5. **禁做清单与新颜色**：红色横幅、LED 屏、仿古、网红件、轮廓灯带、做旧痕迹等一律不做，室内同样适用；新颜色先登记（§5、§6）。
6. **行走分类**：增补物各归可走、可跳上、阻挡、可走（坡）、仅视觉五类之一（§7）。
7. **区文档共同口径**：五个区文档的身份特征、近景要求、四季昼夜写法统一按 §8，区文档只写本区条目。

### 0.1 接入要点

- **新增增补物（各内容包）**：在本包覆盖层分片登记为 `add`，ID 以 `design:` 开头并写明理由，只用调色板色名，写明夜间作用和四季状态；横幅、LED 屏、轮廓灯带、仿古件、网红件、做旧痕迹一律不做，室内同样（§1、§5、§6）
- **整理较大的草坪和空地（各区包、WP-29（公共空间设计））**：两个方向都在约 40 m 以上的，先归类；草丘、浅洼相对高差 ≤ 1.5 m，写进本区地形覆盖层（§3）
- **做有碰撞的增补物**：按 §7 的分类给碰撞，可跳上的东西不能和楼顶连成跳跃链
- **写区文档的身份特征、近景要求、四季昼夜（各区包）**：口径按 §8，区文档不重抄，只写本区的表和条目

## 1 通用规则

1. **登记**：每个增补物作为覆盖层 `add` 登记在本包自己的分片 `overlay/<组>.d/` 里（加载规则见 CORE-CONVENTIONS §3.1），ID 以 `design:` 开头并写明理由；删除登记为 `hide` 并写明理由。
2. **用色**：只能用调色板里的颜色（ART-STYLE §2）；新颜色先登记（§6）。
3. **一处一个主题**：设计感来自三件事：把功能件做好看；每处只讲一件事；给人留下停留的位置。
4. **步道与路网**：覆盖层新增的步道进有效路网，和原路一视同仁。设计步道与 OSM 人行道平行重合（中线相距 ≤ 5 m）时合成一条直道：精确 `hide` 整条 OSM 人行道，再 `add` 保留的各段和新连接，并迁移地形覆盖层对它的引用；命名路、混合来源、与桥或水道交叉的不动，不用 `sourceRoad` 隐藏原车行道。

## 2 默认状态规则与作用代号

默认状态是秋季 17:30：太阳方位 241°、高度 5.5°（SYS-TIME §2），影子朝 61°，影子很长。

- **R1 受光**：主面朝西，对着落日（四季日落方位 244°–272°，黄昏都受光；清晨受光的是朝东的面）。
- **R2 长影**：做成竖向细杆的阵列，大致南北排开。
- **R3 接季**：每个增补物至少有一个能接住季节落物的水平面：秋落叶、春花瓣、冬积雪（SYS-TIME-LOOK §2）。
- **R4 灯位**：新增灯具放在楼影或树影里的路面和座椅边；夜间按 MAP-QSH-ADDITIONS-ATMOSPHERE §1 的分级和时刻表亮灭。
- **R5 细部分级**：细部按 ART-FIDELITY 和 ENG-BUDGET 分级出现，密度按所在精度区取用，K4 的增补物只要求底线和轮廓。
- **R7 夜间与四季**：每个增补物写明夜间作用和四季状态；没写四季的，朝上的面接季，颜色由调色板推导。

| 代号 | 含义 |
| --- | --- |
| 受光 | 被落日照成杏色 |
| 长影 | 石柱、横杆、墙体和大件投出有节奏的长影；栏杆立杆这类细杆不投影（ART-MODELING §1.4） |
| 接季 | 水平面接住当季落物：秋落叶、春花瓣、冬积雪；夏季干净，只有树荫光斑 |
| 初灯 | 默认状态下刚亮起的暖色光点，属初灯组（MAP-QSH-ADDITIONS-ATMOSPHERE §2） |
| 透光 | 半透明材料逆光（夜间被身后或身下的灯）发亮 |
| 剪影 | 细线轮廓压在亮天或亮水（夜间比它亮的夜空）前 |
| 反天 | 光滑表面映出天空渐变，夜间映出夜空和灯点 |
| 痕迹 | 人刚离开时留下的东西 |
| 灯源 | 夜间：自己发光的灯具、灯带、屏幕或招牌 |
| 灯下 | 夜间：落在某盏灯的光斑里被照亮 |
| 月光 | 夜间：只受月光，偏冷、有银色亮边和浅月影（最强 0.45） |
| 暗区 | 夜间：有意留暗，靠剪影和天光读形，给灯光留出对比 |

## 3 大片空地的整理

空地按游戏设计组织，不照校内实际布局；开阔草坪不默认中心留白。两个方向都在约 40 m 以上的草坪和空地，由所在区包归为下面两类之一，无主的由 WP-29（公共空间设计） 归类（WP-29 要草丘或浅洼时提需求，由所属区包代为登记）：

- **功能开敞面**：中心保持空旷，但要说明用途（框住地标的视野、活动草坪，或压缩之后的释放）；边缘照样做足：林缘、花境、坐憩、入口停点。
- **过渡绿地**：原样只是让人走过去等待的，就重组。手段：疏林草地、穿越小路加停留点、季节花田或野花斑块、草丘、雨水花园（植物做法见 WLD-VEGETATION §3.2、§3.4）。
- **选手段**：每块空地至少有一个远处参照、一个停留点、一处走动中的发现；取一两种手段，不叠满候选清单，不堆设施。
- **地形**：重组的过渡绿地可加草丘或浅洼，相对高差 ≤ 1.5 m；草丘按草坡类（坡度 1:6–1:3，可走可坐），浅洼按缓坡类只作过渡；登记在本区地形覆盖层（MAP-QSH-TERRAIN-DISTRICTS §1），只放在能制造揭示、或给坐憩点一个视野的地方。

## 4 参照与转译规则

本作以中国校园的物件为底，掺入日式日常街景物件（ART-STYLE §3.1）；日式物件的形、色、尺度、放置见 ART-AMBIENCE §2、§3、§4、§5、§6、§7、§8、WLD-LIFE-FAUNA §2、ART-AMBIENCE §10，售货机组见 WLD-LIFE-STREET §2，外围增补见 WLD-OUTSKIRTS-BAND §4，钟与广播见 SYS-AUDIO-AMBIENCE §3。

1. **氛围靠物件，不靠地标**：中国感来自外卖袋、桶装水、竹椅、PVC 门帘、电动车挡风被；日式氛围来自成组售货机、背街的电线杆、砌块矮墙、暖帘。
2. **场景里的字一律简体中文**，内容具体：楼号、"水深危险"、"非机动车停放区"。
3. **四季都要有中国校园的样子**，视觉效果优先，不求物候精确，不同时开的花可以同框；各季的景物与生活痕迹按 SYS-TIME-LOOK §2。
4. **新旧并存**只表现为新设备（热泵、充电棚、光伏）与老楼建筑语言的并置，不表现为旧痕；老楼全部翻新（D-173）。
5. **物件真实**：保留中国校园的真实物件，守 D-174（ART-FIDELITY-DETAIL §1.5）；生命迹象只有车、猫、灯和晾晒物（INV-6）。
6. **日式物件不替代中国的识别物件**：自行车棚并存于充电棚和共享单车；成组售货机并存于外卖架和快递货架；电线杆与架空线只在 ART-AMBIENCE §5 规定的背街；让行牌用国标"让"字牌，不用"止まれ"；屋顶围网与塔屋水箱只给 ART-AMBIENCE §2 登记的两栋老教学楼。

## 5 不建议增补（禁做清单）

1. 红色横幅、LED 滚动字幕屏、大电子屏（文字会压住画面）；例外：夏季毕业季阳台上数量少的横幅，属季节痕迹。
2. 欧式罗马柱、铁艺卷草、小天使喷泉（宣邦楼已是新古典，不要再扩散）。
3. 过度仿古：假山叠石、琉璃瓦亭、仿木水泥栏杆、塑料竹篱、仿古廊桥。
4. 网红打卡件：彩虹步道、"I ♥ UESTC"字框、巨型相框、镜面不锈钢球、玻璃栈道。
5. 塑料仿真花草、人工草皮。
6. 满楼的轮廓灯带和霓虹亮化（会冲掉"初灯"的点状暖光，也压过窗灯）。
7. 卡通造型的垃圾桶、路灯、导视牌。
8. 不锈钢抽象雕塑（地球仪、DNA 螺旋、书本造型）。
9. 喷绘 PVC 文化墙、KT 板展板：要做就改用刻字、浮雕或镂空。
10. 防尘网盖裸土、蓝色彩钢围挡、施工网架：全校没有例外；文科楼不开放，中庭入口按关着的楼处理。
11. 宿舍屋顶的太阳能热水器（MAP-QSH-ADDITIONS-VOCAB §4）。
12. 新增饱和色：彩色沥青绿道、亮黄亮蓝的健身器材；要做就用灰绿或灰铝色。
13. 日本的宗教与地标符号、传统和式建筑构件（ART-STYLE §3.1）。
14. 在功能开敞面的中心放东西，或每个路口都放小品。
15. 刻字景观石过多：校内已有 6–7 块，新增的桥头卧石最多 2 块。
16. 外围：大型广告牌、楼顶广告大字、LED 大屏、门架式交通标志、工地与围挡、塔吊、临时板房、杂乱的线束与通信杆、违停车辆。
17. 守 D-174（ART-FIDELITY-DETAIL §1.5）：现实里显旧的东西按 ART-RENOVATION 换成新件。

室内同样适用（WLD-INTERIORS-BUILD §3）：删去杂乱的线槽与管线、临时围挡、刺眼的广告与横幅、成片的指示牌和制度牌（每间房最多一两块）、过多的消防标识（保留"安全出口"绿灯和消火栓箱）。

## 7 增补物的行走分类

每件增补物在行走模式下归入下面一类，由做它的包按 SYS-WALK-BOUNDS §7 与几何同参数给碰撞，不拿可见网格当碰撞。自动登阶与跳跃的高度见契约的 `WalkRules` 与 `WalkTuning`，碰撞顶与缝隙、跳跃链的可达性判定见 SYS-WALK-BOUNDS §2 硬规则；下面只记增补物各归哪一类：

- **可走**：贴地的、低于自动登阶高度的、有台阶坡道接上去的（减速带、汀步、停放区、桥面、风雨连廊）。台阶广场每级 0.45 m，局部嵌一段 0.15 m 小踏步，其余只能跳上；草阶看台每级 0.4 m，隔一段嵌一处小台阶。
- **可跳上**：带顶面、高度在跳得上去的范围内的（长椅、树池沿、读书石台、外摆桌椅、石笼墙），跳上去能站；它们不能和楼顶连成跳跃链。
- **阻挡**：杆件、柱子、闸机、充电桩、挂架、导览亭桩、指路牌、廊架柱，以及用来挡路的栏杆、绿篱、护岸。
- **可走（坡）**：设计地形的坡面（丘、堤、台地边坡、湖岸草坡）；放在坡上的增补物给台基。
- **仅视觉**：行走到不了的地方（楼顶、组团中庭等"能看不能进"的区域）、贴在别的物件上的小件、贴花、门帘（走过时帘条被拨开，不进碰撞）、架空线、雨帘与灯光。季节内容不改变碰撞，所以雪人只放在走不到的地方。

## 8 区文档共同口径

五个区文档（MAP-QSH-CORE、MAP-QSH-SOUTH、MAP-QSH-WEST、MAP-QSH-NORTH、MAP-QSH-CENTER-EAST）的身份特征与近景要求、四季昼夜两部分共用下面的口径，区文档不再重抄，只写本区的表、条目和例外。

### 8.1 身份特征与近景要求

- **保留什么**：主要建筑、道路、设施的位置和大体形状要保留，其余按 ART-MODELING 风格化。区文档的身份特征表和写明结构（体量、层数、平面、屋顶标志物、主入口、特色色或材质）的条目是身份特征，造型和配色要让人认得出来；照片和 OSM 只定结构，材质、陈设、标识、生活痕迹按氛围处理，写明"按画面处理"的细节同样。
- **轮廓调整**：写进 `overlay/<区>.d/` 本包分片，10 m 以内算轻微，超过 10 m 或新增设计物要写理由。
- **视觉精度**（ART-FIDELITY）：底线处处满足；身份特征对象、本区主轴和点位落点 30 m 内是 K1，行走走廊和开放室内是 K2。主轴有哪些、哪些楼按 ART-RENOVATION 翻新（MAP-QSH-RENOVATION 的身份特征例外），由各区文档自己写。

### 8.2 四季与昼夜

- **视觉效果优先**：四季和昼夜一律视觉效果优先，真实花期和作息只作参考，不同时开的花可以同框。
- **默认状态**：秋 17:30。区文档四季表的"秋"一列就是该区外观各节写的现状，"—"或"同秋"表示相同。
- **怎么做**：全部靠 SYS-TIME-LOOK §2 的连续参数（季相行、地面遮罩、按法线覆雪）和灯光通道完成，季节小物做进同一组实例，不换模型；植被由 WP-23（植被系统） 种、WP-38（物候、季节植被与季节氛围） 驱动季相，生活痕迹由 WP-25（动物与生活痕迹） 放置，颜色取自调色板。
- **夜间角色**：用 §2 的作用代号，夜间暗部亮度下限见 SYS-TIME §4。
