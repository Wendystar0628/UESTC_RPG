# MAP-QSH-ADDITIONS · 设计增补

> **范围**：本文规定校园里原本没有设计感的地方怎么补设计的通用规则，让常被近看的地方放大后都有看头、其余地方不粗糙：以中国校园的景观和建筑细部为底，掺入日式日常街景物件，用日式动画背景的画法来画。含增补物的登记与用色、默认状态规则与作用代号、大片空地的整理、参照与转译、本图的禁做补充、行走分类，以及五个区文档共用的身份特征、近景与四季昼夜口径。
> **不在本文**：按场地分类的增补词汇和动物与街道家具的摆放（MAP-QSH-ADDITIONS-VOCAB）；夜间灯光与雨天（MAP-QSH-ATMOSPHERE）；全局禁做清单（WLD-AMBIENCE §1.5）；新颜色的登记（ART-STYLE §2.7）；各区的主体建筑与景观（本区的楼归本区文档）；老楼翻新与普通楼宇的设计规则（WLD-RENOVATION、MAP-QSH-RENOVATION）；日式街景物件的目录与画法（WLD-AMBIENCE）；树种与季相（WLD-VEGETATION）；灯光曲线（ART-COLORSCRIPT §3）和逐盏调度（`lighting-schedule.json`）；天气数值（SYS-WEATHER）；室内陈设（WLD-INTERIORS）；外围增补（MAP-QSH-OUTSKIRTS §5，规则 WLD-OUTSKIRTS-BAND §4）；钟声与广播（SYS-AUDIO-AMBIENCE §3）。

## 0 结论

1. **增补要登记**：每个增补物是本区世界文件里的一条记录，ID 以 `design:` 开头并写 `note`；删掉现实里有、放进画面难看的东西就是删记录，原因写进提交说明（§1）。
2. **默认状态规则**：秋 17:30 太阳方位 241°、高度 5.5°；增补物的主面朝西（落日方向）才受光，阵列大致南北排开才有长影，每件至少有一个能接住落叶、花瓣、积雪的水平面（§2）。
3. **大空地要有游戏设计**：两个方向都在约 40 m 以上的草坪，先归为功能开敞面或过渡绿地（§3）。
4. **参照与转译**：氛围靠物件不靠地标，日式物件不替代中国的识别物件（§4）。
5. **禁做与新颜色**：全局禁做清单在 WLD-AMBIENCE §1.5，室内同样适用，新颜色先在 ART-STYLE §2.7 登记；本图只补两条禁做（§5、§6）。
6. **行走分类**：增补物各归可走、可跳上、阻挡、可走（坡）、仅视觉五类之一，通则在 SYS-WALK-BOUNDS §7，本图归类见 §7。
7. **区文档共同口径**：五个区文档的身份特征、近景要求、四季昼夜写法统一按 §8，区文档只写本区条目。

### 0.1 接入要点

- **新增增补物（各内容包）**：在本区世界文件加记录，ID 以 `design:` 开头并写 `note`，只用调色板色名，写明夜间作用和四季状态；禁做清单按 WLD-AMBIENCE §1.5，新颜色先在 ART-STYLE §2.7 登记（§1）
- **整理较大的草坪和空地（各区包、公共空间设计（game/gen/maps/qingshuihe/public/））**：两个方向都在约 40 m 以上的，先归类；草丘、浅洼相对高差 ≤ 1.5 m，写进本区地形覆盖层（§3）
- **做有碰撞的增补物**：按 §7 的归类和 SYS-WALK-BOUNDS §7 的通则给碰撞，可跳上的东西不能和楼顶连成跳跃链
- **写区文档的身份特征、近景要求、四季昼夜（各区包）**：口径按 §8，区文档不重抄，只写本区的表和条目

## 1 通用规则

1. **登记**：每个增补物作为一条记录加在本区的世界文件 `world/<区>.json` 里（格式见 STD-CONVENTIONS §3.1；跨区的包用自己的文件，如 `world/waterfront.json`），ID 以 `design:` 开头并写 `note`；删除就是删记录，原因写进提交说明。
2. **用色**：只能用调色板里的颜色（ART-STYLE §2）；新颜色先登记（ART-STYLE §2.7）。
3. **一处一个主题**：设计感来自三件事：把功能件做好看；每处只讲一件事；给人留下停留的位置。
4. **步道与路网**：新增的步道进路网，和原路一视同仁。设计步道与原人行道平行重合（中线相距 ≤ 5 m）时合成一条直道：删掉那条原人行道记录或改短它，再加保留的各段和新连接，并迁移地形覆盖层对它的引用；命名路、与桥或水道交叉的不动，不隐藏原车行道。

## 2 默认状态规则与作用代号

默认状态是秋季 17:30：太阳方位 241°、高度 5.5°（SYS-TIME §2），影子朝 61°，影子很长。

- **灯位**：新增灯具放在楼影或树影里的路面和座椅边；夜间按 MAP-QSH-ATMOSPHERE §1 的分级和时刻表亮灭。
- **细部分级**：细部按 ART-FIDELITY 和 ENG-BUDGET 分级出现，密度按所在精度区取用，K4 的增补物只要求底线和轮廓。
- **夜间与四季**：每个增补物写明夜间作用和四季状态；没写四季的，朝上的面接季，颜色由调色板推导。
区文档的四季昼夜表用下面的作用代号写每件的角色；其中受光、长影、接季同时是增补物的形态要求：

| 代号 | 含义 |
| --- | --- |
| 受光 | 主面朝西，对着落日，被照成杏色（四季日落方位 244°–272°，黄昏都受光；清晨受光的是朝东的面） |
| 长影 | 石柱、横杆、墙体和大件投出有节奏的长影，阵列大致南北排开才显；栏杆立杆这类细杆不投影（ART-MODELING §1.4） |
| 接季 | 每个增补物至少有一个水平面接住当季落物：秋落叶、春花瓣、冬积雪（ART-COLORSCRIPT §2）；夏季干净，只有树荫光斑 |
| 初灯 | 默认状态下刚亮起的暖色光点，属初灯组（MAP-QSH-ATMOSPHERE §2） |
| 透光 | 半透明材料逆光（夜间被身后或身下的灯）发亮 |
| 剪影 | 细线轮廓压在亮天或亮水（夜间比它亮的夜空）前 |
| 反天 | 光滑表面映出天空渐变，夜间映出夜空和灯点 |
| 痕迹 | 人刚离开时留下的东西 |
| 灯源 | 夜间：自己发光的灯具、灯带、屏幕或招牌 |
| 灯下 | 夜间：落在某盏灯的光斑里被照亮 |
| 月光 | 夜间：只受月光，偏冷、有银色亮边和浅月影（最强 0.45） |
| 暗区 | 夜间：有意留暗，靠剪影和天光读形，给灯光留出对比 |

## 3 大片空地的整理

空地按游戏设计组织，不照校内实际布局；开阔草坪不默认中心留白。两个方向都在约 40 m 以上的草坪和空地，由所在区包归为下面两类之一，无主的由 公共空间设计（game/gen/maps/qingshuihe/public/） 归类（game/gen/maps/qingshuihe/public/ 要草丘或浅洼时提需求，由所属区包代为登记）：

- **功能开敞面**：中心保持空旷，但要说明用途（框住地标的视野、活动草坪，或压缩之后的释放）；边缘照样做足：林缘、花境、坐憩、入口停点。时间广场周边的大草坪是功能开敞面，作图书馆穹顶的前景。
- **过渡绿地**：原样只是让人走过去等待的，就重组。手段：疏林草地、穿越小路加停留点、季节花田或野花斑块、草丘、雨水花园（植物做法见 WLD-VEGETATION §3.2、§3.4）。
- **选手段**：每块空地至少有一个远处参照、一个停留点、一处走动中的发现；取一两种手段，不叠满候选清单，不堆设施。
- **地形**：重组的过渡绿地可加草丘或浅洼，相对高差 ≤ 1.5 m；草丘按草坡类（坡度 1:6–1:3，可走可坐），浅洼按缓坡类只作过渡；登记在本区地形覆盖层（MAP-QSH-TERRAIN-DISTRICTS §1），只放在能制造揭示、或给坐憩点一个视野的地方。

## 4 参照与转译规则

本作以中国校园的物件为底，掺入日式日常街景物件（ART-STYLE §3.1）；日式物件的目录、形制、放置见 WLD-AMBIENCE，售货机组见 WLD-LIFE-STREET §2，外围增补见 MAP-QSH-OUTSKIRTS §5（规则 WLD-OUTSKIRTS-BAND §4），钟与广播见 SYS-AUDIO-AMBIENCE §3。

- **氛围靠物件，不靠地标**：中国感来自外卖袋、桶装水、竹椅、PVC 门帘、电动车挡风被；日式氛围来自成组售货机、背街的电线杆、砌块矮墙、暖帘。
- **其余按全局规则**：场景里的字一律简体中文（INV-4）；四季视觉效果优先（§8.2）；老楼全部翻新，新旧并存只表现为新设备与老楼语言的并置（D-173、WLD-RENOVATION §2.1）；物件真实，守 D-174（ART-FIDELITY-DETAIL §1.5），生命迹象只有车、猫、灯和晾晒物（INV-6）。

## 5 禁做清单的本图补充

全局禁做清单见 WLD-AMBIENCE §1.5，室内同样适用；本图再加两条：

1. 在功能开敞面的中心放东西，或每个路口都放小品（§3）。
2. 刻字景观石过多：校内已有 6–7 块，新增的桥头卧石最多 2 块。

## 6 需要登记的新颜色

新颜色的登记表见 ART-STYLE §2.7；登记前只能用调色板里已有的色名。

## 7 增补物的行走分类

增补物各归可走、可跳上、阻挡、可走（坡）、仅视觉五类之一，分类通则、碰撞生成和跳跃链判定见 SYS-WALK-BOUNDS §7、§2；本图增补物的归类：

- **可走**：减速带、汀步、停放区、桥面、风雨连廊；台阶广场每级 0.45 m，局部嵌一段 0.15 m 小踏步，其余只能跳上；草阶看台见 MAP-QSH-TERRAIN-DISTRICTS §4。
- **可跳上**：长椅、树池沿、读书石台、外摆桌椅、石笼墙。
- **阻挡**：杆柱、闸机、充电桩、挂架、导览亭桩、指路牌、廊架柱，以及用来挡路的栏杆、绿篱、护岸。
- **可走（坡）**：设计地形的坡面（丘、堤、台地边坡、湖岸草坡）；放在坡上的增补物给台基。
- **仅视觉**：楼顶、组团中庭等"能看不能进"处的东西，贴在别的物件上的小件、贴花、门帘、架空线、雨帘与灯光；雪人只放在走不到的地方。

## 8 区文档共同口径

五个区文档（MAP-QSH-CORE、MAP-QSH-SOUTH、MAP-QSH-WEST、MAP-QSH-NORTH、MAP-QSH-CENTER-EAST）的身份特征与近景要求、四季昼夜两部分共用下面的口径，区文档不再重抄，只写本区的表、条目和例外。

### 8.1 身份特征与近景要求

- **保留什么**：主要建筑、道路、设施的位置和大体形状要保留，其余按 ART-MODELING 风格化。区文档的身份特征表和写明结构（体量、层数、平面、屋顶标志物、主入口、特色色或材质）的条目是身份特征，造型和配色要让人认得出来；照片和资料只定结构，材质、陈设、标识、生活痕迹按氛围处理，写明"按画面处理"的细节同样。
- **轮廓调整**：直接改本区世界文件里的记录，10 m 以内算轻微，超过 10 m 或新增设计物要写理由（`note` 或提交说明）。
- **视觉精度**（ART-FIDELITY）：底线处处满足；身份特征对象、本区主轴和点位落点 30 m 内是 K1，行走走廊和开放室内是 K2。主轴有哪些、哪些楼按 WLD-RENOVATION 翻新（MAP-QSH-RENOVATION 的身份特征例外），由各区文档自己写。

### 8.2 四季与昼夜

- **视觉效果优先**：四季和昼夜一律视觉效果优先，真实花期和作息只作参考，不同时开的花可以同框。
- **默认状态**：秋 17:30。区文档四季表的"秋"一列就是该区外观各节写的现状，"—"或"同秋"表示相同。
- **怎么做**：全部靠 ART-COLORSCRIPT §2 的连续参数（季相行、地面遮罩、按法线覆雪）和灯光通道完成，季节小物做进同一组实例，不换模型；植被由 植被系统（WLD-VEGETATION） 种、物候、季节植被与季节氛围（SYS-TIME） 驱动季相，生活痕迹由 动物与生活痕迹（WLD-LIFE-FAUNA） 放置，颜色取自调色板。
- **夜间角色**：用 §2 的作用代号，夜间暗部亮度下限见 SYS-TIME §4。
