# MAP-QSH-RENOVATION · 清水河翻新清单

> **范围**：本文列出清水河校区按 ART-RENOVATION 翻新的楼与环境：按区分组，每条写明楼名、施工方式、要翻新的部位和所用规则；另列待核实的楼及核实前的做法、不列入的新楼。
> **不在本文**：翻新规则本身（ART-RENOVATION）；楼的位置、体量与身份特征（各区 MAP-QSH 文档）；楼的实体 ID（`game/data/maps/qingshuihe/campus.json`，条目按楼名对应）；增补物与禁做清单（MAP-QSH-ADDITIONS）；生活痕迹（WLD-LIFE）；室内（WLD-INTERIORS）。
> **查阅**：先读 §0；施工方式、条目号、部位代号与楼型看 §1；各区逐栋条目看 §2–§6；全校环境看 §7；待核实的楼看 §8；不列入的新楼看 §9；覆盖层登记与施工顺序看 §10；待验证看 §11

## 0 结论

1. **口径**：校内凡有陈旧元素的楼和环境都翻新，翻新后与新楼同一套部件、色名和洁净度；位置、体量、层数和身份特征不动（D-173），守 D-174（ART-FIDELITY-DETAIL §1.5）。
2. **施工分两档，不分翻新程度**：「预设」档由主线阶段的翻新预设一次做完；「补」档在预设之上、细节阶段再补部位：学知苑 28 栋、硕丰苑 1–20 栋、商业街，宿舍屋面设备，博翰苑 1–6 栋、银杏苑、思学苑、西北餐厅、学生活动中心与成电会堂、品学楼、一号科研实验楼、创新中心、体育场看台，以及组团门禁、临时布置、导视；其余早期建成的楼和道路、铺装、河渠、路灯、球场、停车场、校界都是「预设」（§1.1）。
3. **最常翻新的部位**：宿舍外挂空调外机进机位格栅，教学楼、食堂和商业的外机收上屋面；屋面设备进围挡、管线收成管廊；褪色遮阳篷换灰铝窗楣，窗框全换新；晾晒按干净版；商业街店招统一；横幅、展板、帐篷和彩钢房删掉（§1.3）。
4. **待核实的楼**单列在 §8：年代或立面没查到的楼一样翻新，核实前按 §8 的口径做新，施工按预设。
5. **2015 年以后建成的楼不列入**（§9），按各区文档的新楼外观施工。

### 0.1 接入要点

- **施工本区的老楼（WP-16、WP-18–WP-21）**：按 §2–§6 里本区的条目做；数据里有、要删的登记所在区覆盖层的 `hide`，预设之外加的构件成组登记 `add`，ID 以 `design:` 开头，理由写"老楼翻新 <条目号>：<部位>"（§10）
- **在覆盖层、区文档或回报里提到某栋翻新楼**：按条目号引用；条目号定下后不改、不复用（§1.2）
- **翻新碰到身份特征**：不改；身份特征显旧时只换新材料，颜色家族、位置和比例不变，以各区文档的"本区身份特征"表为准（§1.4）
- **做 §8 的待核实楼**：按 §8 的口径做新，施工按预设，初值就是定稿
- **2015 年以后建成的楼**：不登记翻新条目；同样守 D-174（§9）
- **需要窗、栏板、格栅、围挡、管廊、雨棚**：从部件库取，区包不自己写几何常量（§10）
- **主线阶段（D-168）**：老楼一律直接用 WP-14 的翻新预设，不逐栋精修；细节阶段先做翻新对照楼，再给「补」档的条目补部位（§10）

## 1 施工方式、条目号、部位代号与楼型

### 1.1 施工方式

| 档 | 判定 | 施工 |
| --- | --- | --- |
| 补 | 体量大、出镜多、显旧的部位多（外挂外机、阳台杂乱晾晒、污旧屋面与满铺管线、杂乱店招），或有局部显旧件（彩钢房、横幅、渗修痕、污旧看台） | 主线预设之上，细节阶段先做翻新对照楼，再逐条补本文列的部位 |
| 预设 | 石材主体或外观整洁的早期楼，以及没有明显旧痕的环境 | 按翻新预设一次做完，不单独精修 |

两档都翻新到同一洁净度。

### 1.2 条目号

N 北部生活区（§2）、E 中部与东区（§3）、S 南区（§4）、W 西区与西北区（§5）、C 核心区（§6）、V 不归一个区的环境（§7）、Q 待核实的楼（§8）。条目号定下后不改、不复用；覆盖层的理由、各区文档和回报都按条目号引用。

## 8 待核实的楼

### 8.1 核实前的口径

1. **一样翻新**：年代或立面没查到不等于不翻新，核实前按所属楼型的翻新预设做到与新楼同一洁净度，施工按预设。
2. **只做通用部位**：只做 §1.3 的墙、窗、机、管、顶、底，不加预设以外的设计构件（竖向鳍片、连续挑板、花箱这类）。
3. **不改各区文档写的外观**：区文档写了外观的，照写做新，颜色和身份特征不动；没写的，外墙取相邻楼或所在组团的语言和墙色家族。
4. **附属件只给已知的后勤用房**：用途已按后勤、设备或附属用房写进区文档的楼可用"附"，用途没写的先不用。
5. **核实以后**：年代、用途、立面按初值定稿；层数这类结构修正写覆盖层 `HeightOp`。

## 10 登记与施工顺序

- **覆盖层登记**：翻新由 WP-14 的翻新预设生成，窗、压顶、格栅、围挡这些随楼生成的构件不逐件登记。数据里有、要删的旧元素（如屋顶的临时构筑物）登记为所在区覆盖层的 `hide`；新加的构件按条目成组登记为 `add`（如商业街店头布篷、1–8 号楼外挂钢楼梯、屋顶围网与塔屋水箱），ID 以 `design:` 开头，理由写"老楼翻新 <条目号>：<部位>"。G5 的差异报告按条目号汇总。
- **构件来源**：窗、栏板、格栅、围挡、管廊、雨棚从部件库取，区包不自己写几何常量（ART-MODELING-PROPORTION §6 第 3 条）；没有区包认领的楼（Q-05 的 5232、Q-06–Q-10）由 WP-14 照预设执行。
- **施工顺序**：主线阶段（D-168）老楼直接用预设，不逐栋精修；细节阶段先做翻新对照楼（楼型同 N-02），评审通过后给「补」档的条目补部位；待核实的楼按初值施工。
- **验收**：按 ART-RENOVATION §8，抽两三栋看一眼：看不到旧痕，翻新楼与相邻新楼同框分不出新旧，认得出是哪栋楼，删掉旧痕以后立面不变空。
