# MAP-QSH-CORE-WALK · 核心区行走与声音

> **范围**：本文规定核心区的行走主网、能看不能进的阻挡、开放入口的门口表现、涉水区、点位、节奏与锚点，以及声音要点。
> **不在本文**：各楼与构筑物的外观与身份特征（MAP-QSH-CORE）；灯光、四季昼夜与天气（MAP-QSH-CORE-SEASONS）；图书馆与博物馆的室内（MAP-QSH-INTERIORS-LIBRARY）；室内开放清单与门的通用做法（WLD-INTERIORS-ACCESS §2）；栏杆、碰撞与提示（SYS-WALK-BOUNDS §2）；声音规则（SYS-AUDIO）。
> **查阅**：先读 §0；主网、挡路物与开放入口看 §1，点位、节奏与锚点看 §2，声音看 §3

## 0 结论

1. **主线**：本区是 R1 落金主线的终点，也是 R3 西湖跨湖的全程；主网从银杏大道南段走到时间广场，再到图书馆大台阶、博物馆门前木栈道和西湖栈桥（§1）。
2. **开放**：图书馆（二楼正门、品·悦吧店面门）和博物馆（门廊、朝湖侧门）可进，图书馆二、三楼北侧露台从室内上去可走；屋顶不开放，P03 仅旁观；湖心岛只到观景平台（§1）。
3. **点位与锚点**：P01、P02、P04、P05、P06、P08、P16 和锚点 A02、A07 落在本区，落点要求见 §2。
4. **声音**：喷泉、两处堰、天鹅屋是手工发声器（§3）。

### 0.1 接入要点

- **点位与跳转（UI-NAV-WAYPOINTS） 定点位时**：P01、P02、P05、P06、P08 的落点按 §2；P03 仅旁观
- **平面地图锚点（WLD-LIFE-STREET、SYS-ATLAS-TRAVEL、SYS-WALK-BOUNDS）**：A02 导览亭、A07 导览桩按 §2 摆放；本区开放入口只画门口标记，不另设锚点
- **声音（SYS-AUDIO-AMBIENCE）**：喷泉、两处堰、天鹅屋是手工发声器，清单待建（§3）

## 1 行走：主网、挡路物与开放入口（主线之后）

本区是 R1 落金主线的终点，也是 R3 西湖跨湖的全程。

**主网**：银杏大道南段经时间广场、图书馆大台阶与二楼正门、品·悦吧门前与户外小花园，到博物馆门前木栈道、草阶看台、西湖栈桥与拱桥、北岸台阶花坛；图书馆、博物馆、品·悦吧门前 10–15 m 及连接它们的道路必须走通。广场四周的草坪也能走但不属主网；宁静苑是封闭内院，走不进去。

**能看不能进**：通则见 SYS-WALK-BOUNDS §2、SYS-BORDER §1、WLD-INTERIORS-ACCESS §2–§3，本区独有的挡路物：

| 地方 | 用什么挡 |
| --- | --- |
| 湖心岛 | 观景平台栏杆，平台后密植水杉和小牌；其余岛岸与栈桥隔着水 |
| 小林岛、喷泉、箱涵 | 四面隔水；箱涵两端堰口接岸处设栏杆，顶面不进可行走遮罩；喷泉只能飞到 |
| 北辅楼与北内院的门、西南塔和西北塔底的疏散门、东侧平房 8399、大台阶下设备间 | 关着，门玻璃里是门厅卡；宁静苑从一楼北面落地窗和三楼 G 区露台看 |

**开放入口**：开放范围与室内路线见 MAP-QSH-INTERIORS-LIBRARY，门洞外观与门前台阶见 MAP-QSH-CORE §2、§5。本区负责四处入口的门口表现：每处一盏门口灯、一块地垫、一块绿色开放牌（WLD-INTERIORS-ACCESS §2）。

- 图书馆二楼正门（大台阶上去）：门斗里闸机常开，通道亮绿色箭头。
- 品·悦吧店面门（第二个入口）：固定敞开。
- 博物馆门廊：感应门常开。
- 博物馆朝湖侧门：常开，接木栈道，R3 从博物馆穿过。

**涉水区**：北岸台阶花坛最下一级；西湖东岸草阶看台前的一段卵石滩；西岸、南岸再登记 1–2 段卵石滩；范围四季不变。

## 2 行走：点位、节奏与锚点（主线之后）

点位的行走落点以 `game/data/maps/qingshuihe/waypoints.json` 为准：

| 点位 | 本区要保证 |
| --- | --- |
| P01 日晷 · 望穹顶 | 晷盘作前景，穹顶不被树冠挡住 |
| P02 图书馆正门 | 三根旗杆、大台阶、正门连成一线；位姿和落点都在时间广场地面上（下沉 −0.9 m），不挪到台阶顶平台 |
| P03 八角采光顶 | 仅旁观 |
| P04 图书馆中庭 | 同位，见 MAP-QSH-INTERIORS-LIBRARY §8 |
| P16 图书馆 · 五楼西窗 | 室内同位，`Entry = Door`；西窗越过博物馆白色坡顶看得见西湖和落日，博物馆屋顶不加挡视线的设备 |
| P05 西湖 · 隔湖望馆 | 水杉路地面（MAP-QSH-WEST）；入水口荷花在视线前景里 |
| P06 西湖 · 栈桥逆光 | 栈桥桥面，落点不在栏杆上 |
| P08 银杏大道 | 同位，即 E1，与 MAP-QSH-SOUTH 交界 |

**节奏**：大拍（一两百米一个）：出银杏树廊、时间广场豁然开朗；图书馆大台阶与二楼正门；走进二楼门厅、中庭豁然打开；走上栈桥、湖面忽然打开；湖心岛观景平台；草阶看台。小拍（几十米一个）：路灯下的长椅和椅上的落物、低头可读的十二时辰刻度、晷针、导览亭 A02 的牌面、台阶顶上的那片叶、品·悦吧的窗口、博物馆门里的六边形灯、栈桥栏杆上的翠鸟或家燕、天鹅屋、拱桥底的暖灯、北岸台阶下到水边、"湿地保护"小牌、日晷林树缝里露出穹顶的框景。本区主网上几乎处处能望见图书馆穹顶；栈桥西段背对图书馆时，至少要能望见主楼或宣邦楼钟楼之一。

**锚点与设施**：A02 时间广场（导览亭，牌面朝图书馆正门，日晷在侧）、A07 西湖 · 博物馆（导览桩，博物馆前木栈道口，朝湖），位置以 `world/atlas.json` 为准；离路缘 1.5 m 以上，不挡主人流，背景里的穹顶不被它们挡住。一处直饮水台在西湖栈道入口。草阶看台做法见 MAP-QSH-TERRAIN-DISTRICTS §4。

## 3 声音要点（主线之后）

本区的特别点：

1. **西湖喷泉**声随 MAP-QSH-CORE §7 的时段表走，形态切换时 3–5 s 交叉。
2. **箱涵两端的两处堰**是手工发声器，春夏翻水响，秋冬弱；**天鹅屋**夜里天鹅聚到屋旁时偶尔一声低吟，天鹅离观者 25 m 以内时只在抬头这类小动作的那一刻才出声。
3. **时间广场**是空旷的底床加立面回声（`Open` 类），没有水声；默认状态的主声是外圈常绿树里的麻雀归巢。
4. **脚下的材质**：栈道、栈桥、观景平台 `WoodDeck`（空腔共鸣，每 2 m 板缝一声"咔"，走到湖心时湖岸拍水从两侧来）；时间广场和大台阶 `StonePaving`；门口地垫 `RubberMat`；草阶看台 `Grass`；卵石滩 `Gravel`。
5. **门与闸机**：博物馆感应门常开不动，没有电机声；图书馆门斗的闸机常开，不出提示音。
