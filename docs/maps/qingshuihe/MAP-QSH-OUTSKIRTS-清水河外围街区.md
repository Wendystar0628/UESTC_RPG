# MAP-QSH-OUTSKIRTS · 清水河外围街区：周边结构、地标、灯光、农田与氛围增补

> **范围**：本文规定清水河校界外一圈街区的具体内容：各方位的周边结构与截面线距离、楼型的位置、夜间灯光表、农田与绿地四季、要保留的身份地标、新增的氛围元素与外围植被、河渠格栅、看街长椅。
> **不在本文**：三条线的定义（WLD-OUTSKIRTS）；外围分层、精度、画法、保留删除新增的通用规则、数据与许可（WLD-OUTSKIRTS-BAND）；阻挡与提示（WLD-OUTSKIRTS-BORDER）；外围增补物的逐项外观（MAP-QSH-ADDITIONS）；南门（MAP-QSH-SOUTH）；树冠与季相的通用规则（WLD-VEGETATION）；水面画法（WLD-WATER）。
> **查阅**：先读 §0；周边结构与距离看 §1；楼型位置看 §2；灯光与农田看 §3；身份地标看 §4；氛围增补与外围植被看 §5；格栅与长椅看 §6；待验证看 §7

## 0 结论

1. **周边**：西南、南是西源大道、蓉 2 号线与电子科大站、顺江片区和农田；西、西北是天润路与龙湖时代天街；北、东北是科新南路、蓉昌高速和白色厂房园区；东、东南是绕城高架、杜鹃绿地、农田和 220 kV 变电站。截面线在校界外 250–500 m，清水河以一条静止的银带留在截面线外（§1）。
2. **身份地标**：七项保留，其余泛化成楼型（§4）。
3. **灯光与农田**：外围灯接 WP-39（夜景灯光与时刻表） 时刻表；厂房园区整夜冷白窗带，农田四季换色，春天油菜花最出画（§3）。
4. **氛围增补**：草坪轨道、行道树林荫、站台生活痕迹、川西林盘、绕城绿道，写进外围覆盖层（§5）。
5. **河渠格栅与看街长椅**：三条河渠穿出校界处做钢格栅或节制闸；看街长椅正对电子科大站，E6 就在这里（§6）。
6. **由此定下**：V9 和 P15 是高空斜俯。

### 0.1 接入要点

- **做河渠格栅或看街长椅（WP-30（校界与门）、WP-44（可行走范围、边界与安全点）、WP-24（水体系统）、WP-28（滨水与桥））**：格栅归 WP-30，水面归 WP-24、护岸归 WP-28；长椅归 WP-30 做、WP-44 选点，朝南正对电子科大站，可以跳上去（§6）
- **在清水河外围加或改内容（WP-47（外围环境带））**：身份地标按 §4 保留，新增元素写进外围覆盖层，ID 以 `design:` 开头并写明理由；横切 V1、P00 或 E6 主体的高压线用覆盖层挪线（§4）
- **种外围的树与作物（WP-23（植被系统）、WP-47）**：树种与份额按 §5
- **外围的灯（WP-39（夜景灯光与时刻表））**：按 §3.1 的表接时刻表，不新增灯光通道

## 1 周边结构与截面线距离

### 1.1 周边结构要点

外围数据只用来定结构：道路走向、用地、体量等级和地标位置。西南、南是西源大道、蓉 2 号线有轨电车、电子科大站、顺江片区住宅与学校和农田；西、西北是天润路、龙湖时代天街、合作安置小区和商务园区；北、东北是科新南路、蓉昌高速与高架匝道、白色厂房的园区和综保区；东、东南是互通匝道、紧贴校界的林泽杜鹃绿地、农田、220 kV 变电站、绕城绿道和高架的绕城高速。校界外楼很少，所以楼块用"世界文件的路网与用地 + 程序化楼型 + 覆盖层地标"（WLD-OUTSKIRTS-BAND §2.3）；地铁在地下，不画。

### 1.2 各方位的截面线距离

- **各地段的远近**：校界外 250–500 m 之间，随街区取：北尖多切进一排综保区厂房，让厂房屋面留在箱庭里；东南让绕城高架整段留在箱庭里；南含电子科大站与顺江片区；西含天街。具体多边形由管线按这些规则定稿。
- **清水河**留在截面线外（离校界最近约 450 m）：在雾海顶面上沿真实走向画一条**静止的银色亮带**，从高处看是"雾中一线银色"。**绕城高架**整段留在箱庭里，桥墩节奏、整洁的隔音屏、夜间一线路灯是东南方向的身份地标。**蓉昌高速**整段沿东北边留在箱庭里。

## 3 灯光与农田

### 3.1 夜间灯光

通用规则见 WLD-OUTSKIRTS-BAND §3.1。

| 对象 | 怎么亮 |
| --- | --- |
| 电子科大站等站台雨棚 | **初灯组**（太阳高度 8° 到 4°），西南方向发光最亮的一处；看街长椅靠它接"初灯" |
| 西源大道、天润路、科新南路的路灯；绕城、蓉昌高架上一线路灯 | 普通路灯阈值（3° 到 −1°），比校内主轴晚亮，整夜亮；高架只画灯头光晕和路面灯带，不画车灯 |
| 绕城绿道景观灯 | 三级 · 暖；普通路灯阈值亮起，1:00–5:30 熄一半 |
| 外围住宅窗 | 窗灯总体曲线；夜深后逐渐减少，凌晨很少；暖白与冷白 2:1 |
| 厂房、园区 | 冷白窗带整夜亮着（呼应"电子"主题），做得比住宅更整齐更显眼 |
| 店招、商场名、农贸市场 | 暖色；营业时段亮，22:30 后熄一半 |
| 变电站场灯 | 几盏冷白点灯，整夜 |

### 3.2 农田与绿地的四季

春油菜花黄，夏稻田浓绿，秋收割后的金色稻茬（田埂上几垛稻草），冬霜灰色、田埂露出暗土；田埂、灌渠画成一格格的平涂。林泽杜鹃绿地春季一片片粉红，其他季节按常绿灌木。

## 4 身份地标（保留，让人认得出）

1. **西源大道与蓉 2 号线**：双向主干道、有轨电车接触网的立柱节奏；电子科大站的侧式站台、雨棚和站名牌"电子科大"。
2. **龙湖时代天街**：5 层商场的大体量和屋顶轮廓，商场名暖光字。
3. **绕城与蓉昌的高架和互通**：桥墩节奏、匝道的弧线、夜间一线路灯。
4. **220 kV 发展变电站的铁塔与高压线**：保留铁塔和两回主线作为黄昏逆光下的细线剪影，间距整理成整齐的节奏；横切 V1、P00 或 E6 的主体时用覆盖层挪线。
5. **顺江一带六到八层的板楼群**：从南门和电车站看过去的对街。
6. **综保区和研究所园区的大片白色厂房**：一排排天窗和夜间冷白窗带，呼应"电子"主题。
7. **农田**：东南、南两片，四季换色，春天的油菜花最出画。

其余泛化成楼型，不做真实立面。

## 5 新增的氛围元素与外围植被

都写进外围覆盖层，ID 以 `design:` 开头，写明理由（规则见 WLD-OUTSKIRTS-BAND §4.2）。外围的树用校内同一套树种和季相，份额计入 WP-47（外围环境带），只是视觉，没有碰撞（WLD-VEGETATION §7.1）。

- **草坪轨道**：蓉 2 号线的轨道床铺草带，随草坪换色，冬季压雪。
- **行道树林荫**：西源大道、天润路两侧各一排整齐的行道树，取香樟（常绿）和水杉（秋季锈红、冬季塔形裸枝）两种，不种银杏。
- **站台的生活痕迹**：候车椅、站名牌、线路图、一节静止的电车，夜里雨棚是一团暖光。
- **川西林盘**：东南农田里一两处竹丛环抱的青瓦农舍，带一缕静态炊烟；青瓦按川西民居的小青瓦坡顶，不做成和式瓦屋顶。
- **农田的田埂和灌渠**：零星几株桤木。
- **绕城绿道**：林泽杜鹃绿地成片常绿杜鹃灌丛，春季开粉红花；里面的慢行道夜里一串三级景观灯的光点。
- **小区与高架下**：小区的门岗亭亮一盏暖灯，围墙上爬藤；小区里的树以香樟为主，夹几株银杏以外的秋色叶树；门口和高架下的绿带用红叶石楠、黄绿矮绿篱修剪成灌木带，再加一条步道。

## 6 河渠格栅与看街长椅

### 6.1 河渠格栅（WP-30）

走马河、红光右支渠、磨底河穿出校界的地方做一道竖条钢格栅，或带启闭机小屋的节制闸，两端和两岸的栏杆、护岸接上；这是全图河渠格栅的唯一做法，各区文档只写交点落在本区时接护岸栏杆；格栅前的水面照常流动，格栅条上挂几片落叶（秋），冬季顶上压一线雪。归 WP-30（校界与门），水面与 WP-24（水体系统）、护岸与 WP-28（滨水与桥） 配合。

### 6.2 看街长椅（WP-30 做，WP-44 选点）

校界内侧，隔着栏杆正对电子科大站（约在西南，离校界约 30 m），朝南；前景是西源大道的林荫和草坪轨道，中景是站台雨棚、静止的电车，背景是对街的板楼和远处的雾。默认状态（秋 17:30）太阳在 241°从右前方斜照，站台雨棚的灯（初灯组）正在亮起，这里接"初灯"。长椅可以跳上去；审查视角 E6 就是这里。

## 7 待验证

- **截面线的位置**：§1.2 的距离是估值；WP-47（外围环境带） 管线定稿后，地图包围盒、V9、P15 的位姿看着对即可。
- **看街长椅与 E6 的位置**：WP-44（可行走范围、边界与安全点） 按真实的栏杆和绿带定，E6 随之调整。
