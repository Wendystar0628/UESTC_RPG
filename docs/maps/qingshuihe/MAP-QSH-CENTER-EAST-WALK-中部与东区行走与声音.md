# MAP-QSH-CENTER-EAST-WALK · 中部与东区行走与声音：主网、挡路物、开放入口、点位与锚点、声音

> **范围**：本文规定中部与东区的行走主网、能看不能进的挡路物、可进入的室内与开放入口的门口表现、涉水区、点位、节奏与锚点、声音要点。
> **不在本文**：各楼的外观（MAP-QSH-CENTER-EAST）；光、四季昼夜与天气（MAP-QSH-CENTER-EAST-SEASONS）；开放楼的室内内容（MAP-QSH-INTERIORS §2、WLD-INTERIORS）；校界与闸机的通用做法（WLD-OUTSKIRTS-BORDER §1、SYS-WALK-BOUNDS §2）；点位与锚点的坐标（`waypoints.json`、`world/atlas.json`）；发声器的生成（SYS-AUDIO）。
> **查阅**：先读 §0；主网、挡路物与可进入的室内看 §1；开放入口的门口表现看 §2；点位、节奏与锚点看 §3；声音看 §4；待验证看 §5

## 0 结论

1. **行走**：R5 东行望月全程、R14 支线和 P14、P23 在本区；球场围网门常开，游泳池组团围网门锁着；关着的楼门记 `DoorClosed`，东缘校界记 `Boundary`（§1、§3）。
2. **开放入口**：品学楼 A 区大厅、A 区侧门、C 区大厅和训练馆北附楼门厅做门口表现，门外 2.5 m 是传送落点，不放挡路物（§2）。
3. **点位**：P14 落点要看得到训练馆筒拱和满月，塔楼不挡这条视线；P23 是品学楼阶梯教室（§3）。
4. **声音**：本区只填 `Sounds()` 插座和 `Foot`；品学楼走廊是"窄处更明显"的主参照点（§4）。

- **WP-36（点位与跳转） 定 P14、P23 时**：P14 落点在文科楼前友谊树旁的草坪边，要看得到训练馆筒拱和满月；P23 是品学楼阶梯教室，`Entry = Door`；坐标以 `waypoints.json` 为准（§3）
- **WP-48c（标记、锚点）、WP-44（可行走范围、边界与安全点） 登记锚点 A04、A13 时**：坐标以 `world/atlas.json` 为准，A04 在品学楼门框前广场的坡广场顶平台上（§3）
- **WP-31b 做品学楼、训练馆室内时**：开放范围按 §2；入口、门洞、门口表现和筒拱外壳归本区，楼板、楼梯、家具和 `Acoustics()` 归 WP-31b（§4）
- **WP-47（外围环境带）、WP-30（校界与门） 做磨底河外和东缘校界时**：河外的科新南路、高速与匝道归 WP-47；东缘栏杆和东南出入口闸机归 WP-30，碰撞记 `Boundary`（MAP-QSH-CENTER-EAST §5.1、MAP-QSH-CENTER-EAST-WALK §1）

## 1 行走：主网、挡路物与开放入口（主线之后）

R5 东行望月全程在本区，一路往东走，背对晚霞，迎着月亮；R14 品学楼与训练馆（R5 的室内支线）和 P14、P23 也在本区。

**主网**：银杏大道跨河段和北段（北段一直伸进北部生活区）；品学楼的架空通道；各楼门前 10–15 m（一号科研实验楼、基础实验大楼、科研楼 B/C 区、品学楼、文科楼各栋、综合训练馆）；R5 全程（跨河小桥 → 麦克斯韦像 → 品学楼 → 文科楼 → 网球场 → 训练馆）及连接它们的道路。球场和田径场是开放场地，围网门用门吸固定常开，R5 从一组网球场的"绿色房间"里穿过。本区重点补 R5 沿线和品学楼门前广场的走廊细节。

**能看不能进**：

| 地方 | 用什么挡 |
| --- | --- |
| 关着的楼（科研楼 B/C 区、基础实验大楼、品学楼开放范围以外、文科楼含中庭） | 门关着，门玻璃里是门厅卡（`DoorClosed`，SYS-WALK-BOUNDS §2）；门厅灯、闸机待机绿灯、楼层索引牌看得到 |
| 品学楼、训练馆开放范围的边上 | 楼梯厅起步处的防火门关着、啦啦操房和办公室门锁着，`DoorClosed` |
| 器材室、室外游泳池组团 | 器材室门锁着；游泳池组团一圈 2.2 m 透空围网，门锁着 |
| 楼顶 | 不设通往屋顶的楼梯；场边小看台的雨棚，棚檐到最高一级座板的高差超过跳跃上限（SYS-WALK-BOUNDS §2） |
| 走马河、磨底河 | 护岸装栏杆（SYS-WALK-BOUNDS §2）；磨底河穿出校界处是格栅或节制闸 |
| 东缘校界与东南出入口 | 校界透空栏杆和东南出入口闸机（WP-30（校界与门）），`Boundary`（WLD-OUTSKIRTS-BORDER §1）；门外的科新南路、蓉昌高速和互通匝道、东南的绿地农田和绕城高架能看不能进 |

球场围网本身是挡路的墙段，只能从门进出。

**可进入的室内**：品学楼的 A 区大厅、一间阶梯教室和 C 区一层（见 §2），综合训练馆的北附楼门厅、主馆地面和北附楼 2F 内走廊。开放入口出现在平面地图的"可进入的室内"图层里，可传送到门口。

**涉水区**：品学楼东侧的小溪整段（水深不到 0.3 m，速度降到 0.6 倍；小溪不是主网的临水段，两岸卵石收边、不装栏杆，小桥照常可走）；走马河亲水台阶（MAP-QSH-ADDITIONS-VOCAB §3）的最下一级。

## 2 开放入口与门口表现（主线之后）

开放范围见 MAP-QSH-INTERIORS §2；门口表现（门扇固定敞开、门口灯、地垫、开放牌）、门洞净宽和门外 2.5 m 的传送落点按 WLD-INTERIORS-ACCESS §2，房门自动推开与闭门器按 WLD-INTERIORS-ACCESS §2.1。室内由 WP-31b（西区与中东区精选室内） 实现，本区负责入口、门洞和门口表现。

- **品学楼的入口**：A 区大厅门；门框架空通道下 A 区一侧的侧门；C 区大厅门。三处都做门口表现。
- **阶梯教室**：取 A 区东条楼一层的一间；前门在 1F，后门在 2F 锁着；座位逐排升起，后排有栏杆，前墙绿板加投影幕（参照 B201 实拍），蓝窗帘、吊扇、灰色固定课桌可参考；沿途教室门关着，门上视窗看得进去。灯按教学楼曲线：22 时以后全楼只剩约 5% 的窗亮着，它固定是其中之一，夜里走到品学楼总能找到这一格亮灯（P23，秋 20:00）。
- **综合训练馆**：北附楼的进门大厅（无框玻璃门）是入口，门口表现和筒拱外壳归本区。

## 3 行走：点位、节奏与锚点（主线之后）

点位的行走落点以 `game/data/maps/qingshuihe/waypoints.json` 为准：

| 点位或路线 | 推荐状态 | 要保证的 |
| --- | --- | --- |
| P14 东区 · 月出 | 秋 18:10 | 文科楼前友谊树旁的草坪边；朝 65° 看得到训练馆筒拱和刚离开城市剪影的满月；塔楼不挡这条视线 |
| P23 品学楼 · 阶梯教室 | 秋 20:00 | 室内，`Entry = Door`；从最后一排往下看满屋空座、黑板和亮着的投影幕 |
| R5 东行望月 | 秋 18:20，满月 | 跨河小桥 → 麦克斯韦像 → 品学楼 → 文科楼 → 网球场 → 训练馆，1.2 km，全程不卡 |
| R14 品学楼与训练馆（R5 支线） | 秋 18:20 满月 | 门框架空通道 → A 区大厅 → 大楼梯 2F 平台 → 一层单面廊 → 阶梯教室（P23）→ 中央广场 → C 区大厅 → 美遇空间 → 一层中廊 → 东南角门 → 文科楼前 → 网球场 → 训练馆主馆 → 北附楼 2F 内走廊，约 1.2 km；进出三处入口都不卡 |

**节奏**：R5 的大拍是跨河小桥 → 麦克斯韦像与方程石 → 品学楼门前的叠水喷泉和书法横梁下的架空通道 → 文科楼前的友谊树（P14）→ 网球场的"绿色房间" → 训练馆筒拱与月亮同框（终点），相邻两拍大约一两百米。小拍：路口斜立的科研楼碑、林为干像、非机动车停放区、树下长桌（桌上一本合上的书）、小溪和小桥、开放时间牌、置物横栏上搭着的外套、篮球车、场边小看台、白猫、开放入口的门口灯；品学楼门前广场的导览亭 A04 是 R5 的一拍。收与放：树墙围出一间间"绿色房间"，从最后一间走出来，训练馆前的开阔场地和东边的天空一下子打开，月亮就在那里。

**锚点**：A04 品学楼（导览亭，在品学楼门框前广场、叠水喷泉西侧，牌面朝门框横梁，落在坡广场顶的平台上）、A13 东区（导览桩，在文科楼与综合训练馆之间，朝训练馆筒拱），位置以 `world/atlas.json` 为准；锚点侧前方约 2 m 的落点和它面向的广场上不放挡路物。

**地标可见**：R5 往东走时背对图书馆穹顶，前方目标是训练馆筒拱和月亮；宣邦楼钟楼应当在南侧看得见（WP-44（可行走范围、边界与安全点） 的可见性检查，§5）。

## 4 声音要点（主线之后）

本区只填部件的 `Sounds()` 插座和碰撞体的 `Foot`，发声器由 WP-53b（环境声） 生成。本区的特别点：

1. **品学楼**：A 区大厅 Hall，阶梯教室 Room，C 区一层走廊 Corridor；上课时段隔壁教室隔墙的讲课声只剩节奏（截止 ≤ 500 Hz），课间停；22 时以后只剩日光灯和挂钟秒针；品学楼走廊是"窄处更明显"的主参照点；房门和防火门自动推开、闭门器带上时有开关门声。
2. **综合训练馆**（开放）：Gym 类，地面 `SportWood`；球场群的拍球、篮筐、哨声只来自看不见的球场，观者走近、看见之前就淡出。
3. **文科楼**：不出施工声，楼是"建成、正在搬入"，画面里没有人在干活。
4. **品学楼门前叠水喷泉**：细碎的落水声，只在约 10 m 内听得到，和西湖喷泉同一类点声源。
5. **东缘**：绕城高架没有行驶的车；夜里东区主要的底噪是雾外远处高速的车流，偶尔一声远处重车的低频轰鸣。
