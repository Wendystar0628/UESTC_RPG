# MAP-QSH-SOUTH-WALK · 南区行走与声音

> **范围**：本文规定南区的行走主网、能看不能进的阻挡、可进入的室内与开放入口的门口责任、涉水区、点位、节奏与锚点，以及声音要点。
> **不在本文**：各楼外观与身份特征（MAP-QSH-SOUTH）；四季昼夜与天气（MAP-QSH-SOUTH-SEASONS）；开放室内的范围与要点（MAP-QSH-INTERIORS §1）；楼板、楼梯、碰撞与家具（WLD-INTERIORS）；校界、闸机、栏杆与门洞的通用做法（WLD-OUTSKIRTS-BORDER §1、WLD-INTERIORS-ACCESS §2、SYS-WALK-BOUNDS §2）；声音规则（SYS-AUDIO）。
> **查阅**：先读 §0；主网、挡路物与开放入口看 §1，点位、节奏与锚点看 §2，声音看 §3，待验证看 §4

## 0 结论

1. **开放**：主楼 B2 前后门（R1 从柱厅穿过）与屋顶空廊、宣邦楼山花门廊与钟楼侧门、体育馆与游泳馆平台层入口、立人楼南门与东门可进；其余楼门关着，门里是门厅卡（§1）。
2. **校界**：南门闸机关着、抬杆放下，是校界（`Boundary`）；门外街区能看不能进（MAP-QSH-SOUTH §1、MAP-QSH-SOUTH-WALK §1）。
3. **行走**：R1 本区段、R2 环湖全程和 R7–R10 在本区；主楼 B1–B2–B3 的路网连接由本区覆盖层补上；涉水区只有亲水平台一级和 2–3 段卵石驳岸（§1）。
4. **点位**：P07、P09、P17–P19 落在本区，P17–P19 是 `Entry = Door`；导览亭 A01、A03、A06 位置以 `overlay/atlas.d/` 为准（§2）。
5. **声音**：本区填 `Foot`，钟声越过东湖在 P09 最清楚，是英雄声景"秋蓝调"的主角（§3）。

- **WP-48c、WP-44 登记导览亭 A01、A03、A06 时**：坐标与朝向以 `overlay/atlas.d/` 为准，A06 的 y 取平台顶面；本区不另做校园导览牌（§2）

## 1 行走：主网、挡路物与开放入口（主线之后）

本区是 R1 落金主线的起点，也是 R2 东湖环湖的全程；R7 主楼登顶、R8 东湖登钟、R9 大平台一圈、R10 立人楼上课路也在本区（WLD-INTERIORS-ACCESS §4）。

**主网**：南门内广场；南门到主楼门廊的主轴线步道与门前广场中轴和两侧人行道；主楼门廊与台阶 → B2 前门 → 柱厅 → 背门 → 后广场 → B3–C1 过街楼门洞 → 银杏大道南端；银杏大道本区段到立人楼西侧；东湖环湖跑道全程（1160 m）、六角亭、亲水平台、西岸草阶看台、北岸紫藤廊架、4 处休息点；吴立人像、宣邦楼山花门廊、立人楼转角门洞、体育馆、桃园餐厅、科创餐厅、国际创新中心门前 10–15 m；大平台的台阶、顶面和平台下的街廊。森林公园林下、立人楼多边形院子、校友林、体育场内场（围网门常开）也能走，但不属主网。主楼 B1、B2、B3 在数据里互不连接、前台阶也没接进路网，本区覆盖层补上连接边。

**能看不能进**：

| 地方 | 用什么挡 |
| --- | --- |
| 南门以外与其余校界（体育场馆以南、国际创新中心以西） | 南门闸机关着、抬杆放下，`Boundary`（WLD-OUTSKIRTS-BORDER §1.1）；其余校界是透空栏杆和石柱（WP-30），河渠穿出处是格栅（MAP-QSH-OUTSKIRTS §6.1）；提示见 SYS-WALK-BOUNDS §2 |
| 东湖湖心岛、小林岛 | 四面隔水，跳下水按 SYS-WALK-BOUNDS §4 沉水后回位 |
| 孔雀之家 | 网笼是静态碰撞体 |
| 驳岸与河渠 | 栏杆按 SYS-WALK-BOUNDS §2；无栏杆的草坡岸线由遮罩边缘隐形墙挡住 |
| 关着的楼（主楼 B2 以外各区、宣邦楼塔楼与正楼其余部分、立人楼 A 区与二层以上、国际创新中心、科创餐厅、1–8 号楼、孤儿楼群、平台下街廊门面） | 门关着，门玻璃里是门厅卡（WLD-INTERIORS-ACCESS §2、§3） |
| 开放楼里的"到此为止"（B2 四角楼梯间与通 B1/B3 的门、宣邦楼校友之家各层、体育馆场地层与更衣淋浴、立人楼外廊转角伸缩门） | 封口（WLD-INTERIORS-BUILD §5），隔着门玻璃能看到里面 |
| 楼顶（主楼空廊与钟楼灯笼除外） | 楼梯通到屋顶门，门锁着 |

**可进入的室内**（范围与路线见 MAP-QSH-INTERIORS §1）：主楼 B2（前门 → 柱厅 → 背门，R1 从这里穿过；后门厅楼梯上 2F 校史馆）；宣邦楼（山花门廊 → 中厅；钟楼侧门 → 四跑楼梯 → 钟室 → 柱廊灯笼）；体育馆与游泳馆；立人楼一层；两处高处（主楼屋顶空廊、钟楼灯笼）。开放楼的入口门固定敞开，是"能进"的信号。

**开放入口的本区责任**：各开放入口的门洞、门前台阶、门口表现和外立面与室内的对位归本区。

- 主楼 B2 前后门：门洞与台阶按 MAP-QSH-SOUTH §2.4。
- 宣邦楼：山花门廊和钟楼侧门（南副楼一侧）做门口表现；外立面窄竖窗与楼梯平台对位。
- 体育馆、游泳馆：平台层入口做门口表现；外立面玻璃与环厅对位。
- 立人楼：入口三处，西端转角门洞进院子再上外廊，南门朝东湖与吴立人像，东门在半圆体量旁；南门、东门做门口表现；外廊是半室外，按室外介质处理。

**涉水区**：东湖亲水平台临水的一级；卵石驳岸 2–3 段。涉水区外沿不设墙，往深处走会沉到水下，看到锦鲤和天鹅脚蹼，然后回到岸上；冬季浅滩只是画面，不扩大涉水区。

## 2 行走：点位、节奏与锚点（主线之后）

坐标以 `game/data/maps/qingshuihe/waypoints.json` 为准：

| 点位 | 要保证的 |
| --- | --- |
| P07 南门 · 主轴线 | 闸机内侧约 8 m，朝 33°；前景横进蓉 2 号线接触网时降到 3.5 m 或挪到靠校一侧；导览亭 A01 不挡主轴和校名墙 |
| P08 银杏大道 | 同位，即 E1，与 MAP-QSH-CORE 交界 |
| P09 东湖 · 宣邦楼 | 西岸草阶看台平整的一级；能看到钟面和荷角；钟声最清楚的地方 |
| P17 主楼 · 屋顶空廊 | 经 B2 后门厅电梯；朝 215° 看得到南门主轴线、模纹花坛和旗杆 |
| P18 宣邦楼 · 钟楼灯笼 | 经四跑楼梯；钟面在脚下，东湖倒影、主楼和穹顶连成一片；柱子不挡 270° 视线 |
| P19 体育馆 · 看台顶排 | 环厅外立面玻璃与室内看台对位；看台最高排俯看木地板与放射桁架（夏夜比赛灯全开） |

P17–P19 是 `Entry = Door`：跳转时从最近的开放入口走进去。

**节奏**：R1 本区段（南门 → 主楼门廊 → B2 柱厅 → 背门 → 过街楼门洞 → 银杏大道南端，约 0.45 km）的大拍是南门、主楼门廊的方柱长影、柱厅主题墙、穿过 B3–C1 门洞后银杏大道迎面打开；小拍是石球与防撞柱、模纹花坛、国旗杆、门口地垫与开放牌、后广场长椅。R2 东湖环湖（1.3 km）的大拍是吴立人像、六角亭、草阶看台（正对宣邦楼倒影）、紫藤廊架、亲水平台；小拍是每 100 m 的里程标、休息点拉伸杆、救生圈立柱、驳岸置石、木划船、白鹭、蒲苇、荷角、春夏栏杆上的家燕。R7 主楼登顶的大拍是电梯门打开、空廊外的落日；R8 东湖登钟是中厅仰望、钟室指针剪影、灯笼环 360°；R9 大平台一圈、R10 立人楼上课路沿 WLD-INTERIORS-ACCESS §4，室内段锚点由 WP-31a 登记。东湖环湖任何一点都能望见钟楼。

**锚点与设施**：三座导览亭 A01 南门（朝 35°，南门内广场，牌面与校名墙同框）、A03 东湖（朝宣邦楼，落在看台北端平地，不落在水面和台阶上）、A06 体育中心（大平台顶面，朝体育场），位置以 `overlay/atlas.d/` 为准；本区不用导览桩，MAP-QSH-ADDITIONS-VOCAB §5 的校园导览牌由这三座导览亭代替。东湖跑道上一处直饮水台，4 处跑道休息点计入休息点。草阶看台每级高 0.4 m，每 6–8 m 嵌一段小台阶（同 MAP-QSH-CORE-WALK §2）。

## 3 声音要点（主线之后）

声音由 WP-53 实现，本区填 `Foot`，半室外空间写进声学覆盖层。本区的特别点：

1. **南门**：栏杆外的街是空的，远处城市声从外围以外的雾里来；不做电车声，也不做单辆车开过；闸机被挡住只有一声翼板轻碰。
2. **主楼**：门前主楼喷泉是静止的浅水池，不出水声；B2 柱厅是 Hall，墙后电梯只有门轨和轿厢声，不出"叮"；屋顶空廊是高处的风和更清楚的远处城市。
3. **宣邦楼**：中厅 Atrium，钟楼楼梯 Stair，钟室 SmallRoom，灯笼观景环 Canopy；整点钟声从钟室越过东湖传开，P09 最清楚，是英雄声景"秋蓝调"的主角。
4. **东湖**：环湖跑道 `RubberTrack`；荷角夏夜有蛙；冬季浅滩有涉禽细叫；孔雀叫稀少，每真实小时不超过 2 次。
5. **体育馆、游泳馆**：运动木地板会吱，池岸常湿；空馆底噪、屋盖受冷收缩偶尔一声"嘣"；雨打金属屋盖是全片最响的室内雨。
6. **半室外**（立人楼外廊、过街楼门洞、平台下街廊）：按 Canopy 或 Underpass 写进声学覆盖层，脚步更近、更清楚。
