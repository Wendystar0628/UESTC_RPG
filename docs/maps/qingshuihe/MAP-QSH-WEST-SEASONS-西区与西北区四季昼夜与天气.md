## 0 结论

1. **默认与口径**：默认状态是秋 17:30，四季和昼夜一律视觉效果优先；本区建筑的季节变化只有按法线覆雪和生活痕迹（§1）。
2. **夜里最安静的一块**：科研楼通宵的稀疏窗灯，湿地是暗区、水面映灯，不亮成一片（§1）。
3. **受光**：六号 A 区楼顶傍晚最后暗下、日出最先亮起；P10 的推荐状态是春 07:20 雨后初晴（§1、§2）。
4. **天气**：西门桥头候车亭是雨夜的主画面；湿地雨水花园雨天积成一片浅水（§2）。

### 0.1 接入要点

- **WP-38 放萤火虫、WP-39 排灯时**：湿地栈道只用低位步道灯，两侧贴水的暗处不加灯（MAP-QSH-WEST §10.1、MAP-QSH-WEST-SEASONS §1）

## 2 天气要点

- **避雨处与雨帘**（做法 MAP-QSH-ADDITIONS-ATMOSPHERE §4）：西门桥头候车亭顶前后沿各一排雨帘，站牌灯箱从帘后照亮，是本区雨夜的主画面；光伏车棚单坡，只在低的一侧滴水，帘最密；六号底层退后的玻璃幕墙前是一条干的檐下；四号深蓝玻璃盒入口的白色门框上沿挂一排；六号 2F 连廊外侧檐口挂一排，连廊底下的车道门洞是干的。
- **积水点**（位置，潜势由 WP-15 画）：新停车场沥青车道的低侧，水最后流进植草沟；校训石前广场靠路一侧；西门车行桥两端桥头；水杉路人行道树池边。湿地雨水花园下凹 0.25 m，雨天积成一片浅水，鸢尾和芒草立在水里，雨停后最晚干；栈道和石桥只变湿变暗，不积水。
- **雾里读形**：本区没有雾豁免的地标。六号 A 区高 41.5 m，正午雾顶压在 25–40 m 时楼顶露出雾面，是西区雾天的记号；徽记和大字在 C 区，雾顶低于 C 区楼顶时才露出。晨雾先从湿地和渠面起，芦苇穗和石桥的拱从雾里露出来；水杉路隔湖望穹顶（P05）靠穹顶的雾豁免。
- **雨天的生活痕迹**：四号楼前自行车座套塑料袋；候车亭座椅上一把忘带走的折叠伞。
- **推荐状态**：P10 的推荐天气是雨后初晴：洗过的蓝天下雪山清楚可见，校训石红字更饱和，石前积水映出晨空，前景樱花叶缘有水珠高光。
