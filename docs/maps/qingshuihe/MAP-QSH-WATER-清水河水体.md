# MAP-QSH-WATER · 清水河水体

> **范围**：本文规定清水河各水体的具体水面：西湖的水下森林与喷泉水柱，东湖，三条河渠，游泳馆与室外游泳池的池水，品学楼门前的叠水喷泉，主楼水池，开放泳区的名单与登记，平面反射的候选湖，各时段的主要倒影。
> **不在本文**：水面的通用画法、反光带与倒影的规则、四季与天气、涉水与开放泳区的规则、水体系统规则（WLD-WATER）；西湖喷泉的形态与灯的时段表（MAP-QSH-CORE）；截面水柱的画法与水色（WLD-OUTSKIRTS-DIORAMA §3）；驳岸、栈桥、拱桥、亭子（各区 MAP-QSH 文档）；岸型、水深剖面与常水位（WLD-TERRAIN、MAP-QSH-TERRAIN）；荷和水生植物的位置（MAP-QSH-VEGETATION）；水的动态节奏（SYS-MOTION）；水声（SYS-AUDIO）。
> **查阅**：先读 §0；西湖看 §1；东湖看 §2；河渠看 §3；池水、叠水喷泉与主楼水池看 §4；开放泳区名单看 §5；倒影候选湖与主要倒影看 §6；待验证看 §7

## 0 结论

1. **西湖**：湖底有水下森林的剪影，从图书馆一侧朝西与从湖西岸朝东看的倒影都要成立；扇形喷泉的形态按 MAP-QSH-CORE §7 的时段表，本文只管水柱画法（§1）。
2. **东湖**：映着宣邦楼，荷区之间留暗色空隙，冬季北岸一角露出浅滩（§2）。
3. **河渠**：流向统一设定，流速约 0.45 m/s，暗涵段不画水面，漂浮物截到校界格栅前（§3）。
4. **池水、叠水喷泉与主楼水池**：用同一个水面材质，不新增着色器，不做平面反射（§4）。
5. **开放泳区**：只有西湖主水面、东湖主水面两处；游泳馆池只看不下（§5）。
6. **倒影**：平面反射只给西湖和东湖，各时段的主要倒影列在 §6。

### 0.1 接入要点

- **登记开放泳区（MAP-QSH-CORE、MAP-QSH-SOUTH）**：西湖、东湖由所在区登记泳区；岸型按 WLD-TERRAIN-APPLY §2.2
- **音频（SYS-AUDIO）**：河渠中线、西湖喷泉时段表、叠水喷泉位置在 CPU 侧可读；本文不另发声音事件（§1.2、§3、§4.2）
- **驱动漂浮物和喷泉（SYS-MOTION）**：本文提供波纹相位、流速、喷泉高度和每条河按几米重采样的中线；漂浮物中线截到校界格栅前一点（§3）
- **做驳岸、桥、亭、格栅、喷泉石台（MAP-QSH-CENTER-EAST）**：只做岸上和水中的结构，水面和落水归本文（§4.2）

## 1 西湖

### 1.1 水下森林与反光带

- 湖底有沉水植物：近岸浅水里能透过水面看到几团暗绿色的水草剪影（#2F5A4A），随波纹线轻轻错动；夏季最茂、近岸连成片，冬季稀疏、只剩零散几团；夜间水面不透光，看不到剪影。水面不透明，剪影是水面着色画出来的；水下的实体水草只在镜头进入水下时可见。
- 图书馆在湖的东侧，太阳在西南偏西：从图书馆一侧朝西看有落日反光带，从湖西岸朝东看，湖面映着亮灯的图书馆和满月，两种方向都要成立。白天没有碎金带，西岸朝东看映着蓝天、云和受光的穹顶；夜间从西岸朝东是月光银带加图书馆窗灯的竖条倒影，从东侧朝西是夜空和对岸的路灯竖条。
- 湖西部箱涵两侧的水面颜色可以略有不同：渠水一侧更浑一点，偏黄绿。

### 1.2 扇形喷泉

湖中央的扇形多柱喷泉。形态、灯与停喷的时段表以 MAP-QSH-CORE §7 为准，SYS-AUDIO 的喷泉声按同一张表切换；本节只管水柱的画法：

- **水柱**：白色平涂，顶端散成几点白色小块，底部一圈细小的同心波纹，随水柱高度放大；灯开时由下往上被照亮。
- 形态之间切换用 3–5 s 平滑过渡，不硬切；停喷时水面不结冰。时段表在 CPU 侧开放给 音频（SYS-AUDIO）。

## 2 东湖

- **倒影**：宣邦楼在东岸，默认状态下从西岸看过去，湖面映着塔楼、钟楼和受光的电子管穹顶；蓝调以后映出亮起的钟面（"交班的钟"）和钟面的竖条倒影。
- **荷区的水面**：荷之间要留出暗色空隙，四季不同：春，小荷钱贴在水面，空隙大，波纹线照常；夏，荷叶盖住荷区约六成，空隙暗而碎，粉色荷花映出模糊倒影；秋（默认），残荷之间留出暗色空隙；冬，只剩枯梗，水面开阔平静，波纹线变稀，干梗和它的倒影连成三角形。荷由 WLD-VEGETATION 负责。
- **锦鲤**（可选）：从亲水平台边俯视，水面可以透出两三条模糊的橙白色鱼影；夏季最清楚，冬季更淡更模糊，夜间看不到。鱼影画在水面着色里，不靠透过水面看实体。
- **冬季浅滩**：冬季东湖枯水，北岸与荷区分开的一角（一小片，由 MAP-QSH-SOUTH 定）露出浅滩，滩上有涉禽。不改变水位，浅滩的几何四季都在，顶面略低于常水位；冬季水面按季节阈值让出浅滩，露出湿泥，边缘绕一圈泡沫线，和地面覆盖一样阈值生长，不硬切。浅滩不可行走，也不在开放泳区里。

## 3 河渠

流向按下表统一设定，全片一致。流速约 0.45 m/s：一片落叶漂过 14 m 的桥大约要 30 秒。各河渠的实体与常水位以地形文件和 MAP-QSH-TERRAIN 为准。

| 河渠 | 设定流向 | 说明 |
| --- | --- | --- |
| 走马河 | 从西北流向东南 | 有多段暗涵，暗涵段不画水面；银杏大道跨过它 |
| 红光右支渠 | 从北流向南 | 笔直的人工渠，穿过湿地，在西湖段走箱涵 |
| 磨底河 | 从北流向南 | 沿东缘 |

- **河面**：用 WLD-WATER §1 的画法，但波纹线拉长，顺着流向；不做平面反射；雨天画雨点环，夜里读共用灯条表画灯条。0.45 m/s 的缓流几乎无声，有声的是桥墩、暗涵口、堰这些扰流处（SYS-AUDIO），发声器从本文的河渠中线生成。
- **漂浮物**：稀疏几片，随流移动，由 SYS-MOTION 驱动，跟随季节权重，换季时在起雾里替换：秋是落叶（银杏大道跨走马河一带是银杏叶，其余是其他落叶），春是樱花和美人梅的花瓣（每处两三片），夏基本没有，冬零星枯叶。
- **外围明渠与校界格栅**：格栅或节制闸的做法见 MAP-QSH-OUTSKIRTS §6.1；格栅前水面照常流动，漂浮物的中线截到格栅前一点，越过终点的缩到 0，不穿过格栅。O0 里露出的明渠段按校内标准画，护岸由 滨水与桥（game/gen/maps/qingshuihe/waterfront/） 延续；O1 的明渠只画底色、色带、波纹线和泡沫线，不做倒影和漂浮物，没有水下内容。外围明渠的到岸距离与流向由水面生成器从外围数据算出。
- **河渠护岸**：灰白石砌护岸配浅色栏杆，全部做新，不画水渍线和苔痕，桥栏、望柱完整；各区文档只写本区河渠的走向，护岸画法统一指本条。常水位以上的湿带、压顶与亲水台阶的通则见 WLD-WATER §1.3。

## 4 池水、叠水喷泉与主楼水池

### 4.1 游泳馆与室外游泳池

游泳馆是开放的室内之一，池水只看不下；东区的室外游泳池同样不开放。两处池水都用本文的水面材质。

- **样子**：静水，透出浅青的池底瓷砖色，分道线和池底深色标线透出来；伪深度只按池深分浅水区、深水区两道色带；波纹线比湖面稀、细、慢；池边一圈细白线代替泡沫线，没有断口。
- **取值**：水面比池沿低 0.15 m；浅水区深 1.2 m、占池长的前三分之一，其余深水区 1.8 m；池底瓷砖 `water.poolTile`，泳道中线 `water.poolLine`（色值以调色板为准）宽 0.25 m、道宽 2.5 m，两端各一道 T 形横线（长 1 m，距池壁 2 m）；深水区瓷砖同色相、明度 ×0.82；池边白线宽 8 cm；波纹线按湖面值取密度 ×0.5、线宽 ×0.6、周期 ×1.5。
- **倒影**：不做平面反射。室外泳池走解析天空加灯条；室内池水不映天空，把天空换成顶棚色，夜间叠池顶灯的亮点。碎片化与色块化照 WLD-WATER §2.3。
- **夜间**：游泳馆穹顶下沿的玻璃带透出池水的青光（`water.poolGlow`），随场馆灯的时刻表亮灭；池水在场馆灯下比湖面亮。
- 室外泳池照 WLD-WATER §3 画雨点环，室内池水无雨。

### 4.2 品学楼门前叠水喷泉

三层叠水喷泉，直径约 6 m，在品学楼门框正前方。石台、池沿和碰撞归 中部与东区（MAP-QSH-CENTER-EAST），三层池面和层间落水归本文。

- **池面**：三层各一块小水面，静水略动，只留一道池沿的暗边，中间透出深色花岗岩池底；波纹线比湖面细密，以落水点为心画同心波纹；池沿一圈细白线。
- **落水**：每层池沿溢出一圈薄水帘，白色平涂、带竖向亮纹，亮纹下移，节奏同水柱；水帘落进下一层处加一圈白色碎点，底层落进承水槽，不溅出石台。
- **倒影**：不做平面反射，走解析天空加灯条；夜里架空通道的筒灯在池面上成断续的短竖条；门框轮廓烘一块暗色遮罩投到池面，读得出"映着门框"。
- **时段与季节**：全天常流，没有时段表；水帘亮纹白天取主光色，夜里由筒灯照亮。冬季不结冰，石台顶一线雪；春季池面漂几片花瓣，秋季漂落叶；雨天池面画雨点环。
- **声音**：细碎落水声，约 10 m 内听得到，全天常流；喷泉位置与"常流"标记在 CPU 侧开放给 音频（SYS-AUDIO）。

### 4.3 主楼水池

- **主楼前圆形浅水池**（可选）：水面完全静止，不画波纹线；默认状态映着落日和主楼门廊，夜间映着主楼泛光，冬季也不结冰；静水，不发声。

## 5 开放泳区的名单与登记

泳区的规则见 WLD-WATER §4，进出水深与游泳态见 SYS-WALK-BOUNDS §4。

- **开放泳区只有两处**：西湖的主水面、东湖的主水面。没有体力和氧气，只做水面游泳。游泳馆池只看不下。
- **不开放**：湿地、芦苇带、栈道下方、箱涵口周边 10 m；三条河渠（断面窄、岸陡、有暗涵，只保留涉水带）；东湖冬季浅滩那一角；室内外游泳池；其余水面。它们由可行走遮罩的边界挡住。
- **登记**：泳区多边形由所在区登记，避开冬季浅滩、荷区和栈道：西湖归 核心区（MAP-QSH-CORE），东湖归 南区（MAP-QSH-SOUTH）。

## 6 倒影候选湖与主要倒影

平面反射的候选湖是西湖和东湖，写在 `map.json` 的 `env.reflectLakes`（做法见 WLD-WATER §2.3）。各时段的主要倒影如下：

| 时段 | 主要倒影 |
| --- | --- |
| 默认（秋 17:30） | 图书馆亮灯的穹顶；晚霞；锈红的水杉；宣邦楼的电子管穹顶 |
| 清晨、日出 | 粉金色的天；宣邦楼穹顶最先受光的一点；晨雾里的岸树剪影 |
| 上午到午后 | 蓝天和积云；受光的穹顶；岸边树冠，随季节 |
| 蓝调、入夜 | 洋红到蓝的天；图书馆的窗灯和采光顶；灯的竖条倒影；满月 |
| 深夜 | 月亮和银带；还亮着的窗；路灯的竖条倒影 |
| 阴、雨 | 珍珠粉紫的云盖和亮缝；没有反光带；雨点环打碎倒影；夜雨里灯条更显眼 |
| 雾 | 倒影随雾淡去，只剩近岸树和露出雾面的地标的淡剪影 |
| 雨后初晴 | 洗过的蓝天和向东退去的碎云；水面重新平静 |

## 7 待验证

- **湿路面灯条的长度与连续度**：现在读成灯下几块柔和的短光，英雄帧"秋 21:30 夜雨"要的一排路灯竖影是否要更长更连续，作者看夜雨 P08 后定（WLD-WATER）。
