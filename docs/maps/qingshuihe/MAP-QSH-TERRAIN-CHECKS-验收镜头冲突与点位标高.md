# MAP-QSH-TERRAIN-CHECKS · 地形验收镜头、冲突检查与点位标高

> **范围**：本文规定清水河地形定稿时的验收：A–K 验收镜头各自应有的层次、垫层与跳跃链等冲突检查的结论、点位与锚点的标高处理，以及地形的待验证项。
> **不在本文**：全图骨架与常水位（MAP-QSH-TERRAIN）；各分区的标高与连接（MAP-QSH-TERRAIN-DISTRICTS）；地形的通用规则（WLD-TERRAIN）；截图方式与门禁（ENG-GATES）；点位清单（UI-NAV）；点位与锚点的坐标（`waypoints.json`、`atlas.d`）。
> **查阅**：先读 §0；验收镜头看 §1，冲突检查看 §2，点位与锚点标高看 §3，待验证看 §4

## 0 结论

1. **验收镜头 A–K**：默认状态（秋 17:30）下按层次表检查，位姿由各区包交付本区地形时按截图定（§1）。
2. **冲突检查**：垫层与楼体高差、道路走廊、栏杆与跳跃链、开始页与过场、开放室内首层五项都有结论（§2）。
3. **点位**：P02 落到下沉广场地面（−0.9），P09 落到东湖看台第二级（+0.8），P13 与 P22 随宿舍上台升 3.0 m，P23 随品学楼台基升 1.5 m；室内同位点按"楼面 = 垫层 + 室内外高差"重算（§3）。

### 0.1 接入要点

- **定点位、锚点、传送落点的 y（WP-36、WP-48c、WP-44）**：一律读地形求值，P02、P09、P13、P22、P23 和 A03、A04、A11、A12 按 §3 重定
- **室内同位点（WP-36）**：落脚 y 按室内索引的楼面加眼高 1.62 m 重算（§3）
- **过场与开始页（WP-49b）**：新游戏过场第 3–5 镜经过银杏大道、下沉广场和红枫丘上空，地形定稿后重跑离地 3 m 检查（§2）
- **开放室内（WP-17、31b、31c）**：图书馆与博物馆垫层锁 0；品学楼楼面随台基升 1.5 m，学知苑 1 栋与朝阳餐厅随宿舍上台升 3.0 m（§2）
- **行走范围（WP-44）**：丘、堤、台地边坡都算可走，不登记禁行，陡坡由控制器按坡度挡；栏杆与台缘带的碰撞顶按两侧地形取（§2）

## 2 冲突检查的结论

- **垫层与楼体高差**：图书馆、博物馆垫层 0；品学楼 +1.5；宿舍台原上的楼按台面求垫层；主楼门廊、大台阶、大平台、宿舍首层架高、食堂台阶广场是楼体，不进高度场。
- **道路走廊**：纵坡按 WLD-TERRAIN-SHAPE §2.3 的坡度类；锚点之间做不到的，评估器报错，由 WP-20、WP-21 加长坡段或改台阶。
- **栏杆与跳跃链**：看台、看月台、草阶草坪的边都是 0.3–0.4 m 的级，台缘 ≤ 1.0 m；渠岸栏杆碰撞顶按两侧 ±3 m 内最高地面取（到 +2.4），球场围网到 +2.5；丘、堤、台缘边 1 m 内不放可踩物。设计坡最陡 1:3，低于 WLD-TERRAIN-SHAPE §2.3 不记安全点的 20°。
- **开始页与过场**：T0 不受影响；新游戏过场第 3–5 镜经过大道、下沉广场、红枫丘上空，不经过宿舍台原与东区堤路上空；地形定稿后由 WP-49b 重跑离地 3 m 检查。
- **开放室内首层**：品学楼楼面随台基升 1.5 m，学知苑 1 栋与朝阳餐厅随上台升 3.0 m，其余开放楼垫层都是 0；室内索引按垫层求楼面，不改代码。

| 点位或锚点 | 地面 | 处理 |

| P02 图书馆正门 | −0.9 | 落点 y 按 −0.9；位姿保留 |
| P09 东湖 · 宣邦楼 | +0.8（看台第二级） | 落点约 +0.8；位姿在水面上空，保留 |
| P13 学知苑 · 灯火 | +3.0 | 落点 y 约 4.62；位姿保留 |
| P22 学知苑 · 学习外廊 | 随上台升 3.0 m | y 8.2；入口 `xz1.hall` 4.0 |

| A03、A04、A11、A12 | 0 / +1.5 / 0 / 0 | A03 放看台北端平地；A04 在坡顶平台（x ≥ 122）；A11 避开下台台缘；A12 避开上台南缘 |
