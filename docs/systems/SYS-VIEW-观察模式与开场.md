# SYS-VIEW · 观察模式与旁观漫游

> **范围**：本文规定两种观察模式的总述和旁观者漫游（操作、活动范围、初始位置、镜头规则、提示），以及 3D 画面与平面地图的分工。
> **不在本文**：行走的手感、身体、游泳与行走的第一、第三人称镜头（SYS-WALK）；镜头在楼里、地下、水下、雾海里的介质呈现（SYS-VIEW-MEDIUM）；署名、许可、窗口标题与图标（OPS-RELEASE）；界面、点位跳转与操作说明（UI-NAV、UI-VISUAL）；平面地图与传送（SYS-ATLAS）；扉页、开始页与进场过场（SYS-TITLE）；存档（SYS-SAVE）；多地图（SYS-MAPS）；活动范围的细则与数值（WLD-OUTSKIRTS）；声音（SYS-AUDIO）；命令行参数全表与截图默认串（ENG-GATES-SHOTS §1）；相机的实现（`game/camera/`、`game/contracts/` 里的 `ICameraRig`）。
> **查阅**：先读 §0；旁观操作、速度与视场角看 §2.1；活动范围看 §2.3；初始位置看 §2.4；镜头规则与命令行参数看 §2.5；3D 画面与平面地图的分工看 §4

## 0 结论

1. **两种观察模式**：旁观（§2）和行走（SYS-WALK，新游戏的开局模式，D-242），用 F 键、界面按钮或双击空格切换；不做环绕、俯视、导览和自动运镜。旁观不显示任何角色；行走的第一、第三人称镜头归 SYS-WALK（SYS-WALK §3.2）。
2. **旁观像《我的世界》的旁观者飞行**：W 永远水平前进，升降只靠空格和 Shift；滚轮调 16 档速度上限（0.5–200 m/s），离地越近越慢；镜头穿透一切；垂直视场角 60°（§2.1）。
3. **活动范围是软约束**：减速、沿法线推回、朝外一侧起雾，不撞停、不锁输入；数值以 WLD-OUTSKIRTS-BORDER §2 为准（§2.3）。
4. **初始位置**：新游戏在本图出生点以行走模式交还控制（清水河 P01，D-242），世界是秋 17:30、晴；继续回到存档的状态（§2.4）。
5. **镜头不会自己动**：只有观者触发的点位跳转、传送、模式与人称切换、回位和电梯换位会移动镜头；开始页与进场过场是例外，归 SYS-TITLE（SYS-VIEW §2.5）。
6. **命令行参数**可复现所有审查视角；未知参数、不合季节的天气、读档与世界类参数同时给出，都以非零退出码结束；门禁与基准不读 `user://`（§2.5）。
7. **3D 画面不叠加任何标注**：地点名、选中、追踪只出现在小地图和大地图上（§4）。

**子文档**

- SYS-VIEW-MEDIUM 介质呈现：碰到镜头在楼里、地下、水下、雾海，楼体剖切变体或半入水时读。
- 署名、许可页、窗口标题与图标在 OPS-RELEASE §7.1。

### 0.1 接入要点

- 想在 3D 画面里标出地点、选中或追踪：不许；名字、选中、追踪只画在界面层的地图上（§4）
- 要移动镜头：只能是观者主动触发的过渡，不做自动运镜；开始页与进场过场归 SYS-TITLE（SYS-VIEW §2.5）
- 要读观者位置或镜头位姿：观者在哪读 `IObserverState`（旁观取镜头位姿，行走取物理体，第三人称也一样），画面从哪看读 `ICameraRig`；镜头的介质不代替身体是否入水（SYS-WALK §3.2、SYS-VIEW-MEDIUM §1）
- 要复现审查视角或截图：用 `--` 之后的用户参数，完整列表见 ENG-GATES-SHOTS §1；`--pose` 不合法或落在缓冲带里以非零退出码结束；新增参数同样遵守"未知参数非零退出"（§2.5）

## 1 不做的事

本作不是网页地图的续作，旧网页地图的功能一律不做（INV-1）：搜索与地点卡片、路径规划、在 3D 里点选与选中描边、建筑标签开关、俯视切换、指北针、信息卡、严格高度模式。界面里的平面地图按 SYS-ATLAS 重新设计，不按旧代码补回；手动选择画质的界面要做，它不是地图功能（SYS-GRAPHICS）。贴图加载失败的提示和重试按钮不做，流式加载失败时静默重试并写日志。

## 2 旁观者漫游

观察模式有两种：**旁观**和**行走**（SYS-WALK；新游戏以行走开局，继续恢复存档时的模式），用 F 键、界面按钮或双击空格切换。旁观的观看方式类似《我的世界》的旁观者模式：WASD 和空格自由移动，可以穿透任何物体。行走的手感和键位见 SYS-WALK；鼠标捕获、漫游态与界面态见 UI-NAV §4.1。

### 2.1 操作

| 输入 | 作用 |
| --- | --- |
| 单击画面 | 进入漫游态，鼠标被捕获；只有界面没处理的左键按下才算 |
| Esc | 漫游态 → 界面态：释放鼠标，界面淡入，世界不暂停 |
| 鼠标移动 | 漫游态下转动视角：偏航不限，俯仰限制在 ±89° |
| W / S，A / D | 沿视线的水平分量前进 / 后退，向左 / 向右平移 |
| 空格 / Shift | 上升 / 下降 |
| 按住 Ctrl，或双击 W（0.35 s 内） | 冲刺，速度 ×2，松开即停 |
| F，或双击空格 | 切到行走模式 |
| 滚轮 | 调整速度上限，共 16 档，按对数分布在 0.5–200 m/s；默认第 9 档约 12 m/s |

- 移动方式与《我的世界》的飞行一致：W 永远水平前进，升降只靠空格和 Shift；界面态下移动键仍然有效。
- **实际速度** = min(vₙ, 6 + 0.5 × 离地高度) × 冲刺倍数（ENG-BUDGET-LOD §2）；第 n 档 vₙ = 0.5 × 400^((n−1)/15) m/s，相邻两档之比约 1.49。离地面越近速度越慢，方便贴近看细节。离地高度取地形高度，不用物理射线：旁观不加载碰撞。
- **加速和减速**与帧率无关：加速约 0.15 s 达到目标速度的 95%，减速约 0.2 s 停下。镜头不晃动，没有头部摆动。
- **视场角**：垂直 60°，设置里可在 50–80° 之间调；切到行走时过渡到 70°。
- **鼠标灵敏度**：每个计数转 0.15° × 8f³，f = 0.6s + 0.2，s = 界面百分比 ÷ 200；100% 时正好 0.15°，与《我的世界》同一条曲线；原始输入，不平滑，旋转逐事件立即生效，不进物理步。
- **碰撞**：旁观完全没有。镜头可以穿过墙、地面、树和水面，穿过时的画面由 SYS-VIEW-MEDIUM §1 处理。

### 2.2 触屏

只做 PC，不做触屏操作。

### 2.3 活动范围

旁观的活动范围是软约束：接近边界时减速、朝外一侧起雾、再被沿法线推回，不撞停、不锁输入；校外一圈街区能看不能进。

- 可达空间的水平与竖直公式、缓冲带与推回、边缘雾、参数、合法化和不受约束的镜头，以 WLD-OUTSKIRTS-BORDER §2 为准。
- 在缓冲带里朝外推 0.5 s，或发生了一次推回，出一次"前方暂未开放"（UI-NAV §3.6）。
- 行走模式的活动范围由可行走范围和边界收口决定（SYS-WALK-BOUNDS §1–§2）。

### 2.4 初始位置

初始位置分新游戏、继续和 `--title=0` 三种情况；只有新游戏的开场一定是默认状态。

- **默认出生点**是当前图的 `defaultSpawn`，必须带行走落点。清水河上是点位 P01 日晷·望穹顶（UI-NAV-WAYPOINTS §1），站在日晷旁望图书馆穹顶。
- **新游戏**一律从落金初灯开始（SYS-TITLE-CINEMATIC §1）：交还控制时在出生点、行走模式（有进场过场时，过场落定后在雾幕里落到出生点），世界是本图的默认状态：秋季 17:30、晴、自动天气、流逝 1×。自动天气保持晴到秋季黄昏带结束，所以任何天气种子下，新游戏交还控制时的画面都相同。之后世界时间从 17:30 单调向前，黄昏自然流逝进蓝调和夜晚。
- **继续**：回到存档时的位姿、观察模式和世界状态；位姿不在可达空间里时就近合法化（WLD-OUTSKIRTS-BORDER §2.4）。
- **`--title=0`**（门禁、截图、基准）：没有扉页、开始页和过场，位姿取 `--pose`（截图默认 V1，即 P00），世界状态取命令行；给了 `--slot` 或 `--load` 时，位姿和世界状态都取那份存档。

### 2.5 镜头不会自己动

镜头只由观者控制，不做任何自动运镜（INV-2）。以下过渡都由观者主动触发，不算自动运镜：点位跳转（途中可随时打断）；平面地图上的传送（默认雾幕瞬移，或选"飞过去"）；模式切换时的降落和起飞；行走回位；主楼电梯的"关门换位"（镜头随角色平移，不另运镜）；行走时按 V 切换人称（吊杆长度在 0 与 3 m 之间 0.3 s 过渡）。

**开始页与进场过场**是例外（SYS-TITLE）：由观者在开始页主动选"新游戏"或"继续"触发，可以按住 Esc 0.8 s 跳过，路径来自数据文件，交还控制后镜头不再自己动；返回标题同理。开始页的 T0 是静止机位。

**输入占用**：大页、过场、换图等经按原因计数的占用暂时不接受观者输入，没有任何占用时才接受。

**命令行参数**：截图和自动化脚本用写在 `--` 之后的用户参数，设定出生位置、世界状态和画面设置（`--pose=V3`、`--clock=`、`--season=`、`--weather=`、`--quality=`、`--ui=0` 等）；另有地图、开始页与过场、存档、声音、门禁各组参数。完整列表和截图默认串以 ENG-GATES-SHOTS §1 为准。设定之后，镜头仍然是普通的漫游相机，这不算另一种观看模式。

- 未知参数直接以非零退出码结束，免得拼错的参数被静默忽略；不合季节的天气（如冬季下雨）也一样。`--slot` 或 `--load` 与 `--clock`、`--season`、`--pose`、`--map` 这类世界类参数同时给出，同样非零退出，因为读档时世界状态只来自存档。
- 门禁和基准只由命令行决定，不读 `user://`，命令行优先于画面设置文件；存档与声音在门禁、截图、基准下默认关。

### 2.6 操作说明与提示

画面上允许的操作说明与提示：

- 首次新游戏的过场交还控制之后，屏幕下方一行"单击画面开始 · Esc 打开菜单 · H 操作说明"，4 秒后淡出，以后不再出现（UI-NAV §3.4）；
- 按 H 展开的操作说明卡片；
- 漫游态下 2 秒内淡出的临时提示，只限 UI-NAV §3.6 列出的几种，包括"校外暂未开放""前方暂未开放""此处暂不开放"；
- 左上角的小地图：漫游态唯一常驻的元素，按 N 切换显隐，按 U、`--ui=0` 和过场时隐藏。

## 4 环境痕迹与平面地图的分工

界面里的平面地图（SYS-ATLAS）是唯一标注地点的地方：地点的名字、选中和追踪只出现在小地图和大地图上，3D 画面不叠加任何标注（SYS-ATLAS §1，INV-3）。

3D 里靠环境本身回答"这是哪里、往哪走"：门厅灯和店招、开放室内门口的暖光池与绿色开放牌（WLD-INTERIORS-ACCESS §2）、导览亭与导览桩（SYS-ATLAS-TRAVEL §2）、推开的椅子和车筐里的落叶这类生活痕迹；日晷的晷针指北，与小地图默认的北朝上一致。
