# SYS-GRAPHICS · 画面设置：预设、单项、风格底线、应用与持久化

> **范围**：本文规定画面设置给玩家的体验与边界：设备档与预设的关系、各单项及其生效方式、不随画质关掉的风格底线、应用方式、持久化、画面页的内容。主线范围：约 10 个单项、3 个预设；标题或节末带"主线之后"的内容现在不施工。
> **不在本文**：各预设与单项的具体取值（`game/data/quality-presets.json`）；契约签名（`game/contracts/Quality/`）；画面页的视觉（UI-VISUAL-COMPONENTS §5）；声音设置（SYS-AUDIO）；设备档的预算与帧率目标（ENG-BUDGET §2）；阴影图、级联等参数的预算（ENG-BUDGET）；自动调节的控制律（ENG-PERF-ADAPT §1.2，主线之后）；命令行与门禁（ENG-GATES-SHOTS §1、ENG-GATES §1）。
> **查阅**：先读 §0；预设看 §1；风格底线看 §2；单项与生效方式看 §3；应用方式看 §4；分档与自动调节看 §5（主线之后）；持久化与恢复看 §6；画面页看 §7

## 0 结论

1. **两层概念**：
   - **设备档**是硬件分类（独显高、独显中、最低配置，ENG-BUDGET §2），决定推荐哪个预设和帧率目标。最低配置是近两年的核显轻薄本（酷睿 Ultra 第一代的 Arc 核显、Radeon 780M 同级及以上、16 GB 双通道内存、SSD）；更旧更弱的核显不适配，不另设档（D-169）。主线由玩家自己选预设，默认精致；自动判档在主线之后（§5）。
   - **画面预设**主线 3 个：极致 ↔ 独显高，精致 ↔ 独显中，均衡 ↔ 最低配置。预设是一组单项取值，玩家能选、能改；改动任何单项，预设显示为"自定义"。兜底预设"流畅"在主线之后（§1）。
2. **风格底线不做开关**（§2）：描线、分阶明暗与按材质的影色、柔光、平涂贴图、实时阴影、西湖倒影等在任何画质下都保留；低画质只降渲染比例、阴影图、距离和密度，不降画风和近景建模。
3. **单项按生效代价分三类**（`ApplyClass`）：即时（只改数值，含分帧重写）、雾幕（要重建渲染缓冲，点"应用"后在 0.3 s 雾幕里批量生效）、重启（§3）。**会清空管线的设置不做成选项**，各预设统一取值，所以切换设置永远不触发管线编译。
4. **画面设置只改运行时的选级和引擎参数**：不改烘焙产物、碰撞、世界状态和种子，也不按预设各烘一套，所以本机烘焙缓存跨画质共用（D-165）。生成器完全不感知画面设置。
5. **自动调节画质**（只往下调、不超过玩家所选）在主线之后（§5）；主线的单项只有玩家手动设定。
6. **画面设置不影响声音**：声音设置在独立的"声音"页，同存 `settings.json`，各占一节（SYS-SAVE-FORMAT §3）。

### 0.1 接入要点

- **系统要响应画面设置**：在实现 `IQualityAware` 的 `[KernelNode]` 上标 `[QualityResponsive]`，`Owns` 列自己负责落到引擎上的单项（每项恰有一个负责方，G5 核对），`Reads` 列只读的项；设置经 `IQualityAware.ApplyQuality()` 送达
- **读画面设置**：只经 `IQualityService` 和 `ApplyQuality()`，任何包都不读 `settings.json`；着色器要的细节系数、植被密度、草半径读全局参数 `quality`
- **做会画进画面的东西**：风格底线（§2）不做开关，任何预设、手动值、自适应级别都不能关；实时阴影、西湖倒影只能降到最差值
- **给低画质省开销**：只降渲染比例、阴影图、距离和密度，不降画风和近景建模；季节内容只降密度、不缺席
- **新增画面单项**：在 `QualityKnob` 末尾追加（契约只增不改），写好 `KnobSpec` 和 `quality-presets.json` 里各预设的取值
- **新增引擎设置、后期效果或着色器变体**：会清空管线的设置不做成选项；新的可达组合要进启动预热的并集（§3）
- **负责会被自动调节的单项**（主线之后）：每级降档渐变淡化、不硬切；分帧生效，不卡顿
- **界面或其他包改画面设置**：只调 `IQualityService.Plan()`、`Apply()`；跳转、传送、换季、切图、读档、过场等遮挡期间返回 `Deferred`（§4）
- **临时改画面相关的引擎参数**（如开放室内的阴影范围）：作为介质覆盖自己记，不登记 `Owns`，也不进 `QualityView`（§3）
- **门禁、截图、基准要指定画质**：用命令行参数，不读 `user://`；视觉基准是精致预设、自动调节关（ENG-GATES-SHOTS §1）

## 1 预设

各预设的单项取值以 `game/data/quality-presets.json` 为准，数值是初值，P0 在开发机和一台最低配置的笔记本上实测校准（§8）。设计目标如下：

| 项 | 均衡 | 精致 | 极致 |
| --- | --- | --- | --- |
| 对应设备档 | 最低配置 | 独显中 | 独显高 |
| 帧率目标 | 60 | 60 | 跟随刷新率 |
| 内部像素上限 | 最低 | 中 | 最高（4K 输出另有上限） |
| 抗锯齿 | FXAA | SMAA 1x | SMAA 1x |
| 阴影 | 2 级级联、中距 | 4 级级联、远距 | 4 级级联、远距、最高精度 |

- 各档内部像素上限的数值以 `game/kernel/frame/KernelBudgets.cs` 为准。渲染比例按"内部像素上限"换算到最接近的 FSR1 比例，不写死比例；该输出分辨率下内部像素已低于 FSR1 0.5 的下限时，界面建议改用 1080p 窗口。
- 阴影图、级联、距离的具体数值归 ENG-BUDGET，预设取值见 `game/data/quality-presets.json`。
- 降档的方向：先降渲染比例、阴影距离、细节距离、植被与降水密度、倒影刷新频率，再降柔光与移轴的分辨率；描线、分阶明暗、柔光、平涂贴图始终开，软影滤波与阴影深度各预设固定（§3）。
- **不做**：FSR2、TAA、MSAA（拖影或破坏描线用的材质 ID，ENG-PERF-LIGHT §2.2）；DLSS、XeSS（Godot 4.7 没有）；超采样；HDR 输出（与 LUT + CDL 调色冲突）；纹理质量（降一半就碰到 ART-FIDELITY §3 的贴脸纹素底线）。
- **一拍二的步频**随帧率上限变化：上限 30（含 60 Hz 屏的半刷新率）时每个姿态正好 2 帧，其余取 12（SYS-MOTION §2.2）。

主线之后：兜底预设"流畅"（比均衡更低的像素上限、FXAA、近距级联），不对应设备档，供重场景和自动调节兜底。

## 2 风格底线与风格默认

| 类别 | 内容 | 规则 |
| --- | --- | --- |
| **风格底线**（没有开关） | 描线；分阶明暗与按材质的影色（含透光元素的逆光透射）；柔光（白天只晕高光，黄昏以后才叠一层全帧柔光，ART-STYLE-LINES §2.1）；高光肩部；平涂贴图；雾、天空、调色板与 LUT；窗灯、路灯光斑与亮窗室内；室内窗光斑；季节内容（只降密度，不缺席）；一拍二；剖切与介质呈现 | 任何预设、手动值都不能关（自适应在主线之后，同样不能关） |
| **风格底线**（有最差值） | 实时阴影；西湖倒影 | 只能降到最差值（阴影图与级联、倒影分辨率与刷新间隔的最差值见 `game/kernel/quality/settings/QualityCatalog.cs`） |
| **风格默认**（可关） | 移轴；镜头光斑；光柱（室外软边光柱与室内窗格光柱、细尘一起开关）；暗角（分调烘在 LUT 里，随 LUT 属风格底线，不跟着关） | 各预设默认都开；单项开关在主线之后（也满足无障碍"动态效果要能关"）；关掉之后的画面不进入验收 |
| **性能项** | 其余各项 | 按预设取值，玩家可调 |

**一票否决**：任何预设或手动值下，风格底线里的任一项消失，或实时阴影、西湖倒影低于最差值。

风格底线按 ART-STYLE 的"清透干净"：影子以明度为主、按材质推导，不做接触影；白天只让高光晕开；贴图以平涂为主，斑驳只留在近处。这些是画风，不随画质关掉。

**描线在低渲染比例下不能变糊**：描线通道在放大之前、按内部分辨率执行，线宽随内部高度换算，内部不足 1 px 的线按覆盖率画并设最小宽度，保证放大后上屏的线仍是清楚的 1 px 左右（ENG-PERF-LIGHT §2.2）。

## 3 单项与生效方式

生效：**即时**；**雾幕**＝点"应用"后在 0.3 s 雾幕里生效（重建渲染缓冲，不编译管线）；**重启**＝下次启动生效。具体取值范围与负责方以 `KnobSpec` 和 `quality-presets.json` 为准。

主线的单项（约 10 项）：

| 组 | 单项 | 生效 |
| --- | --- | --- |
| 显示 | 显示模式（窗口 / 无边框全屏默认 / 独占全屏）、窗口尺寸 | 雾幕 |
| 显示 | 垂直同步、帧率上限 | 即时 |
| 清晰度 | 渲染比例（内部像素上限）、抗锯齿 | 雾幕 |
| 光影 | 阴影质量、阴影距离 | 即时 |
| 植被 | 植被与草密度 | 即时 |
| 水 | 西湖倒影刷新间隔 | 即时 |
| 粒子 | 降水与粒子密度（萤火虫不降） | 即时 |

主线之后：可变刷新率；FSR 锐度、各向异性过滤；细小物件投影（雾幕类，避免小件影子在一帧内消失）；柔光质量、移轴、镜头光斑、光柱、暗角的单项开关（即时，关闭时 0.5 s 淡出，不改管线）；细节距离（分帧重写；外围随之）、模型 LOD 精度；近景几何叶、草地范围；自动调节画质开关；图形接口（D3D12 默认 / Vulkan）与显卡选择（重启类，需要引擎启动前读取的独立 `engine_override.cfg`，只写登记过的几个键）。这些项在主线按预设固定取值。

**固定不做选项的引擎设置**（各预设统一，保证切换不编译管线）：软影滤波档位（改一次会清空全部已编译管线；三渲二对阴影做了阈值化，影响很小）；阴影深度固定 16 位；MSAA、SSAO、SSR、体积雾不用；遮挡剔除没有画面差，由程序按视角自动开关。

**介质覆盖**（不是玩家单项，WLD-INTERIORS）：镜头在开放室内时，介质服务把方向光阴影的第一级范围缩小，0.5 s 内过渡，出楼恢复；它叠在阴影设置之上，自动调节和玩家的设置都不动它，`QualityView` 也不报告它。进入室内时抬高阴影方向最低高度同属介质呈现，不是画面单项。

**启动预热**：扉页后面的预热覆盖"各预设和所有单项取值能到达的组合"的并集（SMAA 与 FXAA 两套后期、移轴两种分辨率），所以玩家怎么切都不再编译管线。

## 4 应用方式

1. 界面只调用 `IQualityService.Plan()` 和 `Apply()`。
2. **即时类**：拖动就预览，短去抖。
3. **雾幕类**：标成"待应用"，点"应用"或收起设置卡时一次提交：雾幕淡入 → 按负责方依次执行（显示与渲染比例 → 阴影 → 后期 → 各向异性 → 选级）→ 描线纹理缺了就重建 → 等流式各环就绪（最多 1.2 s）→ 雾幕淡出，管线编译计数的基线在这一刻重置。
4. **重启类**：写盘并提示"重启后生效"，提供"立即重启"。
5. **排队**：跳转、传送、模式切换、换季转场、回位、切图、读档、进场过场与返回标题进行中，`Apply` 返回 `Deferred`，等它们结束再执行；切图途中提交的雾幕类改动并进切图的雾幕一起生效（SYS-MAPS）。

主线之后：改显示模式、窗口尺寸、渲染比例后的 15 秒"保留 / 还原"确认（不确认自动还原）；设置生效的那一帧及其后 2 s 不计入自适应统计。

## 5 自动推荐与自动调节（主线之后）

**首次分档**在扉页后面做完（SYS-TITLE §1），只按显卡名、显存、是否 UMA 判档：

1. 读显卡名、厂商、驱动，再读 Godot 正在用的适配器的显存预算与是否 UMA。**不用**"适配器类型"判核显（D3D12 下核显也会报几十到几百 MB 的专用显存），也不用 WMI 的显存数（封顶约 4 GB）。
2. UMA 或专用显存小于 1 GB 判为核显，一律归最低配置；独显按显存预算和名称判高或中；判不出来的取保守结果（核显取最低配置，独显取独显中）。
3. 设置页可"重新检测"；玩家判得不准时手动改一档即可。
4. 结果写进 `settings.json` 画面节的设备段，推荐预设设为当前预设。首次启动时开始页菜单下方显示一行"已按本机推荐：极致 · RTX 4080 · 设置 › 画面"。

**之后**：玩家手动选过预设，下次启动不覆盖。只有显卡名、驱动版本或输出分辨率变了才重新检测，推荐变了用一条临时提示告知，不自动改玩家的选择。

**自动调节画质**（默认开）：

- 实际生效值 = clamp(min(玩家所选, 自适应上限), 最差值)。只往下调，回升不超过玩家所选。
- 只动"即时"类的性能项：细节距离、模型 LOD 精度、植被与草密度、降水与粒子密度、倒影刷新、柔光质量、阴影距离与级联。不动渲染比例、显示设置和风格底线。
- 玩家手动改过的项被锁定，自动调节跳过它。每级降档渐变完成，不硬切。
- 界面用一行小字写明当前自动降了哪些项，例如"已自动降低：植被密度、阴影距离"。关闭时只保留帧节奏控制。控制律、样本剔除、发热漂移沿用 ENG-PERF-ADAPT §1.2。
- 开始页、进场过场、返回标题期间自适应冻结，这些帧全部剔除出统计；传送的雾幕帧、存档抓缩略图的那一帧同样剔除。

## 6 持久化与恢复

- **画面设置存在 `user://settings.json` 的 `graphics` 节**，文件的权威规则在 SYS-SAVE-FORMAT §3。本节存：当前预设、手动覆盖项（只存与预设不同的项）；主线之后再加显卡与驱动、设备档缓存、自动调节开关。
- **优先级**：命令行 > `settings.json` > 默认值（精致）；主线之后在默认值前加自动推荐。门禁和基准只由命令行决定，不读 `user://`。
- **恢复画面设置**：改坏了游戏起不来时，发版说明里写"删除 user 目录下的 `settings.json`"，下次启动按默认值走；存档不碰。

## 7 画面页（WP-35，视觉见 UI-VISUAL-COMPONENTS §5）

- 设置卡的"画面"页分组列出 §3 的单项，"显示"一组也在这一页。"界面缩放""大页磨砂""降低透明度""界面主题"不是画面单项，留在"设置"页（UI-NAV §3.5）；声音在"声音"页。
- 页首是预设的分段选择：均衡、精致、极致、自定义。主线之后在下面加一行推荐与重新检测。
- 每行是"名称｜控件｜生效标签"：没有标签 = 即时，"雾幕"、"重启"各有标签。
- 悬停或聚焦某一行时，底部注释栏显示说明与负载标签（GPU、显存、CPU 的大中小）；雾幕类配两张对比小图，由截图机按固定视角出。
- 即时类直接看身后实景：画面页只占左侧约 1/3，右侧场景实时变化，不压暗。
- 设置卡是大页，随昼夜主题切换；轻度磨砂随设备档（独显档默认开、最低配置档默认关），"降低透明度"打开后一律不透明。
- 从开始页打开时，右侧是实时的 T0；雾幕类改动照常生效。
- 页脚注："描线、分阶明暗与按材质的影色、柔光、平涂贴图、实时阴影与西湖倒影是本作画风，任何画质下都保留。"
