# SYS-TIME · 时间与季节系统：世界状态、美术日月、过渡口径

> **范围**：本文规定世界状态（钟点、季节、天气）的语义、时间只向前的规则、默认状态、美术太阳与月亮的轨迹、过渡的定目标顺序与改时间用时、质量底线。
> **不在本文**：色彩脚本、四季内容、灯光时刻表（SYS-TIME-LOOK）；过渡的编排、时长与同时转场（SYS-MOTION §3）；偶发事件（SYS-MOTION-LIFE §3）；天空、主光、阴影、雾的观感取值（ART-SKYLIGHT）；天气清单、画面与自动天气（SYS-WEATHER）；接口签名与每帧顺序（`game/contracts/`、ENG-ARCH §3）；存档与世界实例（SYS-SAVE）；按图的默认状态（SYS-MAPS）；时间环与界面主题（UI-NAV、UI-VISUAL）。
> **查阅**：先读 §0；世界状态与时间规则看 §1；日月看 §2；定目标的顺序与改时间用时看 §3；质量底线看 §4；色彩脚本、四季内容与灯光时刻表看 SYS-TIME-LOOK

## 0 结论

时刻和季节都能在界面上调，每种组合都要好看，切换自然过渡、不硬切；视觉优先，真实数据只作参考（CORE-INDEX §0）。

1. **默认状态"落金初灯"**：秋季 17:30、1×、晴、自动天气，天气保持晴到秋季黄昏带结束（约 19:36）。它是新游戏交还控制那一刻的终态，任何种子下画面相同（§1.1）。
2. **世界状态三个量**：钟点、季节、天气。世界时间只向前，钟点由它换算；季节不自动推进；自动天气是种子与世界时间的纯函数（§1.2）。
3. **太阳和月亮走美术轨迹**，不按天文。正午高度压低避免平光；秋 17:30 落在设计好的低太阳上，高度与方位的目标见 ART-SKYLIGHT §1（§2）。
4. **过渡只有一份详述**：改时间像延时摄影快进，最长 3 s；换季走扬起、雾幕、落定；换天气连续插值。编排和时长以 SYS-MOTION §3 为准，本文只定目标的顺序和改时间用时（§3）。
5. **质量底线**：无硬切、明度、影色、只改参数与全局纹理内容（§4）。

### 0.1 接入要点

- **读钟点、季节、日月、天气**：C# 只经 `IWorldState`，不自己写计时器；着色器只读 WorldState 写的全局着色器参数（§1）
- **改时间、季节、天气或套用推荐状态**：只经 `IWorldControl`；时间只向前，换季一律正向转场；读档经存档段恢复，不经它（§1.2、SYS-MOTION §3）
- **每帧要用本帧世界状态**：用 `ProcessPriority` 排在 WorldState（−1000）之后，顺序以 `FramePriority`（ENG-ARCH §3）为准，任何两步不得同值
- **着色器要用时间**：禁用内置 `TIME`，周期动画读 `anim_time`（480 s 循环，与世界时间无关）
- **界面显示世界状态或天气**：直接读世界状态的只读接口，不另存副本（§1.2）
- **世界实例换了（读档、新游戏）**：`Instance` 变化的那一帧自己的过渡直接落到新值；不跨实例比较 `WorldHours`（§1.2）

## 1 世界状态与时间规则

### 1.1 默认状态

- 秋季 17:30、流逝 1×、晴、自动天气，天气保持晴到秋季黄昏带结束（约 19:36，SYS-WEATHER-PROCESS §1.6）。名字"落金初灯"。
- **新游戏的终态**：过场从秋 17:05 正向推到 17:30 停住（完整版 60×，简短版 360×，关与跳过 1440×，同一条世界轨），交还控制时转 1×；所以任何种子下交还那一刻的画面相同（SYS-TITLE-CINEMATIC §4）。
- **按图**：默认状态是每张图的 `world.default`（SYS-MAPS §2）；新游戏一律从起始图的默认状态开始。
- **开始页**显示最近存档的世界状态（无存档时是新游戏的终态），流逝冻结（SYS-TITLE §3）。
- **回到默认状态**（`ResetDefault()`）：正向换季转场、快进到下一次出现的默认钟点、流逝 1×、自动天气，`quietUntilDusk` 为真时保持晴；种子不变，不移动镜头，不换实例。清水河上按钮名是"回到落金初灯"（SYS-MAPS §4）。

### 1.2 三个量与时间规则

- **钟点** c ∈ [0, 24)；**季节** s ∈ [0, 4)，循环量，整数锚点 0 春、1 夏、2 秋、3 冬；**天气**对外是"天气格 + 自动 / 手动"，对内是连续的天气向量（SYS-WEATHER §0）。
- **世界时间 `WorldHours` 单调递增**：同一个世界实例里任何操作都不让它减小；时间环只能往前拨，自动天气随世界时间求值。钟点 = (`WorldHours` + offset) mod 24；offset 只在换季时重算，用来保持太阳在弧线上的位置不变，钟点数字可能变小，但太阳不倒走。
- **换实例不算倒流**：新游戏、读档是换一个世界实例（`IWorldState.Instance` 加 1，SYS-SAVE-FLOW §2.2）；那一帧钟点追随、换季转场、天气过渡、主光量化、窗灯错开、界面主题回差一律直接落到新值，这一刻总在遮挡之下。"回到落金初灯"不换实例。
- **没在玩的时间不计**：关着游戏的现实时间不计入世界时间，读档不补算（SYS-SAVE-FLOW §3）。
- **跨图**（SYS-MAPS §4）：世界时间、季节、流逝倍率、`AnimTime` 全局共享，切图不变；自动天气按图求值，是种子、地图、世界时间的纯函数，无按图状态。
- **`AnimTime`**：风、水、"一拍二"用的动画时间，与世界时间分开，按 480 s 循环；拖动、快进、暂停都不影响它的节奏。
- **钟点追随**：显示钟点用临界阻尼弹簧追随目标，只增不减、不过冲。
- **拖动时间环**：只能顺时针，约每转 15° 前进 1 h；逆时针拖时把手停在原处，目标不变。拖动中流逝暂停，松手 1 s 后继续。云按世界时间积分，其余动画节奏不变。
- **跳转钟点**（`SetClock(h)`）：跳到**下一次出现**的钟点（最多前进 24 h，已在该钟点就不动）；拨到更早的钟点就是快进到次日。`.` 键前进 1 h。都做延时摄影式快进（SYS-MOTION §3.1）。
- **自动流逝**六档：暂停、1×（默认）、10×、60×、360×、1440×。暂停只冻结世界时间和天气，`AnimTime` 照走。**季节不自动推进**。
- **`FlowTo(clock, rate)`**：以 `rate` 正向流逝，到下一次出现的 `clock` 时正好停住；再次调用 `SetFlow` 或 `FlowTo` 取消上一次。新游戏过场靠它。
- **界面读数**：直接读世界状态的只读接口，不另存副本；界面主题（晶白 ↔ 深屏）按真实太阳高度离散切换，由 `UiThemeClock` 判定，WorldState 不写（UI-VISUAL §3.4）。

## 2 美术太阳与月亮

### 2.1 太阳

- 白天：u = (c − 日出) / (日落 − 日出)，高度 h = H · sin(πu)^1.15（指数大于 1，让黄金时刻比正弦曲线长约 15%）；方位从日出方位线性走到日落方位；夜间同一公式取负，H 取 24°。
- **硬约束**：秋 17:30 的太阳必须落在 ART-SKYLIGHT §1 规定的高度与方位上，以保留默认状态的全部设计；默认状态的黄昏太阳高度与方位的变化范围也见该节。
- 日出日落钟点、方位、正午高度上限以 `game/contracts/World/ArtEphemeris.cs` 为准：

| 季 | 美术意图 |
| --- | --- |
| 春 | 清晨西边雪山被照亮，日照金山 |
| 夏 | 日落故意压在西岭雪山的剪影上（日落方位约 272°） |
| 秋 | 默认状态：沿银杏大道投下长影 |
| 冬 | 低角度暖阳，雪地上的影子发蓝 |

- **正午高度压低**（春 55°、夏 62°、秋 41°、冬 34°）：避免平光，并把方位角速度控制在每小时 14° 以内，阴影更稳定。

### 2.2 月亮

美术满月，四季相同，换季时月相不变；四季都在黄昏从方位 62°（东北偏东）升起，夜间沿美术弧线最高 48°（夏季 38°），黎明落在 300° 附近，保证 V8、P14 任何季节都框得进月亮；默认状态的黄昏月亮高度 1°→3°。外观与月影见 ART-SKYLIGHT-ATMOSPHERE §2、ART-SKYLIGHT §3.1。

### 2.3 与主光的关系

只有一盏主光，日月轮流担任，规则见 ART-SKYLIGHT §3、ART-SKYLIGHT-ATMOSPHERE §1.9。

## 3 过渡

过渡的编排、时长、同时转场和打断规则只在 SYS-MOTION §3 详述；本节只定两点。

- **定目标的顺序**：季节 → 钟点 → 天气。先按目标季节定太阳弧线和 offset；再在新季节里定目标钟点；最后按新季节、新钟点取目标天气，不合季节的先替换。点位推荐和"回到落金初灯"都按这个顺序。
- **改时间用时**：向前快进到下一次出现的钟点，用时 = 0.6 + 0.18 × 前进小时数，上限 3 s（快进的表现见 SYS-MOTION §3.1）。

## 4 质量底线

- **无硬切**：录一段过渡看有没有硬切（有雾幕遮罩的区间除外），这是全部过渡的统一判据，SYS-MOTION、SYS-WEATHER 指向这里。时间只向前：同一世界实例里 `WorldHours` 不减，太阳在弧线上的位置不倒退。日月换向只发生在 `shadow_strength` = 0 的帧。
- **明度**：固定机位截图看一眼，默认格和白天格明亮通透，不灰不黑。
- **影色**：按 ART-STYLE-SHADING §2 的推导规则；白天和黄昏只看明度与身份色，夜间看蓝紫；主体与背景分得开，雨天雾天照样；夜间暗部不死黑，窗灯不占满画面。
- **只改参数与全局纹理内容**：改时间、换季、换天气不切特化开关，管线编译计数不增（ENG-GATES §1）。
- **好看**：默认格加每季一张英雄帧的截图，看一眼好看即可（ENG-GATES）。
- **一票否决**（天气项）：天气残留、闪电硬切或全屏闪白（SYS-WEATHER §7）。
