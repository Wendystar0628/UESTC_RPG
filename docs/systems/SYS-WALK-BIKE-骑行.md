# SYS-WALK-BIKE · 骑行

> **范围**：本文规定骑共享单车这条运动分支：运动规则、可骑范围与许可、边界与下车、取车、还车、临停与回收，以及骑行与存档的关系。
> **不在本文**：行走的身体、手感、模式切换与控制器（SYS-WALK）；可行走范围、边界与碰撞（SYS-WALK-BOUNDS）；骑行时的镜头（SYS-WALK §3）；单车的外观与停放点的陈设（WLD-LIFE-STREET §1）；停放点在地图上的标记（SYS-ATLAS-TRAVEL §1）；存档容器（SYS-SAVE）；运动与取还的实现（`game/camera/walk/` 与车辆运行时）。
> **查阅**：先读 §0；运动、可骑范围、边界与下车、取车还车临停回收看 §1；待验证看 §2

## 0 结论

1. **骑行是行走里的运动分支**，与步行、游泳互斥，`ViewMode` 与人称不变；只在许可区里骑（§1）。
2. **可骑范围是显式许可**，由 WP-44（可行走范围、边界与安全点）烘焙；缺数据不当作可骑（§1.2）。
3. **下车做一项站姿净空检查**，不过就保持骑姿并提示，不传到安全点冒充下车（§1）。
4. **取车就上车、还车就还**；读档一律恢复成步行，借的车视为已归还（§1）。

### 0.1 接入要点

- **登记可骑范围**：可骑数据显式授权，缺数据不当作可骑（§1.2）
- **登记停放点**：连着可骑面、上下车空间和步行路径（§1.2）
- **瞬移或换图时碰到骑行**（切旁观、跳转、地图传送、换图、回位）：借用结束，车回收到来源槽位；先准备，被接受后才提交（§1）

## 1 骑行

唯一的载具是匿名共享单车（外观与停放点见 WLD-LIFE-STREET §1）。

### 1.1 运动

- 运动学解算，不做刚体平衡和轮胎模拟：W 蹬车，松开滑行，S 制动，停住后按住 S 低速后退（P0 必须有，用来从面墙或下不了车处退出）；A、D 转向，车速接近 0 时不改车向；鼠标只管看向。
- 每步核对可骑许可、前后支撑、转弯外缘与车尾、头顶净空，缺数据不当作可骑；水平速度 ≤ 12 m/s。
- 骑行时不发脚步、没有步行晃动，有骑行声、制动声、链条声，无车铃；自动登阶不给车用。B 是取车、上车、下车与还车（可改键）；空格、Shift、Ctrl 不起作用；双击空格、F、长按 R 照常切旁观与回位。

### 1.2 可骑范围

- **可骑范围**：已授权的道路、广场、无台阶坡道和核过的桥面，连成一张网。草地、窄栈道和高处不开；楼梯、连续踏步（含做成坡面的梯段）、室内、楼上与屋顶、水域一律不能骑；半室外街廊逐段定。
- **许可是显式的**：可骑数据由 WP-44（可行走范围、边界与安全点）烘焙，桥上桥下同一 XZ 不串层；坡度分级、`RampCollider`、铺装材质和 2 m 分类栅格都不单独授权骑行。
- **停放点**：区包登记，连着可骑面、上下车空间和步行路径；在地图上是可追踪、不可传送的标记（SYS-ATLAS-TRAVEL §1）。

### 1.3 边界与下车

- 前方是台阶、门口、禁骑区或未就绪的数据时，按速度、坡度和制动能力提前减速，停在许可区内：朝禁骑一侧的速度分量压到 0，转离的分量保留；不撞停、不反弹，停住后出一次提示。
- **手动下车**：停稳后按 B。站姿净空检查通过才下车；不过就保持骑姿并提示下不了车，不强行站起，也不传到安全点冒充下车。自动下车和推行不做。

### 1.4 取车、还车、临停与回收

- 取车就上车、还车就还，车不复制、不丢失。同时只借一辆，借新车时原来临停的那辆一并回收。
- **取车**：步行着地，站在可借的车旁按 B 上车。**还车**：骑进停放点登记范围、停稳后按 B，停放点满了不算归还。
- **临停**：在停放点以外下车，车停在合法的室外位置，仍算借着；进楼不带车。
- **回收**：切旁观、跳转、地图传送、换图、回位时借用结束，车回到来源回收槽，来源失效时迁到备选点；先准备，被接受后才提交。车的消失放在起飞或雾幕的转换呈现里。
- **存档**：读档一律恢复成步行，借的车视为已归还；骑行中保存存最近的安全点。
