# SYS-MOTION · 动态与事件

> **范围**：本文规定所有会动的东西共守的框架：世界时钟与动画时钟、计时规则、一拍二与动作幅度上限，以及转场（改时间、换季、换天气、跳转、传送、换图、同时转场）的唯一详述。
> **不在本文**：风、飘落物、流体、光与远景的缓慢变化、季节氛围、粒子类的解析运动（SYS-MOTION-ENV）；生命体与反应动物、室内与钟楼的微动、偶发事件（SYS-MOTION-LIFE）；世界状态与美术日月（SYS-TIME）；天气向量、降水池与天气画面（SYS-WEATHER）；跳转与模式切换的镜头运动（UI-NAV、SYS-WALK）；开始页（SYS-TITLE）；声音的实现（SYS-AUDIO）；代码实现（`game/systems/` 下）。
> **查阅**：先读 §0；两个时钟与计时规则看 §1；一拍二看 §2.2；转场看 §3；风、飘落物、流体、远景、季节氛围、粒子类看 SYS-MOTION-ENV；动物、室内微动、偶发事件看 SYS-MOTION-LIFE

## 0 结论

1. **两个时钟**：世界时钟（只向前）驱动日月、主光、灯、季节和天气；动画时钟 `AnimTime`（帧间隔累加 mod 480）驱动风、水、一拍二和动物的小动作，不受拨时间环、快进、暂停、倍速影响（§1.1）。
2. **计时只用帧间隔累加**：着色器禁用 `TIME`，不读系统时钟；周期量取 480 s 的整数分之一（§1.2）。
3. **一拍二**：落叶、波纹线、布料、动物小动作、雨丝等按 `step_rate`（固定 12 Hz）步进；镜头、光、雾和玩家身体保持连续（§2.2）。
4. **所有动作轻、慢、持续**，幅度都是上限，例外只有雷雨里银杏摆角 4° 和鸽群被身体惊动时的局部惊飞；镜头不做自动运镜（§1.4、§2.1）。
5. **转场只往前走、不硬切**：换季一律"扬起 → 起雾 → 落定"；本文是转场的唯一详述处；闪电、远雷、彩虹是天象状态，既不算转场也不算偶发事件（SYS-WEATHER §5）；无硬切的判据见 SYS-TIME §4（§3）。

**子文档**：

| 编码 | 简题 | 什么时候读 |
| --- | --- | --- |
| SYS-MOTION-ENV | 风与环境动态 | 做随风动的东西、飘落物、流体、光与远景的缓慢变化、季节氛围、粒子类时 |
| SYS-MOTION-LIFE | 生命体与偶发事件 | 做动物与反应动物、室内与钟楼微动、加改偶发事件时 |

### 0.1 接入要点

- **要用时间或周期**：周期动画读 `anim_time`，周期取 480/k；不用 `TIME`、计时器节点、系统时钟；真实秒用帧间隔累加（§1.2）
- **要做一拍二**：用公共 `t12()` 或 `IWorldState.Step12`，不自写取整（§2.2）
- **新增会动的元素**：轻、慢、持续，幅度不超过本文上限；室内不做让人觉得"人还在"的动态（§2.1、SYS-MOTION-LIFE §2）
- **观者发起的过渡**（跳转、传送、切图、读档）算转场：偶发事件 0.5 s 淡出，20 s 计时重新开始（SYS-MOTION-LIFE §3、本文 §3）
- **要读"减少动态效果"**：经 `IMotionSettings`，开启时转场一律用 0.5 s 交叉淡化（§3.6）

## 1 时钟与计时

### 1.1 两个时钟

- **世界时钟**：`WorldHours`（单调递增）换算出 `Clock` 和 `SeasonPos`（SYS-TIME §1）。拨时间环、跳转和流逝只让它前进；换世界实例不算倒流。驱动太阳、月亮、主光、调色板、灯光时刻表、季节内容、云的漂移和自动天气。
- **动画时钟**：`AnimTime` = 帧间隔累加 mod 480，着色器读全局 `anim_time`，按真实时间推进。驱动风的相位场、水面波纹、一拍二、动物的小动作、银杏灯、萤火虫、雨丝和雪花的下落。云的漂移是世界时间项加动画时钟项（SYS-MOTION-ENV §5）。
- 天气随世界时间前向推进，表现只读天气向量（SYS-WEATHER-PROCESS §2），本系统不另设天气计时。偶发事件和转场的计时一律用真实秒。

### 1.2 计时规则

- 每帧 `AnimTime = (AnimTime + delta) % 480`，单帧 delta 上限 0.1 s；"真实秒"是另一个只增不绕的累加。不读 `DateTime.Now`、`Stopwatch`，不用计时器节点。
- **禁用 `TIME`**：它受 `Engine.TimeScale` 缩放且每 3600 s 回绕；白名单着色器出现 `TIME` 不能推送。`Engine.TimeScale` 固定为 1，倍速只改世界时钟。
- **可复现**：Movie Maker 下 delta 恒定，同一组命令行参数每次出的帧序列相同。
- **480 s 回绕无缝**：周期量的周期取 480 s 的整数分之一（阵风 15 s、喷泉 8 s、银杏灯 6 s、萤火虫 1.5–3 s）；有自己寿命的东西用 τ = mod(anim_time + φ, 480) 作局部时间。8 分钟才回绕一次，回绕处轻微跳一下不追。

### 1.3 各档流逝的表现

- **暂停**：世界时间停止；风、水、动物照常动；天气冻结，但雨丝和雪花照常下落。**60× 及以上**：主光角速度超过 0.05°/s，不触发偶发事件，也没有闪电（SYS-WEATHER §5）；天气过渡的最短真实时间见 SYS-WEATHER-PROCESS §1.5。

### 1.4 镜头

镜头完全由观者控制，不做任何自动运镜。例外是观者自己的操作触发的过渡：点位跳转、传送、模式切换、行走回位（路径来自数据）。到达或交还控制之后镜头不再自己动。

## 2 节奏规则

### 2.1 幅度

所有动作都轻、慢、持续。本文给出的幅度和频率是上限，宁可再小一点。

### 2.2 一拍二

落叶、水面波纹线、旗面、布料、热气、动物的小动作，以及雨丝、溅落、雨点环、檐滴，都按 `step_rate` 步进，帧间不插值，就像日式动画的"一拍二"。

- 固定 12 Hz（60 fps 时每个姿态保持 5 帧），截图和门禁也一样；帧率上限没有 30 一档（DECISION-309），不再随帧率换步进。
- 步进由公共 `t12()` 算出，所有一拍二的东西在同一帧换姿态；CPU 侧读 `IWorldState.Step12`，与着色器在同一网格上。T12 来自动画时钟。
- 界面里"被计算出来的"动效（量化出入场、网格逐格点亮、图标换帧）按同一个 `step_rate` 步进，位移、透明度和颜色仍连续补间。
- 镜头、太阳、光照、雾、月亮、钟点追随和季节进度保持连续；**玩家身体的骨骼姿态也连续求值**，否则支撑脚会滑动。

### 2.3 偶发事件

全片只有一个（SYS-MOTION-LIFE §3）。其他动态不能有突发的大动作；唯一的定向例外是鸽群被行走身体惊动时的局部惊飞（SYS-MOTION-LIFE §1.1）。观者触发的过渡按 §3 做，不能硬切。

### 2.4 声音的节奏

一次性声的排程、限量与倍率规则以 SYS-AUDIO §3 为准；连续量与画面共用同一个风场和 `wind`；离散的动作（逐棵抖落、收尾的旗、钟锤落下）由本系统发同步提示，声音不另算一份时刻。

## 3 转场

观者在界面上发起的过渡统称"转场"：改时间、换季、手动换天气、点位跳转、模式切换、传送和换图。转场要自然，不能硬切；不算偶发事件，也不算自动运镜；所有转场都只往前走。本节是转场的唯一详述处。声音按转场阶段编排（SYS-AUDIO §3）；转场打断时，偶发事件已排队的声音整批取消。

### 3.1 改时间

拨时间环只能顺时针，钟点追随半衰期 0.15 s。跳转做延时摄影式快进到下一次出现的钟点，**用时 = 0.6 + 0.18 × 前进小时数，不超过 3 s**（公式只写在这里）。

- 长影扫过地面；云按世界时间积分、加速漂移；窗灯按哈希错开依次亮灭；跨过日出日落时主光在蓝调里完成交接。
- 天气随世界时间推进，画面上的过渡见 SYS-WEATHER-PROCESS §1.5。
- 声音按真实秒排程，快进时钟声广播不补（SYS-AUDIO §3）。

### 3.2 换季

一个季节 4 s，跨两个季节及以上 5.5 s。季节值向前展开（秋 → 夏依次经过冬、春），中间的季节藏在起雾里。一律用同一套正向转场：**扬起 → 起雾 → 落定**，粒子只往下落、不倒放，倒放像时间倒流。

| 阶段 | 发生什么 |
| --- | --- |
| 0–0.8 s · 扬起 | 阵风加强到 2.5 倍，飘落池喷出上一季的叶、瓣或雪团 |
| 0.6–2.6 s · 起雾 | 阵风回落；起雾距离与剪影距离一起向近处收（远处先沉）；柔光 +0.1，整体提亮不超过 25%（ART-SKYLIGHT-ATMOSPHERE §3.4）；当前天气不合新季节时就地替换（§3.4） |
| 2.0–4.0 s · 落定 | 新一季的粒子落下；季节性动物和生活痕迹在起雾中换上；地面覆盖再用 2–4 s 阈值生长到位 |

- **风过换季**：季节进度从西湖开始向东推过全校，每棵树的相位 = 0.6 × hash + 0.4 × 它在风向上的位置，最多错开 0.3。
- **太阳**：保持太阳在弧线上的位置不变，黄昏仍是黄昏；世界时间不变，只重算钟点 offset（SYS-TIME §1.2）。
- **防止中间态难看**：每个元素只在两个好看的端点之间做阈值切换，树冠团块沿 OKLCH 走"绿 → 黄绿 → 金 → 橙 → 锈红"；禁止草与雪、花与叶直接混色；中间态藏在起雾和粒子后面。
- **声音**：季节层（鸟、虫、蝉、蛙）在起雾段交叉，不会出现"冬天的蝉"（SYS-AUDIO §3）。
- 换到前一季走同一套正向转场；中途可打断，从当前季节值重新定目标，粒子继续飘；世界时间不减。

### 3.3 跳转、传送与模式切换

镜头运动由 UI-NAV、SYS-WALK 负责，跳转的方式见 UI-NAV-WAYPOINTS §2.1，传送时序见 SYS-ATLAS-TRAVEL §3.2；本系统只保证途中风、水、动物照常。传送与游戏内换图一律经加载界面（SYS-TITLE §3.1），加载界面盖住期间旧图的飘落池槽位、季节专属物件和偶发事件全部清掉，`anim_time` 不重置。

### 3.4 换天气

手动点天气格、自动天气相变、快进途中的天气过渡，都只让天气向量连续插值：不硬切、不增删节点、不编译管线；编排、时长、手动换天气各参数的延迟和速率规则以 SYS-WEATHER-PROCESS §1.5 为准。自动天气在 60× 及以下按世界时间编排，慢慢发生，不算转场；手动换天气（天气格、Y 键）算转场。

- **锋面**：天气的局部进度沿用风过换季的空间相位 p_i = 1.4p − 0.4x_i（x_i 是风向上的位置，西湖为 0），所以看得见一道从西湖推向东边的前沿：放晴时西边云缝先开，雨西边先停；起雾是湖面 → 低洼 → 雾海爬上截面。
- **随换季替换**：当前天气不合新季节时在起雾中就地替换并给一条临时提示（对应关系见 SYS-WEATHER §1，自动天气重新求值见 SYS-WEATHER-PROCESS §1.5）。途中再换天气从当前向量重新定目标。
- 雨停后仍有雨丝、替换后仍是上一种相态，属一票否决的"天气残留"。

### 3.5 叠加与优先级

改时间、换季、换天气可以同时进行（`WorldTransition` 是位标志）。

- **定目标的顺序**：季节 → 钟点 → 天气（SYS-TIME §3）。
- **共享的效果只做一次，取较大值**：阵风倍数、起雾浓度、柔光增量、整体提亮各取最大；起雾时长取最长；组合转场总时长取最长的一项，不超过 5.5 s。
- 途中被打断时，从各量的当前值按同一顺序重新定目标。

### 3.6 减少动态效果

改时间、换季、换天气、跳转一律用 0.5 s 交叉淡化（旧画面淡到新画面，不用遮挡层），不扬起粒子，不加阵风；闪电关闭；鸽群改为步行让开。开关是设置里的"减少动态"，首次启动默认值读系统设置（"减少动画"），之后以用户为准（UI-NAV §5）。

### 3.7 验收原则

判据同 SYS-TIME §4：录一段过渡看有没有硬切，加载界面盖住的区间除外。

### 3.8 协调者

转场只由一个协调者编排，它不推进钟点、季节和天气，只写风的幅度、飘落池槽位、季节专属物件、动物的整组可见性和偶发事件的淡出系数；新转场从各量的当前值重新定目标。

### 3.9 开始页、进入游戏与读档

进入游戏、返回标题和读档经加载界面（SYS-TITLE §3.1）；Title、Entering、Leaving 禁止偶发事件，交还控制那一刻起计时重新开始。读档是换世界实例，进行中的转场、偶发事件和动物反应都不续播。
