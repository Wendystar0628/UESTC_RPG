# STD-INDEX · 规范总纲

> **范围**：本文是规范域的入口：本域管写文档、写代码，以及命名、坐标与单位等跨文档约定的规范，对所有角色、所有文档和代码生效；列出本域通用的原则和本域全部文档的上下级。
> **不在本文**：各主题的规则与设计（在下面列出的文档里）；全项目的核心准则与信息地图（CORE-INDEX）。
> **查阅**：先读 §0；要找文档看 §1，按标题挑要读的那份，再读它的 §0 与接入要点

## 0 结论

1. **写或改文档读 STD-DOC**，写代码读 STD-CODE，坐标、单位、命名、ID 与确定性写法看 STD-CONVENTIONS。
2. **规范只写一处**：别处引用写"见 STD-xxx §n"，不抄。
3. **规范只管写法，不管内容**：本域规定文档、代码、名字怎么写，不规定某个系统或画面做成什么样，那些在各自的域。

### 0.1 接入要点

- **改一条规范**：同批查出依赖它的脚本和钩子（比如体量上限、文件命名的检查）一起改。
- **在本域新增文档**：主题文档在 §1 加一行、文件头写 `parent: STD-INDEX`；子文档写 `parent: <主题文档编码>`，列进主题文档的 §0 和本总纲的 §1 对应主题下（STD-DOC §5.1、§7）。

## 1 文档树

主题文档在前，缩进的是它的子文档；只列编码与标题。

- STD-CODE 代码结构准则
- STD-CONVENTIONS 坐标单位与命名约定
- STD-DOC 文档写法
