## 0 结论

1. **一句话**：界面是叠在暖色手绘世界上的一层冷光精密仪器。画是暖的，界面是光；**光是信号，不是装饰**。静止时界面只有平面、1 物理像素的发丝线和等宽数字；只有"状态变了""确认了""正在进行"才出现光和运动（§1）。
2. **主色清蓝 #73C9F9**，按 OKLCH 排出 50–950 的阶梯：400 档是清蓝本身，深端的 800、900 两档直接是校色科技蓝 #1961A0、电子蓝 #003F8D，只作小面积的字、线和图标（§3.1）。中性色是带一点蓝的冷灰；语义色只有成功、警告、危险三组。
3. **色彩分工**：场景暖、界面冷。清蓝只在界面层，不进 3D 材质，世界里不放蓝色全息。界面里唯一的暖色点取场景的窗灯色 `window.warm` #FFE0A8，只表示"太阳 / 此刻"。场景里的 `uestc.blue` 仍只给旗面、校车和单车（§2.2）。
4. **两套主题**：白天"晶白"、夜间"深屏"。按真实太阳高度离散切换，带回差（下穿 −0.5° 切到深屏，上穿 +0.5° 切回晶白）。切换时一道扫描前沿在 0.6 s 内扫过全屏，每个像素只处于日态或夜态之一；开"减少动态效果"时直接换。不做连续混色，因为实测连续混色的中点对比度只有 1.0:1（§3.6）。
   - **常驻小部件固定用深屏**：小地图、时间读数、临时提示、到达标题下的推荐小条这类压在实景上的小件，白天也用深屏，不参与切换（完整清单见 §3.6）。ART-STYLE、ART-SKYLIGHT是清透高调的画面，晶白面板在亮墙和天空上分不出来（§2.4）。大页（大地图、设置卡、存档页）和对话框仍按上面的规则随昼夜切换。
5. **面板默认不透明**：晶白约 94%，深屏约 90%，不模糊、不叠纹理。大页（大地图、设置卡、存档页）可选轻度磨砂，独显档默认开、核显档默认关；无障碍设置"降低透明度"打开后一律 100% 不透明（§5.7）。
6. **形状**：每个容器只切左上一个 45° 角（芯片的 1 号脚）；边线一律 1 物理像素；对齐 8 px 网格但不画网格线；小圆点"过孔灯"表示状态；走线只用于连接；衍射光边只给键盘焦点和选中项（§5）。
7. **字体**：中文思源黑体 SC，拉丁字母与数字 Inter，编号、坐标、键帽 JetBrains Mono，全部 SIL OFL 1.1。不用思源宋体，不用书法字（§4）。
8. **组件**：时间是"24 h 天色光谱环"，钟点顺时针增加；天气图标用气象站填图符号；季节用年相位正弦上的一点；速度是 LED 条；存档卡做成"存储模组"；加载不做进度条，等待超过 1.5 s 才亮三颗过孔等待灯（扉页阶段是 4 s，SYS-TITLE）（§7）。
9. **动效**：八个母题分三级使用；被计算出来的东西按 `step_rate` 步进，与 3D 的一拍二同拍；一次性动效用贝塞尔 (.2,.7,.2,1)，可被打断的跟随用临界阻尼弹簧（阻尼比 ≥ 0.9）；辉光只在深色底上，半径 ≤ 4 px，同屏最多 3 处；亮度跳变每秒最多 1 次；每个母题都有"减少动态效果"下的替代（§9、§10）。
10. **实现**：`ui_theme.tres` 由 `game/style/palette/ext/ui.json` 生成；`StyleBoxFlat.CornerDetail = 1` 做切角；两个白名单着色器 `ui_panel.gdshader`、`ui_screen.gdshader`；`rendering/viewport/hdr_2d` 固定为关；界面着色器、MSDF 字形和大页控件都在开场雾幕或扉页后面预热、预建；界面缩放不乘系统 DPI（§11.10）。
11. **窗口图标**是"八角晶片"：图书馆八角穹顶的平面八瓣，画成一块左上切角的芯片（§6.3）。
12. **声也是信号**：界面音效与动效同一套分级，高频事件默认无声，低频编排配一个短而轻的玻璃质感音；设置卡加"声音"页，五组音量是总、环境、动作、界面、音乐。提示音清单和音量默认值以 SYS-AUDIO为准（§9.4、§8.5）。

## 1 设计原则

### 1.1 母题从哪里来

- **身份**：电子科技大学以电子与信息立身，"把校园读成一块芯片"是这个主题最有身份感、也最克制的读法；界面字体和阶梯深端的校色与学校的视觉规范一致（§3.1、§4.1）。
- **只取结构，不取材质**：芯片版图的分层、编号、刻度、45° 走线、1 号脚的切角、过孔、薄膜衍射，这些都是结构，能在暖色画面上保持克制；彩色裸片照片、绿色电路板、CRT、全息箔这些材质一用就廉价。
- **专业感来自规则，不来自特效**：只用一个色相、靠明暗分层，强调色只占很小的面积（上限见 §2.2），2D 菜单不发光。

### 1.2 七条硬规则

1. **细线**：边线一律 1 物理像素；2 px 只给选中指示条（地图路线的宽度由 SYS-ATLAS 定）；不画粗外框。
2. **网格**：8 px 基准网格（4 px 半步），所有元素对齐网格，界面和地图上都不画网格线；数字右对齐、等宽。
3. **留白**：面板内边距 ≥ 16 px，大面板 24 px；一张卡片只有一个主操作；每屏最多一个主按钮。
4. **单色加一点**：清蓝阶梯 + 冷灰 + 墨；暖色只表示"太阳 / 此刻"，一屏最多一处。
5. **光是状态**：闲置界面零发光；只有焦点、选中、"此处"、进行中会亮。
6. **数据要真**：界面上出现的每个数字都来自世界状态、存档或画面设置，不放装饰性数字。
7. **动有因、动有终**：动效只回应操作或状态变化；缓出、可打断、不回弹；揭示类效果每次打开只播一次，不循环。

### 1.3 专业与"土"的对照

| 显得土（一律不做） | 为什么 | 本作的做法 |
| --- | --- | --- |
| 霓虹灯管式的发光字、发光描边，多层彩色外发光 | 光失去信息含义；整屏一样亮等于没有重点；暖色画面会被洗掉 | 光只给状态，半径 ≤ 4 px，只在深屏上出现，同屏 ≤ 3 处（§9.8） |
| 满屏辉光、界面泛光、镜头光晕式的界面特效 | 场景已经有柔光、光斑和光柱，界面再加就是重复 | 晶白主题完全不发光，强调靠深一档的蓝和线变实 |
| 赛博朋克配色：洋红 + 荧光青、荧光黄、荧光绿；彩虹渐变 | 题材套话，与日式背景的清透冲突，与学校身份无关 | 一个色相的明度阶梯加一个暖色点（§3） |
| 数字雨、乱码、假"解码"、打字机逐字出现、无意义的十六进制 | 观众一眼识破是装饰；假数据让真信息也不可信 | 只显示真数据：钟点、太阳、坐标、天气队列、画质负载 |
| 常驻扫描线、CRT 弯曲、故障艺术、RGB 错位、全息闪烁、噪点闪动 | 绝区零式的媒介隐喻，换到电子主题就是最俗的一套，还和三渲二描线冲突 | 扫描只在大转场里扫一次、不留痕（M2）；量化只是 2–4 阶的"采样"（M6） |
| 四角全切或八角的厚 HUD 框、角括号装饰、六边形网格墙纸、满铺电路纹 | "廉价科幻 HUD"的第一特征；纹样当壁纸，信息变噪声 | 只切左上一个角；版图、走线、焊盘只用在地图和连接关系上 |
| HUD 堆叠：四角塞满刻度环、雷达、警示条 | 遮挡画面，违背"画面优先" | 漫游态只有小地图（SYS-ATLAS）和几秒内淡出的临时提示 |
| 透视倾斜的面板、旋转的雷达扫描、循环脉冲波纹、待机呼吸 | 动而无因，抢走风、水、一拍二的注意力 | 静止即安静；呼吸灯只表示"进行中"（M8） |
| 回弹、过冲、橡皮筋 | 手游味，与本作的安静不符 | 贝塞尔不过冲；弹簧阻尼比 ≥ 0.9（过冲 ≤ 0.15%，看不见） |
| Orbitron 一类科幻字体、超粗正文、成段的全大写英文 | 字体本身在喊"我很科技"；中文超粗正文读不清 | 中性的黑体加等宽数字；层级靠字号和明暗，不靠字重堆叠 |
| 3D 世界里的蓝色全息标记、光柱信标、选中描边 | 后加的 CG 界面和手绘世界渲染语言割裂 | 清蓝只在界面层；世界里的锚点是导览亭和导览桩（SYS-ATLAS） |
| 连发的电子提示音、8-bit 嘟嘟声、科幻电流声 | 廉价，且与场景里自然的环境声不配 | 界面音效由 SYS-AUDIO定：风格是轻的玻璃质感正弦音，全部落在同一个五声调式里；高频事件默认无声，只给低频编排配声 |

## 2 与三渲二画面的配合与色彩分工

### 2.1 场景的色彩坐标

3D 世界的美术以 ART-STYLE为准，基调是"清透干净"：整体提亮；分阶平涂；影子按材质推导，以明度为主，浅而透，中性面的影里带一点天光色；描线约 1.25 px，线色由底色压暗，暖处暖棕、冷处青灰；白天只让高光晕开，再加轻暗角和分调；天空是新海诚式。默认格（秋 17:30）的几个关键色：

| 场景色 | 色值 | OKLCH（L / C / H°） |
| --- | --- | --- |
| 暮光地平线 | #FFE1A0 | 0.92 / 0.089 / 86 |
| 主光 `sun.light` | #FFD39C | 0.89 / 0.086 / 73 |
| 窗灯 `window.warm` | #FFE0A8 | 0.92 / 0.079 / 82 |
| 黄金帧天顶 | #4A62A8 | 0.51 / 0.115 / 268 |
| 正午天空中段 | #88C2EC | 0.79 / 0.085 / 241 |
| 暖米白墙的影 `wall.shade` | #A1A6BB | 0.73 / 0.031 / 275 |
| 中性参考影 `shadow.1`（推导值） | #A2A7BD | 0.73 / 0.032 / 275 |
| 描线的暖端 `line.warm` / 冷端 `line.cool` | #4A3426 / #35505A | 0.35 / 0.039 / 53；0.41 / 0.037 / 223 |
| 电子蓝 `uestc.blue` | #003F8D | 0.39 / 0.142 / 258 |

- 影和线的色值是 ART-STYLE推导规则在默认格的结果，以 ART-STYLE为准。受光面上描线的 L 约 0.49。
- 对界面的影响：画面整体变亮（默认格 L 中位 ≥ 0.62，白天格 ≥ 0.74，ART-STYLE），影区 L 0.68–0.80。这让浅色面板更难与画面分开，所以常驻小部件固定用深屏（§2.4）。

场景本来就是暖（H 50–95）对冷（H 220–295）的冷暖对照（ART-SKYLIGHT §8）。清蓝界面站进画面"冷的那一半"，就不是外来物，而是这组对照里冷的一方。界面唯一的暖色点取窗灯色，正好站在"落金 → 初灯"这次交接里"灯"的一侧。

### 2.2 色彩分工

| 色域 | 归属 | 规则 |
| --- | --- | --- |
| 场景的三种跳色（窗灯暖白、砖红、电子蓝） | 场景 | 由场景定，界面不改。`uestc.blue` 仍只用在旗面、校车字样和共享单车上，是场景里唯一饱和的人造冷色 |
| 界面色 `ui.*`：清蓝阶梯、冷灰、墨、深屏底、语义色、一个暖色点 | 界面层（CanvasLayer ≥ 10） | 只在界面层出现，不进 3D 材质、调色板纹理、光照和后期。世界里不出现蓝色的全息标记、光柱信标和选中描边；以后 RPG 需要标记，也画在屏幕空间的界面层上 |
| 校色科技蓝 #1961A0、电子蓝 #003F8D | 界面阶梯的深色端（800、900） | 只用于字、1 px 线、小图标、片名英文行和窗口图标底色；单块面积不超过屏幕的 0.5%，不做大面积填色 |
| 暖色点 `window.warm` #FFE0A8 | 界面（借自场景） | 只表示"太阳 / 此刻"：时间环上的太阳把手、推荐时刻的小点。一屏最多一处 |
| 语义色（成功、警告、危险） | 界面 | 只出现在对话框、临时提示和数值警示里，总是配图标和文字；不算"暖色点"，也不做装饰 |
| 季节花色、银杏金 | 场景 | 不进界面控件（ART-STYLE §8.2） |
| 场景的再现 | 界面里的"画" | 缩略图、存档截图、时间环的天色光谱、地图上的绿地和夜间灯点，属于"再现场景"，可以带场景色；时间环的天色彩度压到 70%，不和暖色点抢（§7.5）。地图的上色规则见 SYS-ATLAS |

- 界面不给画面上色：压暗层用中性的 n-975，不用蓝色。
- 面积：常驻 HUD 里清蓝（300–700 档）的像素不超过界面像素的 15%，不超过全屏的 2%；大页除外。

### 2.3 不打架的细则

1. **清蓝不直接贴在天上**。#73C9F9 与正午天空中段 #88C2EC 的 OKLab 距离只有 0.03 左右，与饱和的天蓝只有 0.04–0.08，几乎同色。清蓝只出现在面板底上，或带 1 px 深色描边；小地图、锚点、光标都先有一层底。
2. **清蓝不当晶白主题的正文字色**。#73C9F9 在晶白面板上只有 1.75:1。晶白主题里蓝字一律用 800 档（≥ 5.4:1），线和图形用 700 档（≥ 3.8:1）；300–500 档只作填色，上面压墨字。深屏主题反过来，300–400 档是字和线。
3. **投影用墨，不用黑**：界面投影用带蓝的墨色 #192A44，不用黑。
4. **界面的光弱于场景的灯**：界面最亮的像素不超过窗灯 `window.warm` 的亮度；辉光只在深屏上（§9.8）。
5. **季节不进界面颜色**：季节只体现在图标和文字上。
6. **天气不进界面材质**：界面不淋雨、不起雾；天气只体现在天气格和预报行。
7. **界面不吃场景后期**：暗角、分调、高光肩部、LUT 都在界面之前完成（ART-STYLE的后期链），界面层不受影响，`hdr_2d` 保持关（§11.1）。

### 2.4 高调画面上的面板与常驻件

界面要在清透高调的画面上，以及暖金低角度阳光加高饱和色块的画面上，都分得开、读得清。清蓝与饱和天蓝几乎同色，所以 §2.3 第 1 条必须执行：清蓝永远压在面板底上。

- **高调青白画面上，晶白面板会"化"进画面**：面板与背景的明度对比只有 1.05–1.16。晶白主题因此有两条固定规格：
  - 面板外缘一条 1 px 的墨色描边 `line.panel`（墨 30%），它与高调背景的对比约 1.6–1.9:1，轮廓清楚但不成硬框；
  - 晶白的常驻面板加一层带蓝墨色的环境影（墨 10%，模糊 12 px，下移 2 px）。常驻件默认是深屏，这一条只在设置"常驻件：随主题"时用到；
  - 深屏主题在这类画面上本来就分得开（面板与背景 11:1 以上），不需要额外处理。
- **常驻小部件固定用深屏**。ART-STYLE、ART-SKYLIGHT的画面清透高调（默认格浅色面的影 L ≥ 0.68，白天格 L 中位 ≥ 0.74），晶白面板不只在正午分不开：默认格 17:30 受光的墙和天空 L 0.88–0.95，晶白 #F8FAFD 压在上面同样分不开。所以：
  - **常驻小部件**一律用深屏：小地图、时间读数（时间卡与收起条）、临时提示、到达标题下的推荐小条。同一角落里与它们并排的速度条与观察模式、天气签条、界面态右上的三个图标钮，也按常驻件处理，免得同一条底边上一半晶白一半深屏。
  - **大页**仍随主题：大地图、设置卡、存档页、确认对话框，以及从开始页打开的这些页（开始页本身按"压在画面上"处理，§8.6）。大地图、存档页和对话框背后有 `scrim` 压暗；设置卡不压暗，但它是贴左的整块大面板，有 `line.panel` 外缘，又只占左侧约 1/3，晶白在这些情况下都分得开。
  - 理由：深屏底（L ≈ 0.23）对 L 0.6–0.95 的画面，明度对比 8–14:1，任何时季天气都分得开；交班时常驻件不跳变，扫描前沿只扫过大页；辉光只在深色底上（§5.8），常驻件的过孔灯照常能亮；小地图在深屏框里用夜间配色（深底亮线），读作"芯片版图"，与清蓝主题一致（SYS-ATLAS）。
  - 设置里留一项"常驻件：深屏（默认）/ 随主题"（§3.6）。选"随主题"时，晶白的常驻件用上面两条固定规格。

### 3.6 昼夜切换

**为什么不连续混色**：面板底和字色同时线性混合时，对比度在中点塌掉：本文配色 t = 0.25 时 3.7:1，t = 0.5 时 1.0:1。1× 流逝下，太阳从 +3° 降到 −4° 约 39 分钟，其中约 25 分钟界面读不清。任何"浅色主题 ↔ 深色主题"的连续混合都有这个问题，与具体配色无关，所以界面不做平滑的交班过渡。

**切换规则**：

| 项 | 规则 |
| --- | --- |
| 信号 | 真实太阳高度 h（SYS-TIME §2；不用有效太阳高度 h_eff，阴雨天不提前切） |
| 回差 | 晶白时 h 下穿 −0.5° 切到深屏；深屏时 h 上穿 +0.5° 切回晶白。秋季约 18:08 切到深屏，正好在"日落"关键帧之后 |
| 过渡 | 一道扫描前沿 0.6 s 扫过随主题的画面（打开着的大页和对话框）：日落时从左向右，日出时从右向左。前沿宽 2%，其余每个像素只处于日态或夜态之一（§11.6）。没有打开大页时，界面上看不到交班，只有界面态时间环上的日、月把手互换。交班音 `ShiftDayNight` 也只在界面确有变化时出（大页开着，或常驻件设为"随主题"，UI-NAV §9、SYS-AUDIO §11） |
| 常驻小部件 | 默认固定深屏，不参与切换（§2.4）：小地图、时间读数（时间卡与收起条）、临时提示、到达标题下的推荐小条，以及与它们并排的速度条与观察模式、天气签条、界面态右上的图标钮。悬浮说明跟随它所属的件 |
| 减少动态效果 | 直接换，不扫 |
| 快进、拨表盘、换季、`Apply` | 快进途中不判断；快进结束后按终点的太阳高度判断一次。所以一次快进最多切一次，不会在 3 s 里来回切 |
| 暂停在阈值附近 | 回差保证不来回闪 |
| 设置项"界面主题" | 自动（默认）/ 晶白 / 深屏，存 `user://settings.cfg`。锁定时不切换。子项"常驻件：深屏（默认）/ 随主题"：选"随主题"时，常驻小部件也按本表切换，晶白的常驻件加 `shadow.ambient`（§2.4） |
| 不随主题的画面 | 开始页、过场字幕与标题卡、`over.title` 类压在画面上的标题（"影院处理"，§8.6、§8.9）；常驻小部件（默认固定深屏） |

### 3.8 登记：`game/style/palette/ext/ui.json`

## 4 字体与字号阶梯

### 4.1 字体与许可

| 角色 | 字体 | 字重（打包） | 许可 |
| --- | --- | --- | --- |
| 中文 | 思源黑体 SC | Light、Regular、Medium | SIL OFL 1.1，保留字名 "Source" |
| 拉丁字母与数字 | Inter | Light、Regular、Medium | SIL OFL 1.1 |
| 编号、坐标、读数、键帽、英文小标签 | JetBrains Mono | Regular、Medium | SIL OFL 1.1 |

- 与电子科大 70 周年视觉规范同一套中英文字体（思源黑体 + Inter）。
- **不改字体文件**：不子集化、不改名，整包打包（同 UI-NAV §2）。思源黑体用官方的 SC 语言版；安装包吃紧时可换官方的 CN 区域子集版（CN Regular 8.4 MB），两者都是未修改的官方发布，不触发 "Source" 保留字名（§15）。
- 不用：思源宋体、书法字、霞鹜文楷；HarmonyOS Sans、MiSans（许可可撤销，且要求在软件中显著注明）；Geist Mono、Orbitron 一类。
- 许可文本进设置卡的"许可"页、开始页的"制作人员与许可"和安装包的 `LICENSES.txt`（SYS-VIEW §6）。

### 4.2 回退链与数字

- **界面正文的 `FontVariation`**：首选 Inter，`Fallbacks` 设为思源黑体 SC。拉丁字母和数字走 Inter，汉字走思源黑体，中英两种界面语言共用同一条链。
- **数据与键帽**：JetBrains Mono，回退到思源黑体 SC（等宽字体没有中文字形；回退链必须显式指定 SC，否则可能落到日文字形，ART-STYLE §9.1 第 5 条、INV-7）。
- **等宽数字**：时间环的大读数、速度、倍率等会跳动的数字，在 Inter 的变体上用 `OpentypeFeatures` 开 `tnum`；JetBrains Mono 本来等宽。思源黑体没有 `tnum` 特性，但 0–9 本来等宽，不对它开 `tnum`。
- 全部 `FontFile.AllowSystemFallback = false`：缺字时不偷用系统字体，截图在不同机器上一致；所需字形由字体覆盖率检查保证。
- `Label.Language` 设简体中文。
- 中西混排：汉字与拉丁字母、数字之间留 1/4 em。Godot 不会自动加，翻译表里直接写 U+2005。混排的基线与行高 P0 截图核对（§15）。

## 5 形状与材质

### 5.1 网格、间距与尺寸

- **网格**：8 px 基准，4 px 半步。只用来对齐，界面与地图上都不画网格线。
- **间距阶梯**：4 / 8 / 12 / 16 / 20 / 24 / 32 / 48 / 64。屏幕边距 32（四角组件贴角）。面板内边距 16–20，大面板 24。控件间距 8，组间距 16；组标题是"`mono-caps` 小标签 + 发丝线"。面板与面板之间留 8–16 px 的"切割道"，不画分隔框。
- **控件高度**：24（键帽、标签）、32（紧凑）、36（分段、下拉）、40（次按钮、图标钮）、44（主按钮）。

### 5.2 切角：1 号脚

芯片封装用一个缺角标出 1 号脚。界面容器只切**左上**一个 45° 角，切角旁可放一枚 Ø4 的过孔灯作为"这是一块面板"的签名。

| 件 | 切角边长 |
| --- | --- |
| 大面板、地图纸、设置卡 | 14 |
| 面板、对话框 | 12 |
| 卡片、存档卡、传送卡 | 10 |
| 主按钮 | 8 |
| 宽度小于 48 px 的件、图标钮、分段、开关、键帽 | 不切 |

- 其余三个角是 2 px 的小斜角（`CornerDetail = 1` 的副作用，看起来等于直角）；键帽 3 px；过孔、灯、环是正圆。
- 不做：四角全切、八角框、角括号 `[ ]` 装饰。

### 5.3 发丝线与刻度

- 一切边线都是 **1 物理像素**，任何界面缩放下不变（§11.4）。装饰线 `line.hair`，面板外缘 `line.panel`，控件边 `line.control`（≥ 3:1）。
- 2 px 只给选中指示条；地图上的路线宽度由 SYS-ATLAS 定。
- 刻度：1×5 px，每 6 格一根长刻（6 h、6 档）。用在时间环、滑杆的离散档、比例尺。

### 5.4 过孔灯（状态点）

Ø6 的核；深屏加 2 px 晕。四态：关（空心环）、开（`led.on` 实心）、警告（琥珀实心）、错误（红实心）。用在：选中分段与按钮、"此处"标签、流逝状态、图标钮的选中角标、存档卡的接点、等待灯。过孔灯从不单独表达状态，总有实心与空心之分或文字陪着。

### 5.5 走线

1 物理像素（地图上 1.2 px）的 45° / 90° 折线，两端各一个过孔。**只用来表达"连接"**：大地图的锚点到传送确认卡（SYS-ATLAS）、设置行到底部注释栏、以后的任务列表到地图标记。出现时 240 ms 从起点画到终点（M1 的变体）。不当装饰，不在空白处画电路纹。

### 5.6 衍射光边

晶圆表面的薄膜干涉。**只给键盘焦点和选中项**，鼠标悬停不显示。

- **焦点**：控件外侧 3 px 一圈 1 物理像素的实线核（晶白 b-800、深屏 b-300，对面板 ≥ 5.4:1），核外再衬 1 px 当前主题的面板底色，所以压在任何背景上都看得见；核的两侧各一条 0.7 px 的冷色色散（`iris.a` 偏青、`iris.b` 偏紫），强度 ≤ 0.35。获得焦点时这圈线从外侧 2 px 收紧到位，160 ms，只发生一次（M5）；之后静止。
- **选中**：卡片、存档卡、传送卡的顶边一条 1.5 px 的同样色散线，静止。
- 不循环流动、不加模糊、不出现暖色。
- `gui/common/show_focus_state_on_pointer_event = 0`：鼠标点击不显示焦点环（UI-NAV §8）。

### 5.7 面板材质

| 材质 | 用在 | 规格 |
| --- | --- | --- |
| **不透明面板**（默认） | 常驻 HUD、浮层、所有面板 | `surface.panel`：晶白 n-25 @94%、深屏 screen @90%；常驻小部件默认固定取深屏值（§3.6）；平涂，不叠纹理、不模糊；顶边 1 px 内高光（晶白白 @70%、深屏白 @6%）；外缘 `line.panel` |
| **实底** | 对话框、下拉、卡片、存档卡、传送卡 | `surface.solid`，100% 不透明 |
| **轻度磨砂**（可选） | 只给大页：大地图、设置卡、存档页 | 底色 84%（晶白）/ 80%（深屏）+ 屏幕纹理 LOD 3.5 的模糊；`ui_screen` mode 1 配 `BackBufferCopy(Rect)`（§11.5）。设置项"大页磨砂"：独显档（精致、极致推荐预设对应的设备档）默认开，核显档默认关 |
| **降低透明度**（无障碍） | 全部 | 打开后所有面板 100% 不透明，关闭磨砂 |

- 为什么常驻面板不磨砂：磨砂的逐帧开销是普通半透明面板的 20–40 倍；4080 上整屏拷贝加 mip 是 +0.10 ms（1080p），限区域后大面板 +0.05 ms，核显估计再乘 10–20（§15）。而常驻面板大多在上下各 20% 的移轴虚化带里（ART-STYLE §7.4），90–94% 的底色下背景几乎看不见，磨砂的收益很小。
- 不用"一阶平涂影"，那是纸面方向的语言；不用纸纹和水彩斑驳。

### 5.8 阴影与辉光

- **阴影**：常驻面板默认是深屏，不加影；只有设置"常驻件：随主题"时，晶白的常驻面板用 `shadow.ambient`（§2.4 的对策）。浮层用 `shadow.float`。阴影一律是带蓝的墨，不用黑。
- **辉光**：只在深屏上；只在线、点、细环上（焦点核、当前过孔、玩家箭头、夜里的月亮把手、等待灯），文字和大面积底色不发光；半径 ≤ 4 px（1080p 基准，随缩放），叠加亮度 ≤ 0.30，指数衰减，不做第二层大光晕；同屏发光元素 ≤ 3 个；界面最亮的像素不超过窗灯 `window.warm` 的亮度（§9.8）。
- 晶白上的强调用"深一档的蓝 + 线变实"，不发光：浅蓝流光压在浅色面板上几乎看不见。

### 5.9 明确不做

§1.3 左列全部不做。另外：

- 不画网格线、不画装饰性电路纹、不做透视倾斜面板（`StyleBoxFlat.Skew` 能做，不用）。
- 不做大段全大写英文和等宽长句；没有含义的装饰数字。
- 不用 Godot 的 `Back`、`Elastic`、`Bounce`、`Spring` 过渡类型。

### 7.5 时间环

**时间卡**：宽 344，`surface.panel`，切角 12，界面态下右下角（§8.3）。

```
 ┌─╱ TIME · 时间 ──────────────────── ● 1× ┐
 │                  12                     │   外环：24 h 天色光谱（当季、当前天气）
 │            ╭─────┴─────╮                │   内侧 24 根刻度，每 6 h 一根长刻
 │       06 ──┤   17:30   ├── 18 ○ ← 太阳  │   中心：钟点 readout
 │            │ 酉时 · 黄昏 │                │         时辰 · 时段（small）
 │            │AUTUMN·CLEAR│                │         季节 · 天气（mono-caps）
 │            ╰─────┬─────╯                │
 │                  00                     │
 │ [晨 午 昏 夜] [+1h]                      │
 │ [‖ 1× 10× 60× 360× 1440×]  ∿∿∿∿ ← 倍率波形│
 │ [∿春 ∿夏 ∿秋 ∿冬]                        │
 │ 稍后 · 夜里转雨          回到落金初灯 →  │
 └──────────────────────────────────────────┘
```

- **方位**：12 在顶、00 在底、**06 在左、18 在右**，钟点前进的方向是顺时针，与"只能顺时针拨"一致，也与"面朝南看太阳东升西落"一致。
- **光谱环**：直径 208，环带宽 12 px，颜色是当前季节、当前天气下 24 个整点的地平线天色。HudModel 在换季、换天气模式时向调色板求值器取一次 24 个样（`IPaletteProbe`，§11.11），不逐帧取；彩度乘 0.7（§2.2"再现场景"）。环内外各一道 `line.hair`；内侧 24 根刻度，标 00 / 06 / 12 / 18（`data` 12）。不画十二时辰外圈，时辰只写在读数里（MAP-QSH-CORE §2.4 的时间广场刻度不受影响）。
- **把手**：太阳是 Ø16 的 `now`，晶白加 1.5 px 墨描边，深屏可带 ≤ 4 px 辉光；夜里换成月亮（n-50 圆加 n-400 月相阴影，不用暖色）。一根 1 px 细针从内圈连到把手。日月互换在交班的 0.6 s 内交叉淡化。
- **中心读数**：`readout` "17:30"；下一行"酉时 · 黄昏"（`small`）；再下一行 `mono-caps` "AUTUMN · CLEAR"。点刻度、点预设、按 `.` 时读数按 M4 一格一格滚。
- **前向预览**：拖动或悬停时，环外 6 px 画一段 1.5 px 的虚线弧（晶白 b-700、深屏 b-400），从当前钟点顺时针到目标，终点一个过孔。逆时针拖时把手不动，悬浮说明写"时间只往前走"。
- **倍率波形**（M7）：流逝分段右侧一条单线波形，暂停是直线，倍率越高越密；只在时间卡展开时显示。1440× 这类持续超过 5 s 的状态不呼吸，用波形表示（WCAG 2.2.2）。
- **收起态**（界面态下按 T 收起）：约 290×56 的条：钟点（Inter Light 26，`tnum`）+ 时辰 + "季 · 天气" + 天气图标 + 96×4 的光谱条与 2 px 当前刻线。**漫游态不显示**（漫游态只有小地图常驻，INV-3）。
- **实现**：拆三层。静态的环与刻度只画一次；把手是独立子控件，只改 `Rotation`；预览弧用 `ui_panel` 的线（kind 1）。每帧整盘重绘要 0.19 ms，所以拆层后把手只改变换。
- 拖动、跳转、预设、`[+1h]`、"回到落金初灯"的语义以 UI-NAV §4.1、SYS-TIME §1 为准；键盘与读屏照 UI-NAV §8。

## 9 动效语言

### 9.1 原则

1. **静止即安静**：没有输入、没有状态变化时，界面上没有任何会动的东西（3D 画面除外）。
2. **光是信号**：只有"状态变了""确认了""正在进行"这三件事才出现光和运动。
3. **方向有因果**：揭示和流光从触发源出发（被点的按钮、小地图所在的角、时间环上的太阳、当前位置），退场朝来处收回。
4. **入场从容，退场利落**：退场时长约为入场的 0.6–0.7 倍，位移减半，不交错。
5. **可打断**：任何动效进行中都接受新输入；跟随类用弹簧，保持速度连续；脚本类从当前值重新定目标，不排队。
6. **减少动态效果时只剩透明度**（§10.1）。

### 9.2 两种时间

- **连续**：位移、透明度、颜色、数值按显示帧率补间，相当于动画的"摄影"。
- **步进**："被计算出来的东西"——量化出入场的抖动阶、网格的点亮阶、图标换帧、示波器的相位——按全局 `step_rate`（12 Hz，帧率上限 30 时 15 Hz）步进：T = floor(t · step_rate) / step_rate（SYS-MOTION §2.2），和场景里的落叶在同一帧换姿态。把一拍二解释成"采样率"，是本作科技风和三渲二画面在节奏上接起来的地方。

### 9.4 频率分级

| 级别 | 场合 | 允许的母题 | 禁止 |
| --- | --- | --- | --- |
| 高频（每秒可能多次） | 悬停、按下、焦点、切换、拖动 | 色调变化、1 px 线变实、弹簧滑块、M5（只限焦点） | 扫描、网格、流光、量化、任何发光 |
| 中频（每分钟几次） | 面板开合、临时提示、图标与缩略图更换、数值变化、地图钉 | 淡入上移、M4、M6、单次 M1 | 扫描、网格 |
| 低频（每次会话几次） | 开始页、开始 → 过场、标题卡、打开大地图、传送、存档成功、画面设置应用、昼夜交班 | M1、M2、M3、M6 的组合编排，总长 600–1200 ms；单个元素仍 ≤ 450 ms，靠重叠铺开 | 循环、闪白 |
| 状态型 | 进行中 | M8；倍率用 M7 | 持续超过 5 s 的呼吸 |

**声音**（提示音清单与时长以 SYS-AUDIO为准）：声也是信号，与上表同一套分级。

- 高频事件默认无声：悬停关；焦点只在键盘导航时有 40 ms 的轻点；切换 30 ms 的点按感，滑杆每档一次。
- 中频只有大页开合一声；临时提示、数值滚动无声。
- 低频编排（开始页、开始进入过场、打开大地图、传送、存档成功、昼夜交班）各配一个与时间线对齐的短音（§9.9）。
- 状态型（呼吸灯）无声：持续的状态不配持续的声音。
- 自动保存一律无声；临时提示不配提示音，阻挡本身的声音由观者声负责（SYS-AUDIO）。

### 9.5 曲线

| 名称 | 定义 | 用于 |
| --- | --- | --- |
| `Enter` | cubic-bezier(.2, .7, .2, 1) | 入场的位移与透明度 |
| `Exit` | cubic-bezier(.3, 0, .8, .15) | 退场 |
| `Standard` | cubic-bezier(.2, 0, 0, 1) | 原地变化：颜色、强度、计数 |
| 空间弹簧 | 临界阻尼（ζ = 1），response 0.2–0.4 s | 选中滑块、时间环把手跟随采样、档位前沿、地图缩放、卡片放大 |
| 效果弹簧 | 临界阻尼，response 0.12–0.2 s | 悬停强度、高亮强度 |
| 步进 | T = floor(t · step_rate) / step_rate | M3 的格子阶、M6 的抖动阶、图标帧、M7 的相位 |

- **贝塞尔与弹簧的分工**：脚本化、只播一次、要和别的元素对齐时间线的（入场、退场、扫描、编排）用贝塞尔；由连续输入驱动、可能半路改目标的（悬停、拖动后的落定、跟随 10 Hz 采样值）用弹簧。贝塞尔被打断时速度会突变，弹簧不会。
- **弹簧的允许范围**：阻尼比 0.9–1.0，默认 1.0。0.9 的过冲是 0.15%（100 px 位移多走 0.15 px，看不见）；不允许 ζ < 0.9。Godot 的 `Tween.TransitionType.Back`、`Elastic`、`Bounce`、`Spring` 一律禁用（`Spring` 是一条固定的振荡曲线，不是物理弹簧，不能打断续接）。
- **临界阻尼弹簧的到位时间**：response 0.15 s 时 158 ms 进入 1%；0.2 s 时 211 ms；0.3 s 时 317 ms；0.4 s 时 423 ms。
- 淡入淡出这类不敏感的场合，Godot 内置的 Quart Out 可以近似 `Enter`（最大偏差 0.048）；位移仍用 `Enter`。

### 9.7 进入与退出、交错、打断

- **交错**：每项错开 30–40 ms；最多 6 项参与交错，第 7 项起和第 6 项同时出现，交错带来的额外时长 ≤ 240 ms；顺序按阅读顺序、从锚定角向外；地图钉、网格这类"空间分布"的，按到起点的距离错开；长表单按组错开，不逐行；退场不交错。
- **退场开始的同一帧**就关掉焦点和鼠标（UI-NAV §3）。
- **打断**：退场中又被打开，从当前透明度和位移直接反向入场，时长按剩余距离缩放；连续的同类请求只保留最新的目标。

### 9.8 辉光与闪烁的上限

| 项 | 上限 |
| --- | --- |
| 发光的位置 | 只在线、点、细环上；文字和大面积底色不发光 |
| 晶白 | 不发外光 |
| 深屏 | 外发光半径 ≤ 4 px（1080p 基准，随缩放）；叠加亮度 ≤ 0.30（sRGB 0–1）；指数衰减，不做第二层大光晕 |
| 同屏 | 同时发光的元素 ≤ 3 个 |
| 相对场景 | 界面最亮的像素不超过窗灯 `window.warm` 的相对亮度（约 0.78） |
| 色彩 | 只用主色一种色相；焦点色散只用冷色，强度 ≤ 0.35 |
| 亮度跳变 | 同一区域亮度变化 ≥ 10% 的事件每秒最多 1 次（比 WCAG 2.3.1 的 3 次更严） |
| 转场 | 不做全屏闪白；转场最亮一帧的平均亮度增量 ≤ 10%；扫描前沿和网格闪亮的增量 ≤ 0.20 |
| 循环 | 没有常驻循环动画（WCAG 2.2.2）：图标只在悬停或状态变化时动一轮，M8 只在有限的"进行中"里出现 |

闪电是场景的事，由 SYS-WEATHER §5 约束，与界面无关。

## 10 减少动态效果与无障碍

### 10.1 "减少动态效果"下的替代

开关、默认值和系统读取方式见 UI-NAV §8（默认跟随系统，`DisplayServer.AccessibilityShouldReduceAnimation()`）。所有组件经 `MotionPolicy` 取时长和"是否做空间运动"，组件里不写判断（§11.7）。

| 母题或动效 | 完整 | 减少动态效果 |
| --- | --- | --- |
| 淡入上移、卡片揭示 | 透明度 + 位移 | 只透明度，≤ 200 ms |
| M1 走线流光 | 光沿线跑 | 终点直接亮 120 ms 后淡回 |
| M2 扫描揭示 | 前沿扫过 | 整页 200 ms 淡入 |
| M3 网格逐格 | 逐格步进 | 整块 200 ms 淡入，不出现网格线 |
| M4 数值滚动 | 竖向滚一格 | 直接换字 |
| M5 衍射边 | 160 ms 收紧 | 直接出现（焦点环本身必须保留） |
| M6 量化出入场 | 4 阶抖动 | 150 ms 淡入 |
| M7 示波器 | 相位按步进推进 | 静止波形（振幅和频率仍表示倍率） |
| M8 呼吸灯 | 正弦呼吸 | 静态实心点 |
| 弹簧（选中、把手、档位） | 弹簧 | 直接到位 + 100 ms 淡入 |
| 等待灯 | 三枚依次点亮 | 三枚静止半亮 |
| 昼夜交班 | 0.6 s 扫过 | **直接换**，不扫 |
| 图标换帧 | 一轮一拍二帧 | 不换帧 |
| 交错 | 30–40 ms | 无交错 |
| 压暗层 | 220 ms | 保留（只是透明度） |
| 3D 的跳转、换季、换天气、传送 | UI-NAV §7、SYS-TIME §5、SYS-ATLAS | 0.5 s 雾幕交叉淡化（UI-NAV §7.6） |

- **声音不是动效**：减少动态效果时界面音照常；昼夜交班直接换，交班音缩短到 0.3 s（SYS-AUDIO）。

### 10.2 无障碍

- **对比度**：§3.7 的表是 G14 的检测依据：文字 ≥ 4.5:1，图标和控件 ≥ 3:1；两套主题各验一遍，交班中的每一帧都要满足（只有前沿那 2% 宽的一条例外）。
- **不只靠颜色**：选中有底色加指示条或过孔灯；过孔灯有实心和空心；开关旁写"开 / 关"；手动天气用实心过孔、自动用空心；语义色总配图标和文字。
- **焦点环**：§5.6；任何背景上都看得见；鼠标点击不显示（UI-NAV §8）。
- **降低透明度**：无障碍设置，打开后全部面板 100% 不透明，关闭磨砂（§5.7）。
- **界面主题锁定**：自动 / 晶白 / 深屏（§3.6）。畏光的观者可以固定深屏。
- **字号**：中文下限 14 px；界面缩放 75–150%（受窗口大小约束，§11.10）。
- **闪烁**：§9.8 的上限；G14 用录像检测。
- **读屏**：每个可获得焦点的控件都有可读的名字；图标钮必须写 `AccessibilityName`；禁用件读出原因；时间环声明为滑杆（UI-NAV §8）。
- **键盘可达**：Tab 顺序按 UI-NAV §8，含界面态右上三个钮和小地图旁的钮（SYS-ATLAS）；大页内的焦点不逃出大页。

### 11.1 分层与 `hdr_2d`

界面与 3D 后期的关系：

- CanvasLayer 上的界面不受色调映射、Glow、Adjustment、Compositor 影响，颜色逐像素原样上屏；FSR 0.5 下 1 px 线仍是 1 px。原理：后期都在 3D 的渲染缓冲里执行，画布在 3D 之后按输出分辨率画到同一个渲染目标上。
- **`rendering/viewport/hdr_2d` 固定为关**（WP-00 写进 `project.godot`，G5 检查）：打开后截图读回的是线性值（整张偏暗），界面的半透明混合也挪到线性空间，与设计稿不一致；本作不做 HDR 输出（SYS-GRAPHICS §1），开它没有收益。
- 界面着色器里的颜色 uniform 一律加 `source_color`：关 `hdr_2d` 时不转换（实测 0.5 → 127），万一以后打开也能自动转成线性。

画面层次（从下到上）：3D 画面 → CanvasLayer 4 预热层（只在扉页阶段，WP-01，SYS-TITLE）→ CanvasLayer 5 雾幕与扉页（WP-01）→ CanvasLayer 9 放映层（黑边、字幕、时间读数、标题卡、跳过环，WP-35d，SYS-TITLE）→ CanvasLayer 10 界面 `HudRoot`（WP-35）→ CanvasLayer 11 署名（WP-01）。放映层在署名之下，所以 OSM 署名始终在最上层；层号以 SYS-TITLE 为准。

### 11.3 `ui.json` 与 Theme 的生成

- **一个 Theme，由代码生成**：`UiThemeBuilder` 在 HudRoot 初始化时，从 `ext/ui.json`（色名，§3.8）和 `UiTokens`（尺寸、圆角、切角、字号）生成一个 `Theme`，挂在 HudRoot 的根 Control 上。色值只有 `ui.json` 一个来源；G4 禁止代码里写十六进制色值和 `main.tscn` 以外的共享 `.tres`。
- `--ui-export-theme=<路径>` 用 `ResourceSaver.Save()` 把生成结果存成 `game/hud/ui_theme.tres`，提交进 git 供编辑器预览和差异审查；运行时不读它。G5 比对提交的文件与生成器的输出一致。
- **类型变体**（`Theme.SetTypeVariation()`，控件上设 `ThemeTypeVariation`）初始清单：
  - 面板：`PanelHud`（常驻）、`PanelPage`（大页）、`PanelSolid`（对话框、卡片）、`PanelStrip`（签条）；
  - 按钮：`PrimaryButton`、`SecondaryButton`、`TextButton`、`DangerButton`、`IconButton`、`SegmentButton`、`DipSwitch`、`Fader`、`TabLine`；
  - 文字：`ReadoutLabel`（等宽数字）、`TitleLabel`（MSDF 标题）、`DataLabel`、`MonoCaps`、`HintLabel`、`CaptionLabel`；
  - 其他：`ListRow`、`MemoryCard`、`Keycap`、`Toast`、`TooltipInverse`、`TitleOverScene`。
- 禁止零散的 `theme_override_*`（UI-NAV §9）。
- **颜色走着色器，Theme 只给形状**：随主题变的颜色全部由 `ui_panel` 着色器按 `ui_night` 取日、夜两值（§11.6）。Theme 里的颜色项只作"无着色器时的兜底"，取晶白值。文字的角色（正文、次要、强调、禁用）用 instance uniform `role` 从色表里选，色表由 `UiMaterials` 从 `ui.json` 写入。
- Godot 的状态 StyleBox（`hover`、`pressed`、`focus`）只在状态改变时换一次，保留作兜底；悬停强度、流光、焦点、量化都走 instance uniform，不靠切换 StyleBox（每帧重绘 11 块 StyleBoxFlat 要 0.29 ms）。

### 11.4 StyleBox、切角与发丝线

| 方式 | 适合 | 代价 |
| --- | --- | --- |
| `StyleBoxFlat`：`CornerRadiusTopLeft` = 切角边长，其余 2，`CornerDetail = 1` | 静态的小件：按钮、签条、键帽 | 静态零开销；重绘约 25 µs/块。`CornerDetail` 为 1 时得到切角 |
| 着色器面板：`StyleBoxFlat` 只作载体（`ExpandMargin` 6 px 留给外发光和焦点环），`ui_panel` kind 0 画切角 SDF | 面板、卡片、存档卡：要流光、焦点、量化、交班、物理像素对齐的发丝线 | 40 块 GPU +0.004 ms；每帧写 40 个 instance uniform +0.031 ms |
| 自定义 StyleBox（C# 重写 `_Draw`） | 需要特殊几何又不想写着色器 | 每帧重绘 11 块 0.033 ms；要自己处理抗锯齿 |

**1 物理像素的发丝线**：

- `StyleBoxFlat` 的边框宽度是整数逻辑像素，界面缩放 1.37 时 1 px 边会变成 1.37 px、发糊，所以面板的边线不用它画；
- 着色器里在物理像素空间算 SDF：`FRAGCOORD` 减去四边形原点（原点取整对齐像素），发丝线 = 1 − |d + 0.5|，缩放因子由 `CANVAS_MATRIX * MODEL_MATRIX` 算出，切角和发光半径按逻辑像素乘缩放，线宽保持物理 1 px。1.37 倍缩放下清楚；
- `_Draw` 里的水平、竖直线（刻度、分隔）宽度传 −1，引擎画两点图元，任何缩放下都是 1 物理像素；斜线用宽度 1 加 `antialiased: true`；
- `gui/common/snap_controls_to_pixels` 只按逻辑像素取整，非整数缩放下仍可能落在半像素上，所以发丝线不依赖它。
- StyleBoxFlat 的 UV 覆盖整个盒子（含 expand margin），着色器能用 `1.0 / fwidth(UV)` 反推像素尺寸，不需要另传尺寸。

**图标**：1.5 px 线宽的图标按 2 倍分辨率导入，在 1.0 倍下略软，可以接受；`DpiTexture` 随缩放重新栅格化 SVG，在 1.5–2 倍下最清楚，但标为实验性。P0 先用 `DpiTexture`，出问题退回 2×、3× 两套 PNG（§15）。

### 11.5 两个界面着色器（白名单）

| 文件 | 内容 | 读屏幕纹理 |
| --- | --- | --- |
| `ui_panel.gdshader` | `kind` uniform 区分面板（0）、线（1，`Line2D` 的 UV.x 沿线）、图标（2，横排帧图集）、文字（3，只改 `COLOR.rgb`）。包括切角 SDF、物理像素发丝线、M1、M5、M6、M7、悬停强度、图标按 `step_rate` 换帧、晶白的环境影、深屏的解析辉光、交班的扫描前沿 `night_at()` | 不读 |
| `ui_screen.gdshader` | mode 0：挂在 `CanvasGroup` 上的整页揭示（M2 扫描、M3 网格、M6 量化）；mode 1：大页磨砂（配 `BackBufferCopy(Rect)`） | 读（`hint_screen_texture, filter_linear_mipmap`） |

- **为什么分两个文件**：一个着色器只要出现 `hint_screen_texture`，引擎就会在它之前做一次背景拷贝（带 mip 时再生成一串高斯 mip），这是按着色器静态判定的，分支没走到也会发生，所以读屏的效果不能和 `ui_panel` 合并。
- **全局参数**：只读 `ui_night`、`anim_time`、`step_rate`。不新增全局参数；悬停、流光、焦点、量化、文字角色、常驻件的固定主题都用 instance uniform（`trace`、`focus`、`reveal`、`hover`、`role`、`pin_night`，§11.6）。
- **instance uniform 的事实**：canvas_item 着色器支持 instance uniform（`CanvasItem.SetInstanceShaderParameter()`）；不随 `UseParentMaterial` 继承；`ClipChildren = AndDraw` 不按父节点着色器算出的 alpha 裁子节点。所以整页揭示用 `CanvasGroup`：只在揭示的那几百毫秒把页挂进组（520×220 的组 +0.033 ms），结束后挪回普通节点。`CanvasGroup` 的缓冲是预乘 alpha，读出后先除回。
- **辉光不走 3D 的 bloom**：Environment 的 Glow 只作用于 3D，让 2D 参与就得把界面卷进色调映射。辉光在 `ui_panel` 里按 SDF 解析计算：exp(−d / (2·缩放)) × `glow_max`（≤ 0.30）× 深屏系数；不读屏幕、不加通道。40 块带这套计算的面板 GPU +0.004 ms。
- **着色器里不用 `TIME`**（SYS-MOTION §1.6）。内置量只能在处理函数里读：在自定义函数里读 `SCREEN_PIXEL_SIZE` 编译失败，要作为参数传进去。
- 项目版的色值全部来自 `ui.json`，着色器里不写字面色值（G4）。
- 材质由 `UiMaterials` 向 `Campus.Style` 的材质库申请（ENG-ARCH §2：只有 Style 能建 ShaderMaterial）。小地图与大地图的底图着色器 `map_base.gdshader` 归 SYS-ATLAS。

### 11.6 主题切换：`ui_night` 的锁存与扫描前沿

- **写入方是 WP-35**：`UiThemeClock`（`ProcessPriority = FramePriority.Hud`）每帧读 `IWorldState.Sun.AltDeg` 和"界面主题"设置，按 §3.6 的回差判定目标主题；快进进行中（`IWorldState.Transition` 含 `Time`）不判定，结束后判定一次（SYS-TIME §1、ENG-PERF §1.5）。理由：锁定设置、减少动态效果和 0.6 s 扫过都是界面的表现决定，只有界面读 `ui_night`。
- **`ui_night` 的语义**：0 = 全屏晶白，1 = 全屏深屏；切换时在 0.6 s 真实时间内线性走完（减少动态效果时一帧走完），它是扫描前沿的位置，不是颜色插值量。
- **着色器**：`n = night_at(FRAGCOORD.xy, 屏幕宽)`：屏幕 x 小于前沿的像素是夜态，大于的是日态，前沿宽 2%。日落时 `ui_night` 0 → 1，前沿从左向右；日出时 1 → 0，从右向左。所有颜色 = mix(日值, 夜值, n)，n 只在前沿那 2% 宽的一条里处于中间值。
- **常驻件固定深屏**：常驻小部件（§3.6）的材质写 instance uniform `pin_night = 1`，着色器取 n = max(`night_at(...)`, `pin_night`)，所以它们始终是夜值，交班前沿扫过时也不变；设置"常驻件：随主题"时由 `UiThemeClock` 改写为 0。小地图的 `map_base` 用同一个约定（SYS-ATLAS）。这样不必为常驻件另建一套 Theme 或材质。
- **所有画面板和文字的地方都必须走这个机制**。没走着色器的 StyleBoxFlat 夜里会出现"浅底浅字"，这是 G14 对比度检测要抓的典型错误。
- 不在交班时替换 Theme，也不逐帧或以 10 Hz 修改 Theme 资源（UI-NAV §9 的禁令）。
- 不受主题影响的放映层、开始页不读 `ui_night`。

### 11.7 动效的驱动

- **Tween：一个动效一个进度驱动**：`CreateTween()` 后只加一个 `TweenMethod`，进度 0 → 1，C# 侧算缓动，一次写多个属性（透明度、位移、instance uniform）。40 个并发主线程 +0.014 ms；`PropertyTweener` + `SetCustomInterpolator()` 是 +0.034 ms。
- **`SetCustomInterpolator()` 的坑**：它收到的进度已经过该 tweener 的 trans/ease，调过 `SetTrans`、`SetEase` 就会双重缓动。规定：用自定义插值器时不调 `SetTrans`、`SetEase`。
- Tween 绑定节点（`node.CreateTween()`），同一控件同一属性开新动效前先 `Kill()` 旧的，从当前值出发。Tween 受 `Engine.TimeScale` 影响，本项目固定为 1；Movie Maker 下帧间隔恒定，界面动效逐帧可复现（G13 可以录界面）。
- **弹簧**：不为每个弹簧建节点。`MotionHub` 在 `_Process` 里推进全部活动弹簧，用临界阻尼的精确解，任意帧间隔稳定、零分配，静止后自动停止。
- **容器陷阱**：`Container.fit_child_in_rect()` 每次排版都会重设子控件的 rect，并把旋转清零、缩放设为 1。所以：不在容器里的面板直接改 `Position`；容器里要动的内容放进 `MotionSlot`；只改透明度时改 `Modulate`，不触发排版；展开收起不改尺寸，外面包一个 `ClipContents = true` 的控件只改它的高度。
- **动效只改这些**：`Modulate`、不在容器里的 `Position` 与 `Rotation`、instance uniform、全局参数 `ui_night`（扫过期间）。不改尺寸、StyleBox、Theme 和文字（读数走 10 Hz 和 `RollingNumber`，ENG-BUDGET §7）。
- **一拍二步进**：着色器里用 `anim_time`、`step_rate` 算帧号，零 CPU；C# 里用 `UiEase.Stepped(t, n)`，需要与全局节拍对齐时用 `Math.Floor(AnimTime * stepRate)`。不用 `CanvasItem.DrawAnimationSlice()`（引擎内部时间，不受 `--anim` 控制）。
- **时间线写在代码里**：开始页、标题卡这类编排写成返回 `Tween` 的方法（`Parallel()`、`Chain()`、`TweenSubtween()`），时间点用 §9.9 的常量；不用 AnimationPlayer（G4 不允许另存共享 `.tscn`、`.tres`）。
- **`MotionPolicy`**：`Full`、`Reduced`、`Instant` 三档。`Reduced` 来自"减少动态效果"；`Instant` 给门禁和截图用，所有动效直接跳到终态、图标停在第 0 帧、悬浮说明不出现，由 `--motion=instant` 打开，`--ui=1` 的截图默认带上。3D 侧（跳转、换季、换天气、传送、过场）读契约 `IMotionSettings`（§11.11）。

### 11.8 字体与 MSDF

- 字体整包打包（§4.1）；`Theme.DefaultFont` 设为正文的 `FontVariation`，`Theme.DefaultFontSize` 设为 16；`ThemeDB.FallbackFont` 也设成同一字体。字距用 `FontVariation.SpacingGlyph`（整数像素）。
- **MSDF 只给标题字重**：着色器只改 `COLOR.rgb` 时，MSDF 字形的 alpha 不受影响（`canvas.glsl` 在用户代码之前完成 MSDF 解码）；缩放 1.37 倍时 MSDF 清楚、位图字边缘梯度降低约 14%。但现场生成 MSDF 汉字约 8 ms/字（500 字 3983 ms）。所以：
  - 只有 `display-1`、`display-2` 和到达标题用 MSDF；
  - **导入时预渲染全部会用到的字**：字形清单从翻译表（`game/hud/i18n/*.csv`）、点位名、地图标注（SYS-ATLAS）、片名与标题卡文案自动收集，写进字体的导入设置；
  - 门禁检查"运行中新生成的 MSDF 字形数为 0"。
- 正文、读数用普通位图字形（hinting、次像素定位），按 UI-NAV §2 开"预渲染译文中的字形"。
- 思源黑体 CN Regular 8.4 MB；三字重的思源黑体加 Inter、JetBrains Mono 约 30–50 MB（ENG-PERF §8）。

### 11.9 预热与预建

一次性开销：界面着色器第一次出现那一帧卡 18.4 ms（冷缓存；`PipelineCompilationsCanvas` +5）；MSDF 汉字约 8 ms/字；按需创建 159 个控件入树 22–40 ms，加第一帧排版 6–11 ms；改一次 `ContentScaleFactor` 1.6–4.1 ms。这些都放在开场雾幕或扉页插画后面（SYS-VIEW §3、SYS-TITLE）：

1. **界面着色器**：`ui_panel` 与 `ui_screen` × {StyleBox 四边形、`Line2D`、`TextureRect`、位图文字、MSDF 文字、`CanvasGroup`、`BackBufferCopy`} 各画一次（画布着色器按绘制类型分特化）。
2. **MSDF 字形**：导入时预渲染（§11.8），运行中不生成。
3. **大页预建**：设置卡（含画面页约 120 个控件、声音页约 30 个控件）、存档页、开始页菜单、制作人员页、大地图的卡片与左栏（SYS-ATLAS）在雾幕里**预建一次并隐藏**。隐藏的子树不绘制、不处理，只占内存。画面页（SYS-GRAPHICS §9）和声音页都预建，不在打开时才创建。
4. **JIT 空跑**：建页、开合、滚动数字、弹簧、交班扫过的代码路径在雾幕里空跑一遍（ENG-PERF §6"雾幕期间各系统至少空跑 30 帧"）。
5. **门禁**：雾幕或扉页淡出之后 `PipelineCompilationsCanvas` 不增长（G16 的计数加这一项）；帧时超过 20 ms 的帧附带"本帧创建的控件数"。

### 11.10 界面缩放公式

- **事实**（`scene/main/window.cpp`）：`canvas_items` 拉伸模式下，画布的总缩放 = 拉伸比例 × `ContentScaleFactor`。拉伸比例 s = min(窗口宽 / 1920, 窗口高 / 1080)，已经让界面随窗口等比放大。
- **不乘 DPI**：把 `ScreenGetDpi() / 96 × 用户缩放` 写进 `ContentScaleFactor` 会把 DPI 算两遍：4K 屏、系统缩放 175% 时 `ScreenGetDpi()` 返回 168，1080p 窗口里界面被放大到 1.75 倍，4K 全屏时是 2 × 1.75 = 3.5 倍。
- **公式**：

```
s     = min(窗口宽 / 1920, 窗口高 / 1080)        // 拉伸比例
lo    = 0.85 / s                                  // 字不小于设计字号的 85%（1280×720 时 lo ≈ 1.27）
hi    = min(窗口宽 / 1280, 窗口高 / 720) / s       // 逻辑视口不小于 1280×720，四角组件不挤进中央
ContentScaleFactor = clamp(用户缩放, lo, max(lo, hi))   // 不乘 DPI
```

- "界面缩放"设置的范围是 75–150%，默认 100%。小尺寸高 DPI 屏的**默认值**提到 125%：首次启动用"物理屏高 = 像素高 / `ScreenGetDpi()`"估计，小于 8 英寸时提高；之后以观者设置为准。`Window.DpiChanged` 只用于这次默认值估计，不参与缩放计算。
- 改缩放那一帧会卡 1.6–4.1 ms，所以滑杆松手后再应用（0.2 s 去抖），不在拖动中逐值应用。
- 21:9 与多分辨率：宽高比 `expand` 让 2560×1080 的逻辑视口变宽、高度仍是 1080，四角组件贴角；动效位移按逻辑像素写，随缩放自然变大；发丝线按物理像素恒为 1 px。

## 13 验收

**G14 界面门禁**（ENG-GATES §2）：

1. **键盘**：能走完 UI-NAV §8 的全部控件，以及开始页、存档页、设置卡（含画面页、声音页）、大地图（SYS-ATLAS）、确认对话框；焦点不逃出打开着的大页。脚本用 `Input.ParseInputEvent()` 注入 Tab 和方向键，用 `GuiGetFocusOwner()` 核对顺序。
2. **对比度**：按 §3.7 的令牌表自动检测，晶白、深屏各一遍；读截图里文字与底的像素按 WCAG 公式算。预报行、读数按文字判；禁用件按豁免处理，但要有可读的原因。
3. **交班**：录太阳下穿 −0.5° 和上穿 +0.5° 各一段：只在越过回差时触发；扫过 0.6 s 内任意一帧，除前沿 2% 宽的一条外对比度都达标；在阈值附近暂停 60 s 不来回切；一次跨日快进只在结束时切一次；减少动态效果下直接换；锁定晶白、深屏时不切。常驻件（默认固定深屏）在交班前后逐像素不变；设成"常驻件：随主题"时，常驻件与大页在同一次前沿里切换。另在默认格（秋 17:30）和白天格各截一张：常驻件的深屏面板对背后画面的明度对比 ≥ 3:1。
4. **发丝线**：画廊在缩放 1.0、1.25、1.5 和 1280×720 下，指定位置的边线宽度都是 1 物理像素。
5. **闪烁**：用 Movie Maker 录开始页、大地图开合、传送、存档成功、交班、等待灯的序列，同一区域亮度变化 ≥ 10% 的事件每秒不超过 1 次；没有全屏闪白；转场最亮一帧的平均亮度增量 ≤ 10%。
6. **辉光与色彩面积**：晶白画面上没有外发光；深屏同屏发光元素 ≤ 3 个、半径 ≤ 4 px；常驻 HUD 的清蓝像素 ≤ 界面像素的 15%、≤ 全屏的 2%；暖色点 #FFE0A8 一屏最多一处（再现场景的缩略图、光谱环、地图除外）。
7. **减少动态效果**：重录第 5 条的序列，相邻帧差只来自透明度，没有位移。
8. **遮挡**：最小窗口 1280×720 和 21:9 的 2560×1080 下，`--ui=1`、四角组件全部展开时不遮挡画面中央 60%；设置卡只占左侧约 1/3；大地图、存档页是全屏页，单独登记豁免。开始页不整页豁免：片名和菜单在 1280×720 与 2560×1080 下都不进中央 60%（SYS-TITLE §11.2）。
9. **漫游态**：只有小地图和临时提示；按 U、`--ui=0`、过场时小地图也隐藏；`--ui=0` 时只剩 3D 画面和署名。
10. **登记**：画面上只出现 UI-NAV 和本文登记的组件；界面资源清单（`game/assets/hud/manifest.json`）里没有银杏、书签、纸纹意象；`ui.json` 的色值没有出现在任何 3D 材质和调色板纹理里。
11. **缩放**：4K、系统缩放 175% 下，界面占屏比例与 1080p、100% 相同（不重复乘 DPI）；1280×720 下字不小于设计字号的 85%。
12. **画廊截图比对**：`UiGallery` 的全部组件 × 六种状态 × 两套主题 × 两档缩放，与基准图比较，容差按"同机连续 10 次"标定（ENG-GATES §1）。
13. **性能**：界面主线程平均 ≤ 0.2 ms；画布渲染 CPU ≤ 0.3 ms；`HudModel` 每秒变化事件 ≤ 10 次；可见且在处理的 Control ≤ 400、总数 ≤ 700；雾幕或扉页之后 `PipelineCompilationsCanvas` 不增长、新生成的 MSDF 字形为 0；帧时超过 20 ms 的帧附带本帧创建的控件数。
14. **交互判据**（同 UI-NAV §10）：时间环逆时针拖动时 `WorldHours` 不减、顺时针拖满一圈前进 24 h；Y 单击只在本季可选的格里循环、按住 0.6 s 回到自动；画面页只经 `IQualityService`；读屏只自动查"每个可获得焦点的控件都有可读的名字"，实际朗读人工抽查。
