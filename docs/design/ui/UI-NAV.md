## 0 结论

1. **风格**：界面的主题是信息、数据、电子、芯片、光与计算，主色清蓝 #73C9F9，专业克制，光只表示状态；白天"晶白"、夜间"深屏"两套主题，常驻小部件固定用深屏。令牌、字体、形状、图标、组件和动效一律以 UI-VISUAL 为准，本文件只定内容和交互（§2）。
2. **呈现**：作品启动后先是扉页和开始页，进入时播进场过场（SYS-TITLE）。漫游态（鼠标被捕获）唯一常驻的元素是左上角的小地图（SYS-ATLAS，可关，N 切换），另有几秒内淡出的临时提示。按 Esc 进入界面态，界面出现，4 秒没有操作后淡出（键盘操作、焦点、大页和读屏都让它保持显示，§3），小地图不淡出。按 U 进入纯净模式，小地图也隐藏。
3. **内容**：时间、季节、天气、速度、观察模式、小地图与大地图（点位目录在大地图的"目录"页，SYS-ATLAS）、操作说明与设置（含"画面"页 SYS-GRAPHICS §9、"声音"页 SYS-AUDIO §13），以及开始页、存档页和过场字幕（SYS-TITLE、SYS-SAVE）。3D 画面里不叠加地点标签、选中描边、世界空间标记或光柱（INV-3）。
4. **跳转与传送**：数字键、`[` `]` 和大地图上的【飞过去】都是飞过去，不做"淡出、加载、淡入"：短距离直线滑移；中距离走弧线；远距离在弧线顶点穿过雾幕；途中随时可以打断。大地图上另有【传送】：雾幕瞬移，是地图上的默认方式（§7.8、SYS-ATLAS §7）。
5. **性能**：界面是 Godot 的 Control 树，放在一个 CanvasLayer（layer 10）里，不进 3D 场景。以 10 Hz 读取世界状态，值变了才刷新（小地图跟随镜头的变换是登记过的逐帧例外，SYS-ATLAS §10）；晶白与深屏按太阳高度离散切换，由 WP-35 写全局参数 `ui_night` 的扫描前沿实现，不改 Theme（UI-VISUAL §3.6）；主线程每帧平均不超过 0.2 ms（§9）。

### 0.1 接入要点

- **要往画面上加界面元素**：只能是本文和 UI-VISUAL 登记的件；3D 画面里不叠地点标签、选中描边、世界空间标记、光柱和路线线条；漫游态唯一常驻的是小地图；`--ui=0` 时全部界面（含小地图、开始页和放映层）隐藏，只剩 3D 画面和署名（§1、§9）
- **要给观者一条临时提示**：只用 §4.9 清单里的条目，清单外的先登记进 §4.9；同时只显示 1 条、新的顶替旧的，不配提示音；`--ui=0`、过场和雾幕期间不出（§4.9）
- **要读键盘、鼠标或加动作**：动作表在 `project.godot` 的输入映射里（WP-00 维护），一律按 `physical_keycode` 绑定，界面上的键名用 `DisplayServer.KeyboardGetLabelFromPhysical()` 换算；Esc 是固定的 `menu` 动作，不改键、不复用 `ui_cancel`；E、I 保留给 `interact`、`inventory`；移动和视角不直接用 `Input.IsActionPressed` 轮询，由 WP-06 按输入优先级的四层过滤后再交出，单键快捷键在第 1、2 层不响应（§5）
- **要占用观者输入（大页、对话框、改键、过场、换图）**：经 `ICameraRig.LockInput(InputLockReason)` 按原因取得，解除时 Dispose；现有原因是 `Atlas`、`Cinematic`、`MapTravel`、`Menu`、`Rebind`，新原因只在枚举末尾追加，契约在 ENG-ARCH §3；占用只挡观者输入，世界照常运行（§5）
- **要弹确认对话框、浮层或卡片**：画在 `HudRoot` 里，不用独占的 `Window` 弹窗，否则关闭请求会被忽略、退出时的保存走不到（§5、§9）
- **要写界面文字**：一律写稳定键 `<域>.<对象>.<用途>`，进 `game/hud/i18n/` 的中英两张 CSV；一句话一条翻译，变量写成 `{place}`、`{key:<动作>}` 这样的具名占位，不拼句；存档和日志只记键（§8）
- **要显示地名、点位名或图名**：区域名与地点名的唯一来源是本图 `atlas/labels.json`，点位名是 `waypoints.json`，锚点和其余标记名是 `atlas/markers.json`，图名是 `map.json` 的 `name`；别处只存 ID、用到时查来源，CSV 里不手写地名（§8）
- **要新增或修改点位**：写进本图的 `waypoints.json`（WP-36），按 `Waypoint` 契约，ID 在本图内唯一，跨图写 `WaypointRef`；位姿必须在可达空间内、不在 30 m 缓冲带里，由 G2 检查（§6；室内点位另见 WLD-INTERIORS §2.17）
- **要让镜头去某处**：飞过去调 `ICameraRig.Transit()`；地图传送一律经 `IAtlasService.Travel`，界面不直接调 `ICameraRig.Transit` 做传送；到达后请求一次保存（§7.3、§7.8）
- **加载与画质统计碰到跳转、传送**：目的地在点击或悬停 150 ms 时插到加载队列最前面（大地图上同一时间只保留一个目的地）；到达帧要求目的地各环就绪，否则雾幕再停最多 1.2 s（行走传送 1.5 s）；跳转帧和传送的雾幕帧不计入自适应画质统计（§7.5）
- **3D 过渡要响应"减少动态效果"**：跳转、改时间、换季、换天气改为 0.5 s 雾幕交叉淡化，读契约 `IMotionSettings` 判断（§7.6）
- **要加一项观者设置**：登记进 §4.6 的设置表，存在 `user://settings.cfg`（档案级，不进存档）；画面设置只经 `IQualityService`、声音设置只经 `IAudioService`，界面不直接读写 `graphics.cfg`、`audio.cfg`；读 cfg 先按文本查 `Object(` 等写法，每个键只接受 bool、int、float、String（§4.6）

## 1 允许什么、禁止什么

本节依据 CORE-INDEX INV-1（不做网页版那套地图功能，允许界面里的平面地图）和 INV-3（允许的界面以 UI-NAV、UI-VISUAL 登记的为准；3D 画面不叠加；漫游态只常驻小地图）。

| 允许 | 禁止 |
| --- | --- |
| 本文件与 UI-VISUAL 登记的面板、按钮、临时提示 | 3D 画面里的地点标签、选中描边、拾取、世界空间标记、光柱、路线线条、追踪标记；罗盘条 |
| 小地图与大地图：目录页、图层与图例、传送卡、自定义标记、比例尺，大地图里的光标坐标与"距此多少米"（SYS-ATLAS §1） | 文字搜索、路径规划、营业时间与电话这类地点信息卡（网页版那套地图功能，INV-1） |
| 操作说明与设置（含"画面"页 SYS-GRAPHICS §9、"声音"页 SYS-AUDIO §13） | 加载进度条、帧率计数（调试构建除外；画面页"试跑"的结果写在画面页的结果卡上，不算帧率计数，SYS-GRAPHICS §5） |
| 开始页、存档页、制作人员与许可（SYS-TITLE §2、SYS-SAVE、UI-VISUAL §8.6–§8.11） | 把扉页做成加载画面：扉页是一张三维静帧；等待只用三过孔等待灯，不显示百分比和剩余时间（SYS-TITLE §1、UI-VISUAL §7.10） |
| 放映层：过场黑边、字幕、时间读数、标题卡、跳过环、等待灯（SYS-TITLE §8.5） | 传送时的 3D 粒子、光柱、锚点发光或"解锁动画"（SYS-ATLAS §1） |
| 界面音效：只给低频编排配短音，悬停默认无声，设置里可以关（SYS-AUDIO §11） | 弹窗广告式的引导、成就、教程关卡 |
| OSM 署名（常驻） | — |

- 地图上的元素只出现在小地图和大地图里；漫游态的其余位置仍然没有比例尺、坐标和距离读数（SYS-ATLAS §1）。
- 场景里的字仍然只用简体中文（INV-4）。界面文案以中文为主，可切换英文（§8）。
- 截图门禁用 `--ui=0` 隐藏全部界面（含小地图、开始页和放映层），这时画面上只剩 3D 画面和署名（ENG-GATES §2 G7）。

## 2 视觉风格（WP-35；以 UI-VISUAL 为准）

界面的视觉一律以 UI-VISUAL 为准，本节只留摘要。

- **主题与主色**：信息、数据、电子、芯片、光与计算。第一主题色清蓝 #73C9F9，按 OKLCH 排成 50–950 的阶梯，深端的 800、900 两档就是校色科技蓝 #1961A0、电子蓝 #003F8D，只作小面积的字、线和图标（UI-VISUAL §3.1）。专业克制，不做霓虹灯管、满屏辉光、常驻扫描线之类的效果（UI-VISUAL §1.3）。
- **色彩分工**：场景暖、界面冷。清蓝只在界面层，不进 3D 材质，世界里不放蓝色全息；界面里唯一的暖色点是 `window.warm` #FFE0A8，只表示"太阳 / 此刻"（UI-VISUAL §2.2）。
- **两套主题**：白天"晶白"、夜间"深屏"，按真实太阳高度离散切换、带回差，切换时一道扫描前沿 0.6 s 扫过；开"减少动态效果"时直接换；不做连续混色（UI-VISUAL §3.6）。
- **常驻小部件固定用深屏**：小地图、时间卡与时间读数、速度条与观察模式、天气签条、界面态右上的图标钮、临时提示、到达标题下的推荐小签，不论昼夜都用深屏底，压在清透高调的画面上也分得开，昼夜交班时也不跳变；设置里"常驻件"一项可改为"随主题"（§4.6）。大页（大地图、设置卡、存档页、数据手册、确认对话框，包括从开始页打开的这些页）仍随昼夜切换，交班的扫描前沿只扫过它们。开始页本身、过场字幕与标题卡、到达标题的字按"压在画面上"处理，不随主题（SYS-TITLE §2.2）。以 UI-VISUAL §2.4、UI-VISUAL §3.6 为准。
- **面板**：默认不透明，晶白约 94%、深屏约 90%，不模糊、不叠纹理；只有大页可选轻度磨砂，独显档默认开、最低配置档默认关；"降低透明度"打开后一律 100% 不透明（UI-VISUAL §5.7）。
- **形状、字体、图标、组件、动效**：每个容器只切左上一个 45° 角，边线一律 1 物理像素（UI-VISUAL §5）；中文思源黑体 SC、拉丁字母与数字 Inter、编号与键帽 JetBrains Mono，全部 OFL（UI-VISUAL §4）；图标按 UI-VISUAL §6，不用植物和器物意象；组件与六种状态见 UI-VISUAL §7；动效见 UI-VISUAL §9 与 UI-VISUAL §10。
- **实现细则**：动效的淡入上移、时长与曲线（不用 Back / Elastic / Bounce / Spring）以 UI-VISUAL §9 为准；用 `SetCustomInterpolator()` 时不调 `SetTrans`、`SetEase`，否则双重缓动（UI-VISUAL §11.7）。字体整包打包、不改字体文件、导入时预渲染字形、用 SC 区域版，细则见 UI-VISUAL §4、UI-VISUAL §11.8。

## 3 布局

布局与坐标以 UI-VISUAL 为准：漫游态见 UI-VISUAL §8.2，界面态见 UI-VISUAL §8.3。下面只是示意。

**界面态**

```
┌──────────────────────────────────────────────────────┐
│ ┌小地图┐[M]     P02 · 核心区 · 坐标       [存][?][≡]  │ ← 中上为到达标题（临时）
│ └──────┘[G]       图 书 馆 正 门                       │
│                                                      │
│                       （画 面）                       │
│                                          ┌时间卡───┐ │
│ [旁观|行走] ▮▮▮▮▮▮▮▮▮▯▯▯ 09/16 · 12 m/s  天气签条 │ 光谱环 │ │
│                                   © OpenStreetMap ...│
└──────────────────────────────────────────────────────┘
```

- **左上**：小地图（SYS-ATLAS §3）；界面态时右侧贴 [M] 大地图、[G] 目录两个按钮。点位目录在大地图的目录页里（§4.5）。
- **右上**：[存档] [说明 H] [设置] 三个图标钮，只在界面态出现。
- **左下**：观察模式与速度条。**右下**：时间卡，天气签条从它的左缘抽出（§4.10）。
- 界面只放在画面上下各约 20% 的移轴虚化带里（ART-STYLE §7.4），不跟主体抢。小地图也在上方 20% 的带里，是唯一在漫游态常驻的元素。
- 布局以 1920×1080 为基准（拉伸模式 `canvas_items`、宽高比 `expand`，§9）。屏幕更宽或更高时，四角的组件贴着各自的角，中间留空。
- 署名仍在右下角，时间卡收起时放在它上方，展开时署名左移让位（SYS-VIEW §6）；存储指示在署名上方（UI-VISUAL §7.10）。
- 开始页的布局见 SYS-TITLE §2.2–§2.3（视觉见 UI-VISUAL §8.6）；存档页见 UI-VISUAL §8.7；大地图见 SYS-ATLAS §4.1；过场的放映层见 SYS-TITLE §8.5。

**隐藏规则**

| 状态 | 呈现 |
| --- | --- |
| 漫游态（鼠标被捕获） | 唯一常驻的是小地图（设置可改为"移动时显示"或"关"，SYS-ATLAS §3）；其余只有临时提示（§4.9），2 秒内淡出。时间卡收起态也不显示 |
| 界面态 | 4 秒没有对界面的操作，普通 HUD 在 1.2 秒内淡到 0；什么算操作、何时不隐藏、怎么唤回见本节末"自动隐藏只作用于没人在用的普通 HUD"一段；小地图不淡出 |
| 热区 | 界面态下鼠标进入屏幕四角 64 px 范围，界面在 180 ms 内回来 |
| 纯净模式 | 按 U 隐藏全部界面，含小地图；再按一次恢复 |
| 大地图打开 | 小地图和其余 HUD 隐藏，世界不暂停（SYS-ATLAS §4.1） |
| 存档页打开；设置卡打开 | 存档页是全屏页，小地图隐藏（SYS-ATLAS §3）；设置卡占左侧约 1/3，盖住左上角，小地图随之隐藏，关上设置卡再回来 |
| 跳转、传送的雾幕段，换图雾幕 | 小地图跟着雾幕淡出，雾幕散开时淡回（SYS-ATLAS §3） |
| 开始页、进场过场、返回标题（`IAppFlow` 的 Title、Entering、Leaving） | HUD 和小地图整体隐藏，只显示开始页或放映层（SYS-TITLE §7.2） |
| 任何状态 | OSM 署名常驻；放映层出现黑边时署名改用固定的浅色（SYS-TITLE §8.5） |

隐藏的界面先关掉焦点和鼠标（`FocusBehaviorRecursive`、`MouseBehaviorRecursive` 设为 `Disabled`），淡出结束再设 `Visible = false`，Tab 键不会落到看不见的控件上（§9）。

**自动隐藏只作用于没人在用的普通 HUD**（WP-35）：

- **什么算操作**：鼠标移动、点击、滚轮，以及对界面的键盘操作（Tab、方向键、Enter、空格作用在控件上；T、H、G、M、`.`、P、J、Y 这类开面板或改时间、季节、天气的快捷键），都让 4 秒重新算起。只移动镜头的键（WASD、升降）不算，所以在界面态里飞行时界面照样会淡出。
- **不自动隐藏**：有控件持有键盘焦点；大页（大地图、设置卡、存档页、数据手册）、确认对话框打开；改键正在等新键；读屏软件在运行（`DisplayServer.AccessibilityScreenReaderActive()` 返回 1 或 −1）。大页本身从不自动隐藏。
- **唤回**：鼠标进四角热区（本节隐藏规则表的"热区"一行），或按 Tab，HUD 在 180 ms 内回来。隐藏时焦点已经关掉，Tab 不会被控件吃掉、会到 `_UnhandledInput`，由 HUD 唤回并把焦点交给 Tab 顺序的第一个控件（§8）。

## 4 组件

各组件的外观、尺寸和状态以 UI-VISUAL §7 为准，本节只写内容和交互。

### 4.1 时间环（时间）

时间环是 24 h 天色光谱环，外观见 UI-VISUAL §7.5。**12 在顶、00 在底、06 在左、18 在右，钟点顺时针增加**，与"只能顺时针拨"一致，也与"面朝南看太阳东升西落"一致。环上不画十二时辰外圈，时辰只写在读数里（MAP-QSH-CORE §2.4 时间广场上的刻度不受影响）。

```
              12
        ╭─────┴─────╮        外环：当季、当前天气下 24 个整点的天色光谱
   06 ──┤   17:30   ├── 18 ○ 把手：太阳（夜里换成月亮）；钟点顺时针增加
        │ 酉时 · 黄昏 │
        ╰─────┬─────╯
              00
  [晨 午 昏 夜] [+1h]
  流逝：暂停 / ●1× / 10× / 60× / 360× / 1440×
  [ 春 | 夏 | ●秋 | 冬 ]          [回到落金初灯]
  稍后 · 夜里转雨                  ← 预报行（§4.10）
```

时间不能逆转（SYS-TIME §1）：时间环只能顺时针拨，没有 −1h 按钮和对应的快捷键；预设和"回到落金初灯"都是前向语义。

- 放在右下的时间卡里（UI-VISUAL §7.5）。时间环是自绘控件，拆三层：静态的环与刻度只画一次；把手是独立子控件，只改 `Rotation`；前向预览弧用 `ui_panel` 的线（§9）。光谱的 24 个天色只在换季、换天气模式时经 `IPaletteProbe` 取一次。时间卡左侧抽出天气签条（§4.10）。
- **拖动把手**：调用 `IWorldControl.SetClock(h, ClockSetMode.Drag)`（SYS-TIME §1），钟点按 SYS-TIME §1 的临界阻尼弹簧跟随，不会跳变。
  - 只能顺时针拖。逆时针拖时，把手停在原处不动，世界时间不减，悬浮说明写"时间只往前走"；
  - 每顺时针拖满一圈，前进 24 h；
  - 拖动或悬停时，环外用一段前向预览弧标出"将要经过的时长"，从当前钟点顺时针画到目标，让观者知道拨到更早的刻度等于快进到次日；
  - 拖动时流逝暂停，松手 1 秒后继续。
- **点击刻度或预设**：调用 `IWorldControl.SetClock(h, ClockSetMode.Jump)`，跳到 h **下一次出现**的时刻（最多前进 24 h），做延时摄影式快进，用时 0.6 + 0.18 × 前进小时数，上限 3 s（SYS-TIME §1）。快进途中天气按前向过程推进，画面只做一次天气过渡（SYS-WEATHER §6.5）；界面主题在快进结束后按终点的太阳高度判断一次（UI-VISUAL §3.6）。
- **[+1h]**：调用 `IWorldControl.Advance(1)`（ENG-ARCH §3），前进 1 小时；快捷键 `.`，按住连续前进（§5）。
- **四个预设按当前季节的太阳计算**，不是固定钟点；都跳到该钟点的下一次出现：
  - 晨：日出后 40 分钟；
  - 午：日出与日落的中点；
  - 昏：日落前 35 分钟（秋季正好是 17:30）；
  - 夜：21:00。
- **流逝**：调用 `IWorldControl.SetFlow()`，取值暂停 / 1× / 10× / 60× / 360× / 1440×，默认 1×（契约 `Flow(int Rate)`，ENG-ARCH §3）。P 键在暂停和上一次的倍率之间切换。分段右侧的倍率波形见 UI-VISUAL §7.5。
- **回到落金初灯**：调用 `IWorldControl.ResetDefault()`（ENG-ARCH §3、SYS-WEATHER §6.6），不移动镜头：
  - 换到秋季，走正向的换季转场（SYS-TIME §5）；
  - 快进到下一个 17:30；已经在 17:22–17:40 之间就不动；
  - 流逝恢复 1×，天气恢复自动，并保持晴到秋季黄昏带结束（约 19:36）；
  - 天气种子不变，也不换世界实例（与新游戏不同，SYS-TITLE §6）；
  - 落定后请求一次保存（SYS-SAVE §4.1）。
  - 多地图下泛化为"回到本图默认状态"，按钮名取本图 `map.json` 的 `world.defaultName`；在清水河上就是"回到落金初灯"，语义不变（SYS-MAPS §5）。
- **读数**：显示"17:30 · 酉时 · 黄昏"这样的读法，不显示日期。世界时间单调递增，但界面只显示钟点，不显示"第几天"。

### 4.2 季节

- 四个分段，图标是年相位正弦上的一点（春：上升零点；夏：波峰；秋：下降零点；冬：波谷）加文字（UI-VISUAL §6.2）；换季进行中，目标段的过孔灯半亮，转场结束才全亮（UI-VISUAL §7.6）。
- 点选调用 `IWorldControl.SetSeason()`，转场按 SYS-TIME §5。转场途中再点别的季节，从当前状态重新定目标。
- 季节可以任意选，但一律用正向转场（扬起 → 雾幕 → 落定，SYS-TIME §5），J 键也一样。
- 换季时保持太阳在弧线上的位置不变，读数里的钟点会重算，数字可能变小；世界时间不倒退（SYS-TIME §1）。
- 换季后手动天气不合法时（例如冬季的雨），在换季雾幕里自动替换（SYS-WEATHER §1），并给一条临时提示（§4.9）。
- 季节不对应具体日期，四季都是满月（SYS-TIME §2）。季节和时间全局共享，切换地图不改（SYS-MAPS §5）。
- 换季落定后请求一次保存（SYS-SAVE §4.1）。

### 4.3 速度

**旁观模式**：16 格离散的"档位条"，和滚轮的 16 档一一对应（SYS-VIEW §2.1）。画成 LED 条：16 个 7×14 的格子，当前档加高，读数用等宽字，例如"09/16 · 12.0 m/s · 巡航"（UI-VISUAL §7.7）。

| 档 | 1 | 4 | 7 | 9（默认） | 12 | 16 |
| --- | --- | --- | --- | --- | --- | --- |
| 速度 m/s | 0.5 | 1.7 | 5.5 | 12 | 40 | 200 |
| 锚点名 | — | 漫步 | 骑行 | 巡航 | 飞鸟 | 云端 |

- 档位按对数分布，相邻两档之比约 1.49。
- 格子下方一条 2 px 的光条表示"贴地限速后的实际速度"（ENG-BUDGET §4），解释为什么离地越近越慢。

**行走模式**："步速"条分 5 档：0.5×、0.7×、1×、1.4×、2×，和滚轮对应（SYS-WALK §2），画成 5 个宽格。

### 4.4 观察模式

- 两段分段 [旁观 | 行走]，图标是"自由视点"与"眼高"（UI-VISUAL §6.2、UI-VISUAL §7.7），放在左下。
- 快捷键 F；双击空格也能切换（SYS-WALK §5）。
- 切换后底部显示"行走 · F 切回旁观"或"旁观 · F 切回行走"，1.6 秒淡出；模式图标按 `step_rate` 翻三帧（UI-VISUAL §9.3 的 M6）。
- 两种模式的界面差别：

| 项 | 旁观 | 行走 |
| --- | --- | --- |
| 速度条 | 16 档 | 5 档步速 |
| 小地图缩放 | 随离地高度和速度自动缩放 | 固定约 120 m（SYS-ATLAS §3） |
| 准星 | 无 | 无 |

两种模式都没有准星，因为没有可以点选的东西。会动的门也不改变这一条：开放室内的房门和楼梯间防火门在观者走近时自动推开、走过后由闭门器缓缓关上（WLD-INTERIORS、SYS-AUDIO），主楼通屋顶空廊的电梯站定 1 秒自动"关门换位"（WLD-INTERIORS §3），都不加交互键。设置里可以打开一个 3 px 的"视角参照点"，作为晕动症辅助：画面里有固定参照物时，晕动症出现得更晚。

### 4.5 点位目录（大地图的目录页）

点位目录是大地图左栏的"目录"页，按 G 直接打开（SYS-ATLAS §4.4）。本节只留摘要：

- **分组**：按总览、核心、南、西、北、东、边界分组（沿用 `WaypointGroup`），组内依次是锚点、观景点、可进入的室内、路线，各带类型图标。点位见 §6。
- **列表项**：96×54 的缩略图（按 1920×1080 基准；按 2 倍即 192×108 导入），由 WP-27 的截图机按推荐状态（含天气）渲染；中英双行名称和编号。缩略图放在 `game/assets/maps/<地图>/thumbs/`（SYS-ATLAS §10）；目录用的小图常驻，在扉页或雾幕期间就已加载。
- **"此处"**：镜头在某个点位 40 m 以内、朝向偏差 60° 以内时，该项标"此处"（过孔灯）。不显示距离和方位。
- 只能在旁观模式下到达的点位，标"仅旁观"图标（自由视点）。
- 焦点或鼠标在目录项上停 150 ms 就开始预取目的地（§7.5）；Enter 打开传送卡（SYS-ATLAS §4.5）。
- 没有搜索框，也没有文字输入。

### 4.6 操作说明与设置

- 可展开的卡片，分"键位""设置""画面""声音""改键""许可"几页，先显示当前模式的键位图。键名按当前键盘布局显示（§5）。设置卡在开场雾幕或扉页之后预建并隐藏，打开时不建控件（§9、UI-VISUAL §11.9）。
- 卡片底部有"返回标题"和"退出"两个按钮：
  - **返回标题**：约 3 s，先保存（`SaveReason.ToTitle`），再在雾幕里回到开始页（SYS-TITLE §4.2、SYS-SAVE §4.1）；
  - **退出**：先同步写设置，再保存存档，然后退出（SYS-SAVE §4.4，流程见 §5）。
- **存档不在设置卡里管理**：存档页从界面态右上的 [存档] 钮或开始页的"存档"打开（§4.13），存档卡的样式见 UI-VISUAL §7.9，存档语义以 SYS-SAVE 为准。
- 设置卡也能从开始页打开（SYS-TITLE §2.2）：画面页右侧 2/3 是实时的 T0，雾幕类改动照常在雾幕里生效；"试跑"在开始页禁用，读出原因"进入后可试跑"。
- **存储**：
  - 设置存进 `user://settings.cfg`（`ConfigFile` 格式），改键存进 `user://input.cfg`（§5）；
  - 画面设置存在 `user://graphics.cfg`，由 WP-32 经 `IQualityService` 读写（SYS-GRAPHICS §6）；声音设置存在 `user://audio.cfg`，由 WP-53a 经 `IAudioService.ApplySettings` 读写（SYS-AUDIO §13）；界面不直接读写这两个文件；
  - **读值只接受基本类型**（SYS-SAVE §8）：ConfigFile 的解析器会按 `Object(…)` 写法当场创建对象，所以先把文件读成文本，含 `Object(`、`Resource(`、`SubResource(`、`ExtResource(` 任一写法就整份不用，退回 `.bak`，`.bak` 也不行就用默认值；再 `ConfigFile.Parse(text)`，每个键按登记表只接受 bool、int、float、String，类型不对或越界用默认值，未知键忽略；
  - 读取失败或文件不存在时用默认值，不报错；
  - 改动后 0.5 s 写盘一次，关闭窗口时再写一次。写法是 `EncodeToText()` → 写 `.tmp` → `FileStream.Flush(true)` → `File.Replace`（留 `.bak`）；不用 `ConfigFile.Save`，也不用 `DirAccess.Rename`（SYS-SAVE §4.5、SYS-SAVE §8）；
  - 这几个设置文件都是档案级的，不进存档，换存档位不变；平面地图的图层筛选也存在 `settings.cfg` 里，自定义标记只进存档（SYS-ATLAS §12）。

### 4.7 首次进入

第一次新游戏的过场交还控制之后（SYS-TITLE §7.3），屏幕下方中央淡淡显示一行"单击画面开始 · Esc 打开菜单 · H 操作说明"，4 秒后淡出，以后不再出现。样式按 UI-VISUAL §7.4 的临时提示。跳过过场时照常出现（SYS-TITLE §5.2）。

- 是否已显示记在 `user://settings.cfg`。这是档案级的，跨存档共享：只在本机第一次新游戏后出现一次，读档、换存档位都不再出现。
- `--title=0`（门禁、截图）不出现。
- 这是唯一的主动引导。

### 4.8 到达标题

- 跳转完成 70% 时，中上淡入到达标题，2.4 秒后淡出。传送到达时在雾幕散到 30% 时淡入（§7.8）。
- 样式见 UI-VISUAL §7.8：一行等宽数据（编号 · 区域 · 经纬度）、细体宽字距的地点名、英文名两侧发丝线与过孔，背后一块暗带，不画面板。
- 标题下方有一枚小签："推荐 秋 18:00 · 晴 [应用]"（天气取 §6 的"推荐天气"列）。点"应用"才改时间、季节和天气；跳转和传送本身都不改。
- **"应用"**：调用 `IWorldControl.Apply(WorldPreset)`（SYS-WEATHER §8），只发一个组合转场：
  - 钟点前向跳到推荐钟点的下一次出现（§4.1）；
  - 季节不同时走正向换季转场（SYS-TIME §5）；
  - 推荐天气从推荐钟点前 0.5 h 到后 2 h 钉住，之后自然演化，天气模式仍是自动；推荐里没写天气的点位按晴钉住（SYS-WEATHER §6.6）。
  - `Apply` 落定后请求一次保存（SYS-SAVE §4.1）。
- 锚点、可进入室内的门口和路线起点没有推荐状态，到达时只出标题，不出小签。

### 4.9 临时提示

漫游态下只允许以下临时提示，都在 2 秒内淡出。样式见 UI-VISUAL §7.4：同时只显示 1 条，新的顶替旧的；底部居中。临时提示一律不配提示音（SYS-AUDIO §11）；`--ui=0`、过场和雾幕期间不出。

- 换季时的天气替换："冬季 · 雨转为雪"（SYS-WEATHER §1）；
- 点不可选的雷雨格："春夏才有雷雨 · J 换季"（SYS-WEATHER §1）；
- 画质推荐变化：显卡名、驱动版本或输出分辨率变了、重新检测后推荐预设变了时，提示一次，例如"推荐画质：均衡 · 设置 › 画面"，不自动改观者的选择（SYS-GRAPHICS §5）；
- 小地图开关（按 N 时）："小地图 · 关（N 打开）"；打开时提示当前模式（SYS-ATLAS §3）；
- 校界与边缘（WLD-OUTSKIRTS §9）：
  - "校外暂未开放"：行走，顶住校界（表面类型 `Boundary`）0.8 s；
  - "前方暂未开放"：旁观，飞到可达空间的水平边缘（在缓冲带里朝外持续 0.5 s，或发生了一次推回）；

- 关着的门（WLD-INTERIORS §4）："此处暂不开放"：顶着关着的门或开放楼里的封口（表面类型 `DoorClosed`）0.8 s，同一扇门 60 秒内不重复；
- 存档（SYS-SAVE §7、SYS-SAVE §4.3）："最近一次保存不完整 · 已回到 5 分钟前"（按两代 meta 的时间差写）、"另一个窗口正在运行 · 本窗口不保存"、"无法保存：磁盘空间不足"之类，各只提示一次；

- 解锁反馈（RPG 预留，观光模式不出现）："已解锁：A08 校训石"（SYS-ATLAS §8）。

### 4.10 天气格

天气清单、季节约束、强度档和自动天气的规则以 SYS-WEATHER §1、SYS-WEATHER §6 为准，本节只定界面的内容与交互，视觉见 UI-VISUAL §7.6。

```
                                           ┌ 时间卡（T 展开）─────────────┐
                                           │      时间环（§4.1）         │
                                           │ [晨 午 昏 夜][+1h] 流逝 …     │
 [自动] 晴 少云 多云 阴 雾 降水 雷雨 初晴  强度 ▪▫▫ ◀┤ [ 春 | 夏 | ●秋 | 冬 ]        │
                                           │              [回到落金初灯]   │
                                           │ 稍后 · 夜里转雨（预报行）     │
                                           └──────────────────────────────┘
 收起时的读数：17:30 · 酉时 · 黄昏 · 秋 · 晴 ○
```

- **位置**：天气放进右下角的时间卡（时间环 + 季节）。时间卡展开时，天气签条从卡的左侧横向抽出，仍在画面下方约 20% 的虚化带里（§3），不加高卡片。签条上只有图标（示意图里写的是格名），名字在悬停、焦点和读屏时给出。
- **8 格加"自动"**：晴、少云、多云、阴、雾、降水、雷雨、初晴，最左是"自动"。
  - 降水格春、夏、秋是雨，冬季是雪；初晴格春、夏、秋是雨后初晴，冬季是雪后初晴。换季后图标和名字跟着换。
  - 雷雨格在秋、冬两季呈禁用态、不可选（按 `IWorldState.IsNative()`，SYS-WEATHER §8），但可以聚焦，读出原因。点它只出提示"春夏才有雷雨 · J 换季"，不替观者换季。
- **图标**：气象站填图符号，36 px 方钮，规格与意象以 UI-VISUAL §6 为准：

| 格 | 符号 |
| --- | --- |
| 自动 | 循环箭头，只在悬停或聚焦时转一轮，不常驻摆动 |
| 晴 / 少云 / 多云 / 阴 | 云量圆：空心 / ¼ / ½ / 实心 |
| 雾 | ≡ |
| 降水 | 雨：两点 ••；冬季的雪：✱ |
| 雷雨 | 雷暴符号 ⟙ 加折线 |
| 初晴 | 空心圆加下方一行短虚线（积水）；冬季为空心圆加下方三枚小雪点 |

- **自动与手动**：
  - 默认是自动：天气按 SYS-WEATHER §6 的前向随机过程变化。"自动"钮为选中态，当前实际天气所在的格下方一枚 4 px 过孔点。
  - 点任意一格进入手动（`IWorldControl.SetWeather(kind, intensity)`，SYS-WEATHER §8），被点的格为选中态；手动天气不随时间变化。
  - 点"自动"（`SetWeatherAuto()`）回到前向过程，从当前天气平滑过渡过去。
  - 换天气的过渡不硬切，按 SYS-TIME §5 和 SYS-MOTION §12.4；"减少动态效果"开启时改为 0.5 秒的雾幕交叉淡化（§7.6）。
  - 天气按地图各一份，切换地图时换成该图的天气（SYS-MAPS §5）；界面照常读 `IWorldState`。
- **强度**：签条右端三枚 10×10 小方块（轻、中、重），只在雾、降水、雷雨下出现，写入 `Intensity` 的 1/3、2/3、1（`SetWeatherIntensity()`）。
  - 默认档按 SYS-WEATHER §1：雨轻、雪中、雾中、雷雨中；雷雨只有中、重两档，"轻"那一枚呈禁用态。
  - 自动天气下，三枚方块用次要色显示当前强度；点其中一枚就以当前天气和所点强度转为手动。
  - 不做连续滑杆，强度不设快捷键。
- **Y 键**（§5）：
  - 单击：切到下一种天气，进入手动。顺序是签条从左到右（晴 → 少云 → … → 初晴 → 晴），只在本季可选的格里循环，跳过禁用格；从自动出发时，从当前天气的下一格开始。
  - 按住 0.6 秒：回到自动，与 R 键的长按语义一致。
  - 受"单键快捷键总开关"约束（§4.6）。
- **读数**：时间卡收起时，读数是"17:30 · 酉时 · 黄昏 · 秋 · 晴"，天气名后一枚过孔灯：自动是空心，手动是实心（UI-VISUAL §7.6）。
- **预报行**：时间卡展开时，卡片底部一行次要色小字（`small`、`text.2`），读前瞻 24 小时的天气队列 `IWorldState.WeatherAhead`（SYS-WEATHER §8）。
  - 例如"稍后 · 夜里转雨""今夜 · 小雨 → 晨雾 → 晴"，最多三个词；
  - 只说粗时段（稍后、傍晚、今夜、明晨），不给钟点、概率、日期和种子；
  - 只在自动天气下显示，手动时这一行隐藏；
  - 队列变了才重排文字（§9）。
  - 不做"将转雨"一类的临时提示：云压低、风变大本身就是预兆。
- **实现**：签条是带 `ButtonGroup` 的切换按钮，强度按三档滑杆声明（§8）；常驻约 20 个 Control（在 §9 的上限以内）。图标放在 `game/assets/hud/icons/`，登记进 `game/assets/hud/manifest.json`（UI-VISUAL §6.1）。

### 4.11 小地图（摘要）

详细规格以 SYS-ATLAS §3 为准，视觉按 UI-VISUAL。

- **位置**：左上角，离屏幕边 32 px，外框约 244×272（上方 226×226 的地图视口、下方 28 px 底栏）；在上方 20% 的虚化带里，不进画面中央 60%。

- **界面态的附加件**：视口右侧两个按钮 [大地图 M]、[目录 G]；单击小地图也打开大地图。漫游态时小地图不可聚焦、不显示这两个按钮。

### 4.12 大地图（摘要）

详细规格以 SYS-ATLAS §4 为准，框架与视觉见 UI-VISUAL §8.4。

- **打开**：M 打开，以玩家为中心；G 直接打开左栏的"目录"页（§4.5），全图适配。从小地图所在的左上角展开，开合动效与时长按 UI-VISUAL §9.9（SYS-ATLAS §4.1）。

### 4.13 开始页、存档页与放映层（摘要）

流程以 SYS-TITLE 为准，存档语义以 SYS-SAVE 为准，视觉见 UI-VISUAL §8.6、UI-VISUAL §8.7、UI-VISUAL §8.9。界面部分归 WP-35d。

- **开始页**（SYS-TITLE §2）：冷启动先是扉页静帧，再交叉淡化成实时的 T0 镜头"云隙望穹"，显示最近存档的世界，流逝停住。菜单：继续 / 新游戏 / 存档 / 设置 / 制作人员与许可 / 退出。"继续"后面跟一行等宽摘要；没有存档时"继续"是禁用态（可聚焦，读出"还没有存档"），焦点落在"新游戏"。首次启动时菜单下方一行"已按本机推荐：……"（SYS-GRAPHICS §5）。片名不用书法，细体宽字距，下面一行真数据。

## 5 鼠标捕获、界面态与快捷键（WP-35，WP-06 配合）

**两种状态**（Playing 状态里）

| 状态 | 鼠标 | 界面 | 输入 |
| --- | --- | --- | --- |
| 漫游态 | 被捕获（`Input.MouseMode = Captured`），Windows 下走原始输入（SYS-VIEW §2.1） | 只有小地图常驻，另有临时提示（§4.9） | 移动、转视角、全部快捷键 |
| 界面态 | 可见（`Input.MouseMode = Visible`） | 界面淡入，4 秒没有操作后淡出，小地图不淡出（§3） | 移动键和快捷键照常有效；鼠标移动不转视角。大页、确认对话框、改键打开时按本节末的"输入优先级"表 |

过场交还控制后处于界面态（SYS-TITLE §7.3），第一次新游戏时由首次引导提示"单击画面开始"（§4.7）。`--title=0`（门禁、截图）时没有开始页和过场，雾幕淡出后直接进入界面态（SYS-VIEW §3）。

**开始页与过场期间**（`IAppFlow` 的 Title、Entering、Leaving，SYS-TITLE §7.2）

- 鼠标可见、不捕获；单击三维画面没有作用；游戏里的单键快捷键（F、G、M、N、P、T、H、Y、J、U、数字键等）全部无效。
- **开始页**（Title）：只认菜单键 ↑ ↓ Tab Enter Esc。Esc 关掉子页面；在主菜单上按 Esc 什么也不做，不会误触退出（SYS-TITLE §2.2）。
- **进场过场**（Entering）：只认"按住 Esc 0.8 s 跳过"（SYS-TITLE §5.1）。移动键、鼠标移动、单击都不打断过场，不做"单击即跳过"。第一次有任何输入时，上黑边里浮出"按住 Esc 跳过"和跳过环；松开在 0.2 s 内退回。跳过后的终态与完整播放一致。
- **返回标题**（Leaving）：约 3 s，不可跳过，期间不接受输入（SYS-TITLE §4.2）。

**切换规则**

- **Esc**：用自定义动作 `menu`，在 `_UnhandledInput` 里处理，不复用 `ui_cancel`。打开着的下拉菜单这类控件会在 GUI 阶段先吃掉 Esc，所以它们自己关闭时不会连带切换状态。
  - 漫游态 → 界面态；
  - 界面态、有面板展开 → 关掉面板；
  - 界面态、没有面板 → 回到漫游态；
  - 大地图打开时：先关传送卡或浮层，再关大地图，留在界面态（SYS-ATLAS §4.7）；
  - 地图传送的雾幕开始升起之前按 Esc，取消这次传送（§7.4）。
  - Esc 固定，不能改键。
- **Esc 不暂停世界**，时间照常流逝；暂停流逝用 P。大地图打开时世界也不暂停。
- **G / T / H / M**：漫游态下按，直接切到界面态并打开对应面板（G 是大地图的目录页，M 是大地图）；界面态下按，开关对应面板。M 关闭大地图时回到打开前的状态：从漫游态打开的，回到漫游态（SYS-ATLAS §4.7）。
- **N**：漫游态、界面态下都直接切换小地图显隐，不改变当前状态（SYS-ATLAS §3）。
- **单击画面**：只有 GUI 没处理、到达 `_UnhandledInput` 的左键按下才算，切到漫游态。有面板展开时，第一次单击画面只收起面板。大地图打开时，地图页自己处理单击，不算单击画面。
- **防误触**：
  - 界面根节点 `MouseFilter = Ignore`，只有面板和控件本身是 `Stop`，点在空白处的鼠标事件才落到画面上；
  - 拖动滑杆和时间环时，按下的控件会一直收到拖动事件，松手落在画面上不算单击画面（§12）。
- **窗口失焦**：收到 `NotificationApplicationFocusOut` 时主动切到界面态。引擎在失焦时会释放已按下的键和鼠标捕获，重新激活时却会自动恢复捕获；主动切到界面态，切回来时鼠标才不会被直接抓走。失焦期间世界照常运行。同一处同时请求一次保存 `ISaveService.Request(SaveReason.FocusLost)`（WP-06，SYS-SAVE §4.1）。
- **退出**：设置卡里的"退出"、开始页的"退出"、关闭窗口、Alt+F4 都会退出。流程（SYS-SAVE §4.4、SYS-TITLE §7.1）：
  - Boot 在第一帧之前设 `GetTree().AutoAcceptQuit = false`；
  - 收到关闭请求（`NotificationWMCloseRequest`）后，`IAppFlow` 进入退出流程，关闭输入；先同步写设置（§4.6），再调 `FlushForQuit(SaveReason.Quit, 2 s)`：雾幕 0.3 s 淡入，存档在后台写完，然后 `Quit()`；等待超过 1.5 s 时亮等待灯；
  - 进场过场途中退出：先把过场的终态落定（按跳过的收尾，不渲染过渡），再保存；开始页、Boot 里退出只写设置；
  - 鼠标被捕获时的 Alt+F4 由 Godot 转成关闭请求，走同一流程；
  - 界面不用独占的 `Window` 弹窗：有独占子窗口打开时，关闭请求会被忽略（§9）；
  - 保存明确失败（`FlushForQuit` 返回 `Failed`）时不退出，在雾幕上弹"重试 / 返回游戏 / 仍然退出"三选一（SYS-SAVE §4.4 第 7 步）；它是确认对话框，按本节末"输入优先级"表的第 1 层处理。

**键位的实现**

- 动作全部定义在 `project.godot` 里（WP-00 维护），一律按 `physical_keycode` 绑定，换键盘布局不改变键的位置。界面上显示的键名用 `DisplayServer.KeyboardGetLabelFromPhysical()` 换成当前布局上的字母。地图相关的动作是 `map`（M）、`atlas_index`（G）、`minimap`（N），可改键（SYS-ATLAS §13）。
- **空格**：引擎内置的 `ui_accept` 和 `ui_select` 都含空格。必须从 `ui_accept` 里去掉空格，否则带焦点的按钮会和上升、跳跃同时触发。
- **改键**：设置里的"改键"页监听下一个按键，用 `InputMap.ActionEraseEvents()` 和 `InputMap.ActionAddEvent()` 改绑定，存进 `user://input.cfg`，启动时由 `Boot` 读回。一个物理键只能绑一个动作，冲突时提示并拒绝。文件里只存物理键码（int）和鼠标键号，不存 `InputEvent` 对象（用 ConfigFile 直接存对象，写出来就是 `Object(InputEventKey,…)`）；读回时按 §4.6 的规则只接受基本类型（SYS-SAVE §8）。
- **输入法**：非文本框获得焦点时，引擎会用 `ImmAssociateContext(null)` 关掉窗口的输入法，中文输入法开启时字母键被拦截的风险因此基本消除；界面里也没有文本框（自定义标记不做文字备注，SYS-ATLAS §4.6）。
- **粘滞键**：连按 Shift 5 次会弹出系统的粘滞键对话框。潜行和下降都是按住 Shift，影响小；只在操作说明里提一句，不改系统设置。
- **Ctrl + Shift**：装了多个键盘布局的 Windows 上，Ctrl+Shift 可能切换布局，疾跑时同时按下降或潜行就可能触发。键位按物理键绑定，切了布局也照常工作；只在操作说明里提示（§12）。

```csharp
    WaypointRecommend Recommend);
```

没有预设 `Stand` 但又需要行走落点时，自动搜索：从位姿在地面的投影开始，向观看目标螺旋搜索，半径 60 m 以内。条件是可站立、头顶净空不小于 2 m、坡度不大于 30°、不是水面、能看到目标、离目标 15–60 m。

## 7 跳转过渡（WP-36）

### 7.1 跳转方式

| 距离 d | 方式 | 时长 |
| --- | --- | --- |
| < 80 m | 直线滑移，五次平滑曲线（smootherstep） | 1.0–1.6 s |
| 80–600 m | 弧线飞行 | T = 1.6 + 0.9·ln(1 + d/120) 秒；100 m 约 2.2 s，600 m 约 3.2 s |
| ≥ 600 m | 升空到 180–250 m，在弧顶进入雾幕约 0.5 s，在雾中移到目的地上空，再从雾里降落 | 3.5–4.5 s |

- 这三种是"飞过去"，由数字键、`[` `]` 和大地图上的【飞过去】触发，按距离自动选。第四种"传送"只能由大地图触发，不按距离自动选择，见 §7.8。
- **弧线顶点高度**：取 max(起点高度, 终点高度, 沿途 16 个采样点的最高屋顶 + 20 m) + 0.18 d，所以途中不会穿楼。
- **活动范围**：途中不施加边界推回；路径的每个采样点都必须在可达空间内，弧线越界时抬高弧顶（WLD-OUTSKIRTS §8.5）。
- **雾幕**：颜色取当前地平线的雾色，和开场雾幕（SYS-VIEW §3、SYS-TITLE §1）是同一种语言。它是界面层之下一个 CanvasLayer 里的全屏 `ColorRect`，由 WP-01 提供（§9），透明度由 Tween 驱动。
- **速度曲线**：按弧长参数化，加速段占 35%，减速段占 65%，落定时更从容。
- **实现**：
  - 自写 `Transit`（`game/camera/transit/`），在 `_Process` 里自己算路径，用弧长表控制速度曲线，朝向用四元数插值并限制偏航角速度；
  - 不用 Tween 驱动镜头：中途打断、改道、"保留速度并在 0.2 秒内减速"都要随时改目标，Tween 不方便；
  - `Curve3D` 只用于点位的进场路径（§6）和过场播放器（SYS-TITLE §8.3）；`Transit` 本身不用；
  - Tween 只管界面淡入淡出、雾幕透明度和视场角。
- **声音**：开始跳转时放界面音"传送确认"，到达标题出现时放"传送到达"；600 m 以上的雾幕里声景压低、换场（SYS-AUDIO §7.2、SYS-AUDIO §11）。

### 7.2 镜头朝向

- 前 25%：转向目的地的观看目标，偏航角速度不超过 90°/s；
- 中段：视线锁定目标；
- 最后 25%：缓入到终点位姿；
- 全程不滚转。

这个思路来自 Cesium 的 `flyTo` 和 van Wijk 的平移缩放路径：时长随距离自动计算，飞得高时镜头朝下看。

### 7.3 到达

- 保持原来的观察模式，镜头不再自己动。
- 行走模式下：目的地是 `Stand`，最后 0.4 秒垂直落定，落地后恢复重力；最后 0.3 m 交给物理，交接时清掉相机的插值缓冲（SYS-WALK §5）。碰撞数据就绪之前不散开雾幕、不开启物理（SYS-WALK §14 第 5 条），最多等 1.5 秒。目的地在开放室内时，还要等这一层的楼板碰撞就绪（ENG-PERF §5 第 6 条，WLD-INTERIORS §6.4）。
- 进入室内或水下时，按点位的 `Entry` 走进场路径，介质切换由 SYS-VIEW §5 处理。
- 到达后请求一次保存（SYS-SAVE §4.1 的 `Settled`）。

### 7.4 打断

- 按任何移动键、鼠标累计移动超过 30 px，都会取消飞行：镜头停在原地，保留当前速度，按 0.2 秒自然减速（与 Cesium 的 `cancelFlight` 一致）。
- 在雾幕阶段打断：先完成移位，再交还控制。
- 途中选了另一个点位：从当前状态平滑改道。
- 再按一次同一个点位：用 0.3 秒的雾幕直接跳到终点。
- **地图传送**（§7.8）：雾幕开始升起之前（按下后约 1 帧内）按 Esc 取消；雾幕升起之后不能取消，先完成移位再交还控制。传送进行中再点别的标记会被忽略，到达后才能再传（SYS-ATLAS §7.5）。

### 7.5 预取与速度律豁免

自由飞行受速度律约束（ENG-BUDGET §4），因为程序不知道观者要去哪里。跳转和传送的路径是已知的，所以豁免速度律，改用以下保证：

1. **点击（或悬停 150 ms）时**，把目的地的 L0+、L0（40 m 环）、L1（150 m 环）、L2（400 m 环）、室内提供者（含 WLD-INTERIORS 开放室内的当前层）插到加载队列最前面；行走模式下，再加上落点周围的碰撞格（SYS-WALK §13）。室内点位和室内门口，把这栋楼的室内包和碰撞一起插进已知目的地队列（WLD-INTERIORS §6.2）。
   - 大地图上：传送卡打开时、标记悬停 300 ms 时、目录项停留 150 ms 时同样预取；同一时间只保留一个目的地（SYS-ATLAS §7.4）。
2. **沿途**：按弧线采样，把途经的 L1 格排在目的地之后预取。传送没有沿途。
3. **为什么这样够用**：
   - d < 80 m 时，起点和终点的 L0 环（各 40 m）已经覆盖全程；
   - 80–600 m 时，中段在高空，只需要 L1、L2，起终两端的 L2 环已覆盖全程；
   - ≥ 600 m 时，高速巡航在雾幕里；
   - 传送的移位整个在雾幕里。
4. **最后 25% 的速度不超过速度律**，所以落地时近景一定是 L0。
5. **到达帧**要求目的地各环就绪，否则雾幕再停，最多 1.2 秒（传送在行走模式下 1.5 秒，§7.8）。
6. 跳转帧和传送的雾幕帧不计入自适应画质的统计（ENG-PERF §11.3）。

### 7.6 减少动态效果

"减少动态效果"开启时（设置项，默认跟随系统，§8），跳转、改时间、换季、换天气都改为 0.5 秒的雾幕交叉淡化，远处的云内闪关闭（SYS-WEATHER §5）。地图传送本来就是雾幕，流程不变，只有大地图的收拢改为透明度变化（SYS-ATLAS §7.2）。界面动画只保留透明度变化（替代表见 UI-VISUAL §10.1）；疾跑时不改视场角。3D 侧读契约 `IMotionSettings`（UI-VISUAL §11.11）。

### 7.7 为什么飞过去，又为什么有传送

- **飞过去保住地理感**：原神、星穹铁道的快速旅行是"淡出、加载、淡入"，《我的世界》旁观者是瞬移，这两种都会丢掉地理感。所以数字键、`[` `]` 和大地图上的【飞过去】仍然在起点和终点保留飞行，只在中段用雾幕。
- **传送提供原神式的直达**：大地图上的【传送】是默认方式（§7.8、SYS-ATLAS §7）。它不是"淡出、加载、淡入"：雾幕的颜色取当前地平线的雾色，与开场、跳转是同一种语言；不显示加载画面、进度和等待文字；到达帧保证就绪。观者可以在设置里把地图上的主按钮改成【飞过去】（§4.6）。
- **跨图**：飞过去和传送都只适用于同一张图里。跨图没法避免加载，走"雾幕 → 加载 → 雾幕散"（SYS-MAPS §4）；以后可以换成飞越雾海的演出（SYS-MAPS §14）。清水河现在只有一张图。

### 7.8 传送（地图）

详细规格以 SYS-ATLAS §7 为准，本节只留摘要。

- **入口**：只有大地图能触发：传送卡的主按钮【传送】，或在目录里选中后按 Enter、再按 Enter（SYS-ATLAS §4.7）。只有锚点、观景点、可进入室内的门口、路线起点可以传送；目的地就在 20 m 以内时按钮灰显，写"此处"。
- **时序**（雾幕瞬移）：
  1. 按下【传送】：大地图收拢 0.25 s，与下一步同时开始；镜头输入保持关闭；
  2. 雾幕 0.3 s 盖满；
  3. 一帧内把相机放到目的地位姿，清掉相机的插值缓冲；
  4. 等目的地就绪：各环（§7.5 第 5 条）、行走模式的碰撞格（SYS-WALK §14 第 5 条）、开放室内的当前层（WLD-INTERIORS）；至少停 2 帧，最多 1.2 s，行走模式 1.5 s；
  5. 雾幕 0.6 s 散开，散到 30% 时淡入到达标题（§4.8），读屏的实时区域写入"已到达：……"（§8）；
  6. 交还控制：旁观静止悬停；行走落地，最后 0.3 m 交给物理（§7.3）。
  - 总时长约 1.1–2.4 s。到达后请求一次保存（SYS-SAVE §4.1）。
- **落点**（SYS-ATLAS §7.3）：锚点、观景点照各自的 `Fly`、`Stand`；可进入的室内落在门外 2.5 m、面向门，不直接落进室内，让观者自己走进那道暖光；室内观景点（P16–P23）直接落在 `Stand`，不走进场路径；路线起点落在第一个节点，朝路线前进方向。"仅旁观"的目的地在行走模式下自动切到旁观并提示一次。
- **契约**：`TransitOptions.Prefer = TransitPreference.Teleport` 触发 `TransitKind.Teleport`（ENG-ARCH §3、SYS-ATLAS §11）。界面不直接调 `ICameraRig.Transit`，传送一律经 `IAtlasService.Travel`（WP-48c）。
- **与其他过渡叠加**：换季、换天气过渡或快进时间进行中也可以传送，雾幕和这些过渡叠在一起，不额外处理。换图雾幕、过场、开始页期间，地图打不开，也不能传送（SYS-ATLAS §7.5）。
- **声音**：按下时放"传送确认"，雾幕盖起时声景压低，散到 30% 时放"传送到达"（SYS-AUDIO §11）。
- "减少动态效果"开启时流程不变（§7.6）。

## 8 无障碍与语言（WP-35）

读屏用引擎内置的 AccessKit 支持。

- **对比度**：文字不低于 4.5:1，图标和控件不低于 3:1。按 UI-VISUAL §3.7 的令牌表，晶白、深屏两套主题各验一遍，交班扫过中的每一帧都要达标（只有前沿那 2% 宽的一条例外）。
- **焦点环**：衍射光边（UI-VISUAL §5.6）：控件外侧 3 px 一圈 1 物理像素的实线核（晶白 b-800、深屏 b-300），外衬 1 px 面板底色，两侧极淡的冷色色散，在任何背景上都看得见；由 `ui_panel` 的 instance uniform `focus` 画，Theme 的 `focus` StyleBox 只作兜底。`gui/common/show_focus_state_on_pointer_event` 设为 0：鼠标点击不显示焦点环，只有键盘导航时显示。
- **键盘可达**：
  - 界面态下按 Tab 依次经过：小地图旁的两个按钮（SYS-ATLAS §3）、右上的存档 / 说明 / 设置钮、模式、速度、时间、季节、天气。顺序用控件的 `FocusNext`、`FocusPrevious` 显式指定。
  - 速度用 `HSlider`。时间环是自绘控件：在 `NotificationAccessibilityUpdate` 里用 `AccessibilityServer.UpdateSetRole(GetAccessibilityElement(), AccessibilityRole.Slider)` 声明为滑杆，再用 `UpdateSetNumValue()`、`UpdateSetValue()` 写入数值和"17:30，黄昏"这样的读法；方向键拨动钟点，只有"增大"方向有效（时间不能倒退，§4.1）。
  - 季节、模式和天气签条用带 `ButtonGroup` 的切换按钮，读屏时是一组单选；天气强度声明为三档的滑杆。禁用态的雷雨格保持可聚焦，读屏读出原因"春夏才有雷雨"（§4.10）。说明钮打开设置卡的"键位"页。
  - **大地图**：Tab 在左栏（图层、目录）和地图页上的传送卡之间移动；只用键盘就能完成一次传送：G → ↑↓ → Enter → Enter（SYS-ATLAS §4.7）。焦点不逃出打开着的大页。
  - **开始页**：↑ ↓ 或 Tab 移动焦点，Enter 确认；禁用的"继续"可聚焦，读出原因（SYS-TITLE §2.2）。存档页、确认对话框同样能用键盘走完。
  - 设置卡的"画面"页（SYS-GRAPHICS §9）和"声音"页（SYS-AUDIO §13）同样要能用键盘走完：预设分段是一组单选，每行的分段选择用方向键切换，"雾幕""重启"生效标签写进可读的名字。
  - 到达点位或传送到达时，一个 `AccessibilityLive = Polite` 的 Label 写入"已到达：图书馆正门"，读屏软件会朗读。过场字幕和标题卡也写进这样的 Label（SYS-TITLE §3.2）。
  - 每个可获得焦点的控件都要有可读的名字：用按钮文字，或 `AccessibilityName`。图标按钮必须写 `AccessibilityName`；小地图的名字是"小地图，核心区 · 图书馆"（SYS-ATLAS §3）。
  - 四角的组件各放在一个 `AccessibilityRegion = true` 的容器里，读屏软件可以按区域跳转（4.7 新增的地标导航）。
  - **界面不会在键盘和读屏用户手里消失**：对界面的键盘操作、持有焦点、读屏软件在运行都让 HUD 保持显示，隐藏后按 Tab 唤回并落到 Tab 顺序的第一个控件（§3）。确认对话框、改键和大页打开时，键盘只到最上面那一层（§5 的输入优先级），焦点不逃出打开着的对话框和大页。
- **读屏支持仍是实验性的**，G14 的读屏判据只能尽力而为（§10）。`accessibility/general/accessibility_support` 保持默认的"自动"：没有辅助软件运行时，不处理读屏更新。
- **减少动态效果**：设置项，默认跟随系统。系统值用 `DisplayServer.AccessibilityShouldReduceAnimation()` 读，Windows 上取的是系统的动画开关；返回 −1（未知）时按"关"处理。效果见 §7.6；界面侧的替代表见 UI-VISUAL §10.1，昼夜交班直接换、不扫。
- **降低透明度**：打开后全部面板 100% 不透明，关闭大页磨砂（UI-VISUAL §5.7）。
- **界面主题锁定**：自动 / 晶白 / 深屏（UI-VISUAL §3.6）；畏光的观者可以固定深屏。
- **闪烁**：同一区域亮度变化 ≥ 10% 的事件每秒不超过 1 次，没有常驻循环和全屏闪白（UI-VISUAL §9.8）。
- **声音**（SYS-AUDIO §13）：单声道、突发声音（正常 / 柔和 / 关）、安静模式登记为无障碍项；"声音"页要能用键盘走完（G14）。
- **语言**：中文为主，提供英文。
  - 用 `TranslationServer` 加 CSV 翻译表（放在 `game/hud/i18n/`；4.6 起 CSV 支持上下文列）；
  - 默认按 `OS.GetLocaleLanguage()` 选择，设置里可以切换；
  - 点位名在大地图的目录页里中英双行显示，地图上的字可以有英文名（SYS-ATLAS §1）；
  - 理由：校内有留学生组团，博物馆门头已有一行英文。场景里的字仍然只用简体中文（INV-4）。
- **文本约定**（WP-35c 维护；所有写界面文字的包照此写）：
  - **稳定键**：界面文字一律写键，不写原文。键名是小写加点的 `<域>.<对象>.<用途>`，例如 `hud.toast.save_failed`、`save.error.disk_full`。发布过的键不改名、不复用；文案改了键不变，意思变了换新键。存档和日志只记键（如 meta 的 `placeKey`，SYS-SAVE §3.2）。
  - **整句加具名占位**：一句话是一条翻译，变量写成 `{place}`、`{time}`、`{key:menu}` 这样的具名占位，不把几段译文拼成一句（中英文语序不同）。数字和时间由代码按当前语言格式化后填进去；`{key:<动作>}` 填当前绑定的键名（`KeyboardGetLabelFromPhysical`，§5）。英文要分单复数的写成两个键（`.one`、`.other`）。
  - **地名只有一个来源**：区域名和地点名（含楼名）在本图 `atlas/labels.json` 的区域与地点表，点位名在 `waypoints.json`，锚点和其余标记的名字在 `atlas/markers.json`，图名在 `map.json` 的 `name`（SYS-ATLAS §2.5、§9）。别处只引用 ID，用到名字时查来源：平面地图标注、目录、到达标题、地点字幕、存档卡摘要都走同一个查询。`place.<区域 ID>` 这类键在加载时由区域与地点表注册进 `TranslationServer`，不在 CSV 里手写地名。
  - **回退**：系统语言以 `zh` 开头取中文，其余取英文；当前语言缺键时回退中文，中文也缺就显示键名并写日志；`LocalizedName.En` 为空时用 `Zh`。
  - **刷新**：控件只记"键 + 参数"，显示的文字由它们算出。切换语言时在同一帧调 `TranslationServer.SetLocale`，可见的控件收到 `NotificationTranslationChanged` 后重算文字和读屏名字；预建隐藏的页标脏，打开前先重算，不会出现半个界面换了语言的一帧。改键提交后，含 `{key:…}` 的文字同样重算。平面地图换用这种语言的标注布局（SYS-ATLAS §2.5）。
  - **排版语言**：`Label.Language` 跟随当前语言，汉字字形由字体链保证是 SC（UI-VISUAL §4.2）。
  - **检查**（G2）：代码里引用的键在中英两张表里都有，两边的占位名一致；同一个 ID 的中英文名只在来源里出现一次，CSV 里没有手写的地名。

- **读取世界状态**：`HudModel` 是 WP-35 自己注册的 Kernel 服务（`Kernel.Get<T>()` 取用），不另设 Autoload。
  - 它把帧间隔累加到 0.1 s 采样一次 `IWorldState`（SYS-TIME §1，含天气 `Weather` 和前瞻队列 `WeatherAhead`，SYS-WEATHER §8）、`ICameraRig`（ENG-ARCH §3）和 `IAppFlow` 的状态（SYS-TITLE §7.4），值变了才发 C# 事件。不用 `Timer` 节点（ENG-ARCH §2 的计时规则）；
  - 换季、换天气模式时经 `IPaletteProbe` 取一次 24 个整点的天色，供时间环的光谱（UI-VISUAL §11.11）；
  - 画面页打开时订阅 `IQualityService.Changed`（SYS-GRAPHICS §8），关上就退订；
  - 隐藏的面板不订阅、不刷新；
  - 时间环拆层：静态层只画一次，把手只改变换（UI-VISUAL §7.5）；
  - 禁止在 `_Process` 里逐帧改控件的文字、尺寸或主题（ENG-BUDGET §7）；动效只改 `Modulate`、不在容器里的 `Position` 与 `Rotation`、instance uniform 和扫过期间的 `ui_night`（UI-VISUAL §11.7）；淡入淡出交给 Tween。
  - **小地图与大地图的逐帧例外**（SYS-ATLAS §10、ENG-BUDGET §7）：可以逐帧写着色器参数和变换（`Position`、`Rotation`、`Scale`），"随镜头"模式下标记层可以逐帧重画；仍然不逐帧改文字、尺寸和主题。
- **写入**：只调用 `IWorldControl`（SYS-TIME §1；天气的 `SetWeather`、`SetWeatherAuto`、`Apply` 见 SYS-WEATHER §8）、`IViewControl`（SYS-WALK §13）、`ICameraRig.Transit()`（ENG-ARCH §3，数字键与 `[` `]` 的飞过去）、`IQualityService` 的 `Plan()`、`Apply()`、`ConfirmDisplay()`（SYS-GRAPHICS §8）、`IAppFlow` 的 `Enter`、`ReturnToTitle`、`Quit`、`Skip`（SYS-TITLE §7.4）、`IAudioService` 的 `PlayUi`、`ApplySettings`（SYS-AUDIO §11、SYS-AUDIO §13）；实现并注册 `IMotionSettings`（UI-VISUAL §11.11）；写全局参数 `ui_night`（只此一项）。不直接改内核状态，也不读写 `user://graphics.cfg`、`user://audio.cfg` 和存档。地图界面另依赖 `IAtlasService`，传送一律经 `IAtlasService.Travel`，不直接调 `ICameraRig.Transit`（SYS-ATLAS §11）。G4 检查 `game/hud/` 只依赖契约和这几组接口。
- **界面音效**：在输入回调里调 `IAudioService.PlayUi(UiCue)`，当场发声；"界面音效"关时不产生声部（SYS-AUDIO §11）。
  - 交班音 `ShiftDayNight` 不来自输入，由 `UiThemeClock` 在切换那一帧发，**只在界面确有变化时出**：扫描前沿真的扫过屏上的控件，即有大页（大地图、设置卡、存档页、数据手册、确认对话框）开着，或"常驻件"设为"随主题"。常驻件固定深屏、又没有大页开着时，主题切换在屏上看不见，也就不出声。另按 SYS-AUDIO §11 只在流逝 ≤ 10× 时出。
- **隐藏**：开始淡出时，先把面板的 `FocusBehaviorRecursive` 和 `MouseBehaviorRecursive` 设为 `Disabled`（4.5 起），淡出结束再设 `Visible = false`。
- **对话框**：确认对话框、传送卡、浮层都画在 `HudRoot` 里，不用独占的 `Window` 弹窗：有独占子窗口打开时，关闭请求会被忽略，退出时的保存流程就走不到（SYS-SAVE §4.5）。
- **缩放与 DPI**：
  - 项目设置：拉伸模式 `canvas_items`，宽高比 `expand`，基准分辨率 1920×1080；3D 渲染不受影响；
  - `canvas_items` 下画布的总缩放 = 拉伸比例 × `ContentScaleFactor`，拉伸比例 s = min(窗口宽 / 1920, 窗口高 / 1080) 已经让界面随窗口等比放大，所以 `ContentScaleFactor` 不乘 `ScreenGetDpi() / 96`，否则 DPI 会被算两遍（UI-VISUAL §11.10）；
  - 公式（UI-VISUAL §11.10）：`ContentScaleFactor = clamp(界面缩放, lo, max(lo, hi))`，其中 lo = 0.85 / s（字不小于设计字号的 85%），hi = min(窗口宽 / 1280, 窗口高 / 720) / s（逻辑视口不小于 1280×720）；**不乘 DPI**；
  - DPI 只用于首次估计默认值：物理屏高小于 8 英寸的小尺寸高 DPI 屏，默认 125%；`Window.DpiChanged` 不参与缩放计算；
  - 改缩放那一帧会卡 1.6–4.1 ms，所以滑杆松手后 0.2 s 去抖再应用，不在拖动中逐值应用。
- **字体与图标**：字体与 MSDF 见 UI-VISUAL §4、UI-VISUAL §11.8（标题字重用 MSDF，导入时预渲染全部会用到的字）；图标见 UI-VISUAL §6.1（SVG 用 `DpiTexture`，出问题退回 2×、3× 两套 PNG）。
- **预热与预建**（UI-VISUAL §11.9、SYS-TITLE §1.1）：界面着色器 × 各绘制类型在扉页或开场雾幕后面各画一次；设置卡（含画面页、声音页）、存档页、开始页菜单、制作人员页、大地图的卡片与左栏预建一次并隐藏；建页、开合、滚动数字、交班扫过的代码路径空跑一遍。之后 `PipelineCompilationsCanvas` 不再增长，运行中不新生成 MSDF 字形。
- **预算**：
  - 界面脚本与排版：主线程平均每帧不超过 0.2 ms（HudModel、界面脚本和布局合计），峰值 0.3 ms；画布渲染 CPU（剔除与合批）单列，≤ 0.3 ms，最低配置档 ≤ 0.5 ms（UI-VISUAL §12）；
  - 界面每秒刷新不超过 10 次（小地图与大地图的逐帧例外见本节"读取世界状态"）；
  - 可见且在处理的 Control 不超过 400 个，预建隐藏的另计，总数不超过 700。天气签条常驻约 20 个；小地图 ≤ 12、大地图 ≤ 120（预建、隐藏）；画面页约 120 个、声音页约 30 个，都预建；开始页可见的不超过 60 个；
  - 小地图主线程平均 ≤ 0.02 ms，大地图打开时界面合计仍 ≤ 0.2 ms（SYS-ATLAS §10）；
  - 常驻面板不做实时模糊；大页磨砂可选，最低配置档默认关（UI-VISUAL §5.7）。
- **命令行参数**：`--ui=0` 隐藏全部界面（含小地图、开始页和放映层），只给截图和测试用（ENG-GATES §1）；`--ui-theme=auto|light|dark`、`--motion=full|reduced|instant`、`--ui-scale=<0.75–1.5>`、`--ui-gallery=<页名>`、`--ui-export-theme=<路径>` 见 UI-VISUAL §11.12；`--title`、`--cine` 见 SYS-TITLE（ENG-GATES §1）。
