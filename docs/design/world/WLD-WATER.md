## 0 结论

1. **动画式画法**：所有水面都是硬边波纹线、带断口的泡沫线和按到岸距离分的三道硬边色带，不做写实的法线波；颜色读调色板行 0，随关键帧自动变化（§1.1、§1.2、§1.4）。
2. **主光反光带**：画在主光的倒影方向，太阳和月亮由同一盏主光轮流担任；强度随太阳升高减弱，并乘 (1 − 阴度)，满阴时关掉；白天波纹亮线上有四芒星闪点，同屏不超过 40 个（§1.3、§7.3）。
3. **倒影**：每帧只给屏幕上面积最大的那个湖做平面反射（独立 World3D 里的 SubViewport，每轴 1/4，每 2–4 帧刷新），它是风格底线，不能关；其余湖、河渠和池水走解析天空加灯条；倒影切成碎片，明度分 5 级（§1.5、§7.2）。
4. **灯的竖条倒影**：全场共用一张 `refl_lamps`（最多 16 条），水面和湿地面同用；WP-24 按亮度和距离挑灯，亮度由着色器按灯光通道算（§1.3、§7.3）。
5. **四季与天气不改几何、不重编译**：只走调色板、全局参数和遮罩阈值。冬季不结冰，泡沫线变宽变白；雨天波纹线换成雨点环，阴雨天关反光带，太阳雨时两者同在（§1.7、§1.9）。
6. **各水体**：西湖有水下森林的剪影和按时段换形态的扇形喷泉（§2）；东湖映着宣邦楼，荷区留暗色空隙，冬季一角露出浅滩（§3）；河渠按设定流向，流速约 0.45 m/s，暗涵段不画水面，漂浮物截到校界格栅前（§4）。
7. **水面材质默认不透明**：不读深度和屏幕纹理，接收阴影，`cull_disabled`，自身不投影；水面是按内容格产出的网格，用同一个 `water.gdshader`，没有遮罩贴图；透明变体默认不启用（§7.1、§7.4）。
8. **涟漪与水下**：涉水涟漪由 WP-42 的落脚事件驱动，写进每个湖的 `ripples[8]`；镜头进入水下时按介质呈现处理（§1.8、§7.3、§7.5）。
9. **池水与叠水喷泉**：游泳池和品学楼叠水喷泉用同一个水面材质，不新增着色器，不做平面反射（§8、§9）。
10. **多地图**：水面系统的节点实现 `IMapAware`，换图时在雾幕全黑的帧里重建水面网格、河渠中线和倒影代理；全图纹理按 `map_rect` 采样（§7.6）。

### 0.1 接入要点

- **湿地面或积水要画倒影（WP-45b）**：读共用灯条表 `refl_lamps`，复用本包公共 include 里的解析天空函数和灯条函数，不另建灯表，不做平面反射（§7.2、§7.3）
- **改灯光通道或偶发事件的提亮（WP-39、SYS-MOTION）**：水面和湿地面的灯条按灯光通道纹理和开灯阈值自己算亮度，CPU 不写，亮灭自动与岸上一致；灯条由 WP-24 挑选，最多 16 条（§7.3）
- **行走踩进涉水区（WP-42）**：每步落脚发一个落脚事件，WP-24 据此画涟漪，WP-53 据此放涉水脚步，画面和声音不各自判定（§1.8、§7.3）
- **地标、岸树、荷要出现在倒影里（区域包、WP-23）**：倒影世界里只放平涂的 REFLECT 代理，复用 TileBundle 里已有的网格和 MultiMesh 资源，与本体同格加载、同格卸载；地标不超过 10 个（§7.2）
- **地图数据声明倒影候选湖（SYS-MAPS）**：写在本图 `map.json` 的 `env.reflectLakes`，列表顺序就是湖号 `reflect_lake`（§7.2）
- **画面设置（WP-32）**：倒影刷新是每 2 / 3 / 4 帧，经 `IQualityAware.ApplyQuality()` 交给倒影节点；倒影不能关，分辨率固定每轴 1/4（§7.2）
- **镜头进入地下或水下（WP-07）**：倒影视口设 `SubViewport.UpdateMode.Disabled`；水下画面由介质呈现负责，本包只提供水下的颜色和能见度（§7.2、§7.5）
- **音频（WP-53）**：河渠中线、西湖喷泉的时段表、叠水喷泉的位置和"常流"标记都在 CPU 侧可读；本包不另发声音事件（§2.4、§4.2、§9）
- **驱动漂浮物和喷泉的节奏（SYS-MOTION）**：本包提供波纹相位、流速、喷泉高度和每条河按 1 m 重采样的中线；漂浮物的中线截到校界格栅前 2 m（§4.2、§4.3）
- **做驳岸、桥、亭、格栅、喷泉石台（区域包、WP-21、WP-30）**：只做岸上和水中的结构，水面和落水归本包；格栅条上挂的落叶是 WP-30 的静态物件（"分工"一节、§4.3、§9）
- **阴天和雨夜的水色（WP-37）**：由调色板的天气修正层给出，水面只读调色板，不另读天气（§7.1）

## 1 动画式水面（所有水体通用）

水面的底色、波纹线和倒影都读调色板，自动跟随关键帧（ENG-PERF §10.4）；本文给出的色值是默认状态（秋 17:30）的值，其他时段与季节另行说明。

- **1.1 底色**：取天空的倒影再压暗，默认状态的基准色 #5B6FA8；其他时段由调色板行 0 的天色推导。
  - 视线越平，越多映出天空。
  - 视线越陡，越能透过水面看到下面的青绿色 #4E7A6A。
  - 夜间水面映着夜空，要比岸上的建筑亮，剪影才看得清（SYS-TIME §3.4）；暗部不低于 SYS-TIME §8 的明度下限。
  - 水的深浅不读真实深度，按到岸距离换算成"伪深度"，分成三道硬边色带（§7.1）。
  - **三道硬边色带**：
    - 按到岸距离 1.5 m、4 m、9 m 三条硬边分带；
    - 1.5 m 以内是近岸带，取透出色 L +0.10；1.5–4 m 是中带，取透出色；4 m 以外是远带，取天空倒影色；9 m 那条边再从远带里分出更深的湖心一档；
    - 菲涅耳的倒影照旧叠在上面：视线越平，色带越被天空盖住。
  - **白天格**（上午到午后）的透出色提亮成清透的青。由浅到深依次参考 #C4EBE1、#9AD8CB、#74C8C0、#3F97A3，对应上面四档，正式值由 WP-37 按天色推导。默认格的主色不变，仍以天空倒影为主。
- **1.2 波纹线**：用阈值化的噪声做出硬边的波纹线，不要柔和的法线波。
  - 默认状态下亮线 #CBD6F0；暗线跟随天色，按 ART-STYLE §3.2 的影色规则推导（水面 r_mat 1.10，影比岸上浅）。参考值 #3E4A7A，正式值以 WP-37 的输出为准。夜间亮线是月光的银白。
  - 线是细长的横向短段，固定在世界空间的短段格子上，转镜头时不游移，越远越密、越细（§7.1）。
  - 雨天按降水量把波纹线淡成雨点环（§1.9）：小雨还留一半波纹线，大雨和雷雨几乎全是雨点环。
- **1.3 主光反光带**：
  - **默认状态**：落日正下方是一条断续的竖向碎金带，颜色 #FFF0C0。它由横向的亮短段堆成，只在镜头朝西、能看到太阳倒影的方向出现，从西湖上最明显。
  - **其他时段**：反光带始终画在主光的倒影方向上，颜色取主光色（WP-37 关键帧）。强度随太阳升高减弱，乘 (1 − h/60°)，h 是太阳高度，结果不低于 0：正午几乎没有，只剩波纹亮线上零星的白点；冬季正午太阳低，还留着一条淡金带。
  - **四芒星闪点**：
    - 太阳较高时，波纹亮线上零星的白点画成四芒星；
    - 亮度为 HDR 2.0–2.8 倍，被柔光抓住，晕开一点（ART-STYLE §7.1）；
    - 同屏不超过 40 个，阴度 > 0.5 时为 0；
    - 位置取波纹亮线与主光倒影方向的重合处，按 T12 步进（SYS-MOTION §2.2）；
    - 和湿面闪点（ART-STYLE §5.5）是同一种语言，用来撑起"正午太平"时的画面（SYS-TIME §3.4）。
  - **夜间**：主光换成月亮后，画成月光银带，颜色取月光色，强度约为日落碎金带的一半。蓝调里太阳的金带淡出、月亮的银带淡入，与 SYS-TIME §2 的主光交接同步。
  - 反光带在水面着色器的 `light()` 里按主光方向算，太阳和月亮由同一盏主光轮流担任，所以交接自然同步（§7.3）。
  - **阴雨天关掉**（SYS-WEATHER §2）：阴、雨、雪时没有直射光，反光带和月光银带都乘 (1 − 阴度)，满阴时完全关掉；雾天阴度较低，只剩一条被雾冲淡的淡带；多云时云影扫过反光带的那一段，它随之断开。雨后初晴恢复，云隙光扫过湖面时反光带跟着亮起。
  - **灯的竖条倒影**：天黑以后，岸边最亮的灯源在水面上拉出暖色的竖向断续短条，按亮度和距离挑选。路灯、图书馆的窗灯、宣邦楼的钟面都算灯源。灯条用全场共用的灯条表 `refl_lamps`（最多 16 条，水面和雨天的湿地面共用，SYS-WEATHER §7）。阴雨天灯按有效太阳高度提前亮（SYS-WEATHER §7），灯条也随之提前出现。数据通道见 §7.3。
- **1.4 岸边泡沫线**：沿岸绕一圈白色细泡沫线，宽度约 0.3–0.5 m，有断口。冬季加宽到 0.5–0.9 m，断口变少，颜色更白（#F4F6FA）（SYS-TIME §4）。泡沫线读水面网格顶点属性里的到岸距离，断口用沿岸噪声阈值（§7.1）。
- **1.5 倒影**：倒影被波纹线切碎，颜色压暗一阶。采样方式见 §7.2。
  - **碎片化与色块化**：
    - **碎片化**：波纹扰动的偏移按倒影 UV 0.012 一格量化，倒影因此切成一片片；碎片之间画 1 px 的水色细缝，比水色暗 0.04 L。
    - **色块化**：倒影的明度量化成 5 级，再与水色按 0.58 : 0.42 混合，保住 55–60% 的原色相。
    - 两步都在"压暗一阶"之前做；平面倒影和解析天空的倒影一视同仁。
  - 主要倒影按时段：

| 时段 | 主要倒影 |
| --- | --- |
| 默认状态（秋 17:30） | 图书馆亮灯的穹顶；晚霞；锈红的水杉；宣邦楼的电子管穹顶 |
| 清晨、日出 | 粉金色的天；宣邦楼穹顶最先受光的一点（MAP-QSH-SOUTH §5.9）；晨雾里的岸树剪影 |
| 上午到午后 | 蓝天和积云（夏季是积雨云）；受光的图书馆穹顶与宣邦楼；岸边树冠，颜色随季节（春粉带与新绿，夏浓绿，冬裸枝和雪岸） |
| 蓝调、入夜 | 洋红到蓝的天；图书馆的窗灯和采光顶；灯的竖条倒影；满月 |
| 深夜 | 月亮和月光银带；还亮着的窗（图书馆的品·悦吧和中庭台灯、科研楼、零星宿舍）；路灯的竖条倒影 |
| 阴、雨 | 珍珠粉紫的云盖和亮缝；没有反光带；雨点环把倒影打碎；夜雨里是暖紫的天和更显眼的灯条 |
| 雾 | 倒影随雾淡去，只剩近岸树和露出雾面的地标的淡剪影 |
| 雨后初晴 | 洗过的蓝天和向东退去的碎云；水面重新平静，波纹线恢复 |

  - 倒影材质读调色板行 0，夜间画亮窗和灯（ENG-PERF §10.4）。天气的天色和云由调色板与天空（WP-37、WP-40）给出，倒影自动跟随，本包不另调。
- **1.6 阴影里的水面**：在楼影或树影里的水面，影色按 ART-STYLE §3.2 推导（水面 r_mat 1.10，影比岸上浅）。波纹线照样画，但亮线变暗。夜间月影很浅（最强 0.45，SYS-TIME §2），水面的明暗差也相应减小。水面不透明，直接接收主光的阴影，走 toon include 的两阶合成（§7.1）。
- **1.7 四季的水面**：

| 季 | 水面 |
| --- | --- |
| 春 | 樱花林、粉带临水的地方漂一层稀疏的花瓣（§4.2） |
| 夏 | 水色偏绿：透出的青绿 #4E7A6A 占比加大；荷区之间的水面更暗（§3.3） |
| 秋（默认） | 现有设定；水面漂几片落叶，叶形随岸边的树（WLD-VEGETATION §2），银杏临水的地方才是银杏叶 |
| 冬 | 不结冰；泡沫线变宽变白（§1.4）；水色偏灰青；东湖一角露出浅滩（§3.5） |

  - 季节变化只走调色板、全局着色器参数和每个湖的遮罩阈值，不改水面几何，不重编译（ENG-BUDGET §7）。
  - 湖面漂的花瓣和落叶画在水面着色器里：按格子哈希在格心贴叶卡纹理数组的对应层（旋转和大小随哈希），季节权重做阈值；凑近看仍是完整的叶形和瓣形，不建实例。河渠上随流漂动的漂浮物见 §4.2。
- **1.8 涉水涟漪**（SYS-WALK §9）：
  - 行走模式下，观者踩进涉水区（亲水台阶最下一级、登记的卵石滩）时，每一步在落脚处画 2–3 圈硬边的同心环。环在 0.6 s 内扩到半径约 1.2 m，然后断开、消失。
  - 环的颜色与 §1.2 的亮线、暗线相同，按一拍二步进（SYS-MOTION §2.2）。
  - 由 WP-42 在每步落脚时发出事件，本包负责画环，数据通道见 §7.3。这是观者唯一留在水面上的痕迹，不留脚印（SYS-WALK §1）。
  - 走出涉水区后沉入水下的过程，由 SYS-WALK §9 和 SYS-VIEW §5.3 负责。
  - **声音**：每一圈涟漪都配同一步、同一时刻的涉水脚步。脚步按水深分三档换样本，另有一路蹚水循环（SYS-AUDIO §9.8）。WP-42 发的是同一个落脚事件，画面和声音不各自判定。
- **1.9 天气的水面**（SYS-WEATHER §2）：

| 天气 | 水面 |
| --- | --- |
| 少云、多云 | 云影扫过湖面时，那一片降一阶明度，波纹亮线变暗，做法同 §1.6 |
| 阴 | 水色随天色偏珍珠粉紫（读调色板，不发灰）；反光带关掉（§1.3）；波纹线照常 |
| 雾 | 湖面贴一层湖雾（ART-SKYLIGHT、SYS-WEATHER §2），倒影、波纹线和反光带随雾淡去；夜雾里岸灯的光晕半径 ×2，灯条变短、变淡 |
| 雨（轻、中、重） | 波纹线换成雨点环；反光带关掉；夜里灯条照常，而且更显眼；水面不画溅落（SYS-WEATHER §7） |
| 雷雨 | 同大雨，雨点环更密；闪光帧水面随 toon 一起翻到受光色（SYS-WEATHER §5） |
| 雨后初晴 | 雨点环在几秒内停下，波纹线恢复；倒影映洗过的蓝天；云隙光扫过时反光带随之亮起 |
| 太阳雨（雨后初晴开头的 30–90 s，SYS-WEATHER §2） | 雨点环还在，降水量减小，环随之变稀；太阳已出来，阴度低于 0.5，所以反光带按 §1.3 的 (1 − 阴度) 同时亮起。默认状态下就是一条被雨点环打碎的碎金带，映着西边的落金和东边的暗云。不另写参数，全部读天气向量 |
| 雪 | 雪花落到水面就消失，不画雨点环；泡沫线和水色照冬季（§1.7）；倒影映薰衣草灰的天 |

  - **雨点环**：硬边同心环，颜色同 §1.2 的亮线、暗线，按一拍二步进（SYS-MOTION §2.2）。水面按 0.8 m 网格取格，每格按哈希定一个出现时刻和位置，环在约 0.5 s 内扩到半径约 0.35 m，一两圈，然后断开、消失；一格同时只有一个环。有环的格子占比随降水量：小雨约 15%，大雨约 60%。60 m 以外，环并成细碎的亮点，再远交给雾。写法见 §7.1，不占 `ripples[8]` 的槽位（SYS-WEATHER §7）。
  - **遮挡**：桥下、亭下、栈桥下的水面读 `precip_occ`，那里没有雨点环；荷叶盖住的地方不画环，只在荷区的空隙里画（§3.3）。
  - **河渠**同样画雨点环，环心随流向平移 0.45 m/s（§4.1）。
  - **切换**：全部只读天气向量（降水量、降水类型、阴度，SYS-WEATHER §8），随它连续变化；不改水面几何，不重编译（ENG-BUDGET §7）。
  - **声音**：雨落在水面上的声音由 WP-53 按落点表面分层（SYS-AUDIO §5.1）。它读同一个天气向量，所以雨点环变密时雨声也变密。本包不另发事件。

**倒影的实现**：

- 每帧只给屏幕上面积最大的那个湖做平面反射，分辨率为每轴 1/4。反射里只画远景、少数地标、树冠替身和荷，不画天空；视口背景透明，天空由水面着色器解析补出（§7.2）。
- 刷新间隔由画面设置的"西湖倒影刷新"决定：精致、极致每 2 帧，均衡每 3 帧，流畅每 4 帧（SYS-GRAPHICS §1、SYS-GRAPHICS §3）。倒影是风格底线，不能关，最差就是每 4 帧；分辨率固定每轴 1/4，不随预设变（SYS-GRAPHICS §2）。自动调节画质也只能把它降到每 4 帧（SYS-GRAPHICS §5）。
- 做法是 SubViewport 加镜像相机，放在独立的 World3D 里；水面用反射相机的 VP 矩阵算 UV 去采样。接口见 §7.2。
- 其他湖和全部河渠不做平面反射，改用解析天空加灯条。
- 路面积水也不做平面反射：反射视线沿 `precip_occ` 步进出剪影，其余画解析天空，夜间叠灯条，做法见 SYS-WEATHER §7（WP-45b）；解析天空函数和灯条函数用本包公共 include 里的同一份。
- 性能约束见 ENG-PERF §10.4。

## 2 西湖

- **2.1 基本情况**：实体 `qsh:relation:7849759`，水面约 3.9 万㎡，有两座岛（MAP-QSH-CORE §5.2）。
- **2.2 水下森林**：湖底有沉水植物。
  - 近岸 5–15 m 的浅水里，能透过水面看到几团暗绿色的水草剪影，颜色 #2F5A4A。
  - 剪影随波纹线轻轻错动。
  - 剪影的多少随季节：夏季最茂，近岸连成片；冬季稀疏，只剩零散几团（WLD-VEGETATION §7.1）。夜间水面不透光，看不到剪影。
  - 水面不透明，从水面以上看到的剪影是水面着色器按水草遮罩画出来的：带视差偏移，偏移按波纹线错动，多少按季节阈值（§7.1）。水下的实体水草只在镜头进入水下时可见（§7.5）。
- **2.3 反光带**：
  - **默认状态**：图书馆在湖的东侧，太阳在西南偏西。所以从图书馆一侧朝西看时，湖面上正好有落日反光带；从湖西岸朝东看时，湖面映着亮灯的图书馆和满月。两种方向都要成立。
  - **白天**：太阳较高时没有碎金带。从西岸朝东看，湖面映着蓝天、云和受光的穹顶。
  - **夜间**：从西岸朝东看，是月光银带（月亮黄昏从约 62° 方向升起，SYS-TIME §2）加上图书馆窗灯的竖条倒影；从东侧朝西看，是夜空和对岸的路灯竖条。
- **2.4 喷泉**：湖中央那座扇形多柱喷泉。
  - 形态按 MAP-QSH-CORE §5.7 的时段表对齐，SYS-AUDIO的喷泉声也按那张表切换。
  - **默认状态**（以及太阳 10° 到 −4° 的黄昏段）：只喷低低的一排。
    - 水柱高 1.5–2.5 m，画成白色平涂的柱形，顶端散成几点白色小块。
    - 水柱底部一圈细小的同心波纹。
    - 喷泉灯不开。
  - **白天**（9:00 到黄昏段）：扇形全开，中间最高约 5 m，向两侧递减，顶端散成白色小块；同心波纹的半径随之放大。
  - **入夜到 22:00**：低排之上，中间 3 柱升到约 4 m。喷泉灯打开，水柱由下往上被照亮。灯色只用暖白 `window.warm`（与 MAP-QSH-CORE §5.7 一致；电子蓝仍只用于旗面、校车和单车，ART-STYLE §8.2）。
  - **22:00 到次日 9:00**：停喷，同心波纹散尽，水面恢复平静，留给图书馆和月亮的倒影。
  - **下雪时**：停喷，只留水柱根部的暖白灯点；水面不结冰。其他冬日照常按本节各时段的形态。
  - 时段以 MAP-QSH-CORE §5.7 和 SYS-TIME §6 的灯光时刻表为准，本节只管形态。形态之间切换时，水柱高度用 3–5 s 平滑过渡，不硬切。
  - **声音**：喷泉是 SYS-AUDIO的手工发声点，按同一张时段表切换形态，交叉 3–5 s（SYS-AUDIO §4.2）。本包把喷泉时段表在 CPU 侧开放给 WP-53 读取。
  - 实现：水柱是生成的网格，`vertex()` 按 `anim_time` 拉伸高度（节奏见 SYS-MOTION §5.1）；喷泉灯读灯光通道；底部的同心波纹由水面材质的 `fountain` uniform 画（§7.3）。
- **2.5 箱涵两侧**：湖西部的箱涵（MAP-QSH-CORE §5.8）两侧，水面颜色可以略有不同：渠水一侧更浑一点，偏黄绿。

## 3 东湖

- **3.1 基本情况**：实体 `qsh:relation:7849760`，OSM 面积约 4.8 万㎡，湖里有一座岛。
- **3.2 倒影**：宣邦楼在东岸。默认状态下，从西岸看过去，湖面映着宣邦楼的塔楼、钟楼和受光的电子管穹顶。蓝调以后，映出亮起的钟面（"交班的钟"，MAP-QSH-SOUTH §5.4）和钟面的竖条倒影。
- **3.3 荷的四季**：近岸一角的荷由 WP-23 负责（WLD-VEGETATION §7.3）。水面在荷之间要留出暗色的空隙，四季的样子不同：

| 季 | 荷区的水面 |
| --- | --- |
| 春 | 小荷钱贴在水面上，空隙大，波纹线照常画 |
| 夏 | 荷叶盖住荷区约六成，空隙暗而碎；粉色荷花在水里映出模糊的倒影 |
| 秋（默认） | 残荷之间留出暗色的空隙 |
| 冬 | 只剩枯梗，水面开阔平静，波纹线变稀；干梗和它的倒影连成三角形 |

  - 荷区由水面遮罩的荷区通道标出：空隙压暗一阶，波纹线变稀，程度随季节（§7.1）。

- **3.4 锦鲤**：湖里有锦鲤。从亲水平台边俯视时，可以透出两三条模糊的橙白色鱼影，这一点是可选的。夏季鱼影浮得浅，最清楚；冬季沉得更深，透出度减半，更淡更模糊；夜间看不到。实现：鱼影画在水面着色器里（2–3 个模糊椭圆，沿按 `anim_time` 走的闭合解析路径游动），不靠透过水面看实体几何（§7.5）。
- **3.5 冬季浅滩**：冬季东湖枯水，一角露出浅滩，滩上有涉禽（SYS-TIME §4、WLD-LIFE §1）。
  - 不改变水位。浅滩的几何四季都在，顶面比常水位低约 5 cm；冬季在这片区域里，水面按遮罩阈值让出浅滩，露出湿泥，边缘绕一圈泡沫线。和地面覆盖一样，用阈值生长，不硬切。水面用 alpha scissor 挖掉浅滩，仍留在不透明通道（§7.1）。
  - 位置在东湖北岸、与荷区分开的一角，约 300–500 m²，由 WP-18 定。浅滩不可行走，在可行走遮罩里标为水（SYS-WALK §6）。

## 4 河渠

流向都没有核实，按下表统一设定，全片保持一致。流速约 0.45 m/s：一片落叶漂过 14 m 的桥大约要 30 秒。

| 河渠 | 实体 ID | 设定流向 | 说明 |
| --- | --- | --- | --- |
| 走马河 | `qsh:way:693513895`（西段）、`qsh:way:217855313`（图书馆北侧段）、`qsh:way:844548973`、`qsh:way:844548974`（东南段）、`qsh:way:1172471444`、`qsh:way:1061419134`、`qsh:way:1061419135`、`qsh:way:701057001`、`qsh:way:701057002` | 从西北流向东南 | 有多段暗涵，暗涵段不画水面。银杏大道在约 (82, −9) 处跨过它。 |
| 红光右支渠 | `qsh:way:693515475`（北段）、`qsh:way:1172471443`（西湖段）、`qsh:way:1172471442`（南段）、`qsh:way:735552989` | 从北流向南 | 笔直的人工渠，穿过湿地，在西湖段走箱涵 |

- **4.1 河面**：用 §1 的画法，但波纹线拉长，顺着流向。噪声坐标沿河面网格 UV 的流向平移 0.45 m/s（§7.1）；河渠不做平面反射。雨天画雨点环（§1.9），夜里读共用灯条表画灯条（§7.3）。
  - **声音**：0.45 m/s 的缓流几乎无声，只在 8–12 m 内听得到。有声的是桥墩、暗涵口、堰这些扰流处（SYS-AUDIO §4.2）。WP-53 的发声器从本包的河渠中线生成：开敞段是线声源，每段暗涵两端各一个暗涵口点。中线数据见 §4.2。
- **4.2 漂浮物**：数量稀疏，每 20–30 m 河道一两片，随流移动，由 SYS-MOTION 驱动。漂的东西按季节换：

| 季 | 漂浮物 |
| --- | --- |
| 秋（默认） | 落叶，以 WP-23 的叶形为准；银杏大道跨走马河一带（MAP-QSH-CENTER-EAST §1.7）是银杏叶，其余河段是其他落叶 |
| 春 | 樱花和美人梅的花瓣，每处两三片；樱花林、粉带临水的湖面也漂一层稀疏的花瓣 |
| 夏 | 基本没有，偶尔一片绿叶 |
| 冬 | 零星枯叶；雪后泡沫线变宽变白（§1.4） |

  漂浮物的出没跟随季节权重（SYS-MOTION §11.1），换季时在雾幕里替换（SYS-MOTION §12.2）。实现：每条河一个 MultiMesh，位置在顶点着色器里沿河道中线解析算出，不存状态（SYS-MOTION §13.4）；本包提供每条河的中线数据（按 1 m 重采样）。同一份中线还要在 CPU 侧可读，供 WP-53 生成河渠的发声器（SYS-AUDIO §21.2）；漂浮物的中线截到校界的河渠格栅为止（§4.3）。

- **4.3 外围明渠与校界格栅**（WLD-OUTSKIRTS §7.3、WLD-OUTSKIRTS §12.2）：
  - **格栅**：走马河、红光右支渠、磨底河穿出校界的地方，各有一道竖条钢格栅或节制闸，由 WP-30 做。格栅前的水面照常流动。漂浮物用的中线截到格栅前 2 m 为止，越过终点的漂浮物和暗涵段一样缩到 0（SYS-MOTION §13.4），不穿过格栅；格栅条上挂的几片落叶是 WP-30 的静态物件。
  - **O0 街道带里露出的明渠段**：按校内河渠的标准画（§4.1），护岸由 WP-28 延续。
  - **O1 外围街区里的明渠**：用同一个 `water.gdshader`，只画底色、色带、波纹线和泡沫线；不做倒影（灯条也不画）、不画漂浮物，也没有水下内容。
  - 外围明渠的到岸距离与流向由 WP-24 的水面生成器从 WLD-OUTSKIRTS的 `outskirts.json` 算出，逐顶点写进水面网格，与校内水体同一种做法，不另开数据通道。

## 5 主楼喷泉（可选）

如果 MAP-QSH-SOUTH §2.6 做了主楼前的圆形浅水池，水面完全静止，不画波纹线。默认状态下映着落日和主楼的门廊；夜间映着主楼的泛光（MAP-QSH-SOUTH §2.8）；冬季也不结冰。它是静水，所以也不发声（SYS-AUDIO §4.2）。

## 6 截面水柱的水色

- 上层浅青绿 #7FB8B0，下层深青绿 #2F5C5E。
- 分层处是一条略亮的细线。
- 水柱侧面像玻璃：边缘有一道白色高光竖线。
- 以上是默认状态的色值，其他时段由 WP-37 的脚本按关键帧推导；夜间不低于 SYS-TIME §8 的暗部下限。
- 实现：截面水柱是不透明盒体，河渠与截面线的每个交点一个（暗涵断面同理），交点由 `pipeline/outskirts` 求出、写进 `outskirts.json`，不手写；河渠穿出校界的地方不画水柱，做格栅或节制闸（WLD-DIORAMA §3）。两层水色、分层线、玻璃白边都在同一个着色器里按世界 y 和边缘距离画；不走透明管线。
- **分级色带**（可选）：
  - 玻璃侧面按 Beer–Lambert 的衰减分 5 级，再按水深分 4 条硬边色带；
  - 液面一条亮线，下方一条暗带；掠射角处映天色；
  - 仍是不透明盒体、同一个着色器，只多几个阈值。默认不开，P0 在截面的近景看图决定。

## 7 Godot 实现

实现基于 Godot 4.7.2 .NET、Forward+。C# 写法以 `docs/godot-api/` 的签名为准；着色语言的内置变量查官方 Shading reference（4.7）。

### 7.1 水面材质（默认不透明）

- **为什么不透明**：读了深度纹理或屏幕纹理的材质，会被强制归入透明通道，而且不投影；屏幕纹理也只抓得到不透明物体。所以默认水面这两样都不读：
  - 留在不透明通道，吃深度预通道；
  - 接收主光阴影，走 `toon.gdshaderinc` 的两阶合成（§1.6）；
  - `cull_disabled`，从水下能看到水面的背面（§7.5）；
  - 本身 `cast_shadow = Off`，否则湖底和水下的东西会被水面遮暗。
- **水面网格与顶点数据**：水面按内容格由 WP-24 的生成器（纯 .NET）从水体多边形和覆盖层算出，随格烘焙（D-165）、随格加载，所有水面用同一个 `water.gdshader`。到岸距离与流向逐顶点写进水面网格，不做全图岸线遮罩，也没有按湖的遮罩贴图：UV = 流速 (vx, vz)，单位 m/s，湖为 0；UV2 = (到岸距离，单位 m；倒影湖号，−1 表示不做平面倒影)。以后别的包需要岸线距离或逐像素的标记数据，再由生成器的数据提供。
- **伪深度**：三道硬边色带（§1.1），阈值 1.5 / 4 / 9 m 读顶点属性里的到岸距离，近岸浅、湖心深。边界用 fwidth 抗锯齿。
- **四芒星闪点**（§1.3）：在 fragment 里按 0.5 m 网格取格，只在波纹亮线遮罩为 1、反射视线与全局 `sun_dir` 夹角很小的格里画；星形用两条正交的细长亮条，颜色取调色板的主光色，HDR 增益 2.0–2.8，写进 `EMISSION`，乘 (1 − smoothstep(0.4, 0.5, 阴度))；同屏 40 个的上限用格子的哈希阈值随距离收紧来保证，不在 CPU 计数。
- **泡沫线**：到岸距离小于 w 处画白线，w = 0.3–0.5 m，冬季 0.5–0.9 m（读全局 `snow`）；断口用沿岸噪声做阈值；边缘用 fwidth 抗锯齿。浅滩边缘的泡沫线取浅滩阈值的等值线。
- **波纹线**：
  - 波纹短线固定在世界空间的短段格子上：噪声坐标取水平面的世界坐标，在格子里拉成横向短段，不随相机转动，转镜头时不游移；越远越密靠透视得到。格子尺寸与短段半长是 `water.gdshader` 开头的可调常量（`WTR_DASH_CELL`、`WTR_DASH_HL`、`WTR_FLOW_HL`）。
  - n > 1 − w 画亮线，n < w 画暗线，w 随 fwidth 调，保持 1–2 px 宽。
  - 偏移按 T12 步进（SYS-MOTION §2.2）；阵风来时整体挪一格（SYS-MOTION §3.5）。
  - 河渠：坐标沿河面网格 UV 的流向，平移 0.45 m/s（§4.1）。
  - 随 `anim_time` 平移的量要满足 480 s 回绕无缝的规则（SYS-MOTION §1.6）。
  - 雨天按全局 `weather_a` 的降水量把波纹线的宽度阈值收窄，淡成雨点环（§1.9）。
- **雨点环**（§1.9）：在 fragment 里按水平面的 0.8 m 网格取格；每格的哈希给出环心偏移和相位，局部时间 τ = mod(T12 + 相位, 周期)，周期取 480/k，所以 `anim_time` 回绕时不跳（SYS-MOTION §1.6）；环的半径按 τ 步进，用 fwidth 保持 1–2 px 宽；哈希低于"降水量 × 占比上限"的格才画。降水类型是雪时不画。读 `precip_occ`，顶面高于水面的地方不画。每像素只查本格和相邻 3 格，开销很小。
- **透出**：视线越陡，越多透出 #4E7A6A（§1.1）；夏季占比加大，夜间不透（读调色板）。
- **冬季浅滩**：A 通道 × 季节量做阈值，写 `ALPHA` 和 `ALPHA_SCISSOR_THRESHOLD`。被裁掉的地方露出下面的湿泥网格，材质仍在不透明通道。
- **颜色**：底色、亮线、暗线、天色全读调色板行 0（§1.1–§1.2），夜间自动换成月光与夜空。阴天水色、雨夜的暖紫天色由调色板的天气修正层给出（WP-37，SYS-TIME §3），水面不另读天气。

### 7.2 倒影接口

| 项 | 规定 |
| --- | --- |
| 视口 | 一个 SubViewport，尺寸为窗口的每轴 1/4；`OwnWorld3D = true`；MSAA 关，点光阴影图集设 0。每 N 帧把 `RenderTargetUpdateMode` 设为 `SubViewport.UpdateMode.Once`，N 是画面设置的倒影刷新间隔（2 / 3 / 4，见本表"画面设置"一行） |
| 为什么独立世界 | 每个视口渲染时都会把方向光阴影重渲一遍，又没有视口属性能单独关掉它。独立世界里没有投影的光，也就没有这份开销 |
| 世界里放什么 | 平涂的 REFLECT 代理：远景环、不超过 10 个地标（L2/L3 网格）、岸边树冠替身、两组荷（WLD-VEGETATION §7.3）。代理着色器读全局调色板，岸树替身读季相行，亮窗和灯读同一套哈希与灯光通道纹理，所以倒影里的亮灭与岸上一致。倒影世界里不画天空：放一个 WorldEnvironment，背景用纯色清除，环境光、反射源、辉光和雾全关，色调映射参数与主世界同步 |
| 天空 | 倒影视口的背景透明，倒影世界里不画天空。水面着色器用 `fog.gdshaderinc` 的 `sky_side_weight`、`sky_column_lab` 解析补出天空：平面倒影图里没画到的像素，以及走解析天空的湖，都用它，与 WP-40 的天空同源 |
| 怎么放 | 复用 TileBundle 里已有的网格和 MultiMesh 资源，用 RenderingServer 在倒影世界的 scenario 里另建实例，不复制几何；代理与本体同格加载、同格卸载 |
| 镜像相机 | 位置 y′ = 2h − y（h 为该湖水面高度），朝向用镜像后的前向和上向量经 `LookAtFromPosition` 得到；视场角、长宽比、远近裁剪面与主相机相同 |
| 裁剪 | 4.7 的 Camera3D 没有斜裁剪：只放水面以上的代理，并在代理着色器里丢弃 y < h 的片元 |
| 选湖 | WP-24 的 C# 估算各候选湖在屏幕上的面积，只给最大的那个湖做倒影，换湖带回差；其余湖和全部河渠用公共 include 里的解析天空函数，加上灯条（§7.3）。路面积水复用同一个解析天空函数和灯条（SYS-WEATHER §7）。候选湖读本图 `map.json` 的 `env.reflectLakes`，列表顺序就是湖号 `reflect_lake`（SYS-MAPS §3）。清水河要列西湖和东湖两个：东湖映着宣邦楼的塔楼和钟楼（§3.2），只靠解析天空画不出来 |
| 交给水面 | 全局参数 `reflect_tex`（sampler2D，SubViewport 的 ViewportTexture）、`reflect_vp`（mat4，渲这张图那一帧的反射相机"投影 × 视图"矩阵）、`reflect_lake`（int，当前做倒影的湖号）。水面顶点属性里的倒影湖号（UV2.y）等于 `reflect_lake` 时，把片元的世界坐标乘 `reflect_vp` 得到 UV 去采样；否则走解析天空 |
| 波纹扰动 | UV 再加 1–3 个倒影纹素的偏移，偏移量按波纹线遮罩取整，再按 0.012 一格量化成碎片，碎片之间画 1 px 细缝；采样结果的明度量化成 5 级，与水色按 0.58 : 0.42 混合，再压暗一阶（§1.5）。解析天空的倒影走同一个函数 |
| 延迟 | `reflect_vp` 总是和那张图同一帧的矩阵，每 N 帧更新时内容和采样坐标始终配套，只有不超过 N 帧的内容延迟 |
| 画面设置 | "西湖倒影刷新"：每 2 / 3 / 4 帧，即时生效（SYS-GRAPHICS §3）。WP-24 的倒影节点用 `[QualityResponsive]` 声明负责这一项，经 `IQualityAware.ApplyQuality()` 接收，不读 `graphics.cfg`（SYS-GRAPHICS §8）。倒影属于风格底线，不能关，最差每 4 帧；分辨率固定每轴 1/4（SYS-GRAPHICS §2）。自动调节画质可以把它降到每 4 帧（SYS-GRAPHICS §5）。注意：下一行的"停用"是镜头不在水面以上时省掉看不见的倒影，不是画质选项 |
| 停用 | 镜头处在地下或水下时设 `SubViewport.UpdateMode.Disabled`（SYS-VIEW §5） |
| 不用 | 屏幕空间反射（只作用于不透明物体，到画面边缘会断）；ReflectionProbe（设成每帧更新时要渲 6 个面） |

- 用反射相机自己的 VP 矩阵采样，左右镜像由投影自然得到，不需要另外约定"是否翻转 x"。
- 开销估计每次更新 0.3–0.6 ms，记账按 ENG-PERF §10.4。

### 7.4 透明变体（只在需要时）

- 只有需要真实的物体交界泡沫（荷梗、桥墩）时，才给那一块水面换成透明变体：读深度纹理，用 `INV_PROJECTION_MATRIX` 重建深度，写法按官方文档的片段。
- 透明变体是白名单里单独的一个着色器，加载时预热，运行时不新建着色器，也不改 render_mode。
- 默认不启用；要不要用，由 P0 原型在荷区和桥墩近看决定。

### 7.5 水下

- 镜头进入水下时，按介质呈现处理（SYS-VIEW §5.3）：MediumService 写全局介质参数，共用雾函数和贴在相机上的全屏四边形负责青绿染色和焦散。本包提供水下的着色参数（颜色、能见度 5–10 m）。
- 水面 `cull_disabled`：从下面看到的背面（`!FRONT_FACING`）画成浅色的"水下天花板"，波纹线照画。
- 从水面以上看，水草剪影和锦鲤鱼影都画在不透明水面的着色里（§2.2、§3.4）；水下的实体沉水植物、鱼影、卵石只在水下介质里看得见（SYS-VIEW §5.3）。

### 7.6 多地图（SYS-MAPS）

- 水面系统的节点跨图常驻，实现 `IMapAware`（SYS-MAPS §4）：换图时，在雾幕全黑的帧里按新图重建水面网格（随内容格由烘焙产出，随格重建）、河渠中线纹理、`fountain` 数据和倒影世界里的代理，旧图的全部释放。
- 用到的全图纹理（`precip_occ` 等）一律按全局参数 `map_rect` 采样，用 `map_uv()`、`in_map()`，不写死"全校"的原点和尺寸（SYS-MAPS §10）。清水河的 `map_rect` 是 ±1280 m。
- 倒影候选湖读 `env.reflectLakes`（§7.2）；按图的水体数据放在 `game/data/maps/qingshuihe/` 下，跟随世界模型和覆盖层。
- 实体 ID 的前缀 `qsh:` 是 OSM 管线的数据写法，不是地图 ID，本文照旧引用（SYS-MAPS §2.1）。

## 8 游泳馆与室外游泳池的池水

游泳馆是第一批开放的室内之一（WLD-INTERIORS §2.5），观者能走到池岸，落水后沉下去看池底的分道线和水下灯。东区还有一组室外游泳池（MAP-QSH-CENTER-EAST）。两处的池水都用本包的水面材质，不新增着色器。

- **样子**：静水，透出浅青的池底瓷砖色，分道线和池底的深色标线透出来；伪深度只按池深分两道色带（浅水区、深水区），不按到岸距离。波纹线比湖面稀、细，按 T12 慢慢错动；池边一圈细白线代替泡沫线，没有断口。
- **倒影**：不做平面反射。
  - 室外泳池走解析天空加灯条。
  - 室内池水不映天空，把解析天空换成顶棚色，取池顶的室内色名；夜间叠池顶灯的亮点。
  - 碎片化与色块化照 §1.5。
- **夜间**：游泳馆穹顶下沿的玻璃带透出池水的青光，用色名 `water.poolGlow`（MAP-QSH-SOUTH），随场馆灯的时刻表亮灭；池水本身在场馆灯下比湖面亮。
- **水下**：介质参数另给一套池水的，颜色更清、偏青，能见度约 15–20 m（SYS-VIEW §5.3）；沉水回位按 SYS-WALK §9。
- **天气**：室外泳池照 §1.9 画雨点环；室内池水无雨。
- **声音**：池岸是 `PoolDeck` 地面（SYS-AUDIO §9.3），游泳馆的声学类别归 SYS-AUDIO。本包不另发声音事件。

## 9 品学楼门前叠水喷泉

品学楼门框正前方的三层叠水喷泉，直径约 6 m，位置约 (140, −65)（MAP-QSH-CENTER-EAST §2.3）。石台、池沿和碰撞归 WP-21；三层池面和层间落水归本包，用本包的水面材质，不新增着色器。

- **池面**：三层各一块小水面，静水略动。伪深度不按到岸距离分三道色带，每层只留一道池沿的暗边，中间透出深色花岗岩池底；波纹线比湖面细密，以落水点为心画同心波纹，复用 `fountain` uniform（§7.3），每层一组，强度恒定。池沿一圈细白线代替泡沫线，没有断口。
- **落水**：每层池沿溢出一圈薄水帘，画成白色平涂、带竖向亮纹的环形面片，`vertex()` 按 `anim_time` 让亮纹下移，节奏同 SYS-MOTION §5.1 的水柱（一拍二）；水帘落进下一层的地方加一圈白色碎点。底层落进最下面的承水槽，不溅出石台。
- **倒影**：不做平面反射，走解析天空加灯条（同室外泳池，§8）。夜里架空通道的筒灯进 `refl_lamps` 的候选，在池面上成断续的短竖条；门框的剪影不做真实倒影，生成器把门框轮廓投到池面上烘一块暗色遮罩，视觉上读得出"映着门框"（MAP-QSH-CENTER-EAST §7 的"反天"一行）。
- **时段**：全天常流，不像西湖喷泉那样按时段换形态，所以没有时段表；水帘的亮纹白天取主光色，夜里由架空通道的筒灯照亮（灯光通道同门框筒灯，SYS-TIME §6）。
- **四季与天气**：冬季不结冰，照常流，石台顶一线雪（MAP-QSH-CENTER-EAST §7、SYS-TIME §4）；春季池面漂几片花瓣，秋季叠水边接着几片落叶，走飘落池与地面覆盖的同一套季节阈值；雨天池面照 §1.9 画雨点环，水帘不变；太阳雨同 §1.9。
- **声音**：细碎的落水声，约 10 m 内听得到，是 SYS-AUDIO §4.2 自动生成表里的一个点声源，全天常流（MAP-QSH-CENTER-EAST §9 第 4 条）。本包把喷泉位置和"常流"标记在 CPU 侧开放给 WP-53 读取，不另发事件。
