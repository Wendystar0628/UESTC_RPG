# RFC-ART-JP-CONFLICTS · 日式方向与现行规则的冲突

> **范围**：本文盘点现行文档里与"地图细节走日式氛围"冲突的规定，按作者选定的边界 (a) 给出每处的改法和可以直接替换的规定草稿；声音单列一节（§4）。
> **不在本文**：地图结构（不改，MAP-QSH-CORE 至 MAP-QSH-CENTER-EAST）；边界 (b)(c) 的展开；增补物的最终数值与落位（评审通过后写进 MAP-QSH-ADDITIONS、WLD-LIFE 等）。

## 作者已定（2026-10-15）

| 事项 | 结论 |
| --- | --- |
| 日式的边界 | 日式日常街景元素可以用；宗教与地标符号不用；场景文字一律简体中文 |
| 传统和式建筑构件（和式瓦屋顶、唐破风、障子） | 不用 |
| 教室推拉门 | 不用 |
| 日式附属件（店头布篷、卷帘门、外挂钢楼梯、波纹铁皮雨棚） | 只用在商业街和后勤小楼，按新的、干净的样子做 |
| 黄昏乌鸦 | 有叫声；画面上黄昏时 2–3 只静止停在楼顶或电线上，不画成群飞过，夜里和雨天不出现 |
| 傍晚广播旋律 | 用原创旋律；不用威斯敏斯特钟声；钟楼仍是单音 |
| 老旧元素 | 一律修掉，换成与项目风格统一的新设计，不保留岁月感 |
| 做旧层 | 全校建筑立面和地面都不做旧（沥青裂缝、补丁、油渍、路缘缺口也不做），只留天气湿痕和季节落物；生活感靠干净的生活痕迹 |

## 0 结论

- **冲突的根**：现行文档把"不出现日本特有元素"写成全局不变量（INV-7、D-064）。细则展开在 ART-STYLE §9.1、WLD-INTERIORS §8.5、MAP-QSH-ADDITIONS §4–§5 和 SYS-AUDIO §4.3、§6.2、§6.3，由 ENG-GATES §3 第 3 条一票否决。共找到 45 处冲突，分布在 15 份文档里（含 REF-PROMPT 备份），见 §2。
- **作者已定边界 (a)**：日式日常街景物件可以用；宗教符号、日本地标符号不放；场景文字仍用简体中文。声音同时放开两样：黄昏的乌鸦叫，以及傍晚广播里的一段旋律（原创或公有领域曲目）。(b)(c) 两种边界不展开。
- **按 (a) 处理后的三种结果**：
  - **放开**：日常物件，例如成组售货机、电线杆、自行车棚、栏杆晒被、木檐公告板、砌块矮墙、暖帘、橙色凸面镜；
  - **保留**：宗教符号、地标符号、日文文字，以及改变门窗系统、房间布局的室内项；
  - **只改措辞或理由**：规定本身和日式方向无关，只是理由写成了"像日本"。
- **改法骨架**：
  - INV-7 和 D-064 从"全部排除"改成"分界"。
  - ART-STYLE §9.1 原位改写成分界清单，条目编号不变，别处引用的"第 N 条"基本不用跟着改。
  - WLD-INTERIORS §8.5 拆表：陈设类放开；门窗系统、房间布局和带日文的标识保留。
  - MAP-QSH-ADDITIONS §4 第 7 条从"逐一替换"改成"并存"，新增 §2.16 收日式街景物件的落位。
  - ENG-GATES §3 第 3 条的判据跟着改。
  - 以上草稿见 §3。
- **声音（§4）**：
  - 放开：乌鸦叫只在黄昏和清晨从远处来，画面默认不画乌鸦；傍晚广播 17:40 开头放一段旋律，之后的人声仍然听不清（INV-6）。
  - 不变：宣邦楼钟楼是地标，仍只敲单音铜钟（D-103）。
  - 要改：INV-7、D-064、D-104、ART-STYLE §9.1 第 9 和 11 条、SYS-AUDIO §3.3、§4.3、§4.8、§6.2、§6.3、§25、WLD-LIFE §1，以及 MAP-QSH-ADDITIONS §2.15。
- **和日式方向无关、应保留的规定**（§5）：场景文字一律简体中文（INV-4、D-065）、不画人、动态轻慢、不画成群飞的鸟、调色板与饱和色限制、覆盖层登记、视觉精度、钟楼单音、不做上下课铃、素材许可。
- **需要作者拍板的 6 项**见 §6，包括和式瓦屋顶、乌鸦是否入画、威斯敏斯特钟、现成曲目、教室推拉门、楼宇附属件的范围。拍板前按 §6 写的默认施工。
- **落地顺序**：评审通过后，主代理先在 CORE-DECISIONS 里改写 D-064、D-103、D-104，再改各文档（CORE-CONVENTIONS §7.8）。草稿里的数值都是初值，P0 看图、听评后再定（§6.2）。

## 4 (a) 的改法：声音

### 4.1 原则

- **放开两样**：
  - 黄昏的乌鸦叫，清晨也有少量，都从远处传来。
  - 傍晚广播开头一段可以听出曲调的旋律。
- **不变的**：
  - 宣邦楼钟楼只敲单音铜钟，钟楼是地标（D-103）。
  - 人声听不清，中文语音识别门禁照跑（INV-6、SYS-AUDIO §8、G21a、G21h）。
  - 一次性声的节制（INV-10、SYS-AUDIO §7）。
  - 只在流逝 ≤ 10× 时放（D-105）。
  - 素材许可（D-106、SYS-AUDIO §14）。
  - 不做上下课铃。
- **乌鸦默认不画进画面**：乌鸦声从看不见的远处传来，和现在的麻雀归巢一样。麻雀也不在 WLD-LIFE §1 的动物表里，而 WLD-LIFE §1 已经写明"声音不反过来要求加画动物"。要不要画乌鸦见 §6.1 第 2 条。
