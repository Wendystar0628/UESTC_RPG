# ENG-ONBOARD-LOOKUP · 子代理开工手册：按要做的事查哪里

> **范围**：本文是 ENG-ONBOARD §4.2 指向的路由表：要做某件事时，先去哪份文档的哪一节查。开工时不用读它，需要找资料时再来。
> **不在本文**：开工环境、硬规则、查资料的总方法和回报：ENG-ONBOARD；各系统的设计细则：各自的文档。
> **查阅**：先读 §0；工程与流程相关看 §1.1；接入各个系统看 §1.2；画面与内容看 §1.3。
> **关联**：[ENG-ONBOARD 子代理开工手册](ENG-ONBOARD.md)、[CORE-INDEX 总索引](../README.md)、[ENG-WP 工作包](ENG-WP.md)、[ENG-STATUS 施工状态](ENG-STATUS.md)

## 0 结论

1. **按要做的事查**：在 §1 的表里找到最接近的一行，先读它指向的小节；表里没有的，用 `docs/design/SECTIONS.md` 按关键词搜。
2. **碰到别的系统先看接入要点**：每份规范文档 §0 的最后一个小节"接入要点"写着别的包碰到它必须守的规则。
3. **表只是起点**：每份文档范围块的"查阅"行会再往下指；规则与表冲突时以文档原文为准。

### 0.1 接入要点

本文只是查找路由，没有对其他包的接口要求。新增或改名的规范文档，要同步在 §1 对应的表里补一行，才能被查到。
