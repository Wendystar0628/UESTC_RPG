# ENG-GATES-VETO · 一票否决与收尾清单

> **范围**：一票否决 24 条（§1）与收尾阶段的全局清单（§2）。
> **不在本文**：门禁表与测试节奏（ENG-GATES）；审查视角与截图方式（ENG-GATES-SHOTS）；视觉精度的一票否决清单（ART-FIDELITY §3）；硬规则（ENG-BUDGET-RULES §1）。
> **查阅**：先读 §0；否决条目看 §1；收尾清单看 §2

## 0 结论

1. **一票否决 24 条，任一条即不通过**；集中测试时全面检查，平时只要求不违反（§1）。
2. **与视觉精度、硬规则重叠的条目只指向它们**：精度类以 ART-FIDELITY §3 为准，硬规则以 ENG-BUDGET-RULES §1 为准（§1 第 9、10、13 条）。
3. **收尾清单由主代理逐项检查**：INV-1 至 INV-12、风格、增补与翻新、箱庭、帧率、导出、门禁、新游戏（§2）。

### 0.1 接入要点

- **任何改动**：不得命中 §1 的一票否决，含 ENG-BUDGET-RULES §1 的硬规则与额度

## 1 一票否决

满足任一条，直接判不通过。集中测试时全面检查，平时只要求不违反。

1. 出现登记的界面与署名以外的叠加（文字、图标、按钮、加载或操作提示、引擎启动画面标志）；3D 画面里出现地点标签、选中描边、世界空间标记、光柱、路线线条、追踪标记，或锚点实体发光；`--ui=0` 下出现署名以外的叠加。
2. 画面里出现人、人影或行驶中的车辆（含过场）；行走模式画出观者的手、脚、影子或脚印；展陈出现人物肖像。判据取自 `sightseeing` 规则集的 `Characters = false`（ENG-ROADMAP §2）。
3. 出现日本的宗教或地标符号、日文文字或传统和式构件；或日式日常物件超出 ART-STYLE §3.1、ART-AMBIENCE 给的地点、数量和文字限定。
4. 使用照片纹理，或出现灰黑色阴影。
5. 镜头原地转一圈某方位的远景是空的；天空穿帮、黑洞、翻面；剖切面闪烁；外围露出未建模背面，或截面线以外露出地面和空洞。
6. 偶发事件超过一种，或出现快速、突兀的动作（观者触发的过渡不算，但时长和曲线须符合各系统文档；闪电、彩虹不算偶发事件）。允许的事件取自规则集的 `Incidents`。
7. 时间广场上有喷泉（MAP-QSH-CORE §3）。樱花、压在雪山剪影上的日落是设计，不在此列。
8. 改动了 OSM 原始数据；或覆盖层调整超出容差却没写理由。
9. 触发 ART-FIDELITY §3 一票否决清单的任一条，含第 19–27 条。底线类条目任何位置都判；与距离、密度有关的条目按所在精度区的判定距离换算（ART-FIDELITY §1.1）。
10. 违反 ENG-BUDGET-RULES §1 的任一条硬规则，或本包关掉前后的差值超出额度。
11. 时间、季节、天气或画面设置硬切：过渡期间超出 G13 的 ΔE 上限又不在雾幕里；影子某一帧突然换方向；自动调节某级降档没淡化。
12. 夜间大块死黑：太阳高度低于 −6° 时，肉眼可见大片纯黑，或夜间暗部不在蓝紫色相；雨夜、雾夜同样适用；天空与地下、水下、雾海不参与。
13. 季节残留：叶量为 0 的树上还有悬空叶片，或转场落定后仍有上一季的粒子、地面覆盖、植被色、积雪，草与雪、花与叶直接混色，判据以 ART-FIDELITY §3 第 17 条为准。
14. 行走：镜头进入关着的楼、封口以外、楼体实心部分、未登记的屋顶或地下层；走进显示空壳的楼；进得去出不来；掉出世界；卡死超过 3 s；能走上登记以外的楼顶；在 SYS-WALK-BOUNDS §2 允许的三处以外被隐形墙挡住。
15. 天气残留：雨停后仍有雨丝；换季替换后仍是上一种相态。
16. 闪电硬切或全屏闪白：闪光帧超出 G13 的闪电判据，或整屏翻白、画出落地闪电。
17. 未验证的转移边：自动天气走了动态格里没验过的"转移边 × 光段 × 季节"，或在晨昏带里发生自动转移。
18. 风格底线缺失：任何预设、手动值、自动调节级别下，描线、分阶明暗、按材质影色、柔光、高光肩部、平涂贴图、窗灯路灯光斑、实时阴影、西湖倒影有任一项消失，或阴影、倒影低于最差值（SYS-GRAPHICS §2）。
19. 切图残留：切图或同图重载后残留旧图的实例、碰撞 body、天气状态、安全点。
20. 丢档或读档后不一致：正常退出后再进同一存档，状态不是退出时的落定状态。
21. 读档执行了存档里的任何代码，或创建了存档指定的对象。
22. 无法回退：存档被覆盖或删除，回不到上一代。
23. 新档被覆盖：来自更新版本的存档被旧构建覆盖。
24. 声音：听得清的人声（取自规则集 `ClearVoices = false`）；可辨认的近处车辆开过；加速时一次性声爆发；室外数字静音；循环接缝咔哒；雨停后还有雨落声；声音硬切或爆音。

## 2 全局清单

收尾阶段由主代理逐项检查：

- [ ] CORE-INDEX 的 INV-1 至 INV-12 全部成立，§1 无一命中。
- [ ] 风格符合 ART-STYLE、ART-MODELING，V1、V4、V7 四季各看一遍；视觉精度满足底线 B1–B13，各区评分按精度区达标（ART-FIDELITY）。
- [ ] 设计增补与翻新清单全部落实，夜间灯光与天空冷暖对照成立，立面与地面无做旧痕迹（D-174）。
- [ ] 大箱庭完整（外围 O0–O3、截面、雾海、360° 远景）；各区、植被、水、动物与家具、动态的验收项通过。
- [ ] 三档设备在各自推荐预设下满足 ENG-BUDGET §2 的帧率目标，F1 无超标卡顿。
- [ ] 导出版：G6 通过，在没装 .NET SDK 的 Windows 机器上解压即可运行，窗口标题、图标、许可页符合 OPS-RELEASE §7.1。
- [ ] 门禁：G12 的 8 组看图通过、英雄帧好看；G13–G21 通过；F3、F4 全部达标。
- [ ] 新游戏在任何天气种子和画面预设下都从秋 17:30、晴、P00 开始；开始页、过场、跳转、传送、存档按各自系统文档工作。
