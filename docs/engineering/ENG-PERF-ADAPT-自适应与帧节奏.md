# ENG-PERF-ADAPT · 自适应与帧节奏

> **范围**：运行时自适应、帧节奏与画面设置约束（§1）。
> **不在本文**：设备档表、帧率目标与份额（ENG-BUDGET §2）；首次分档与画面设置的单项、预设值（SYS-GRAPHICS）；渲染器与 D3D12、Vulkan 的选择（ENG-BUDGET-RULES §2）；门禁判据与截图默认串（ENG-GATES）；绘制管线（ENG-PERF）；性能数据与指标口径（ENG-PERF-DATA）；测量、剖析与调优（ENG-PERF-MEASURE）。
> **查阅**：先读 §0；自适应看 §1.1；帧节奏与画面设置约束看 §1.2

## 0 结论

1. **自适应只往下调（主线之后）**：玩家手改的项锁定，只动即时类性能项，不动风格底线；每级降档 0.5–1 s 淡化；用完阶梯就停在最后一级（§1.1）。
2. **设备档只决定推荐预设、帧率目标和自动调节预算（主线之后，§1.1）**；档位表见 ENG-BUDGET §2，首次分档见 SYS-GRAPHICS §5。
3. **测量只判成本口径与两条单边判**：AI 采集与门禁按 ENG-PERF-MEASURE §2，口径见 ENG-PERF-DATA §3.2；测量时自动调节关闭（ENG-PERF-MEASURE §1）。

### 0.1 接入要点

- **新增画面设置单项或可被自动调节的性能项**：按即时、加载、重启三类生效，自动调节只动即时类；不触发管线重编译（§1.1、§1.2）
- **写基准或测量脚本**：只经 ENG-PERF-MEASURE §2 的入口，只判成本口径与那里的两条单边判（ENG-PERF-DATA §3.2）

## 1 自适应与帧节奏

### 1.1 运行时自适应（主线之后）

- **预算**：取设备档帧周期与玩家帧率上限对应帧周期中较大者；设备档表与目标见 ENG-BUDGET §2。
- **规则**：实际生效值 = clamp(min(玩家所选, 自适应上限), 最差值)，只往下调，回升不超过玩家所选，玩家手改的项锁定；只动即时类性能项，不动渲染精度、阴影质量、细小物件投影、显示设置，也不动风格底线与风格默认；每级降档 0.5–1 s 淡化，不得硬切。
- **降级阶梯**（顺序）：植被与粒子密度 → 细节距离系数 → 模型 LOD 精度 → 柔光质量 → 倒影刷新间隔 → 阴影距离。用完仍不达标就停在最后一级，不改渲染精度、不换预设。
- **控制律**：连续掉帧（ENG-PERF-DATA §3.1）就降 1 级，稳定约 30 s 再升 1 级。
- **非稳态帧**不计入统计、不触发降级，清单见 ENG-PERF-DATA §3。
- **不做静止降频**。

### 1.2 帧节奏与画面设置约束

- 帧率目标"跟随刷新率"：开垂直同步时只交给它，不叠加软件上限（按刷新率取整会周期性掉帧）；关垂直同步时按显示器刷新率设软件上限，读不到按 60；跟不上就如实显示帧率，靠降每帧成本解决，不降到整数分之一掩盖。
- **不做情境限帧**（DECISION-321）：窗口失焦与开始页都不另限帧，帧率只由玩家所选与垂直同步决定；后台跑的测量、门禁与截图都没有焦点，另限帧会牵动测量。
- 画面设置按即时、加载、重启三类生效（SYS-GRAPHICS §3）：即时类下一帧在 `FramePriority.Quality` 统一分发；加载类在加载界面下重建渲染缓冲（不编译）；跳转、传送、切图、加载界面进行中 `Apply` 返回 `Deferred`。会清空管线的设置不做成选项，所以怎么切都不再编译。
