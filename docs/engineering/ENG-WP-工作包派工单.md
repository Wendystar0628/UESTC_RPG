## 0 结论

1. 共 56 个包（WP-00 至 WP-55）。WP-00 由 Astra 在 D0 先做；完成后其余包分两波开工，同一波内并行；大包可再拆（§1.1、§3）。
2. §2 每包一行：规格文档、依赖、阶段、主线版交什么。独占目录看 `ownership.json`，状态看 WF-STATUS。
3. 阶段依次是 D0、D1 起、主线闸口、闸口之后、收尾；各文档里的 P0–P3 按 §1 对应；金样与主线并行、不阻塞主线（§1）。
4. 主线版先行：闸口之前每包按 §2 的"主线版"交付，后置细节留到闸口之后；闸口以主线冒烟（G5）通过为准（§1，WF-RULE §8）。
5. 建模完成度是主线（D-183）：派工先做第二波 Opus 侧的建筑、部件、分区、植被、街道家具、箱庭与室内包，再做游泳、生物、角色本体等新功能（§1.1）。
6. 拆出的子包共用原包的目录和程序集，各自独占其中一个子目录，沿用原包的行（§3）。
7. 契约分批冻结、共享文件、Godot 与 .NET 版本、插件清单、开放室内清单和预算核账由主代理负责（§4）。
8. 目标框架 net10.0（C# 14），正式启动链须跑通编译、导入、导出、导出版启动四步（§4，D-177）。

- **开工时**：看本包在 §2 的行和派工简报；主责的文档（文件头 `owners` 里有本包）读熟它的 §0 和本包负责的小节；改文件的边界与契约申请见 WF-BUILD §1（§2）
- **主线闸口之前**：只交 §2 本包"主线版"列写的东西，细节留到闸口之后（§2）
- **闸口之后排细节**：按 §2.2 本包牵头或协作的条目做；§2.3 的候选范围在定下归属与编号之前不开工
- **做拆出的子包**：沿用原包的行，只独占其中一个子目录（§3）
- **要增删开放室内、改 `map.json` 的字段或 `budgets.json` 的 `maps.<id>` 一节**：经回报提交，由主代理审批（§4 第 4 条）
- **要加插件**：只收 MIT、ISC、Apache、BSD、OFL，由主代理登记进 `third_party.json`（§4 第 3 条）

## 4 主代理的工程维护事项

主代理的角色与日常职责见 WF-ROLE；下面是契约、版本、插件、清单与预算这些工程维护事项。

1. **契约分批定死**（D-134，ENG-ARCH §3）：WP-00 先交能编译的契约 v1 候选和全部桩。某组契约的真实生产方与使用方在主线上接通、相关核心专项通过后，主代理宣布冻结这一组，记进施工状态，之后只增不改；未冻结的组按申请修改。改契约、加全局着色器参数、着色器白名单、程序集引用和 NuGet 包的申请由主代理统一处理；共享文件的改法见 WF-BUILD §1。
2. **版本**：Godot 4.7.2 与 net10.0（C# 14）、SDK 10.0.402 以 `tools/godot-version.txt`、`global.json`、csproj 为准，三处一致，门禁比对引擎 `--version`；升级单独评估，经主代理（D-177）；升级后按 `docs/godot-api/README.md` 重新生成 API 参考并通知各包。正式启动链须跑通 `dotnet build` → `--import` → `--export-release` → 导出版启动，不通时报作者决定，不自行退回 net8.0。.NET 导出模板约 1.2 GB，第一次做 G6 导出前从官方来源下载，下完说明（WF-RULE §6）。
3. **插件清单**：`game/addons/` 与 `third_party.json`（名称、版本、提交、许可证、哈希）。只收 MIT、ISC、Apache、BSD、OFL（D-170），插件须声明支持当前小版本；NuGet 包在 `Directory.Packages.props` 集中锁版本。
4. **开放室内清单**：`game/data/maps/qingshuihe/interiors.json` 的格式与 schema 归 WP-51，条目由负责包经回报提交，增删由主代理审批，以用户的决定为准；加一栋楼按 WLD-INTERIORS §11。`map.json` 的字段增改、`budgets.json` 的 `maps.<id>` 一节也由主代理批准。
5. **预算核账**：GPU 与主线程的主代理余量所剩无几（外围、室内、平面地图都可能动用），P0 实测后统一核账，写回 ENG-BUDGET §8。
6. **音频素材与版本库**：维护 `.gitattributes` 的 Git LFS 条目（`*.wav`、`*.ogg`）；仓库公开时，只许随游戏发布、不许公开分发的素材放私有素材库；开场音乐的委托或自制由 53e 跟进，做好之前开始页只放环境声（SYS-AUDIO §11、SYS-AUDIO §13）。
