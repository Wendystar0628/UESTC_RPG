# ENG-PERF-LIGHT · 植被、阴影、后期与灯光

> **范围**：植被的分级、风、飘落池和投影（§1）；阴影、后期链、窗灯路灯和倒影的做法（§2）。
> **不在本文**：阴影方向、强度、月影与天气修正的取值（ART-SKYLIGHT §3.1）；阴影档位与光柱、倒影、灯的数量上限（ENG-BUDGET §2、ENG-BUDGET-LOD §4）；植被的种类与外观（WLD-VEGETATION）；容器、着色器、图层（ENG-PERF）。
> **查阅**：先读 §0；植被看 §1；阴影看 §2.1；后期链与描线看 §2.2；窗灯路灯看 §2.3；倒影看 §2.4

## 0 结论

1. **植被按单株选级，不跟随格子**；风分主干、团块、叶片三层，相位读 `anim_time`；飘落池、降水池、草是无状态的 MultiMesh（§1）。
2. **阴影开销只能靠减少投影物省**：引擎每帧全量重渲所有级；植被与远处体量用 `ShadowsOnly` 代理；阴影方向量化、日月交接的取值见 ART-SKYLIGHT §3.1，做法见 §2.1。
3. **后期链固定顺序**，描线靠材质 ID 编进 ROUGHNESS 的 7 位，线宽按内部分辨率换算；抗锯齿不用 TAA 与 MSAA（§2.2）。
4. **窗灯、路灯光斑由哈希与灯表决定，可复现**；倒影用独立 `World3D`，不放投影光（§2.3、§2.4）。

### 0.1 接入要点

- **让植被或远处体量投影**：本体 `cast_shadow = Off`，另建 `ShadowsOnly` 代理，可见上限 = 本体可见上限 + 最长影长；草、插片、落叶、粒子、光晕不投影（§1、§2.1）
- **改描线、后期或灯光通道**：描线读 ROUGHNESS 里的材质 ID，不开 MSAA；新灯种走 `light_channels` 数据纹理，不新增通道（§2.2、§2.3）

## 1 植被

- **分级**：按单株选级，不跟随格子；近池（150 m 内）每个"母模型 × 级"一个动态 MultiMesh，不超过 10 Hz 分级并整块写入；远池 64 m 一块静态随格烘焙；L3、L4 是树冠云并进格子几何。远距替身（团块低模或半八面体，P0 二选一）四季共用一套，不烘四季各一套。
- **树叶**用 alpha scissor 留在不透明通道，不用 alpha-to-coverage 与 alpha hash（无 TAA 时满屏噪点）。
- **风**分主干、团块、叶片三层，相位读 `anim_time`；阴影通道编译同一段 `vertex()`，风与叶量缩放自动跟到影子，代价是阴影通道里的距离判断必须用主相机。系数只乘幅度、不改相位，快进、换季、换天气不让阵风错拍；`IWindField.Sample` 与着色器同一公式。
- **飘落池、降水池、草**都是 MultiMesh，位置由 `anim_time` 与种子解析算出，没有状态，截图与录像可复现；降水池循环盒跟相机走，`vertex()` 读 `precip_occ` 让檐下无雨；密度用 `VisibleInstanceCount`（SYS-WEATHER §3、§6）。
- **季相**不换模型、不重建格子、不重编译：连续参数加阈值生长。
- **阴影**：树干、团块、高于 1 m 的绿篱投影，草、插片、落叶不投影；本体 `cast_shadow = Off`，另建 `ShadowsOnly` 代理，其可见上限 = 本体可见上限 + 最长影长（影子长、会投进近处）。均衡、流畅关闭近景几何叶。

## 2 阴影、光照与后期

### 2.1 阴影

取值（阴影方向钳制与室内抬高、主光强度曲线、日月交接的区间、月影强度、阴影强度随天气）以 ART-SKYLIGHT §3.1 为准，档位与级联参数见 ENG-BUDGET §2、ENG-BUDGET-LOD §4；这里只写做法。

- 引擎每帧把所有级全部重渲，没有降低远级更新率的办法，开销只能靠减少投影物省；场景里只有一盏 KeyLight（WP-03），日月轮流担任。不开 PCSS，要干脆的影边。
- **方向量化**：方位与高度分别量化，步长取固定的一两度，跨过一步才转灯并带回差；快速变化（拨表盘、快进、换季）时连续转动，慢下来再回量化。
- **太阳贴地**：主光强度曲线不改 `LightEnergy`；退光线让受光按地面 → 低层 → 高层 → 穹顶的顺序退场，穹顶必须是单独实例；掠射面在 `light()` 里判进影里以防痤疮，地面材质例外。
- **日月交接与月影**：交接那一帧任选，主光转到月亮；月影强度不能用 `ShadowOpacity` 实现（它在阈值化之前混合，会越过卡通阈值），要在 `light()` 里对阈值化后的阴影混合。
- **阴影空跑**：阴影强度低于 0.01 时 `ShadowOpacity` 与 `ShadowCasterMask` 置 0；恢复时先在强度仍为 0 的那一帧恢复 mask，下一帧再淡入。云影不占阴影通道。
- **降开销**：远处体量与植被用 `ShadowsOnly` 代理，按大小限投影距离；不做接触阴影。

### 2.2 后期链

- **顺序**：预通道 → 不透明 → 天空 → Compositor `PostSky`（描线、边缘光、雨幕带）→ 透明 → `PostTransparent`（移轴、高光肩部、暗角、光斑）→ Glow → Tonemap Linear → 运行时 LUT → 去色带、抗锯齿、FSR1。界面画在链之后。
- **CDL 与 LUT**：CDL 参数按关键帧插值后每帧写进运行时 LUT；高光肩部与暗角并在移轴合成那次 dispatch 里，不随移轴关掉。
- **描线**：材质 ID 编进 ROUGHNESS 的 7 位，前提是关闭 `screen_space_roughness_limiter`、不开 MSAA、预通道开。线画在前景一侧；ID 不同才描材质交界；天空与 400 m 以外提前退出。**线宽按内部分辨率换算**，名义宽度 ≥ 1 px 的线内部宽度不小于 1 个内部像素。远处倒角变窄后由凸边亮线接替倒角提亮；远雨幕带、闪光帧、边缘光并进同一次 dispatch，不另加通道。
- **抗锯齿**：不用 TAA（一拍二、风动、细线会拖影）与 MSAA（ID 和法线不能 resolve）；P0 查 SMAA 是否侵蚀 1 px 线，会就改用自写 FXAA。
- **可关项**（移轴、光斑、光柱、暗角）的管线启动时就建好，关时先 0.5 s 淡到 0。
- 窗灯光晕与光柱都走 `fx_glow`；不用体积雾（开销约 1–3 ms，且写 `FOG` 的材质会跳过它）。

### 2.3 窗灯与路灯

- 窗灯亮灭只由窗号哈希与通道值决定，可复现；L2 窗带用同一哈希，远近切换不跳。
- **灯光通道**共 32 个，按"建筑类别 × 灯种"划分，由 WP-39 登记并写进数据纹理 `light_channels`；外围与开放室内接进这些通道，不新增。时刻表曲线以 SYS-TIME-LOOK §3 为准；阴雨天灯提前亮，用有效太阳高度 h_eff = h − 6° × 阴度 − 4° × 降水量，着色器与 C# 同一公式。
- **路灯光斑**：离线生成 8 m 网格灯表，着色器读灯表画平涂光斑，光斑里把影色换成调色板灯照行，仍是两阶；开放入口的门口灯登记进灯表，不加绘制调用。重点灯用 `OmniLight3D`，全校 ≤ 32 盏、不投影（几百盏路灯不能都用真实点光）。

### 2.4 倒影

SubViewport 每轴 1/4 分辨率（风格底线），按预设间隔更新。每个视口都会把方向光阴影重渲一遍，所以倒影用独立 `World3D`、不放投影光；内容是共用的 Sky 和平涂的 `reflect_flat` 代理，总绘制 ≤ 40 次；Camera3D 没有斜裁剪，只放水面以上的代理。每帧只给面积最大的湖。水面默认不透明、不读深度与屏幕纹理；不用 SSR 与反射探针。
