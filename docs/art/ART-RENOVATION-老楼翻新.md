# ART-RENOVATION · 老楼翻新：全部翻新的规则

> **范围**：本文规定校园老旧建筑的全部翻新：位置、体量、层数和身份特征不动，外观上显旧的东西全部换成与新楼同一套材质、配色、部件和洁净度。内容包括适用范围、总则、材质与配色、删简留，各部位的改法，氛围与成电辨认，三种楼型的示例和验收。
> **不在本文**：所有老楼共用的翻新预设之外的身份特征例外（MAP-QSH-RENOVATION）；楼的身份特征（各区文档、ART-MODELING-PROPORTION §1）；明暗、描线与调色板（ART-STYLE）；不做旧通则（ART-FIDELITY-DETAIL §1.5）；日式街景物件（ART-AMBIENCE）；生活痕迹的摆放（WLD-LIFE）；室内（WLD-INTERIORS）。
> **查阅**：先读 §0；范围与限度看 §1；会脏处换什么构件看 §2.2；材质与色额看 §3；删简留看 §4；窗、檐口、楼梯间、屋顶与首层看 §5；氛围与成电辨认看 §6；楼型示例看 §7；验收看 §8

## 0 结论

1. **显旧的楼一律全部翻新**（D-173）：位置、体量、层数、层高和身份特征不动，换成与新楼同一套部件、色名和洁净度（§1）。
2. **借"美化"，不借"做旧"**：删杂物、规整立面、提亮墙色，再用光、树影、天空和季节落物让普通的楼好看；翻新楼与新楼并排分不出谁旧（D-174，§2.1）。
3. **会脏的位置换成设计构件**：勒脚、带滴水的窗台、机位格栅、压顶檐口和收管线的管槽；生活感只靠干净的痕迹（§2.2、§2.3）。
4. **每栋楼的颜色有配额**：立面固有色最多 3 种，大面积墙色提亮、压彩，跳色不上墙（§3.2、§3.3）。
5. **日式氛围先靠画法和构件语言**：每层的水平亮线、薄挑檐、透光白帘、叶影上墙、楼梯间竖向亮窗；日式物件按 ART-AMBIENCE 上楼，同样是新件（§6.1、§6.2）。
6. **成电要认得出**：身份特征、组团墙色和中国校园物件保住辨认（§6.3）。
7. **验收三件事**：无旧痕、与新楼并排分不出新旧、3 秒认得出（§8）。

### 0.1 接入要点

- **区域包认领了翻新楼**：照 WP-14 的翻新预设执行，构件只从部件库取；覆盖层的登记写法按 §1.1
- **改翻新楼的外形**：位置、平面轮廓、层数、总高和层高不改；身份特征 ±10% 以内，显旧时只换新材料（§1.2、§6.3）
- **加挑出构件或屋顶物**：挑出主墙面 ≤ 0.6 m（通长雨庇 ≤ 1.2 m），高出女儿墙 ≤ 3 m（§1.3）
- **做建筑立面的材质或贴图、部件库内核与全局材质常量**：斑驳按 ART-STYLE-SHADING §4.2，不跟着排水走；不带立面的旧痕层，只留天气湿痕的遮罩（§2.1、§3.4）
- **给翻新楼上色**：立面固有色最多 3 种（主墙 ≥ 65%、副色 ≤ 25%、深色 ≤ 10%），大面积墙 L ≥ 0.80、C ≤ 0.05，只用登记色名，不自己调色（§3.2、§3.3）
- **在翻新楼上放生活痕迹**：只用干净的痕迹，衣物不挂在窗外、格栅或护窗栏上（§2.3、§4.3）
- **在翻新楼上加日式物件**：形制与地段按 ART-AMBIENCE，不压身份特征，不让固有色超过 3 种（§6.2）

## 1 适用范围

### 1.1 哪些楼列入翻新

- 对照实景，凡有 ART-FIDELITY-DETAIL §1.5 所列旧痕或旧构件的楼都算翻新楼；看台罩棚、车棚、围墙、外楼梯同一口径。没有逐栋清单：所有老楼按本文的翻新预设做，几栋身份特征要保的楼另有例外，见 MAP-QSH-RENOVATION。
- 删掉的旧元素登记为覆盖层的 `hide`，新构件登记为 `add`（MAP-QSH-ADDITIONS §0）。
- 翻新预设 = MAP-QSH-ADDITIONS-VOCAB §6 的规则 + 本文 §2–§6，做进通用建筑生成器（WP-14），区域包认领的楼照同一预设执行；新构件（窗套、护窗栏、伸出杆、管槽、管廊）按 ENG-WP 的部件分组进部件库。

### 1.2 不动什么

- 位置、平面轮廓、层数、总高和层高不改；层高也不加，比 ART-MODELING-PROPORTION §1 更严。
- 3–5 项身份特征照旧 ±10% 以内；显旧时只换新材料，颜色家族、位置和比例不变（§6.3）。
- 开窗的层位不改；开间数和窗宽按 ART-MODELING-PROPORTION §2 调。

### 1.3 能加多少

- 主墙面位置不动。附加构件（压顶檐口、窗套、窗台、窗楣、遮阳板、机位格栅、花箱）挑出主墙面 ≤ 0.6 m；入口雨棚按 MAP-QSH-ADDITIONS-VOCAB §6；每层通长雨庇最多挑出 1.2 m（ART-AMBIENCE §2）；原有大挑檐照原尺寸翻新。
- 屋顶新增物（设备围挡、管廊、光伏）高出女儿墙顶 ≤ 3 m；高架水箱与屋顶围网只在 ART-AMBIENCE §2 登记的两栋老楼上。

## 2 总则

### 2.1 全部翻新，与新楼同标准

1. 每个可见构件都按"新做"：从部件库取件，用登记色名，不做旧（ART-FIDELITY-DETAIL §1.5）。
2. 洁净度与新楼相同，墙面斑驳与顶点色按 §3.4；与相邻新楼并排看分不出谁旧。部件库内核不带立面旧痕层，只留天气湿痕的遮罩。
3. 年代感只来自建筑语言（窗墙比、面砖、开间节奏），不来自损耗；新旧并存只表现为新设备与老楼语言的并置（MAP-QSH-ADDITIONS §4）。

### 2.2 会脏的地方换成构件

| 现实中显旧的位置 | 换成 |
| --- | --- |
| 窗台下的流挂、雨痕 | 厚 0.15–0.3 m 的实体窗台加滴水槽，顶面浅色 |
| 墙根返潮、泛碱、脏带、苔 | 0.6 m 勒脚、0.8 m 散水、雨水篦（MAP-QSH-ADDITIONS-VOCAB §6） |
| 外机下的水渍、乱走的冷凝水管 | 1.0×0.9 m 机位格栅（开孔约 55%，上下对齐）、深灰冷凝竖管 |
| 女儿墙顶破损、檐下雨痕 | 新压顶檐口、滴水、避雷带 |
| 落水管两侧的污迹 | 落水管只走阴角或开间分界，竖直到底，每 15–25 m 一根 |
| 锈蚀褪色的雨棚、遮阳篷 | 白铝板雨棚、灰铝窗楣 |
| 屋面补丁、积水痕 | 整片屋面，分仓缝在 L1 内画色块 |
| 面砖色差、补砖、缺砖 | 新面砖（§3.5） |

### 2.3 生活感只靠干净的痕迹

- **可用的痕迹**：阳台晾晒、窗帘的三种状态与颜色、窗台绿植与水杯、阳台花箱、开着的窗、亮灯、单车与电动车、门口物件（外卖挂架、桶装水、伞）、季节落物；数量与时段以 WLD-LIFE-FAUNA §2 为准。
- **状态全新**：衣物挂在杆上，被子可以整齐地搭在栏杆上拍晒；不挂在窗外、格栅或护窗栏上；花盆完整，车不锈不缺件，海报平整。
- **密度**：K1–K3 的立面每 30 m 至少 1 件，K4 背立面不要求；成簇，簇外留白（ART-FIDELITY-DETAIL §1.4）。

## 3 材质与配色

### 3.1 材质族

立面只用五类：
- **涂料墙**：默认的主墙和窗间墙，平涂，按 1.5×0.75 m 分格，60 m 内用色块显分缝、不描线。
- **面砖**：只给原本是面砖、且面砖色列为身份特征的楼（如食堂），按 §3.5。
- **石材**：勒脚、门套、台阶，粉质平涂。
- **金属**：窗框、窗楣、雨棚、栏杆、格栅、管，灰铝、深灰或白铝板，曲面一条亮带，不画锈。
- **玻璃**：一栋楼一种玻璃色（深青灰），楼梯间窗带可用磨砂玻璃。

不用：马赛克、仿石贴纸、彩钢板、塑料扣板、镜面或彩色反光玻璃、贴膜、多色混搭的窗框。

### 3.2 每栋楼的颜色配额

- 立面固有色最多 3 种（不计玻璃）：主墙 ≥ 65%，副色（窗间板、墙带、腰带、楼梯间开间）≤ 25%，深色（勒脚、格栅、冷凝竖管）≤ 10%。
- 窗框、窗楣、栏杆、雨棚只从灰铝或白两种里选一种主用，同楼不混。

### 3.3 取值

- 大面积墙色固有色 L ≥ 0.80、C ≤ 0.05（ART-STYLE-SHADING §4.3、ART-MODELING-PROPORTION §5）。老楼原色只取色相（偏移 ≤ 8°），明度提到 ≥ 0.80（暖棕深墙至少 0.78），彩度压到 ≤ 0.05。
- 同组团同色，组团之间用大块墙色区分（MAP-QSH-NORTH §4.5）。老食堂暖砂面砖 L 约 0.76，低于 0.80 的建议值，先不改，用样楼看图再定（WP-04、WP-20）。
- 砖红、电子蓝不上墙（ART-STYLE §2.2）。
- 用的色名（固有色以 `game/style/palette/core.json` 为准）：宿舍暖米黄墙（本科老宿舍主墙）、宿舍米白墙（白窗框和窗台压顶的顶面）、灰白墙面（老教学楼主墙）、浅米灰石材（窗间板、门套）、食堂暖砂面砖（老食堂主墙）、低饱和棕板（暖墙楼勒脚）、深灰屋面（屋面、中性墙楼勒脚）、灰铝框、深青灰玻璃；以及翻新专用的两个：
  - **陶红墙带**：本科 A 型的竖向墙带和 1–8 号楼的副色，替代现实的砖红；色相近砖红、彩度约一半，远看仍读作"红墙带"，影仍是陶红。它属局部板，不算跳色，面积受副色 ≤ 25% 约束。
  - **浅奶咖墙**：暖棕外墙的老楼组团，替代现实的深暖棕，与宿舍暖米黄墙拉开明度和色相。

### 3.4 斑驳、笔触与顶点色

- 斑驳按 ART-STYLE-SHADING §4.2：颜料感、不是脏，不跟着排水走，对全校立面都适用，幅度取那里的值。
- 笔触只在 5 m 内，方向取水平或竖直，不画成下垂的流痕；墙脚渐变保持关，墙脚的深色只由勒脚给出。
- 墙板之间的明度微变按整块分格板取（ART-FIDELITY-DETAIL §1.2），同一块板内不变，免得读成新旧涂料的色差块。

### 3.5 面砖

新砖、单色；两色只按构件规则拼（腰带、窗间、柱面），不随机拼、不画补砖；砖缝只在 L0+ 生成、缝宽一致；5–60 m 用 1.2×0.6 m 分格色块，60 m 外平涂。

### 3.6 描线

新构件按 ART-STYLE-LINES §1.1 自然出线。构件多了交界线也多，所以一个立面上互相接壤的固有色不超过 3 种；窗台、窗楣、压顶与所在墙同色时用同一个材质 ID，只靠折角线和投影读形。面砖缝、分格缝、穿孔板的孔不描。

## 4 删、简、留

### 4.1 删：旧痕、杂物与防盗网

- 水渍、流挂、返潮、泛碱、苔、墙根脏带 → 由 §2.2 的构件接替；褪色、色差块、修补色块、补砖 → 统一固有色；缺角、裂缝、剥落、锈 → 删。
- 废弃支架、旧空调孔封堵痕、旧招牌钉孔；墙面线槽、成片弱电箱、乱拉的线、旧标语、广告、横幅（MAP-QSH-ADDITIONS §5）→ 删，每个入口一个与墙同色的设备箱，毕业季横幅照 WLD-LIFE-FAUNA §2。
- **防盗网** → 删；首层临路的窗需要时，在洞口内嵌一道与窗框同色、只到窗高下半的护窗栏，立杆间距 0.25–0.3 m。
- 私搭雨棚、窗外花架、外伸的杂乱晾衣架 → 统一花箱、晾衣杆与伸出杆。
- 屋面补丁、杂物、旧太阳能热水器、电视锅 → §5.4；后场泔水桶、气瓶、纸箱 → 删或收进后院围墙。

### 4.2 简：外机、管线、窗分格与标识

- **外机**：宿舍每间一格机位格栅，上下对齐成竖向条带；教学楼、食堂的外机收进屋面围挡，立面不挂。
- **外挂管线**：雨水管只走阴角或开间分界，冷凝水管贴格栅一侧，燃气管、排油烟管收进一条与墙同色的竖向管槽。
- **窗分格**：每扇 2–3 格，一个立面最多 2 种窗型。
- **遮阳篷**换成灰铝窗楣或每层通长雨庇；**楼梯间错层窗**做成竖向对齐的窗带；**屋面设备**进围挡，管线收成 1–2 条直管廊。
- **标识**只留楼名、楼号、学院竖牌三样（MAP-QSH-ADDITIONS-VOCAB §1）；入口一组楼号牌、安全出口、消防箱、摄像头、壁灯排成一横排。

### 4.3 留：干净版的生活痕迹

晾晒挂在阳台内或统一伸出杆上、颜色低饱和；窗帘三到四成是逆光透亮的浅色薄帘；窗台绿植盆完整，盆色只用陶土、白、灰；统一的钢制阳台花箱；约五分之一的窗开着；新车按中国校园的停法；门口的外卖挂架、桶装水、伞；窗台、檐口、雨棚顶的季节落物；夏季外机只在地上留一块会干的湿斑，墙上不留痕。数值以 WLD-LIFE-FAUNA §2 为准。

## 5 窗、檐口、楼梯间、屋顶与首层

### 5.1 窗

1. **洞口**进深 0.25–0.4 m；原窗与墙齐平时加一圈外凸 0.15–0.25 m 的窗套，让窗洞任何时刻都有干净的影边。
2. **窗框**全部换新，灰铝或白选一种，框宽 0.12–0.2 m，每扇 2–3 格，玻璃退进 20–30 mm；教学楼可用推拉错开的铝窗（ART-AMBIENCE §2）。
3. **窗台**厚 0.15–0.3 m，底面滴水槽，顶面浅色，能接落物。
4. **窗楣**：原遮阳篷位置换成灰铝窗楣（厚 0.15–0.2 m、挑 0.4–0.6 m）；南立面可连成每层通长雨庇。窗台和窗楣每层画出上下两条水平线，黄昏顶面是亮线。
5. **西立面**可加竖向鳍片，不压身份特征。
6. **重复**：同一开间连续 ≤ 3–4 次，变化用楼梯间窗带、格栅、窗帘和亮灯，不用"新旧窗混排"。

### 5.2 檐口与女儿墙

1. 压顶全部换新，取部件库 M 档（ART-MODELING-PROPORTION §6）；低层食堂的原挑檐照原尺寸翻新。
2. 压顶顶面浅色，配避雷带：黄昏一线暖亮边，夜里一线冷色高光。
3. 檐底平整，不画雨痕，带一点地面暖反光。
4. 天际线起伏只用整块体量（出屋面楼梯间、设备围挡、水箱间），不用天线、细杆和杂物凑。

### 5.3 楼梯间

1. 楼梯间开间做成立面上的竖向主变化：半层位的窗上下对齐，连成一条通高窗带，窗间用副色实板或磨砂玻璃，窗带宽取原窗宽的 1.1–1.25 倍。
2. 墙面用本楼副色或主墙色，不新增颜色。
3. 夜里读本楼公共区的灯光曲线（SYS-TIME-LOOK §3），在暗下来的立面上留一列竖向亮窗。
4. 出屋面楼梯间与主楼同一种压顶，一扇深灰门加小雨棚，它同时是屋顶的高差。
5. 已有的外挂楼梯换新钢构：深灰扶手、实心侧板、白梁底、扶手顶一线亮带；新加的外挂钢楼梯只用在商业街和后勤小楼（ART-AMBIENCE §3）。

### 5.4 屋顶

1. 屋面整片一色（宿舍灰白，其余深灰），分仓缝在 L1 内画色块；雨天积水随天气出现、雨停干掉。
2. 热泵、水箱、多联机、油烟净化器一律进深灰穿孔铝板围挡，只露顶部（MAP-QSH-ADDITIONS-VOCAB §4）。
3. 管线收成 1–2 条沿女儿墙内侧的直管廊，等距支墩。
4. 宿舍屋顶不放太阳能热水器、不晾晒；1–8 号楼那一小排热水器做成统一支架的新的一排。
5. 可选屋顶光伏、屋顶花园（MAP-QSH-ADDITIONS-VOCAB §4）。

### 5.5 首层、入口与阳台

1. 勒脚、散水、雨水篦按 MAP-QSH-ADDITIONS-VOCAB §6；勒脚色：暖墙楼用低饱和棕板，中性墙楼用深灰。
2. 墙根外一条 0.8–1.2 m 宽的修剪绿篱，每 20–30 m 断开，留给入口、落水管和检修。
3. 入口雨棚、楼名、学院竖牌按 MAP-QSH-ADDITIONS-VOCAB §6。
4. 一栋楼只用一种阳台做法，栏板优先实心，顶扶手浅色。

## 6 氛围与成电辨认

### 6.1 画法上的氛围手法

日式氛围先来自"怎么画"和构件语言（光、天空、叶影、透光、留白、整齐），不依赖任何日本物件；这些手法不能盖住身份特征。

- **每层的水平亮线**：窗台与窗楣（或雨庇）每层两条水平线，顶面浅色；主面朝西南时黄昏全线受光，冬季顶面一线积雪。
- **薄挑檐**：压顶挑出，檐底平整，夜里压顶与避雷带有月光高光。
- **透光白帘**：三到四成浅色薄帘，约五分之一的窗开着，夜里被室内灯照透。
- **叶影上墙**：朝西、朝南的立面前 4–10 m 每 30 m 至少一棵阔叶乔木，立面上留一块至少 6×6 m 的平墙专门接叶影；默认状态的低太阳把树影整片投上墙，冬季是枝影。
- **楼梯间竖向亮窗**：夜里亮成一列。
- **干净的剪影**：屋顶线只有整块体量，压在天空前，玻璃映天。
- **季节落物**：窗台、檐口顶、雨棚顶接落叶、花瓣、积雪；楼本身不换季节色。
- **外廊**：朝院子的单面外廊，实心栏板、浅色扶手、连续柱影。
- **留白与绿的遮挡**：立面约 80% 平、20% 密；山墙下部爬山虎 1/3–2/3、修齐不爬过窗；主视角里树冠和爬藤遮住立面不超过 35%。

### 6.2 日式物件上楼

- 物件的形制、地段与限定以 ART-AMBIENCE §2–§3、§6 为准，外挂钢楼梯、店头布篷、卷帘门、波纹铁皮雨棚只用在商业街和后勤小楼（ART-STYLE §3.1）；上楼时按本文 §5 的尺寸和 §3 的色额做，不压身份特征，固有色不超过 3 种。
- **不上楼**：传统和式建筑构件（ART-STYLE §3.1）；外墙竖向垂幕和横幅。
- 日式物件只加在翻新后的立面上，不能拿来保留或替代旧痕。

### 6.3 保住"认得出是成电"

1. 先列身份特征，翻新不碰；显旧时只换新材料，例如 A 型的红墙带换成陶红墙带。
2. 组团墙色只提亮、不换色相，远看仍能按墙色分出组团。
3. 中国校园物件照常出现：山墙楼号、学院竖牌、简体中文楼名、外卖挂架、桶装水、充电棚、PVC 门帘、机位格栅（MAP-QSH-ADDITIONS §4）。
4. 翻新对照楼金样的参考板的两张反例：一张"做旧"，一张"日式物件盖过身份特征"（ART-MODELING-PROPORTION §6）。

## 7 示例：三种楼型

身份特征要保的楼的例外见 MAP-QSH-RENOVATION；下面是三种楼型的做法样板。

### 7.1 老式宿舍楼

原型是本科 A 型 6 层板楼与米黄、暖棕外墙的组团（MAP-QSH-NORTH §4.2、§4.5）。
- **不动**：6 层与平面轮廓；米黄主墙配竖向红墙带；白窗框；组团门口的值班室。
- **配色**：主墙宿舍暖米黄墙（暖棕组团换浅奶咖墙）；墙带陶红墙带；勒脚低饱和棕板，格栅与竖管深灰；窗框、窗台顶、压顶顶用宿舍米白墙。
- **改了什么**：按 §4、§5 删防盗网、散挂外机、流挂、褪色遮阳篷、外伸晾衣架、线槽、屋顶热水器；加窗套、带滴水窗台、灰铝窗楣、全楼对齐的机位格栅、实心阳台栏板；楼梯间窗带用陶红实板相隔；M 档压顶加避雷带；勒脚、散水、绿篱；山墙大号楼号和约 1/3 爬山虎。
- **氛围**：每层两条水平亮线；山墙前乔木把叶影投满山墙；夜里楼梯间一列亮窗，23:30 成片熄灯（MAP-QSH-NORTH §4.9）。

### 7.2 老教学楼

原型是 4–5 层框架教学楼，条楼或回字形，朝内院有单面外廊（品学楼 A、B 区，MAP-QSH-CENTER-EAST §2；立人楼同楼型）。
- **不动**（以品学楼为例）：书法横梁门框与架空通道、门前叠水喷泉、回字形内院、斜放的门厅与半圆楼梯厅、浅色框架配青灰窗组、屋面玻璃脊式采光带。
- **配色**：主墙与框架灰白墙面；窗间板浅米灰石材；勒脚深灰；灰铝框。
- **改了什么**：删散挂外机、新旧混杂的铝窗与彩色玻璃、线槽与旧标语、落水管污迹、屋面补丁；框架内做带形窗，南立面通长雨庇，西立面非身份段加鳍片；内院外廊 1.1 m 实心栏板；半圆楼梯厅只换新折线玻璃幕，封闭疏散梯改竖向窗带；已有题字，不加屋顶构架和楼名大字。
- **氛围**：内院外廊是最接近日式校舍的一处：实心栏板、连续柱影、19:30–21:55 一格格整齐亮起的教室（SYS-TIME-LOOK §3）；内院的树把叶影投上朝院的墙。

### 7.3 老食堂

原型是 1–3 层暖砂面砖低层食堂，大开间、水平檐板，带外楼梯或室外扶梯（MAP-QSH-NORTH §5.2–§5.3、MAP-QSH-SOUTH §7.4）。
- **不动**：低层大开间体量、暖砂色面砖、水平檐板或大挑檐、室外扶梯罩棚或直跑外楼梯、PVC 门帘入口。
- **配色**：主墙食堂暖砂面砖；柱面或腰带第二种面砖色；檐板按原楼米白或暖棕；金属深灰。
- **改了什么**：删面砖色差与补砖、油渍、散挂外机群、乱走的燃气与排烟管、锈蚀雨棚、褪色店招与灯箱、窗上贴纸、后场杂物；面砖按 §3.5，首层深色玻璃加灰铝竖框，二三层带形窗，原挑檐翻新、檐底嵌筒灯；外机和油烟净化器进围挡，排烟管并成一条屋面直管；后院用同面砖围墙加绿篱遮住；店名只用浮雕字或立体字。
- **氛围**：首层大玻璃在黄昏以后是"暖色发光区"（ART-STYLE-SHADING §2.4），檐下筒灯在台阶上落一排暖光，树阵把叶影投在面砖墙上。

## 8 验收

1. **无旧痕**：在巡检点（ART-FIDELITY §4）看，§4.1 的任何一项都不出现；不做旧是底线 B13。
2. **并排分不出新旧**：与相邻新楼同框，洁净度一样；删掉旧痕后立面不变空，缺的由 §5 的构件和 §2.3 的痕迹补。
3. **认得出**：与实景对比 3 秒内认出是哪栋楼。
