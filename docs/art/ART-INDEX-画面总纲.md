# ART-INDEX · 画面总纲

> **范围**：本文是画面域的入口：本域管画成什么样的视觉语言：风格、明暗与描线、视觉精度、造型、天空与光照、色彩脚本；列出本域通用的原则和本域全部文档的上下级。
> **不在本文**：各主题的规则与设计（在下面列出的文档里）；全项目的核心准则与信息地图（CORE-INDEX）。
> **查阅**：先读 §0；要找文档看 §1，按标题挑要读的那份，再读它的 §0 与接入要点

## 0 结论

1. **视觉优先**：任何时刻、季节、天气都要好看，真实数据只作参考（PRD-SCOPE §1）。
2. **画风底线是硬约束**：三渲二日式动画背景、精度底线处处成立（INV-5、INV-11）；画质设置只降质量，不降画风。
3. **本域只写画法与通用取向**：画什么物件、放哪归世界域（WLD-INDEX）和各图文档，清水河专属的景物与楼的设定不写在本域；参数与写法以 `game/style/` 等代码为准。
4. **几何与精度不随时刻、季节、天气变**：造型、倒角、厚度、构件对任何世界状态一样成立，变的只有色彩与光（INV-8）。
5. **颜色只经色名**：文档、内容与代码都不写十六进制色值，新色先登记再用（ART-STYLE §2.5，G4）。
6. **默认状态是基准**：文中的光色与取值默认指秋 17:30、晴，其他格由色彩脚本推导（ART-COLORSCRIPT §1）；标"主线之后"的节现在不施工（STD-DOC §2）。

### 0.1 接入要点

- **碰画面的改动**：推送后由主会话跑固定机位截图看一眼，审美以作者为准。
- **在本域新增文档**：主题文档文件头写 `parent: ART-INDEX`，在 §1 加一行；子文档写 `parent: <主题文档编码>`，列进主题文档的 §0 和本总纲 §1 那个主题下（STD-DOC §5.1、§7）。
