# ART-STYLE-SHADING · 明暗、影色与材质表现

> **范围**：本文规定全局卡通着色：明暗阶数与法线、影色的推导、高光边缘光与透光、贴图与笔触，以及材质速查。
> **不在本文**：目标、参照、调色板与排除元素（ART-STYLE）；描线与后期（ART-STYLE-LINES）；天空、太阳与雾（ART-SKYLIGHT）；各时季格的取值（ART-COLORSCRIPT §1）；着色器的参数与写法（`game/style/`，白名单清单见 ENG-PERF）。
> **查阅**：先读 §0；明暗 §1，影色 §2，高光与透光 §3，贴图 §4，材质速查 §5

## 0 结论

1. **明暗少阶**：建筑与硬质大件两阶，曲面道具和软物两阶半，植被团块三阶；没有接触影，遮蔽只推阈值（§1）。
2. **影以明度为主、按材质定色**：影色从固有色推导，只有中性面随天光偏色，影不一律蓝紫；室内取暖影（§2）。
3. **倒角靠三件事读出**：自定义法线、着色器的倒角带提亮、远处的凸边亮线（§1.6、ART-STYLE-LINES §1.7）。
4. **光要看得见**：玻璃斜条与低太阳眩光、背光暖边、薄物逆光透光、湿面闪点（§3）。
5. **贴图只有颜料感**：禁止照片纹理，只用弱斑驳、近处笔触和构造图案线；斑驳不表现脏（§4.2）；不用法线贴图（§4.3）。
6. **材质速查**：石材、金属屋盖、塑胶、积雪、木地板各一句画法（§5）。

### 0.1 接入要点

- **涉及影子**：没有接触影，接地靠物体分界线加投影（§1.1）
- **写材质或着色器**：只用 include 了 `toon.gdshaderinc` 的白名单着色器，新增经主会话批准（Codex 主线负责白名单与技术接入）；颜色只经调色板纹理（§1.5）；材质 ID 的约束见 ART-STYLE-LINES
- **建模**：法线做法见 ART-MODELING §1.6，不用法线贴图（§4.3）
- **做贴图**：不用照片来源（G6）；斑驳按 §4.2

## 1 明暗分阶

### 1.1 阶数

| 类 | 阶 | 用于 |
| --- | --- | --- |
| 建筑、地面、硬质大件 | 两阶 | 墙、屋面、地面、台阶、桥、球场 |
| 曲面道具、金属件 | 两阶半（影 / 半受光 / 受光） | 灯杆、扶手、垃圾箱、雕塑、车 |
| 软物 | 两阶半，过渡带加宽约 2 倍 | 坐垫、靠枕、被子、窗帘褶、猫 |
| 植被团块 | 三阶（深影 / 影 / 受光） | 树冠团块、灌木球、绿篱 |

- 阈值略偏影侧，受光多吃一点；交界窄而干脆。观感阈值以 `toon_look.gdshaderinc` 为准；C# 与着色器共享的规则值以各 C# 规则类为准，由构建步骤生成着色器 include；植被深影由影色压出，不另登记色名。
- **没有接触影这一阶**：物体与地面、墙与地面的接地感交给物体分界线（ART-STYLE-LINES §1.1）加真实投影。
- **遮蔽只推阈值、不加一阶**：只在窄凹处（窗洞内壁、檐底 0.5 m 内、门洞、栏杆缝）把阈值往影侧推，颜色仍是同一个影色；接触处不推。
- 影里的天光渐变、地面反光（§2.3）和云团树冠的冠内明度梯度是连续变化，不算一阶。

### 1.2 法线展平

平墙上不许出现碎影。

- 建筑、曲面、球柱类道具的法线按 ART-MODELING §1.6，地面与土坡的法线按 WLD-TERRAIN-APPLY §4。
- 地标曲面（八角穹顶、电子管穹顶、圆鼓体量）的明暗交界要干净：手调法线加阈值偏移。

### 1.3 树冠法线

云团型每个小球自成一块干净的明暗，插片型整团成块；法线做法与树种分类按 WLD-VEGETATION §1。

### 1.4 平涂与渐变

- 大面积平涂。墙脚渐变默认关；需要时只加在影面，明度 ≤ 4%，色相取该材质的影色相，不偏紫。
- 室内竖向渐变：天花和墙上部压暗 ≤ 5%、不偏冷；窗下 1 m 内提亮约 5%、偏暖。
- 天空、水、雾照旧用渐变。

### 1.5 统一的卡通着色

- 所有材质 include 同一个 `toon.gdshaderinc`，每类物体一个白名单着色器（清单见 ENG-PERF，禁用写法见 ENG-ARCH）；颜色只经调色板纹理进来（ART-STYLE §2.5），不用引擎的环境光、灯光颜色和补光。
- 始终保留主光，蓝调无影时只把强度和阴影置 0；太阳、月亮用同一套分阶。
- 阴、雨、雪时明暗按天光方向判，顶面和朝主光一侧受光，阶数不变。改时间、季节、天气只改参数，不切特化开关。
- 自发光件（灯牌、灯罩、灯箱面）亮时不分阶，明度封顶、不变纯白；灭时压成一对暗色；灯罩跟自己那盏灯亮灭。

### 1.6 倒角提亮与只改明暗的修正

两阶下两面都受光时阳角只剩一条线，所以倒角要配三件事（DECISION-176）：

- **自定义法线**（ART-MODELING §1.2）。
- **近处的倒角带提亮**：倒角宽不小于约 1.5 px 时，受光项上提亮一阶，影里略提，免得两面都在影里时阳角消失；只给硬质建筑材料和道具的平直件。
- **远处的凸边亮线**：倒角过窄的距离交给描线（ART-STYLE-LINES §1.7）。

倒角提亮、假倒角、地标曲面的手调交界都**只改明暗、不写 `NORMAL`**，不进描线读的法线缓冲；只有球柱类道具的解析法线写回 `NORMAL`。

## 2 影子：明度为主，按材质定影色

### 2.1 原则

1. 影子以明度为主：每个色名在每格有自己的影色，主要差别是明度；不一律蓝紫，不为影子另设计一套颜色。
2. 影色从固有色推导，不从受光色推导：落日的暖是光带来的，影里色相回到固有色。
3. 中性材质（固有色彩度 < 0.06 的白墙、灰石、混凝土、雪）的影随天光偏色：白天偏天青，黄昏偏淡紫，阴天偏珍珠粉紫，量只有 C 0.02–0.045。
4. 有彩材质降明度、略增彩，色相向天光最多转 8°（植被 15°）；黄橙不向绿转，绿改向青转。
5. 越不实的材质影越浅，透光元素按逆光透射处理（§3.5）。

### 2.2 推导规则

- 各"关键帧 × 季节"格的受光色和影色由色彩脚本在 OKLab 里推导（ART-COLORSCRIPT §1），不拿白天的颜色乘实时灯光；公式与明度比等参数以 `game/style/palette/keys/derive.json` 为准，花、布、灯罩、水面的影最浅。
- **自检约束**（SYS-TIME §4、ART-FIDELITY §3 第 19 条按这里判）：
  - 浅色面（受光 L ≥ 0.85）的影 L 白天 ≥ 约 0.74，默认格 ≥ 约 0.68；
  - 非绿色材质的影不落在 100°–150°（橄榄区）。
- **受光不过艳**：草和叶不比英雄帧更艳，傍晚是暖黄绿；黄橙类任何光下色相都不往绿偏，夜里是压暗的暖金。
- 不用"固有色 × 天光"的纯乘法（橙木的影会发橄榄绿）。默认格暖白墙的影 L 约 0.73，是"清透干净"的主要来源。

### 2.3 天光与地面反光

影里朝上的面略亮、朝下的略暗（约 ±0.03 L）；檐底、冠底、雨篷底这类朝下的面混一点地面暖反光，室内和夜间为 0。

### 2.4 室内暖影

- 室内的影与受光按 §2.2 推导，天光目标换成室内暖调：中性材质的影是浅暖米灰，明度不低于同材质室内受光面（窗光照到的那面）的约 85%，彩度不超过中性材质的上沿（`derive.json` 的 `neutralCEdge` 低端），白墙和白字在影里仍读成白；彩色材质色相向橙最多转 8°，木色在影里仍读成木色。
- 窗光斑只抬明度、不放大彩度；从外看室内是"暖色发光区"（WLD-INTERIORS-BUILD §3.1–§3.2）。

### 2.5 哪些材质有色调变化

只有这些影明显偏色，其余只降明度、略增彩：中性面与雪（§2.1 第 3 条）；植被（转角上限 15°、彩度略降）；花瓣花团向品红偏；跳色只降明度、色相小转，砖红的影仍是砖红，不发粉发灰；水面的影比岸上浅（WLD-WATER）。

### 2.6 夜间与阴雨

- **夜间**：暗部仍偏蓝紫，满足 SYS-TIME 的夜间下限。
- **阴雨**：软光下影变浅，天光目标向阴天色混合；两阶照样保住，白天投影强度不低于 0.2，明暗按天光方向判（§1.5）。

## 3 高光、边缘光与透光

### 3.1 玻璃

- 每扇窗叠 2–3 条平行斜条（30°–45°，一宽一窄），全天都有，影里也有；大面积玻璃按格稀疏挑选；夜里只留在不亮的窗上、减半。
- 低太阳时正对太阳的立面玻璃整块亮成白金色眩光（默认是西立面），被挡住时没有；高太阳映天蓝；阴雨雾天没有眩光，映当前天色。

### 3.2 金属亮带

栏杆、灯杆、金属屋盖顺着曲面走一条各向异性亮带，像动画头发上的"天使环"；颜色取主光色，夜里路灯下取灯照色。

### 3.3 边缘光

- **背光暖边**：背光一侧的剪影加 1–1.5 px 暖边，跟随主光；夜里改成细而淡的冷银边；无影蓝调里不画。
- **受光侧剪影暖边**：曲面道具、树干、雕塑和建筑的受光侧边缘一线暖色，影里不出，金属更强。
- 逆光树冠的边缘最亮（WLD-VEGETATION §1）；雨后初晴边缘光加强（SYS-WEATHER §2）。

### 3.4 湿面与积水

- 被雨淋到的面压暗、提彩度，掠射角映一条平涂天光带；夜里湿路面映出灯的竖条，让每盏灯在地上再亮一次。积水映天空、剪影和灯条；檐下、连廊下、树冠下少湿。
- 朝上的湿面在太阳方向出硬边闪点，交给柔光晕开，湿瓦、铁件、湿铺装最明显。
- 湿面不丢细节：分阶、影色、描线照旧，湿润不许改写 ROUGHNESS。数值以 SYS-WEATHER §6 为准。

### 3.5 透光

- 薄物被太阳从背后照透时亮起来，被挡住时不透；透光色由受光色提亮加彩。
- 透光由强到弱：树叶花瓣、薄窗帘、灯罩灯箱遮阳伞晾晒旗面（旗面透过仍是电子蓝）、磨砂玻璃与玻璃砖；透明玻璃不透光；冬季裸枝和重阴时为 0。系数以 `ToonSpec.Translucency`（`MatTable.cs`）为准。

## 4 贴图与笔触

### 4.1 禁止照片纹理

照片来源的纹理与旧网页栈的程序纹理一律不进工程（G6）。

### 4.2 斑驳、笔触与构造图案线

- 只用三样：2–8 m 的低频斑驳、5 m 内的方向笔触、室外构造图案线；另允许平涂图案贴图（木地板板条、货架标签、地毯、黑板字）。
- 斑驳要弱，中远景读作干净的平涂：明度约 ±0.03 L（笔触同），不画深色晕边。
- **斑驳只表现颜料感，不表现脏**：世界空间里各向同性，不随窗台、墙脚、落水管、外机、檐口变暗；只留天气湿痕、季节落物和常年接水驳岸上干净的常水湿带（WLD-WATER）。
- **构造图案线**（DECISION-195）：铺装缝、面砖格、砖缝、板缝、模板线做成只改明度的平涂线，缝比底色略暗；尺度按真实模数，方向沿楼边或铺向；格子小于约 4 px 时淡成平均明度，K4、K5 不画；不在排水位置加深。

### 4.3 不用法线贴图

建筑和道具不用法线贴图：两阶下会变碎影，还会把噪声写进描线读的法线缓冲。凹凸交给几何、自定义法线、AO 推阈值和只改明暗的假倒角；修边贴图按 ART-MODELING §1.4。

## 5 材质速查

米色石材是粉质平涂加少量斑驳；银色金属屋盖的板缝画暗细线；砖红塑胶哑光，颗粒只在贴脸时出现；青铜像暗哑；积雪平涂、边缘一道硬边，不画颗粒；打蜡木地板和水磨石加一道硬边宽高光（WLD-INTERIORS-BUILD §3.2）。金属、玻璃、树叶、薄布、湿面按 §3，湖水按 WLD-WATER。
