# ART-SKYLIGHT-ATMOSPHERE · 天空、月亮与雾

> **范围**：本文规定天空（渐变、霾带、云、星空、银河、城市天光、天气天象、日月盘）、月亮外观，以及雾与大气透视（共用雾函数、边缘雾、换季起雾、天气雾与地标豁免）的观感与取值。数值是默认状态（秋 17:30，晴）的参考值，其他格来自关键帧。
> **不在本文**：主光、阴影、天光、受光退场、人造光、光效清单与冷暖对照（ART-SKYLIGHT）；日月的轨迹、关键帧与色彩脚本（SYS-TIME）；天气清单与每种天气的画面规则（SYS-WEATHER）；远山、城市剪影与雾海的形态（WLD-OUTSKIRTS-DIORAMA）；外围街区与边缘（WLD-OUTSKIRTS）。
> **查阅**：先读 §0；天空与云星看 §1；月亮看 §2；雾与大气透视看 §3

## 0 结论

1. **天空**全写在一个 sky shader 里，颜色只读调色板纹理，不写死；夜空天顶 L ≥ 0.25，夜晚不能死黑，天空永远比建筑亮（§1.5、§1.6）。
2. **云**的云量与云型由天气向量给出，漂移 = f(世界时间) + g(`AnimTime`)：快进时加速掠过，暂停时仍极慢飘动，不会倒走（§1.3）。
3. **日月盘**按全局参数里的真实方向画，不受主光量化和阴影方向钳制；月亮是美术满月（§1.9、§2）。
4. **雾**：所有材质用同一个共用雾函数，不开 Environment 雾；介质、换季起雾、边缘雾和天气只修正它的输入（§3.5）。
5. **雾不造成裸面**：雾只盖住远处，地标在浓雾里仍可辨认（§3.6）。

### 0.1 接入要点

- **写室外可见的材质（卡通、水、粒子、雾海）**：include 共用雾函数，在 fragment() 里写 `FOG`；不开 Environment 雾、体积雾和 FogVolume（§3.5）
- **介质状态（楼里、地下、水下）**：雾色、能见度和混合度写进全局参数，不换 Environment（§3.5）
- **地标要在浓雾里可辨**：在该实例上设 instance uniform 偏置做雾豁免（§3.6）
- **改天空或夜景**：夜空天顶 L ≥ 0.25，天空永远比建筑亮，夜晚不死黑；新东西写进 sky shader，颜色读调色板纹理（§1.6、§1.8）
- **旁观飞到可达空间的水平边缘**：边缘雾规则见 SYS-BORDER §2.3
- **天气要改天空或雾**：只经天气向量的全局参数修正输入，色值修正叠进调色板（SYS-WEATHER §6）

## 1 天空

默认帧"秋 · 黄金"的天空见下；其余关键帧与四季修正见 ART-COLORSCRIPT §1，色值由调色板提供，天空着色器只读不定色。

- **1.1 渐变**：太阳一侧的竖向五段渐变，从地平线往上依次是金 → 橙 → 玫瑰 → 薰衣草 → 天顶蓝；粉橙只落在地平线以上约 0–25° 的带里，天顶通透。紫、洋红、深金渗进阴影，暗部开放、不压死。背阳一侧从地平线的灰粉过渡到淡蓝紫，再到天顶；日出日落两帧的背阳侧还有地影和维纳斯带。两侧随方位角平滑过渡；夜间"太阳侧"改为"月侧"。
- **1.2 霾带**：默认状态下地平线上压着一道米灰泛黄的霾带，约占地平线以上 2°–3°；冬最厚偏珍珠灰紫，夏最薄。霾带不能把雪山完全吞掉：晴天雪山可见度有下限，阴雾雨时仍留一道最淡的剪影（WLD-OUTSKIRTS-DIORAMA §6）。
- **1.3 云**：默认状态下西南天边只有几缕高积云，其余天空干净，像冷空气过境后的晴日。
  - 云被落日从下方照亮：顶缘淡金带金边，云腹偏紫，下沿一道白色细高光；云比背后的天空亮一阶。
  - 其他时段与季节：正午积云覆盖 25%–35%；夏季高耸的积雨云、傍晚火烧云；冬季是雪后初晴或薰衣草灰天。夜间云比天空暗，边缘被月光描一道银边。
  - **随天气**：云量与云型由天气向量给出（SYS-WEATHER §2）。积云硬边三阶上色，层云满覆盖并留亮缝，雷雨沿用夏季积雨云卡片；地面云影跟随同一份云。
  - **漂移** = f(世界时间) + g(`AnimTime`)：快进时云像延时摄影一样加速掠过，暂停时仍有极慢的飘动，云不会倒走。方向与速度在 `game/data/maps/qingshuihe/sky.json`。
  - **飞机云**：夏、秋晴天的下午可有一两道细长的硬边白线，尾部慢慢散开，随云漂移，不画成划过天空的过程；是持续的天象状态，不算偶发事件；阴、雨、雾天和夜里不出现。
- **1.4 天气背景**：其余天气按 SYS-WEATHER §2 的画面规则画。天色底线：阴天是珍珠粉紫，冬季是薰衣草灰，夜雨天顶是暖紫（云层把城市天光放大，天比楼亮）；禁止中性灰和灰黑的天。
- **1.5 星空、银河与城市天光**：
  - 星星不超过 300 颗，闪烁按"一拍二"步进，入夜淡入、黎明前淡出；阴雨雾天随云量和雾淡出。
  - 银河只在夏夜出现（英雄帧 4），是低彩度的淡紫白带子，不画写实星云；位置按英雄帧取景定，不按真实星图。
  - 夜间地平线一圈暖紫的城市天光，给城市和雪山剪影垫一层底，同时满足"天空必须比建筑亮"。
- **1.6 夜空的明度下限**：天顶 L ≥ 0.25（夜雨同）；夜晚不能死黑。
- **1.7 阴天云盖、雨幕、闪电与彩虹**（触发与安全规则见 SYS-WEATHER §5）：
  - **阴天云盖**：层积云盖满，云底平涂、按天光方向分两阶，至少留一道亮缝；亮缝下有云缝光柱，地面有缓慢扫过的云洞光斑；云盖不画成灰黑。
  - **远处雨幕**：雷雨时一道深色雨幕从西湖方向推来，东半边可以还在阳光里；雨的分层、线宽与数量归 SYS-WEATHER §3。
  - **闪电**：只做远处云内闪：天空画被照亮的云团，场景一瞬间翻到受光色、没有投影。
  - **彩虹**：背对太阳，视觉优先，不用真实的固定 42°：主虹半径低太阳时约 30°、随太阳升高放大到 42°，17:30 时整道进 60° 视场的平视镜头。太阳在 32° 以下虹顶不低于地平线以上约 10°，34°–40° 之间平滑淡出，免得一道贴地的残虹。五条硬边色带，副虹更淡、色序相反，彩度低、半透明；也加进雾色，远山前面也看得到虹。
- **1.8 天空的统一约束**：天空穹顶、云、星空、银河、城市天光、日月盘全写在一个 sky shader 里（`game/systems/sky/`）；颜色读全局调色板纹理，着色器里不写死颜色；卡通材质不读天空。
- **1.9 日月盘**：用日月的真实方向画，不受主光量化和阴影方向钳制（ART-SKYLIGHT §3.1）；月相与月晕在月盘内画，主光只照场景。

## 2 月亮

月亮是**美术满月**，四季默认都是满月，季节转场时月相不变（轨迹与规则见 SYS-TIME §2.2）。

- **外观**：一枚淡奶油色的圆盘，低悬时偏暖（入夜帧"低悬的暖月"），升高后变银白；按月盘受光方向做球面明暗；直径放大到真实的约 1.5–2 倍，这是动画的惯例；月面只用两三块淡灰斑，不画写实月面。
- **光晕**：外面只带一圈很淡的光晕；月亮不出镜头光斑（ART-STYLE-LINES §2.3）。
- 阴、雨、雪天月盘和月晕藏在云后，没有月影。

## 3 雾与大气透视

数值来自关键帧；下面是默认格，其他关键帧与季节雾色见 ART-COLORSCRIPT §1。

- **3.1 颜色**：按视线方向取地平线的天空色（默认格朝阳一侧暖杏、背阳一侧淡蓝紫）；夜间按月侧和背月侧取色。
- **3.2 随距离的变化**：
  - 起雾距离（开始降饱和）与剪影距离（远处只剩剪影）取各时刻关键帧，值见 `game/style/palette/keys/` 下各季 `*.keys.json` 的 fog 段；近处清晰、远处渐淡到只剩剪影的观感是目标。
  - 越远，明度越高，色相越接近天空；夜间同样，远处剪影向更亮的夜空色靠拢，不沉进死黑。
  - 清晨贴地雾和日出湖面浓雾是关键帧的设定。
  - **外围街区**（WLD-OUTSKIRTS-BAND §3.2）走同一套规则，自动淡出。
  - **边缘雾**：旁观飞到可达空间的水平边缘时，朝外一侧的雾加浓，规则见 SYS-BORDER §2.3。
- **3.3 箱庭外的雾海**：形态由 WLD-OUTSKIRTS-DIORAMA 负责，颜色与本节一致；深夜顶面微微发光，雾天升到截面上缘；内缘在截面线上，雾里露出 O2 的楼顶（WLD-OUTSKIRTS-BAND §1.1）。
- **3.4 起雾**：换季转场中段的起雾走本节同一套雾，不另起一套效果。起雾从远到近收：起雾距离与剪影距离一路收到镜头前，远处的楼先沉、近处最后沉；不只乘雾密度。传送与换图遮挡画面时经加载界面（SYS-TITLE §3.1），不走本节。
- **3.5 雾的实现原则**：所有材质共用一个雾函数，不开 Environment 雾和体积雾，介质（楼里、地下、水下）、换季起雾、边缘雾和天气都只修正它的输入，0.25 s 过渡，不换 Environment（SYS-VIEW-MEDIUM §1）。雾色取同一天空函数在该方位的地平线色，从起雾距离起降饱和、到剪影距离混成剪影色，贴地雾和湖雾按高度积分；卡通材质、天空、水、粒子、雾海都用它，地平线处无缝。
- **3.6 天气雾与地标豁免**：
  - **雾天**：起雾距离大幅收近，剪影距离不低于 600 m；雾色乳白；贴地雾加湖雾；正午雾顶压低，高楼和穹顶露出雾面受光。**夜雾**：路灯光晕变大，光锥可见。**雨后初晴**：能见度提高。
  - **地标豁免**：浓雾下八角穹顶、宣邦楼钟楼仍可辨认，相关部件做成单独实例并按实例偏置做雾豁免（SYS-WEATHER §7）；雨雾天在点位上的剪影距离不小于 800 m。
  - **雾不造成裸面**：雾只盖住远处，不替代建模；30 m 内两阶、描线和斑驳都在，雾里的剪影要有轮廓复杂度，露出雾面的屋顶按所在区做完整。
