# ART-STYLE-LINES · 描线与后期

> **范围**：本文规定后处理描线（描哪些线、线色、线宽、折角线、凸边亮线），以及后期的风格底线、可关项和各项做法。
> **不在本文**：目标、参照、调色板与排除元素（ART-STYLE）；明暗、影色与材质表现（ART-STYLE-SHADING）；天空与光线条件（ART-SKYLIGHT）；预设取值（SYS-GRAPHICS）；描线与后期的参数与写法（`game/style/outline/`、`game/kernel/post/`）。
> **查阅**：先读 §0；描线 §1，后期 §2

## 0 结论

1. **线细、随底色染色**：后处理描外轮廓、主折角、材质交界、物体分界四类，线色禁止纯黑（§1）。
2. **后处理描边，材质 ID 不许改写**：用深度、法线、材质 ID 检测，不用外扩反面网格；ID 存在 ROUGHNESS 里（§1.5）。
3. **倒角在远处由凸边亮线代替**：倒角窄于约 1.5 px 起到 150 m，画一条受光色提亮的 1 px 亮线（§1.7）。
4. **后期克制**：柔光、色调映射、光晕、描线是不能关的风格底线；移轴、光斑、光柱、暗角可关（§2）。
5. **特效都是硬边平涂形状**；不用 TAA 和 MSAA（§2.6、§2.7）。

### 0.1 接入要点

- **做画面设置或自动调节**：风格底线四项（柔光、色调映射与 LUT、窗灯和路灯光晕、描线）不能关；可关的四项关时 0.5 s 淡出，关掉后的画面不进验收（§2）
- **写任何效果的着色器或后期**：任何效果都不改写 ROUGHNESS 里的材质 ID；ID 由 WP-04 按材质类分配，特殊 ID 向 WP-05 申请（§1.5）

## 1 描线

线细、随底色染色：暖处暖棕、冷处青灰，有轻微的轻重；按浅线定，受光面上线的 L 约 0.49。

### 1.1 描哪些线

- 四类：外轮廓；主要折角（法线夹角约 45° 以上，软阈值，§1.6）；材质交界；物体分界（材质 ID 不同的物体相接处，如道具与地面）。同材质的两件相接不描。
- 窗格、砖缝这类内部细线用色块表达，不描；几何铺装块只描外轮廓；修边条与墙面分属不同线类，正视也有交界线，远处可淡但不淡到 0。
- 树冠：插片型、混合型只描外轮廓；云团型内部折线按软线淡掉。
- **小件淡出**：重复小件的线先于几何淡掉。
- **不描**：水面、透明玻璃、贴面痕迹、粒子、花瓣、草叶、落叶、雨丝。

### 1.2 线色

- 本色压暗再冷暖染色，禁止纯黑；冷暖两端是随帧色名 `line.warm`、`line.cool`，不分建筑与树木。
- 远处向雾色过渡；夜里线比影暗 0.06–0.10 L，不被暗部吞掉（SYS-TIME-LOOK §1）；雨雾天线色、线宽不变。

### 1.3 线宽

以 1080p 为基准按内部分辨率换算：外轮廓贴脸 1.6 px，5–30 m 为 1.25 px，150 m 为 0.75 px，400 m 外为 0、只靠剪影的色差；主折角取外轮廓的 0.8 倍，物体分界与材质交界取 0.6 倍；贴脸上限 2 px（ART-FIDELITY §2.0 的 B11）。距离曲线以 `game/style/outline/post_outline.glsl` 为准。

### 1.4 逐材质调线与轻重

- 线宽要能逐材质调节、局部擦掉（例如采光顶网格只描主肋），按材质 ID 登记线类。
- 轻重变化锚在世界坐标上：走动时线不游、不闪，也不随时间变。

### 1.5 后处理描边

- 用深度、法线、材质 ID 在后处理里检测，不用外扩反面网格（穿模时糊满屏、顶点翻倍），英雄件也不例外。
- 材质 ID 存在 ROUGHNESS 里，任何效果都不许改写；ID 由 WP-04 按材质类分配，特殊 ID 向 WP-05 申请。
- 不足 1 px 的线按覆盖率画，放大后仍是清楚的细线；剖切面也出线（SYS-VIEW-MEDIUM §1）。

### 1.6 折角线与低模

- 折角判据用软阈值，线随角度和距离平滑淡出，不在 45° 附近闪。
- 近处倒角宽到约 3 px 后折角线消失，接受"倒角替线"：阳角由倒角提亮和明暗交界读出。
- 对低模只提四条要求：曲面剪影段数够（1 px 折线误差）；硬折角避开 40°–50°；模块接缝焊死；薄件的线随距离淡出。

### 1.7 凸边亮线

- 倒角在远处的替身：凸且受光的折角在受光一侧加一条 1 px 亮线，颜色取受光色提亮一阶，影里不画；从倒角窄于约 1.5 px 起画到 150 m。
- 它满足底线 B3 的"有倒角或边缘高光"（ART-FIDELITY §2.0），所以小件的几何倒角可以只放在 L0+。
- 它与背光暖边（ART-STYLE-SHADING §3.3）是两件事；暗折角线保留，亮线并排画。

## 2 后期

- **风格底线**，任何预设、手动值、自动调节都不能关：柔光（只能选质量档）、色调映射与 LUT、窗灯和路灯光晕、描线。
- **风格默认**，可单独关，关时 0.5 s 淡出，关掉后的画面不进验收：移轴、镜头光斑、光柱、暗角。
- 预设取值见 SYS-GRAPHICS。

### 2.1 柔光：白天只晕高光

白天全帧柔光会发灰，所以白天只让超过 1 的真高光（日盘、灯、闪点）晕开；低太阳起渐入全帧柔光，黄昏以后把手绘天空和场景粘成一体，但不抬影面。雾、雨、雾幕和闪光帧上加量（SYS-WEATHER）。

### 2.2 色调映射

- 不用 ACES。登记的受光色原样上屏（前后 ΔE ≤ 2），只把大于 1 的溢出柔和压进余量并向白去饱和，不爆白、不偏色。
- 静态 LUT 加按关键帧插值的 CDL：抬黑让影和暗部清透，暗部略冷、亮部略暖。

### 2.3 镜头光斑

只在镜头转向主光源时出现，跟随太阳；月亮只带光晕、不出光斑；一条横向变形光条加 3–5 个淡彩光圈，不透明度 ≤ 25%；阴雨雾天不出（ART-SKYLIGHT §4）。

### 2.4 移轴景深

画面上下各约 20% 轻微虚化，混合上限 25%，不糊主体和线。

### 2.5 窗灯光晕

亮窗和路灯带一圈柔和光晕，半径不超过窗宽的一半；夜雾里路灯光晕变大，光锥可见（SYS-WEATHER §2）。

### 2.6 特效形态与光柱

- 光斑、尘埃、季节粒子（樱瓣、落叶、雪花、萤火虫）、雨丝、溅点、涟漪、彩虹都是硬边平涂的实心形状，不做真实感的半透明粒子云。
- 光柱是软边加法体，不用体积雾：室外沿太阳方向，按太阳高度淡入；室内每块受光窗格一根棱柱，带细尘（WLD-INTERIORS-BUILD §3.2）。近镜淡入、顺轴看时减弱，免得 17:30 近水平的光柱穿过时满屏发白。天气条件见 ART-SKYLIGHT §4。

### 2.7 抗锯齿

不用 TAA（一拍二、风动、细线会拖影）和 MSAA（坏材质 ID）；描线自带抗锯齿，SMAA、FXAA 不许侵蚀 1 px 细线。

### 2.8 暗角与分调

暗角轻（白天约 0.10，夜里约 0.12），黄金时段略暖。界面画在后期之后，不吃后期（UI-VISUAL）。
