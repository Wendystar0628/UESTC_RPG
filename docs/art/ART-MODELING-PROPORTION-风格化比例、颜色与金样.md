# ART-MODELING-PROPORTION · 风格化比例、颜色与金样

> **范围**：本文规定建筑、植被、道具与室内的风格化比例和形体、身份特征、固有色约束，以及金样与部件库如何让二十多个建模者风格一致。造型规则对任何时刻、季节、天气一样适用（INV-8）。
> **不在本文**：最低合格构件、几何门槛、收边倒角、法线与换级（ART-MODELING）；精度判据与一票否决（ART-FIDELITY）；明暗、影色、描线与调色板（ART-STYLE）；树种与季相（WLD-VEGETATION）；室内清单与预算（WLD-INTERIORS）；部件库的写法（`game/gen/parts/` 源码）。
> **查阅**：先读 §0；身份特征看 §1；比例看 §2；植被与地表看 §3；道具看 §4；颜色看 §5；金样与部件库看 §6

## 0 结论

1. **先定身份，再放开**：每栋有名字的楼列 3–5 项身份特征，误差 ±10%；其余构件可调 ±20–30%；层数不改（§1）。
2. **建筑按风格化比例**：窗框、窗洞进深、窗台、檐口加厚加深；门、栏杆、踏步、座面按真实值；同一开间连续不超过 3–4 次（§2）。
3. **道具"少、粗、圆、干净"**（§4）。
4. **颜色**：大面积固有色 C ≤ 0.05，跳色 C 0.12–0.19；只登记固有色（§5）。
5. **风格一致靠金样和部件库**：金样只留 3 个，所有区同时按预设做，作者看固定机位截图挑毛病；部件库是几何的唯一入口（§6）。

### 0.1 接入要点

- **各区或生成器要放几何**：只取部件库（`game/gen/parts/`）的参数和预设，区域代码不写几何常量（G4）（§6）
- **给有名字的楼建模**：先列 3–5 项身份特征，误差 ±10%，其余只在 ±20–30% 内调，层数不改；新增元素按 INV-9（§1）
- **定构件尺寸**：取风格化比例表；人体尺度锚点按真实值，栏杆最高 1.2 m（§2）
- **要随机变化**：用稳定 ID 的带种子哈希，不用 `System.Random`（§3）
- **定颜色**：只登记固有色，不为某个季节或时刻单独调色（§5）

## 1 先定身份，再放开

- **身份特征**：每栋有名字的楼先列 3–5 项，从平面轮廓、层数、屋顶标志物、主入口、特色色或材质里选，误差 ±10%（底线 B1）。
- **其余构件**允许 ±20–30% 的风格化调整；竖线笔直，不学 Fortnite 式的歪扭；层数不改，层高最多加 8%（翻新楼不加，WLD-RENOVATION §1.2）。
- 结构与细节的取舍、增删与登记按 INV-9（难看的现实元素的删减见 WLD-AMBIENCE §1.5）。老楼全部翻新（WLD-RENOVATION）；日式日常元素按 WLD-AMBIENCE。

## 2 现代混凝土和石材楼的比例规则

| 项目 | 风格化取值 |
| --- | --- |
| 窗洞 | 宽度放大 10–25%；窄窗可合并；长立面开间数最多减 30% |
| 窗框、竖梃 | 0.12–0.2 m（真实约 2.5 倍）；幕墙竖梃隔一根取一根 |
| 窗洞进深 | 0.25–0.4 m，形成清楚的影边；玻璃退进 20–30 mm |
| 窗台、雨篷厚度 | 0.15–0.3 m；窗台挑出 40–60 mm，带滴水 |
| 檐口、女儿墙压顶 | 高 0.5–0.8 m，挑出 0.3–0.6 m |
| 栏杆 | 高度不放大，最高 1.2 m，否则楼会显小；扶手 0.08–0.15 m；阳台优先实心栏板，通透处立杆间距 0.25–0.3 m |
| 台阶 | 近景保留真实踏步 0.15 × 0.30 m；远级可 2–3 级并 1 级，总高不变 |
| 门 | 高度不放大；门套和雨篷加厚 1.5 倍 |
| 倒角 | 主墙阳角 R 25–40 mm，压顶外沿可到 0.15 m；压顶、窗台、台阶前缘、路缘 R 10–20 mm；窗框、栏杆、把手 2–5 mm（只在 L0+）；小道具 3–10 mm；阴角不倒 |
| 屋顶起伏 | 平屋顶每 20–30 m 至少一处 1–3 m 高差（楼梯间、水箱、设备、构架）；天际线高差 ≥ 楼高的 10% |

- **重复上限**：同一开间连续不超过 3–4 次，之后插入变化：楼梯间窗、柱、色板、机位、亮灯或拉帘状态。
- **防摩尔纹**：周期性元素（窗格、百叶、立杆）在所在级别里一个周期不到 4 px 就改画色块。
- **人体尺度锚点不放大**：门、栏杆、踏步、座面按真实值，它们让人感到真实尺度，其余构件可以敦实一些。
- 本节的比例、重复上限、防摩尔纹和锚点对所有精度区都成立（B1、B10）。
- **室内**（WLD-INTERIORS-BUILD §5）：可走路线上的单扇门洞 1.1 m、净宽 ≥ 1.0 m；走廊按真实宽度，放宽了楼会显空；楼梯按真实踏步，踏步与扶手是锚点。

## 3 植被与地表

- **树冠**：轮廓曲直搭配，留出缺口；云团画法与法线见 WLD-VEGETATION §1.1、§1.2。
- **不让树长得一模一样**：每种至少 4 个母模型（幼、成、老，对称与偏冠）；每株缩放范围见 `game/gen/vegetation/TreePlacement.cs`、绕竖轴随机转、倾斜 ≤ 3°，随机量由稳定 ID 的带种子哈希算出（G4 禁用 `System.Random`）；世界坐标低频噪声给色相 ±4–8°、明度约 6% 的偏移，相邻的树颜色接近；留 5–10% 的离群个体（秋季偏绿、全黄、半落叶的几棵）。
- **四季不换模型**（INV-8）：靠插片缩放、换枝条笔触、换季相色（ART-COLORSCRIPT §2），所以落叶树的母模型从一开始就带可信的枝序，叶量为 0 时剪影仍成立。
- **绿篱和灌木**：圆角盒或馒头形，倒角半径取高度的 20–30%，顶面比侧面亮一阶。
- **草坪、水面与铺装**：草坪平涂加 5–15 m 的低频色斑，远处变浅、偏黄绿，颜色与长影见 WLD-VEGETATION §3，近景草叶见 ART-FIDELITY-DETAIL §2；水面画法见 WLD-WATER §1；铺装的程序缝与远近取舍见 ART-MODELING §1.8 地面与路缘一行、ART-STYLE-SHADING §4.2。

## 4 道具与小物件

"少、粗、圆、干净"对所有精度区都成立；每类的最低合格构件见 ART-MODELING §1.8。

- **少**：3–5 个主部件，大中小面积比约 70 : 20 : 10；螺栓、胶条、检修门是 L0+ 变体，只在 K1、K2 摆放时启用。
- **粗**：杆件最小截面 0.08–0.12 m（室内家具 0.035–0.05 m）；路灯杆 0.2–0.28 m，灯头放大 1.3–1.5 倍；道具整体放大 1.1–1.25 倍，座面和扶手不放大。
- **圆**：倒角取最小截面的 10–20%，杆件端头加圆帽，不留 90° 尖角；小件的几何倒角可以只放 L0+，L0 由凸边亮线代替（ART-STYLE-LINES §1.7）；圆件用平滑或解析法线。
- **典型件**：一排自行车做成一个单元，轮圈 0.08–0.1 m，车架并成 2–3 根粗杆；长椅板条不超过 3–4 条；垃圾箱是圆角盒，箱口一圈色带。
- **干净**：固有色不超过 3 种、主色 ≥ 70%；30 m 外不出现小于 4 px 的高对比碎件；删掉杂乱管线、临时围挡、刺眼广告、成片指示牌；软物用两阶半宽过渡（ART-STYLE-SHADING §1.1）；状态全新（INV-11）。
- **密度**：生活痕迹成簇，簇外留白；室内填满的格架只用在焦点区（WLD-INTERIORS-BUILD §4）。

## 5 颜色

- 固有色以真实为参考，按画面需要只提高饱和度和明度对比；大面积低饱和，小面积点缀饱和色。
- **明度与彩度上限只约束固有色**：大面积（墙、地、屋面）OKLCH C ≤ 0.05，墙面 L 宜 ≥ 0.80（深色材质除外），跳色 C 0.12–0.19。受光色和光造成的颜色（室内光斑、春夏草坪、秋叶）不受这条限制。
- 同类楼的墙色目测是同一家族；区分楼群靠大块墙色，不靠单栋楼里随机换色。
- 颜色只从调色板登记处取，几何只带色名（ART-STYLE §2.5，G4）；建模包只登记固有色，各时季格由色彩脚本推导（ART-STYLE §2.3），不为某个季节或时刻单独调色。

## 6 让 20 多个建模者风格一致

1. **金样只留 3 个**（D-168）：与主线并行做，其余包不等它们，所有区同时按预设做细节：石材科研楼一栋（六号科研楼为原型）；宿舍一栋（学知苑六组团为原型）加旁边一栋翻新对照楼（本科 A 型，MAP-QSH-RENOVATION §1.5），同评；树组（一株插片型银杏、一株云团型樱花或桂花，加灌木球）。评审是作者看固定机位截图挑毛病，默认状态和冬夜各看一眼（截图方式见 ENG-GATES-SHOTS §1），区与区之间没有先后门。
2. **每个金样附一页参考板**：实景照片、身份特征清单、金样截图；其余地标不做。
3. **参数化部件库是唯一入口**：檐口分 S、M、L 三档（0.3、0.6、1.0 m）；倒角、栏杆、台阶、屋顶设备都从部件库取；区域代码不写几何常量（G4）。部件按语义级别（L0+–L4，ENG-BUDGET-LOD §1）给几何，L0 必须有实体厚度和倒角并具备最低合格构件；碰撞由同一组参数生成。写法以 `game/gen/parts/` 和契约 `IPartDef` 为准。
4. **统一的全局常量**：倒角表、最小像素规则、重复上限、描线类别、修边条截面库、最低合格构件表，都放在部件库内核里（game/gen/parts/core/）。
5. **共同口号："走进剧场版动画的校园，清透、敦实、干净、有生活。"** 拿不准风格取舍时回到这句话。
6. **审查**：
   - 自动查：颜色已登记、最小尺寸、开间重复、倒角、最低合格构件、面数；
   - 人工查：与金样并排；默认状态下 3 秒内认出是哪栋楼；翻新楼另按 WLD-RENOVATION §7。
