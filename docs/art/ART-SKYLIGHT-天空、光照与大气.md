# ART-SKYLIGHT · 天空、光照与大气

> **范围**：本文规定默认状态的光与太阳、主光与阴影、天光、受光退场、人造光、全局光效和冷暖对照的观感与取值；天空、月亮、雾与大气透视在子文档 ART-SKYLIGHT-ATMOSPHERE。24 小时 × 四季 × 天气的每种组合都要好看，切换自然过渡，视觉优先，真实情况只作参考。文中数值是默认状态（秋 17:30，晴）的参考值，其他格来自关键帧。
> **不在本文**：天空、云星、月亮、雾与大气透视（ART-SKYLIGHT-ATMOSPHERE）；日月的轨迹、世界状态、默认状态、色彩脚本与关键帧（SYS-TIME）；天气清单、每种天气的画面规则与自动天气（SYS-WEATHER）；远山和城市剪影（WLD-OUTSKIRTS-DIORAMA）；水面反光的着色（WLD-WATER）；动态节奏（SYS-MOTION）；季节植被与粒子（ART-COLORSCRIPT §2）；阴影配置与性能做法（ENG-PERF-LIGHT §2）。
> **查阅**：先读 §0；默认状态的光与太阳看 §1–§2；主光、阴影、天光、受光退场与灯光看 §3；光效清单与冷暖对照看 §4–§5；天空、月亮、雾看 ART-SKYLIGHT-ATMOSPHERE

## 0 结论

1. **视觉优先**：提亮靠浅影和有形状的光，不靠整体加曝光，明度目标见 §3.3。
2. **默认状态的太阳**是秋 17:30 的低太阳，高度与方位的设计目标在 §1，轨迹见 SYS-TIME §2；影朝东北偏东，长影是画面的主角（§1）。
3. **只有一盏方向光**：太阳和月亮轮流担任主光；颜色和强度只经调色板与全局参数进材质；交界的硬靠 toon 对阴影阈值化（§3.1）。
4. **日月交接**在无影蓝调里、`shadow_strength` = 0 的那一帧转向（§3.1）。
5. **天光不放灯**：影色随天光偏色已算进调色板和 toon 的连续项（§3.2）。
6. **受光退场**按地面 → 低层 → 高层与树冠顶 → 宣邦楼穹顶，日出反向（§3.4）。
7. **光效与冷暖**：12 项光效都画成看得见的形状，光柱与镜头光斑属风格默认，单项开关在主线之后（SYS-GRAPHICS §3）；默认状态六组冷暖对照都要成立，其他时段至少两组（§4、§5）。
8. **天空与雾**：天空全写在一个 sky shader 里，所有材质用同一个共用雾函数，见 ART-SKYLIGHT-ATMOSPHERE。

### 0.1 接入要点

- **着色器要用光照或世界状态的量**：只读全局着色器参数和全局纹理（ENG-PERF §1.5），运行时不切阴影特化开关和 Environment 的 `*Enabled`（§3.1）
- **写卡通材质**：开 `ambient_light_disabled`，主光颜色强度从调色板与全局参数取，不读灯的颜色属性；不放第二盏方向光（§3.1）
- **新增灯具或灯随时间亮灭**：接灯光通道，曲线写进本图灯光时刻表（ART-COLORSCRIPT §3）；灯不建真实点光（§3.5）
- **地标要最后暗下**：在该实例上设 instance uniform 偏置（§3.4）
- **水面反光、湿面倒影**：取主光的方向和颜色，阴雨天关掉；夜里读共用灯条表（§4）
- **天气要改主光或光效**：只经天气向量的全局参数修正输入，色值修正叠进调色板，不改灯的属性（SYS-WEATHER §6）
- **写室外可见的材质、天空里加东西、介质与边缘雾**：见 ART-SKYLIGHT-ATMOSPHERE 的接入要点

## 1 默认状态的光

默认状态是秋 17:30、晴（SYS-TIME §1.1）。太阳在这一刻必须是 5.5°、241°，误差不超过 1°。

- 影子朝东北偏东。
- **影长**≈ 物高 ÷ tan(高度)：5.5° 时约为物高的 10 倍。夏季正午影子短而浓，冬季正午仍有斜长的蓝影。
- **黄昏**：17:22–17:40 太阳高度约从 6.9° 降到 3.7°，方位走过约 4°。西南偏西远山脊仰角约 1°–2°，秋季太阳约 17:50–17:57 落到山后（待核对，§6）。

## 2 太阳本体与主光色

- 低悬时是一枚可以直视的橙红圆盘：默认状态它挂在西南偏西的远山脊线上方，17:22 时约 9 个日面高，17:40 前后约 3–4 个日面高；日面可放大。
- 高太阳时日盘是白金色，被柔光晕开。阴、雨天藏在云后；雾天隔雾可见，是一枚淡白的圆，不出光斑。
- **西岭雪山**：夏季日落故意压在西岭雪山的剪影上（日落方位约 272°，大雪塘的方位）。默认状态（秋）的太阳不在西岭雪山上方——大雪塘比它偏北约 31°，贡嘎几乎同向但仰角约 0.8°、淹没在霾和眩光里不画。"悬在西岭雪山剪影上方"在夏季日落成立，在默认状态不成立，不作为否决项。
- **主光色 `sun.light`**（色值以调色板为准）：白天和黄昏是日光，夜间是月光，无影蓝调里是不投影的天光。受光面统一用当前格的主光色推导（ART-STYLE §2.3）。

## 3 光照骨架

### 3.1 主光

只有一个方向光，**太阳或月亮二选一**。它决定明暗分阶的交界（ART-STYLE-SHADING §1.1）和投影；投影覆盖整个校区（距离按画面预设，SYS-GRAPHICS §1）；影子边缘清楚，尾端变软。无论谁当主光，都用同一套明暗分阶。

- **实现原则**：场景里只有一盏方向光；阴影用引擎原生级联；阴影方向钳制、室内抬高、月影与强度的取值以本节为准，预设档、方向量化与引擎做法见 ENG-PERF-LIGHT §2.1 和 `game/kernel/lighting/ShadowSettings.cs`；会改特化常量的阴影开关运行时一律不动。要的是干脆的影边。
- **无影蓝调与日月交接**：太阳高度从 −2° 降到 −7° 是"无影蓝调"，全局 `shadow_strength` = 0。在这段里任选一帧，把主光转到月亮方向；**转向的那一帧 `shadow_strength` 必须是 0**，快速拖动时一帧跨过整段蓝调也在这一帧转向并按 0 处理。黎明按相反顺序。这样影子不会在某个钟点突然从另一个方向冒出来。
- **月影**：太阳从 −7° 降到 −12° 时月影淡入到最深 0.45，比日影浅；月亮低于 15° 时为 0，15°–20° 之间淡入。
- **强度**：太阳作主光时强度随高度从 −2° 到 4° 平滑升起，0° 时仍有约四分之一，所以日出日落的受光面看得见颜色；月光要太阳落到 −7° 以下才有，月亮自身低于 −2° 时为 0，强度取关键帧。
- **阴影方向钳制**：阴影方向的高度不低于 4°；日盘可以继续下落，两者最多差 4°，看不出来。日月盘按真实方向画，不受钳制（ART-SKYLIGHT-ATMOSPHERE §1.9）。
- **室内阴影抬高**：镜头在开放室内（介质为 Interior）时，阴影方向最低高度从 4° 抬到约 14°（待验证，§6），0.5 s 过渡、出楼还原。目的是让 17:30 普通窗的光斑也能落到地板上（否则主要爬在后墙上）；代价是从窗里看出去的室外影子变短。
- **天气**（SYS-WEATHER §6）：阴、雨、雪时明暗改按"天光方向"（主光方位、仰角 55°）判定，顶面和朝主光一侧受光，其余在影里，阶数不变；投影乘 (1 − 0.8 × 阴度)，白天不低于 0.2，两阶不丢。阴天主光降一档、大雨再降、雷雨时主光大减，这些是调色板的天气修正，不改灯的属性。主光一直在，不关。
- **画面设置**：阴影质量与距离按预设取值，实时阴影不能关（SYS-GRAPHICS §2、§3）。

### 3.2 天光（环境光）

天光不放灯，不产生第二套影子。它在画面上只有两个作用：中性材质的影色随天光偏色（有彩材质的影只向它小转角）；影里随法线 y 的细微渐变，以及朝下面的地面暖反光（ART-STYLE-SHADING §2）。天光色白天天青、黄昏淡紫、阴天珍珠粉紫、夜间蓝紫。卡通材质不读环境光（开 `ambient_light_disabled`，Environment 的环境光与反射源设为非 Sky）。

### 3.3 受光分布

- **默认状态（太阳 5.5°）**：地面大半落在楼影和树影里；受光的只有开阔草坪、湖面、西立面、楼的上半截和树冠顶部。这正好表现"白昼一层层退上楼顶"。保留这个构图，是因为它好看，而不是因为它真实。大面积的影要保住材质身份色，浅色面的影保持浅（ART-STYLE-SHADING §2.2）。
- **这一条只在低太阳时成立**：日出方向相反，东立面和宣邦楼穹顶先受光。高太阳时地面大半受光，画面靠树荫光斑、窗洞的真实投影、移动的云影和物体分界线撑起层次（ART-COLORSCRIPT §1.4）。夜间受光的是月光照到的大面和灯下的光斑。
- **明度目标**：默认格 L 中位数约 0.6；白天格（晴）约 0.7。提亮靠浅影、清透的后期和浅色墙面，不靠整体加曝光。
- **阴、雨天**：屋顶、树冠顶和朝主光一侧受光，墙面多在影里，分阶和剪影保住。投影很淡，层次由"云洞光斑"（缓慢扫过地面的一块受光区）、白天窗灯、物体分界线和顶光两阶撑起；正午阴天、正午雨不能发平。

### 3.4 受光退场的顺序

地面 → 低层 → 高层与树冠顶 → 宣邦楼钟楼顶的"电子管"穹顶；穹顶永远最后一个暗下（SYS-MOTION-ENV §4）。日出时反向，穹顶最先受光。

太阳高度从约 2.5° 降到 0.3° 时，一条全局"退光线"把受光区域的下限从地下升到约 80 m，带软边；穹顶实例另加偏置，保证它最后暗下。

### 3.5 人造光

各通道全天的亮灭曲线按 ART-COLORSCRIPT §3 的灯光时刻表（按图存放），亮灭按哈希可复现。阴雨天按有效太阳高度让灯提前亮，雷雨更早。灯不建真实点光；路灯光斑读离线烘出的灯光表，光晕和光锥各用一个 MultiMesh（ENG-PERF-LIGHT §2.3）。

| 光源 | 颜色与说明 |
| --- | --- |
| 窗灯 | 约六成暖白（`window.warm`）、三成冷白（`window.cool`）、一成不亮，带光晕（ART-STYLE-LINES §2.5）；默认状态黄昏的亮灯比例见 ART-COLORSCRIPT §3 |
| 图书馆檐口灯带与采光顶 | 暖黄，天暗后常亮，由内向外透出；白天采光顶只映天光 |
| 路灯 | 暖色，地面投出一圈圈暖色光斑；初灯组先亮，让霞光和灯光同框，机制与默认状态的比例见 ART-COLORSCRIPT §3；冬季夜间光斑放大 |
| 球场灯、门厅灯、店招 | 球场灯冷白；门厅灯暖色，有名字的楼宇入口都有（SYS-VIEW §4）；店招各店颜色 |

**路灯光斑的画法**（`lamp_pool_shade`，参数见 ENG-PERF-LIGHT §2.3）：

- 灯光按底色相乘着色，只沿灯色把底色抬亮，不覆盖底色：草地在光斑里仍是绿，铺装是暖一点的浅色，不能像刷了一层饱和的黄漆；
- 强度随环境变暗升起：黄昏弱、入夜强，读调色板的暗度，不自己计时；
- 分两级：亮芯加一圈收边的外圈，台阶边界干净，符合三渲二的分阶；
- 立面上的光斑（4 m 以下）画成扇贝形：灯下最亮，往下变宽变暗，上沿是一道弧；朝下的面不画光斑；曲面渐变过渡，不出折面；
- 灯具类部件的灯罩自发光跟随它的灯光通道；新增的灯具类部件一律登记进灯表，不借窗灯类通道。

## 4 光效清单

每一项都要画成看得见的形状，不能只是"调亮一点"。触发条件用太阳高度 h：低太阳指 h < 12°，白天指 h > 0°，夜间指太阳低于 −7°。条件之间平滑过渡，不得硬切。光斑和光柱是"风格默认"，主线一直开着；单项开关在画面设置推迟到主线之后（SYS-GRAPHICS §3）。

1. **楼影**：朝东北偏东拉得极长，边缘清楚，尾端发软。白天；低太阳最长，高太阳短而浓并叠移动的云影；日出时朝西拉长。夜间替代：月影；无影蓝调没有影子。
2. **西立面玻璃**：画法见 ART-STYLE-SHADING §3.1。低太阳时只出现在正对太阳的立面（默认西立面，清晨东立面）；高太阳只留斜条，玻璃映天蓝。夜间替代：亮窗和窗灯光晕。
3. **西湖碎金带**：落日正下方一条断续的竖向反光带，从西边逆光看最明显；画法见 WLD-WATER §2.1，高太阳时变弱。夜间替代：月光银带，以及岸边亮窗和路灯在水面的竖向倒影。
4. **树冠逆光**：树冠被背光照透，镶一圈暖边，叶片薄的银杏最亮；透光色随季节（秋金、春新绿、夏浓绿）；冬季裸枝不透光，改为枝头积雪的一线亮边。夜间替代：路灯从下方照亮的树冠底面。
5. **光柱**：从树冠缝和楼缝斜穿下来的软边光柱，近窗处偏白，远处变成主光的高彩色，里面漂着暖白细尘。太阳高度 2°–30°；清晨有贴地雾时最强；高太阳不画，改为树荫光斑。用加法透明体，不用体积雾；**镜头前 1.2 → 5.5 m 线性淡入，视线与光柱轴夹角小时再衰减**——17:30 的光柱接近水平、正好在人眼高度，没有这两条，行走时一穿过光柱就满屏发白；每屏不超过 8 根。夜间替代：路灯光锥；冬季下雪时光锥里的雪花被照亮。
6. **镜头光斑**：白天和黄昏镜头转向太阳时出现（画法与月亮不出光斑见 ART-STYLE-LINES §2.3）。
7. **窗灯和路灯**：按 §3.5 的比例和颜色，带光晕；白天窗灯接近 0；夜间是主角之一，路灯在地面投出平涂的暖色光斑。
8. **图书馆**：采光顶的网格里透出暖黄光，檐口灯带亮着；天暗以后亮起，22:30 后一层层熄灭（ART-COLORSCRIPT §3）。
9. **室内光条**：图书馆转角的竖缝窗把落日切成细长的金色光条，斜铺在回廊地面上（MAP-QSH-INTERIORS-LIBRARY §5）。其他开放室内的窗格光斑与光柱同理，室内用暖影，把画面"灌满光"。只在太阳照到竖缝窗时出现（上午东侧、下午西侧）；夜间没有。
10. **远处云内闪**：只在雷雨时出现（ART-SKYLIGHT-ATMOSPHERE §1.7）。
11. **彩虹**：只在雨后初晴（含太阳雨后半段）、太阳高度 2°–40° 时出现（ART-SKYLIGHT-ATMOSPHERE §1.7）。
12. **太阳雨**：画面与条件见 SYS-WEATHER §2；这里的要求是光柱在太阳雨里照画，雨丝被染成暖金。

**天气下的光效**：眩光、光斑、光柱、光条随阴度和雾淡出（阴、雨、雾天没有眩光和光斑，玻璃映当前天色，斜条照旧）；阴天只在云盖亮缝下画云缝光柱，雨中的白天不画光柱（太阳雨例外），雾天光柱加强；主光反光带在阴雨天关掉，湖面映天色；夜雨时湿路面和积水拉出灯的竖条（共用灯条表）；灯按有效太阳高度提前亮；雨后初晴的低太阳下眩光和光条照常出现，叶缘有水珠高光。

## 5 冷暖对照

**默认状态（秋 17:30）**：六组对照在画面上都要成立：

1. 西天的金 ↔ 东天的蓝紫。
2. 受光墙面的杏色 ↔ 影里的淡紫灰（影浅而透）。
3. 湖面的碎金带 ↔ 湖水的蓝。
4. 室内灯光 ↔ 窗外暮色。
5. 西边的落日 ↔ 东边的满月。
6. 室内的暖影和光柱 ↔ 窗外的冷天光。

整体比喻是"一座正在交班的钟"：白昼从地面一层层退上楼顶，月亮从东边进门，灯光在室内一盏盏接手；清晨反过来。

**其他时段**：每个时段至少要有两组冷暖对照成立：

| 时段 | 对照 |
| --- | --- |
| 正午 | 受光路面和墙面的暖白 ↔ 树荫、檐下的浅青灰影；白色积云 ↔ 深蓝天顶 |
| 夜间 | 窗灯的暖白 ↔ 月光的冷蓝；路灯光斑的暖黄 ↔ 月影和暗部的蓝紫；地平线城市天光的暖紫 ↔ 天顶的深蓝；冬季暖灯 ↔ 蓝色的雪 |
| 阴、雨 | 白天的暖窗灯 ↔ 珍珠粉紫的天；夜雨里湿路面上灯的暖竖条 ↔ 暖紫夜空下偏冷的湿面；鲜绿（秋为金）的湿树冠 ↔ 灰紫的云盖 |
| 雾、雨后初晴 | 雾晨里露出雾面受光的穹顶的暖 ↔ 乳白偏紫的雾海；雨后积水里的晚霞或蓝天 ↔ 湿路面的深色；彩虹下洗过的蓝天 ↔ 受光墙面的暖白 |

每季抽一张英雄帧（ART-COLORSCRIPT §1.5）看这些冷暖对照。
