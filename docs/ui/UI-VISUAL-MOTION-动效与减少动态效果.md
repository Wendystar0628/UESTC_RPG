# UI-VISUAL-MOTION · 界面动效与减少动态效果

> **范围**：界面动效的原则、八个母题（M1–M8）、频率分级与声音、曲线时长与上限，以及"减少动态效果"下每个母题的替代和无障碍。
> **不在本文**：设计原则、令牌与主题、实现边界（UI-VISUAL）；组件外观、形状与图标（UI-VISUAL-COMPONENTS）；场景里的动态与事件（SYS-MOTION）；开关的位置与默认值（UI-NAV §3.5）。
> **查阅**：先读 §0；动效原则、母题与上限看 §1；减少动态效果与无障碍看 §2

## 0 结论

1. **静止即安静**：没有输入、没有状态变化时，界面上没有任何会动的东西；动效只回应操作或状态变化，缓出、可打断、不回弹（§1.1）。
2. **八个母题 M1–M8 按频率分级**：高频只用色调变化、线变实和 M5，低频才编排组合；声音用同一套分级（§1.2、§1.3）。
3. **上限**：辉光只在深屏的线、点、细环上，同屏最多 3 处；同一区域亮度变化 ≥ 10% 每秒最多 1 次；没有常驻循环动画（§1.4）。
4. **减少动态效果**：每个母题都有替代，所有组件经 `MotionPolicy` 取时长，组件里不写判断；昼夜交班直接换（§2.1）。
5. **无障碍**：降低透明度打开后面板 100% 不透明，界面主题可锁定（§2.2）。

### 0.1 接入要点

- **界面动效**：只用 M1–M8 八个母题；时长经 `MotionPolicy` 取；3D 侧的过渡读 `IMotionSettings`（§1、§2）
- **新增界面动效**：必须同时写出"减少动态效果"下的替代，不做循环动画和回弹（§1.4、§2.1）

## 1 动效语言

### 1.1 原则与两种时间

1. **静止即安静**：没有输入、没有状态变化时，界面上没有任何会动的东西（3D 画面除外）。
2. **方向有因果**：揭示和流光从触发源出发（被点的按钮、小地图所在的角、时间环上的太阳），退场朝来处收回。
3. **入场从容、退场利落、可打断**：退场约为入场的 0.6–0.7 倍，不交错；动效进行中接受新输入，跟随类用弹簧保持速度连续，脚本类从当前值重新定目标。

**两种时间**：位移、透明度、颜色、数值按显示帧率连续补间；"被计算出来的东西"（抖动阶、网格点亮阶、图标换帧、示波器相位）按全局 `step_rate` 步进，和场景里的落叶在同一帧换姿态（SYS-MOTION §2.2）。

### 1.2 八个母题

| 母题 | 样子 | 用在 | 条件 |
| --- | --- | --- | --- |
| M1 走线流光 | 沿已有的发丝线跑过一段短亮光 | 面板第一次展开；传送前沿路线；存档成功沿卡边；设置"应用"完成 | 只沿已有的线，只跑一次，不用于悬停 |
| M2 扫描揭示 | 一道前沿一次扫过整页，不留痕 | 只给大页和昼夜交班 | 同一页一次会话里不重复 |
| M3 网格逐格点亮 | 网格按到起点的距离错开点亮，落定为内容后网格线消失 | 开始页标题背后；大地图底图；存档缩略图拼出 | 整个波约 0.4 s；对齐 8 px 网格 |
| M4 数值滚动 | 变了的那一位像里程表竖向滚一格 | 钟点、速度、倒计时 | 没有随机字符；数字等宽 |
| M5 衍射边 | 焦点环收紧 | 只给键盘焦点 | 不给悬停，不循环 |
| M6 量化出入场 | 3–4 阶有序抖动从无到有，每阶停一拍 | 图标与缩略图更换、地图钉、标题卡逐字 | 没有色噪和 RGB 偏移；正文不用 |
| M7 示波器 | 一条单线波形，振幅频率对应真实数据 | 只在流逝倍率和降水强度 | 只有一条线；相位按 `step_rate` 推进 |
| M8 呼吸灯 | 一个小过孔透明度正弦往复，周期 2.4 s | 只在"进行中"：快进、换季、换天气、跳转飞行、设置应用、保存、等待 | 不让整块面板呼吸；可能持续超过 5 s 的状态（如高倍率）改用静态标记加 M7（WCAG 2.2.2） |

### 1.3 频率分级与声音

- **高频**（悬停、按下、焦点、切换、拖动）：只用色调变化、线变实、弹簧滑块和 M5，禁止其余母题与任何发光。**中频**（面板开合、临时提示、图标与缩略图更换、数值变化、地图钉）：淡入上移、M4、M6、单次 M1。
- **低频**（开始页、标题卡、打开大地图、传送、存档成功、画面设置应用、昼夜交班）：M1、M2、M3、M6 的组合编排，总长约 1 s，单个元素约 0.4 s；禁止循环、闪白。**状态型**（进行中）：M8，倍率用 M7。
- **声音用同一套分级**（清单以 SYS-AUDIO 为准）：高频、状态型和自动保存无声，中频只有大页开合一声，低频编排各配一个对齐时间线的短音，临时提示不配提示音。

### 1.4 曲线、时长与上限

- **曲线**：脚本化、只播一次、要对齐时间线的用贝塞尔；由连续输入驱动、可能半路改目标的（悬停、拖动后的落定）用临界阻尼弹簧。曲线、弹簧与时长参数以 `ui_metrics.json` 的 `motion` 为准；弹簧阻尼比不低于 0.9，回弹、过冲类过渡一律禁用。
- **交错**：每项错开约 30 ms；退场不交错，且退场开始的同一帧就关掉焦点和鼠标；退场中又被打开，从当前值直接反向入场。
- **辉光与闪烁的上限**：发光只在线、点、细环上，晶白不发外光，深屏同屏最多 3 处、半径与亮度上限以 `ui_metrics.json` 的 `glow` 为准，界面最亮的像素不超过窗灯的亮度。同一区域亮度变化 ≥ 10% 的事件每秒最多 3 次（WCAG 2.3.1）；不做全屏闪白。**没有常驻循环动画**（WCAG 2.2.2）：图标只在悬停或状态变化时动一轮。

## 2 减少动态效果与无障碍

### 2.1 "减少动态效果"下的替代

开关与默认值见 UI-NAV §3.5。所有组件经 `MotionPolicy` 取时长和"是否做空间运动"，组件里不写判断。

- 淡入上移、卡片揭示：只透明度，≤ 200 ms。M1：终点直接亮 120 ms 后淡回。M2、M3：整页或整块 200 ms 淡入，不出现网格线。M4 与弹簧：直接换字、直接到位加 100 ms 淡入。M6：150 ms 淡入。
- M5：直接出现（焦点环本身必须保留）。M7：静止波形。M8 与等待灯：静态实心点、三枚静止半亮。
- 昼夜交班：**直接换**，不扫。图标不换帧、无交错。3D 的跳转、换季、换天气、传送：0.5 s 雾幕交叉淡化（UI-NAV-WAYPOINTS §2）。

### 2.2 无障碍

对比度与"不只靠颜色"见 UI-VISUAL §3.5，焦点环见 UI-VISUAL-COMPONENTS §2，闪烁上限见 §1.4。**降低透明度**打开后全部面板 100% 不透明、关闭磨砂；**界面主题锁定**，畏光的观者可以固定深屏。读屏与键盘规则见 UI-NAV §5。
