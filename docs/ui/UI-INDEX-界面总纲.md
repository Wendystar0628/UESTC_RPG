# UI-INDEX · 界面总纲

> **范围**：本文是界面域的入口：本域管界面有什么、怎么操作，以及长什么样；列出本域通用的原则和本域全部文档的上下级。
> **不在本文**：各主题的规则与设计（在下面列出的文档里）；全项目的核心准则与信息地图（CORE-INDEX）。
> **查阅**：先读 §0；要找文档看 §1，按标题挑要读的那份，再读它的 §0 与接入要点

## 0 结论

1. **内容与外观分开**：有什么、怎么操作看 UI-NAV，长什么样看 UI-VISUAL。
2. **3D 画面里不叠标签**：允许的界面以本域登记的为准（INV-3）。
3. **颜色与文字只经登记**：界面色名只来自 `ui.json`，代码和文档不写十六进制色值（G4）；界面文字写稳定键，地名只从来源查，不手写（UI-NAV §5）。
4. **默认画面是漫游态**：常驻件越少越好，哪些件常驻以 UI-NAV §2 为准，别处只指向它。
5. **每个界面件都守无障碍底线**：状态不只靠颜色，键盘可达，动效有"减少动态效果"下的替代（UI-VISUAL §3.5、UI-VISUAL-MOTION §2、UI-NAV §5）。
6. **"主线之后"**：标题或节末带这四个字的件和选项现在不施工，含义见 STD-DOC §2。

### 0.1 接入要点

- **加一个界面件**：先在 UI-NAV 登记，再在 UI-VISUAL 定外观。
- **在本域新增文档**：主题文档文件头写 `parent: UI-INDEX`，在 §1 加一行；子文档写 `parent: <主题文档编码>`，列进主题文档的 §0 和本总纲 §1 那个主题下（STD-DOC §5.1、§7）。

## 1 文档树

主题文档在前，缩进的是它的子文档；只列编码与标题。

- UI-NAV 界面与操作说明
  - UI-NAV-WAYPOINTS 点位、跳转与传送
