# UI-VISUAL · 界面视觉语言：令牌、字体、形状、材质、图标、组件、画面布局与动效

> **范围**：界面的外观规范：色彩、主题、字体、形状材质、图标、组件、画面布局、动效。主题是信息、芯片、光与计算，主色清蓝 #73C9F9，专业克制；界面、图标和锚点里不用银杏。
> **不在本文**：界面有什么、怎么操作见 UI-NAV；地图与传送卡见 SYS-ATLAS；开始页与过场见 SYS-TITLE；提示音见 SYS-AUDIO；额度见 ENG-BUDGET；门禁判据见 ENG-GATES G14。
> **查阅**：先读 §0，再按节号查。

## 0 结论

1. **一句话**：界面是叠在暖色手绘世界上的一层冷光精密仪器；**光是信号，不是装饰**。静止时只有平面、1 物理像素的发丝线和等宽数字，状态变了、确认了、正在进行才出现光和运动（§1）。
2. **主色清蓝 #73C9F9，场景暖、界面冷**：清蓝只在界面层，不进 3D 材质，世界里不放蓝色全息；深端 800、900 取校色，只作小面积；界面唯一的暖色点是窗灯色 #FFE0A8，只表示"太阳 / 此刻"（§2、§3）。
3. **两套主题**：白天"晶白"、夜间"深屏"，按真实太阳高度带回差离散切换，一道扫描前沿 0.6 s 扫过，不做连续混色；**常驻小部件固定用深屏**（§2.3、§3.4）。
4. **形状**：每个容器只切左上一个 45° 角；边线一律 1 物理像素；过孔灯表示状态，走线只表示连接，衍射光边只给键盘焦点和选中项（§5）。
5. **动效**：八个母题按频率分级；辉光只在深屏上；每个母题都有"减少动态效果"的替代（§9、§10）。

### 0.1 接入要点

- **取色**：只用 `game/style/palette/ext/ui.json` 里的色名，经 `UiPalette` 读；代码和着色器里不写十六进制色值（G4）；缺色名由 WP-35 登记（§3.6）
- **画面板、按钮、文字**：用 `UiThemeBuilder` 生成的那一个 Theme，不写零散的 `theme_override_*`；随主题变的颜色走 `ui_panel` 着色器按 `ui_night` 取值；界面着色器只用白名单里的 `ui_panel` 与 `ui_screen`（§11）
- **界面动效**：只用 M1–M8 八个母题；时长经 `MotionPolicy` 取；3D 侧读 `IMotionSettings`（§9、§10）
- **字体与图标**：字体整包不改，回退链显式指定 SC；图标自绘单色 SVG，登记进 `manifest.json`（§4、§6）

## 1 设计原则

- **只取结构，不取材质**：分层、编号、刻度、45° 走线、1 号脚切角、过孔、薄膜衍射是结构；彩色裸片、绿色电路板、CRT、全息箔一用就廉价。

**七条硬规则**：

1. **细线**：边线一律 1 物理像素，2 px 只给选中指示条。
2. **网格**：8 px 基准，所有元素对齐，界面与地图上都不画网格线；数字右对齐、等宽。
3. **留白**：面板内边距 ≥ 16 px；一张卡片一个主操作，每屏最多一个主按钮。
4. **单色加一点**：清蓝阶梯加冷灰加墨；暖色只表示"太阳 / 此刻"，一屏最多一处。
5. **光是状态**：闲置界面零发光；只有焦点、选中、"此处"、进行中会亮。
6. **数据要真**：界面上的每个数字都来自世界状态、存档或画面设置，不放装饰性数字。
7. **动有因、动有终**：动效只回应操作或状态变化；缓出、可打断、不回弹；揭示类效果每次打开只播一次。

**一律不做**：霓虹发光字、满屏辉光、赛博朋克配色、数字雨；常驻扫描线、CRT 弯曲、故障艺术、RGB 错位；四角全切或八角的厚 HUD 框、角括号、满铺电路纹；透视倾斜的面板、循环脉冲、待机呼吸、回弹与过冲；科幻字体、超粗正文；3D 世界里的蓝色全息标记、光柱信标、选中描边。

## 2 色彩分工与常驻件

### 2.1 场景暖，界面冷

场景本是暖对冷的冷暖对照（ART-SKYLIGHT §8），清蓝界面站进"冷的那一半"就不是外来物；唯一的暖色点取窗灯色。

- **界面色 `ui.*`** 只在界面层（放映层 9、界面 10、署名 11），不进 3D 材质、调色板纹理、光照和后期；
- **深端校色**（800、900）只用于字、1 px 线、小图标，单块面积不超过屏幕的 0.5%。
- **暖色点** `ui.now` = `window.warm`：时间环上的太阳把手、推荐时刻的小点。**语义色**只在对话框、提示和数值警示里，总配图标和文字。
- **再现场景的画**（缩略图、存档截图、时间环的天色光谱、地图绿地）可以带场景色，光谱彩度压到 70%；季节花色和银杏金不进控件。常驻 HUD 里清蓝像素不超过全屏的 2%（大页除外）。

### 2.2 与场景色不冲突的规则

1. **清蓝不直接贴在天上**（与天蓝太接近）：只出现在面板底上，或带 1 px 深色描边；小地图、锚点、光标都先有一层底。
2. **清蓝不当晶白主题的正文字色**（对比只有 1.75:1）：晶白里蓝字用 800 档，线与图形用 700 档，300–500 档只作填色、上面压墨字；深屏反过来，300–400 档是字和线。
3. **界面不吃场景后期**：暗角、分调、LUT 都在界面之前完成，`hdr_2d` 保持关。

### 2.3 高调画面上的面板与常驻件

晶白面板对清透高调的画面明度对比只有 1.05–1.16，会"化"进去，所以：

- **常驻小部件固定用深屏**（对画面明度对比 8–14:1）：小地图、时间卡、临时提示、到达标题推荐小条、速度条与观察模式、天气签条、右上图标钮（清单以 `ui_metrics.json` 的 `themeSwitch.pinnedDark` 为准）。交班时它们不跳变，扫描前沿只扫大页；小地图在深屏框里用夜间配色，读作"芯片版图"。
- **大页与对话框随主题**：大地图、设置卡、存档页、确认对话框，以及从开始页打开的这些页。大地图、存档页、对话框背后有 `scrim`；设置卡不压暗，但贴左整块、有外缘线，晶白下也分得开。
- **晶白的固定规格**：面板外缘一条 1 px 墨色描边 `line.panel`；设置"常驻件：随主题"时，晶白的常驻面板再加一层带蓝墨色的环境影。

## 3 令牌

**色值以 `game/style/palette/ext/ui.json` 为准，非色令牌（尺寸、字号、线宽、时长）以 `game/hud/style/ui_metrics.json` 为准。**色名前缀 `ui.`，阶梯写作 b-400、n-25；对比度按 WCAG 2.2 校验。

### 3.1 清蓝阶梯

以 #73C9F9 为 400 档排 50–950 共 11 档：浅端略偏青，深端渐移到蓝调天空的色相，夜里不显得外来；800 #1961A0、900 #003F8D 直接取校色。400 是主色（主按钮底、开关开、选中滑块、深屏的图形）；800 是晶白的强调字、焦点核、选中指示条，晶白的线与图形用 700；900 只作小面积。

### 3.2 中性、专用与语义色

- **中性与专用色**：中性是带一点蓝的冷灰阶梯。`ui.ink` 是晶白正文、标题与投影色（带蓝的墨，ART-STYLE 的"禁止纯黑"延伸到界面）；`ui.screen` 是**深屏面板底**；`ui.nighttext` 是深屏正文；`ui.iris.a / b` 是衍射光边两侧的冷色色散（偏青、偏紫），不出现暖色。
- **语义色**：成功（绿）、警告（琥珀）、危险（红），各有晶白字、深屏字和按钮实底三个值；危险按钮永远不是默认焦点。

### 3.3 两套主题的语义令牌

控件按语义令牌取色，不直接写阶梯名：`surface.*`、`text.*`、`line.*`、`primary.*`、`graphic`、`glow`、`scrim`、`shadow.float`、`over.title`；晶白与深屏各一份取值，在 `ui.json` 的 `themes`。

- 深屏的 `glow` 是 b-400 的细光，晶白无；`over.title`（直接压在画面上的标题）不随主题：白字加暗投影加背后 55% 的椭圆暗带。

### 3.4 昼夜切换

**不做连续混色**：面板底和字色同时线性混合时，对比度在中点塌到 1.0:1，1× 流逝下约 25 分钟读不清。

- **信号与回差**：看真实太阳高度（SYS-TIME §2），阴雨天不提前切；晶白时下穿 −0.5° 切到深屏，深屏时上穿 +0.5° 切回晶白，暂停在阈值附近不来回闪。
- **过渡**：一道扫描前沿 0.6 s 扫过随主题的画面，日落从左向右、日出从右向左（参数以 `ui_metrics.json` 的 `themeSwitch` 为准），每个像素只处于日态或夜态之一。没开大页时看不到交班，只有时间环上的日、月把手互换。快进途中不判断，结束后按终点判一次。
- **设置项**：界面主题"自动（默认）/ 晶白 / 深屏"，锁定时不切换；子项"常驻件：深屏（默认）/ 随主题"。开始页、过场字幕与标题卡、`over.title` 类压在画面上的标题不随主题（"影院处理"，SYS-TITLE）。

### 3.5 对比度规则

文字 ≥ 4.5:1，图形与控件 ≥ 3:1，面板按"最坏背景"算；逐项数值由 G14 自动检测。设计上必须遵守：

- 晶白主按钮填色 b-400 对面板只有 1.75:1，**必须加 1 px b-800 内描边**；暖色点对晶白只有 1.22:1，**必须加 1.5 px 墨描边**（深屏上不描边）。
- 禁用件按 WCAG 豁免，但要有可读的原因并保持可聚焦。**状态从不只靠颜色**：选中同时有底色和指示条或过孔灯，过孔灯有实心和空心之分。

### 3.6 登记

`ui.json` 由 WP-35 登记（ART-STYLE §8.5：界面色不分色号、不进调色板纹理）；`map` 部分是地图的色名 `map.*`，SYS-ATLAS 只引用色名。地图上不用暖色点；玩家、选中、追踪和可传送标记的"通电"状态是地图上唯一出现清蓝的地方。

## 4 字体与字号

- **三套字体**：中文思源黑体 SC，拉丁字母与数字 Inter，编号、坐标、读数、键帽、英文小标签 JetBrains Mono；全部 SIL OFL 1.1。**不改字体文件**：不子集化、不改名，整包打包；不用宋体、书法字和科幻字体。
- **回退链**：Inter 与 JetBrains Mono 都回退思源黑体 SC，且必须显式指定 SC，否则可能落到日文字形（ART-STYLE §9.1、INV-7）；禁用系统回退；会跳动的数字用等宽数字。
- **字号阶梯**以 `ui_metrics.json` 的 `type` 为准：展示字（片名、过场标题卡）用思源黑体 Light 加宽字距，其下依次是到达标题、时间环读数、页标题、组标题、正文、次要说明、数据（等宽）、英文小标签（等宽全大写）。中文下限 14 px，OSM 署名 10–11 px 是例外。

## 5 形状与材质

- **网格与切角（1 号脚）**：8 px 基准，面板之间留 8–16 px 的"切割道"，不画分隔框。容器只切**左上**一个 45° 角，按件的大小分档（大面板最大，主按钮最小；宽度小于 48 px 的件、图标钮、分段、开关、键帽不切），其余三角是小斜角。不做四角全切、八角框、角括号。
- **发丝线**：一切边线都是 **1 物理像素**，任何界面缩放下不变：装饰线 `line.hair`，面板外缘 `line.panel`，控件边 `line.control`（≥ 3:1）。
- **过孔灯**：四态：关（空心环）、开（实心）、警告（琥珀实心）、错误（红实心），用在选中项、"此处"标签、存档卡接点、等待灯。从不单独表达状态，总有实心与空心之分或文字陪着。
- **走线**：45° / 90° 折线，两端各一个过孔，**只用来表达"连接"**（大地图锚点到传送确认卡、设置行到注释栏），不当装饰。
- **衍射光边**（薄膜干涉）**只给键盘焦点和选中项**，悬停和点击都不显示。焦点：控件外侧一圈 1 物理像素的实线核（晶白 b-800、深屏 b-300），核外衬 1 px 面板底色，压在任何背景上都看得见，两侧各一条极淡的冷色色散，收紧到位只一次（M5）；选中：卡片类顶边一条同样色散的线，静止。不循环、不模糊、不出现暖色。
- **面板材质**：默认不透明平涂（不叠纹理、不模糊，外缘 `line.panel`）；对话框、下拉、各类卡片用实底。**轻度磨砂**只给大页，设置项"大页磨砂"独显档默认开、最低配置档默认关；**降低透明度**打开后所有面板 100% 不透明。常驻面板不磨砂（多在移轴虚化带里，背景几乎看不见）。
- **阴影与辉光**：常驻面板默认是深屏，不加影；浮层用带蓝的墨影，不用黑。辉光只在深屏上、线与点与细环上；晶白上的强调用"深一档的蓝加线变实"（上限见 §9.4）。

## 6 图标体系

### 6.1 规格

网格 24、活动区 20；线宽 1.5 px，方头斜接，以 0°、45°、90° 为主，圆只用于过孔、环和云量，实心部分不超过图标面积的 25%；单色，取当前控件的字色。自绘 SVG，放 `game/assets/hud/icons/`，登记进 `manifest.json`，不引入第三方图标库。

### 6.2 意象

不用银杏、书签、日晷、樱、荷、蜡梅、羽毛、足印这类植物或器物意象。

- **功能类**：大地图是版图（方框里的走线与过孔），小地图是方框加十字准线，传送锚点是光学基准点；存档是带引脚的存储芯片，设置是推子组，说明是方框问号，退出是电源键；时间是时序环；季节是年相位正弦上的一点。
- **天气图标**用气象站填图符号，不是卡通太阳和云：晴 / 少云 / 多云 / 阴为云量圆（空心、¼、½、实心）；雾为 ≡；降水为两点，雪为 ✱；雷雨为雷暴符号。

### 6.3 窗口图标"八角晶片"

一块左上切角的方形芯片，四边各 3 根短引脚，芯片面上是图书馆八角穹顶的平面八瓣线，切角旁一枚过孔。底 b-800，八瓣线 b-200，过孔用暖色点（只此一处，代表"初灯"）。导出规格照 SYS-VIEW §6。

## 7 组件外观

### 7.1 六种状态（"通电"隐喻）

- **常态**：发丝边。**悬停**：边换成 `primary.line`，底叠 6% 主色，字和图标换成 `text.accent`。**按下**：底换深一档，内容下沉 1 px，不缩放。
- **焦点**：衍射光边。**禁用**：字 n-500，边改虚线，不发光，**仍可聚焦**并读出原因。**选中**：选中底加 2 px 指示条或过孔灯，卡片类另加顶边色散线；同组只有一项。

### 7.2 控件与容器

- **按钮**：主按钮填 `primary.fill`、1 px `primary.line` 内描边、切角，每屏最多一个；次按钮透明底加 `line.control`；危险按钮只出现在确认对话框里；图标按钮必须有悬浮说明（含快捷键）和读屏名。**开关**右侧写"开 / 关"；**滑杆**拖动时出等宽数值气泡。
- **列表项与卡片**："此处"标签带过孔灯；卡片用实底、切角。**确认对话框**居中、背后 `scrim`，Esc 等于取消、默认焦点在安全项。
- **临时提示**：左侧类型条加图标，同时一条、底部居中。**悬浮说明**反相底，可含键帽，悬停 400 ms 后出现，键盘焦点立即出现。

### 7.3 时间环

时间卡位于界面态右下角，固定深屏、切角：上方是 24 小时天色光谱环，中心是钟点读数，下方是预设、流逝分段、季节分段、预报行（操作见 UI-NAV §3.1）。

- **光谱环**：当前季节、当前天气下 24 个整点的地平线天色（`IPaletteProbe`），彩度乘 0.7。
- **把手**：太阳是 `now` 暖色圆（晶白加 1.5 px 墨描边），夜里换成月亮（不用暖色）。
- **中心读数**三行：钟点、"酉时 · 黄昏"、英文小标签，变化时一格一格滚（M4）。拖动或悬停时环外画一段虚线弧，从当前钟点顺时针到目标。
- **倍率波形**（M7）：暂停是直线，倍率越高越密。**收起态**是一条钟点、时辰、"季 · 天气"和光谱条；**漫游态不显示**。

### 7.4 天气签条、速度条与到达标题

- **天气签条**从时间卡左缘横向抽出，在画面下方约 20% 的带里；自动天气下自动钮选中、实际天气的格下方一枚过孔点；手动时被点的格选中；不合季节的雷雨格为禁用态；强度是右端三枚小方块。
- **速度 LED 条**：16 个格子，已到达的档实心，当前档更高并用主色，下方一条光条表示贴地限速后的实际速度；行走模式换成 5 个宽格。
- **到达标题**居中、不画面板，背后一块 `over.title` 暗带：第一行等宽数据（区域代号、区名、由位姿换算的经纬度）；第二行地点名；第三行英文小标签；下面一块深屏小条"推荐 秋 18:00 · 晴 [应用]"。

### 7.5 存档卡"存储模组"与等待灯

存档位的语义以 SYS-SAVE 为准。存档卡做成存储模组：表头"SLOT 01"加状态标签，左侧 16:9 截图，右侧主名、季节时刻天气、游玩时长、保存时间，底边 16 根接点（"金手指"）。

- **选中**时接点全部点亮；**最近**表头带实心过孔灯；**空槽**是虚线边加"空 · 新游戏"；**损坏**截图换成 45° 危险色影线加原因；**保存失败**配危险色过孔灯，**只读**用中性色；写入中卡角亮 M8，成功时接点依次点亮。
- **等待灯**（不用任何进度条）：三枚过孔依次点亮再一起熄；**只在等待超过 1.5 s 时出现**，冷启动的扉页阶段例外（SYS-TITLE）；不显示百分比和剩余时间。**存储指示**：存储芯片图标加一枚过孔灯，位于署名上方，写入超过 0.3 s 才出现。

## 8 画面布局

全部按 1920×1080 基准（拉伸 `canvas_items`、宽高比 `expand`，尺寸以 `ui_metrics.json` 为准），四角组件各自贴角。"中央 60%"（`centralFree`）常驻组件不得进入，开始页片名和菜单也不进（SYS-TITLE）；界面只放在上下各约 20% 的移轴虚化带里（ART-STYLE §7.4）。

**主题与压暗**：哪些件随主题见 §2.3、§3.4；从开始页打开的大页按 T0 世界的太阳高度取主题；开始页左侧暗渐变、不用面板；设置卡右侧 2/3 留给实景。

- **漫游态**：唯一常驻的是左上角小地图，其余只有临时提示和到达标题；按 U、`--ui=0`、过场时小地图也隐藏。
- **界面态**：小地图视口右侧排 [M] 大地图、[G] 目录两个图标钮；右上存档、说明、设置；左下观察模式与速度条；右下时间卡，天气签条贴在它左侧；署名在右下角，时间卡收起时放在它上方。
- **大地图**：背后 `scrim`，左栏（图层、目录页签、图例）加地图纸（切角、可磨砂）；底图、标记与传送卡以 SYS-ATLAS 为准。
- **设置卡**：贴左的大页面板；生效标签是等宽的"雾幕""重启"，负载标签画成三格 LED，注释栏用走线连到当前行。
- **制作人员与许可**（"数据手册"样式）：静态两栏表格，可滚动，不做自动滚屏片尾。

## 9 动效语言

### 9.1 原则与两种时间

1. **静止即安静**：没有输入、没有状态变化时，界面上没有任何会动的东西（3D 画面除外）。
2. **方向有因果**：揭示和流光从触发源出发（被点的按钮、小地图所在的角、时间环上的太阳），退场朝来处收回。
3. **入场从容、退场利落、可打断**：退场约为入场的 0.6–0.7 倍，不交错；动效进行中接受新输入，跟随类用弹簧保持速度连续，脚本类从当前值重新定目标。

**两种时间**：位移、透明度、颜色、数值按显示帧率连续补间；"被计算出来的东西"（抖动阶、网格点亮阶、图标换帧、示波器相位）按全局 `step_rate` 步进，和场景里的落叶在同一帧换姿态（SYS-MOTION §2.2）。

### 9.2 八个母题

| 母题 | 样子 | 用在 | 条件 |
| --- | --- | --- | --- |
| M1 走线流光 | 沿已有的发丝线跑过一段短亮光 | 面板第一次展开；传送前沿路线；存档成功沿卡边；设置"应用"完成 | 只沿已有的线，只跑一次，不用于悬停 |
| M2 扫描揭示 | 一道前沿一次扫过整页，不留痕 | 只给大页和昼夜交班 | 同一页一次会话里不重复 |
| M3 网格逐格点亮 | 网格按到起点的距离错开点亮，落定为内容后网格线消失 | 开始页标题背后；大地图底图；存档缩略图拼出 | 整个波 ≤ 450 ms；对齐 8 px 网格 |
| M4 数值滚动 | 变了的那一位像里程表竖向滚一格 | 钟点、速度、试跑结果、倒计时 | 没有随机字符；数字等宽 |
| M5 衍射边 | 焦点环收紧 | 只给键盘焦点 | 不给悬停，不循环 |
| M6 量化出入场 | 3–4 阶有序抖动从无到有，每阶停一拍 | 图标与缩略图更换、地图钉、标题卡逐字 | 没有色噪和 RGB 偏移；正文不用 |
| M7 示波器 | 一条单线波形，振幅频率对应真实数据 | 只在流逝倍率和降水强度 | 只有一条线；相位按 `step_rate` 推进 |
| M8 呼吸灯 | 一个小过孔透明度正弦往复，周期 2.4 s | 只在"进行中"：快进、换季、换天气、跳转飞行、设置应用、保存、等待 | 不让整块面板呼吸；可能持续超过 5 s 的状态（如高倍率）改用静态标记加 M7（WCAG 2.2.2） |

### 9.3 频率分级与声音

- **高频**（悬停、按下、焦点、切换、拖动）：只用色调变化、线变实、弹簧滑块和 M5，禁止其余母题与任何发光。**中频**（面板开合、临时提示、图标与缩略图更换、数值变化、地图钉）：淡入上移、M4、M6、单次 M1。
- **低频**（开始页、标题卡、打开大地图、传送、存档成功、画面设置应用、昼夜交班）：M1、M2、M3、M6 的组合编排，总长 600–1200 ms，单个元素 ≤ 450 ms；禁止循环、闪白。**状态型**（进行中）：M8，倍率用 M7。
- **声音用同一套分级**（清单以 SYS-AUDIO 为准）：高频、状态型和自动保存无声，中频只有大页开合一声，低频编排各配一个对齐时间线的短音，临时提示不配提示音。

### 9.4 曲线、时长与上限

- **曲线**：脚本化、只播一次、要对齐时间线的用贝塞尔；由连续输入驱动、可能半路改目标的（悬停、拖动后的落定）用临界阻尼弹簧。曲线、弹簧与时长参数以 `ui_metrics.json` 的 `motion` 为准；弹簧阻尼比不低于 0.9，回弹、过冲类过渡一律禁用。
- **交错**：每项错开 30–40 ms，最多 6 项；退场不交错，且退场开始的同一帧就关掉焦点和鼠标；退场中又被打开，从当前值直接反向入场。
- **辉光与闪烁的上限**：发光只在线、点、细环上，晶白不发外光，深屏同屏最多 3 处、半径与亮度上限以 `ui_metrics.json` 的 `glow` 为准，界面最亮的像素不超过窗灯的亮度。同一区域亮度变化 ≥ 10% 的事件每秒最多 1 次（比 WCAG 2.3.1 更严）；不做全屏闪白。**没有常驻循环动画**（WCAG 2.2.2）：图标只在悬停或状态变化时动一轮。

## 10 减少动态效果与无障碍

### 10.1 "减少动态效果"下的替代

开关与默认值见 UI-NAV §3.5。所有组件经 `MotionPolicy` 取时长和"是否做空间运动"，组件里不写判断。

- 淡入上移、卡片揭示：只透明度，≤ 200 ms。M1：终点直接亮 120 ms 后淡回。M2、M3：整页或整块 200 ms 淡入，不出现网格线。M4 与弹簧：直接换字、直接到位加 100 ms 淡入。M6：150 ms 淡入。
- M5：直接出现（焦点环本身必须保留）。M7：静止波形。M8 与等待灯：静态实心点、三枚静止半亮。
- 昼夜交班：**直接换**，不扫。图标不换帧、无交错。3D 的跳转、换季、换天气、传送：0.5 s 雾幕交叉淡化（UI-NAV §6）。

### 10.2 无障碍

对比度与"不只靠颜色"见 §3.5，焦点环见 §5，闪烁上限见 §9.4。**降低透明度**打开后全部面板 100% 不透明、关闭磨砂；**界面主题锁定**，畏光的观者可以固定深屏。读屏与键盘规则见 UI-NAV §7。

## 11 实现边界

- **一个 Theme，由代码生成**：`UiThemeBuilder` 从 `ui.json`（色名）和 `ui_metrics.json`（尺寸、字号、时长）生成唯一的 Theme，运行时不修改。G4 禁止代码里写十六进制色值和 `main.tscn` 以外的共享 `.tres`。随主题变的颜色全部由 `ui_panel` 按全局参数 `ui_night` 取日、夜两值；悬停、流光、焦点、量化、常驻件的固定主题用 instance uniform。
- **两个白名单着色器分成两个文件**：`ui_panel`（切角、发丝线、辉光、M1/M5/M6/M7、交班前沿，不读屏幕）与 `ui_screen`（整页揭示与大页磨砂，读屏幕纹理）；着色器一旦出现屏幕纹理就会触发一次背景拷贝，不管分支走没走到。发丝线与辉光不用 `StyleBoxFlat` 的整数边框，也不走 3D 的 bloom。
- **主题切换**：唯一写 `ui_night` 的是 WP-35 的 `UiThemeClock`，它是扫描前沿的位置，不是颜色插值量；常驻件的材质写 instance uniform `pin_night = 1`，始终是夜值。凡是画面板和文字的地方都必须走这个机制，否则夜里会出现"浅底浅字"（G14 要抓的典型错误）。
- **`hdr_2d` 固定为关**：界面画在后期之后，颜色逐像素原样上屏。动效只改 `Modulate`、不在容器里的 `Position` 与 `Rotation`、instance uniform 和 `ui_night`。
- **大页按需创建、关闭即释放**：挂上 `ui_panel` 材质就占一个全局实例参数池的槽，只有释放节点才归还。
- **界面缩放**：拉伸比例已让界面随窗口等比放大，所以 **`ContentScaleFactor` 不乘系统 DPI**，否则 DPI 会被算两遍；设置"界面缩放"的最终值夹在"字不小于设计字号的 85%"与"逻辑视口不小于 1280×720"之间。
