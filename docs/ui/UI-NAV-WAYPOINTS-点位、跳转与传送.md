# UI-NAV-WAYPOINTS · 点位、跳转与传送

> **范围**：本文规定观景点位的设计意图与合法性、"飞过去"的方式与打断规则、预取与速度律豁免的界面侧约定，以及传送在界面上的取舍。
> **不在本文**：界面态、组件、输入与无障碍（UI-NAV）；传送规格、锚点与大地图（SYS-ATLAS）；速度律与预取的数值（ENG-BUDGET-LOD §2、ENG-PERF-STREAM §1.4）；英雄帧与推荐状态的来源（ART-COLORSCRIPT §1.5）；跨图切换（SYS-MAPS §3）。
> **查阅**：先读 §0；点位看 §1；跳转与传送看 §2

## 0 结论

1. **观景点位**（个数以 `waypoints.json` 为准），数字键与 `[` `]` 轮转；位姿与推荐状态以 `waypoints.json` 为准；锚点不是点位（§1）。
2. **位姿合法**：必须在可达空间内且不在缓冲带里，G2 检查；推荐天气"晴"写 `null`，应用时钉住晴（§1）。
3. **飞过去**保留地理感：按距离自动选滑移或弧线，途中不穿楼，镜头不滚转（§2.1）。
4. **都可打断**：任何移动键或鼠标累计移动 30 px 取消飞行，镜头减速而不是急停（§2.2）。
5. **传送**由大地图触发（飞过去超出弧线距离时也改走传送），规格以 SYS-ATLAS-TRAVEL §3 为准；跳转和传送本身不改时间、季节、天气，点【应用】才改（UI-NAV §3.4）。

### 0.1 接入要点

- **新增点位**：写进本图 `waypoints.json`，位姿须在可达空间内（§1）
- **让镜头去某处**：飞过去调 `ICameraRig.Transit()`，传送一律经 `IAtlasService.Travel`；到达不触发保存（DECISION-241）；3D 过渡读 `IMotionSettings`（§2）

## 1 点位

按构图选的观景位姿，推荐状态来自 ART-COLORSCRIPT §1.5 的英雄帧。**位姿、行走落点、进场路径、推荐状态（钟点、季节、天气）以 `game/data/maps/qingshuihe/waypoints.json` 为准**，契约见 `game/contracts/` 的 `Waypoint` 系列。设计意图：

- **组成**：P00 全景、P01–P15 各区的主要观景位、P16–P23 室内与高处八处（以 `waypoints.json` 为准）。P00、P03、P15 仅旁观；英雄帧见 ART-COLORSCRIPT §1.5。
- **特例**：P07 位姿在校界外，行走落点在闸机内侧，前景可能横进接触网，截图复核后必要时降低位姿；P12 从北端街口外侧看，不放在玻璃拱顶下；P02 落点在广场地面，不放到大台阶顶。
- **合法性**：位姿必须在可达空间内且不在缓冲带里（SYS-BORDER §2.2，宽度以 `map.json` 的 `roam` 为准），G2 检查。推荐天气"晴"在数据里写 `null`，应用时按晴钉住，英雄帧靠这一钉住保证。
- **落点与进场**：行走落点是位姿在地面（楼板）的投影，眼高 1.62 m；"仅旁观"的点位在行走模式下选中时自动切到旁观并提示一次；进场路径 `Entry` 让镜头从采光顶、门洞、水面或最近的开放入口进入，最后 0.4 秒落定。
- 这些位姿是 ENG-GATES-SHOTS §1 的 P 组，用 `--pose=P05` 调用。
- **锚点**（A01–A13）是场景里的导览亭与导览桩，3D 里点它没有反应，只是大地图上的可传送标记：**不是点位**，不进数字键与 `[` `]` 轮转，没有推荐状态；清单见 SYS-ATLAS-TRAVEL §2 与 `atlas/markers.json`。

## 2 跳转与传送

### 2.1 飞过去

数字键、`[` `]` 和大地图上的【飞过去】触发，按距离 d 自动选：d < 80 m 直线滑移，1.0–1.6 秒；80–600 m 弧线飞行，1.6 + 0.9·ln(1 + d/120) 秒；≥ 600 m 不飞，改走传送（经加载界面，SYS-ATLAS-TRAVEL §3）。

- 弧顶高于起终点和沿途最高屋顶 + 20 m，途中不穿楼；每个采样点都须在可达空间内，越界时抬高弧顶；镜头全程不滚转。

### 2.2 到达与打断

- **到达**：保持原观察模式。行走模式下目的地是落点，最后 0.4 秒垂直落定，碰撞就绪前不交还控制；室内或水下按 `Entry` 进场；到达不触发保存（DECISION-241）。
- **打断**：任何移动键或鼠标累计移动 30 px 取消飞行，镜头保留速度并 0.2 秒减速；途中选了另一个点位则平滑改道；再按一次同一点位改走传送（经加载界面）直接到终点。传送的取消与打断见 SYS-ATLAS-TRAVEL §3.4。

### 2.3 预取与速度律豁免

自由飞行受速度律约束；跳转和传送的路径已知，所以豁免，改用目的地预取和到达保证，规则以 ENG-BUDGET-LOD §2 和 ENG-PERF-STREAM §1.4 为准，传送的触发时机见 SYS-ATLAS-TRAVEL §3.4。飞过去在点位点击或悬停 150 ms 时开始预取，沿途按弧线预取；最后 25% 的速度不超过速度律，落地时近景一定是 L0。

### 2.4 传送与减少动态效果

传送规格（时序、落点、预取、打断）以 SYS-ATLAS-TRAVEL §3 为准，由大地图的传送卡触发。

- **两种方式的分工**：飞过去全程是相机运动，不遮挡画面，保留地理感，只在同一张图里；传送经加载界面直达，同图和跨图都用（SYS-ATLAS-TRAVEL §3.1）。
- **减少动态效果**开启时，跳转、改时间、换季、换天气的处理以 SYS-MOTION §3.6 为准；传送流程不变，大地图收拢改为透明度变化；疾跑时不改视场角。
