# UI-NAV · 界面与操作说明

> **范围**：本文规定界面的内容与交互：组件、界面态与漫游态及四角归属、输入优先级与关键键位、无障碍与语言。点位设计与跳转传送在子文档 UI-NAV-WAYPOINTS。
> **不在本文**：点位、飞过去与传送（UI-NAV-WAYPOINTS）；外观见 UI-VISUAL；地图界面见 SYS-ATLAS；开始页与加载界面见 SYS-TITLE；存档见 SYS-SAVE；界面音效见 SYS-AUDIO；份额与验收见 ENG-BUDGET、ENG-GATES。
> **查阅**：先读 §0；界面态、四角归属与隐藏看 §2；组件看 §3；输入与键位看 §4；读屏、语言与文本键看 §5；点位、跳转与传送看 UI-NAV-WAYPOINTS

## 0 结论

1. **分工**：界面是信息科技感的浅蓝风格，外观以 UI-VISUAL 为准；本文只定内容、交互与输入，点位和跳转见 UI-NAV-WAYPOINTS。
2. **两种状态**：漫游态鼠标被捕获，常驻件只有 §2 列的那几件，其余是几秒淡出的临时提示；Esc 进入界面态，普通界面 4 秒无操作后淡出，小地图不淡出；U 纯净模式隐藏一切（§2）。
3. **内容**：时间、季节、天气、速度、观察模式、地图、操作说明与设置、开始页、存档页；3D 画面不叠加标注（INV-3，§1）。
4. **时间只能前进**：时间环只能顺时针拨，没有"减一小时"（§3.1）。
5. **输入**：动作表在 `game/project.godot`；Esc 固定；输入分四层，同一时刻只有最上层接键（§4）。
6. **点位与跳转**：观景点位；【飞过去】保留地理感，大地图的【传送】经加载界面瞬移；都可打断（UI-NAV-WAYPOINTS §1、§2）。

**子文档**：

| 编码 | 简题 | 什么时候读 |
| --- | --- | --- |
| UI-NAV-WAYPOINTS | 点位、跳转与传送 | 新增或改点位、让镜头去某处、做飞过去与传送的界面侧 |

### 0.1 接入要点

- **加界面元素或提示**：只能是本文和 UI-VISUAL 登记的件；临时提示只用 §3.6 清单里的条目，清单外的先登记；`--ui=0` 时只剩 3D 画面和署名（§1）
- **读键盘、加动作**：动作表在 `game/project.godot`；Esc 固定为 `menu`；移动和视角由 相机与输入（SYS-VIEW） 按四层优先级过滤后交出（§4）
- **占用观者输入**：经 `ICameraRig.LockInput` 按原因取得（ENG-ARCH §3）；确认框与浮层画在界面根节点内，不用独占的系统窗口，否则退出时的保存走不到
- **写界面文字、显示地名**：稳定键，地名只从来源查（§5）
- **加观者设置**：存 `user://settings.json` 的 `ui` 节（SYS-SAVE-FORMAT §3）；画面设置只经 `IQualityService`，声音设置只经 `IAudioService`（§3.5）

## 1 允许什么、禁止什么

依据 INV-1（不做网页版那套地图功能，允许界面里的平面地图）和 INV-3（3D 画面不叠加标注）。

- **允许**：本文与 UI-VISUAL 登记的面板、按钮、临时提示；小地图与大地图；操作说明与设置；开始页、存档页、加载界面；界面音效（只给低频编排配短音，悬停默认无声）。
- **禁止**：3D 画面里的任何叠加（INV-3）以及拾取、路线线条、罗盘条；文字搜索、路径规划、营业时间电话这类地点信息卡；加载界面以外的进度条（加载界面的进度条只跟真实进展走，SYS-TITLE §3.1）；帧率等计数，唯一的例外是设置里的"显示性能信息"（默认关，§2）；传送的粒子与光柱；弹窗式引导、成就、教程关卡。
- 共享单车不加界面件，借还只用一个键，状态靠 3D 里的车、临时提示和地图停放点。
- 场景里的字只用简体中文（INV-4），界面文案以中文为主、可切英文。

## 2 界面态、漫游态与隐藏

布局基准与中央 60% 不进的规则见 UI-VISUAL-COMPONENTS §5。**四角归属**：

- **左上**：小地图；界面态下，小地图视口右侧排 [M] 大地图、[G] 目录两个图标钮。
- **右上**：存档、说明、设置三个钮，只在界面态；设置里开了"显示性能信息"时，钮下方常驻一行性能信息（帧率、帧时、CPU 与 GPU 渲染耗时、本进程 CPU、内存与显存；不做 GPU 占用率与输入延迟），跟小地图一样随 U 与 `--ui=0` 隐藏。
- **左下**：观察模式与速度条。
- **右下**：时间卡，天气签条贴在它左侧；署名在右下角，时间卡收起时放在它上方。
- **漫游态常驻的件只有两个**：左上小地图和开着的性能信息（都可关），其余只有临时提示和到达标题；按 U、`--ui=0` 时小地图也隐藏。这是常驻件的唯一权威，别的文档只指向本节。

| 状态 | 鼠标 | 界面 | 输入 |
| --- | --- | --- | --- |
| 漫游态 | 被捕获 | 小地图（设置可改为"移动时显示"或"关"）与临时提示 | 移动、转视角、全部快捷键 |
| 界面态 | 可见 | 淡入；4 秒无操作后普通界面淡出，小地图不淡出 | 移动键与快捷键照常，鼠标移动不转视角 |

- **进出**：加载界面淡出后处于界面态。单击画面（只算没被界面处理的左键）切到漫游态，有面板展开时第一次单击只收面板；窗口失焦时主动切到界面态。
- **覆盖**：大地图打开时小地图和其余界面隐藏、世界不暂停；存档页与设置卡打开时小地图随之隐藏；开始页和加载界面期间只显示开始页或加载界面；署名常驻。
- **自动隐藏只作用于没人在用的普通界面**：鼠标动作，以及作用于界面的键盘操作（Tab、方向键，T、H、G、M、`.`、P、J、Y 这类开面板或改时间、季节、天气的键）重新计时，只移动镜头的键不算；有控件持焦点、大页或确认框打开、改键等待、读屏运行时不隐藏。鼠标进屏幕四角热区或按 Tab，界面 180 ms 内回来；隐藏的界面不接受焦点。

## 3 组件的内容与交互

### 3.1 时间环

时间卡里的 24 小时天色光谱环（外观 UI-VISUAL-COMPONENTS §4.3）。**12 在顶、00 在底、06 在左、18 在右，钟点顺时针增加**，与"面朝南看太阳东升西落"一致。时间不能逆转（SYS-TIME §1），没有 −1h 按钮与快捷键。

- **拖动把手**：`SetClock(h, Drag)`。只能顺时针：逆时针拖时把手不动，悬浮说明写"时间只往前走"；每拖满一圈前进 24 h；拖动和悬停时环外画前向预览弧；拖动时流逝暂停，松手 1 秒后继续。
- **点刻度或预设**：`SetClock(h, Jump)`，跳到 h 下一次出现的时刻，延时摄影式快进（用时见 SYS-MOTION §3.1）。预设按当前季节的太阳算：晨为日出后 40 分钟，午为日出日落中点，昏为日落前 35 分钟，夜为 21:00。`.` 前进 1 小时，按住连续。
- **流逝**：暂停 / 1× / 10× / 60× / 360× / 1440×，默认 1×；P 暂停与继续。
- **回到落金初灯**（多地图取本图 `world.defaultName`）：回到默认状态（SYS-TIME §1.1），不移动镜头。

### 3.2 季节、速度与观察模式

- **季节**：四个分段，点选与 J 键都走正向换季转场（SYS-MOTION §3），转场途中再点别的季节从当前状态重新定目标。换季后手动天气不合法（如冬季的雨）时在起雾里自动替换并给一条临时提示。
- **旁观速度**：16 档对数分布，与滚轮一一对应（SYS-VIEW §2.1，数值以 `game/camera/FlightTuning.cs` 为准）。速度条下一条光条表示贴地限速后的实际速度（ENG-BUDGET-LOD §2）。行走步速 5 档：0.5×、0.7×、1×、1.4×、2×。
- **观察模式**：[旁观 | 行走] 两段，F 切换，双击空格也能切（设置可关）。两种模式都没有准星，会动的门自动开合、不加交互键；设置里可开 3 px 的"视角参照点"作晕动症辅助。

### 3.3 点位目录

点位目录是大地图左栏的"目录"页，G 直接打开（SYS-ATLAS-UI §3.3）：按总览、核心、南、西、北、东、边界分组，列表项有缩略图、中英双行名称与编号。镜头在某点位 40 m、朝向偏差 60° 以内时标"此处"；只能旁观到达的标"仅旁观"；没有搜索框。小地图与大地图见 SYS-ATLAS，开始页与加载界面见 SYS-TITLE，存档页见 SYS-SAVE；危险操作须经确认且默认聚焦"取消"。

### 3.4 首次进入与到达标题

- **首次进入**：第一次新游戏落地后，下方中央淡显一行"单击画面开始 · Esc 打开菜单 · H 操作说明"，4 秒后淡出，以后不再出现（记在 `settings.json`，跨存档）。这是唯一的主动引导。
- **到达标题**：跳转完成 70% 时淡入，2.4 秒后淡出；传送在加载界面淡出时淡入。内容见 UI-VISUAL-COMPONENTS §4.4。标题下有小签"推荐 秋 18:00 · 晴 [应用]"。**跳转和传送本身不改时间、季节、天气，点 [应用] 才改**：`Apply(WorldPreset)` 发一个组合转场，钟点前向跳到推荐钟点，季节不同时走换季转场，推荐天气钉住一段后自然演化（SYS-WEATHER-PROCESS §1.6）。锚点、室内门口、路线起点没有推荐状态，只出标题。

### 3.5 操作说明与设置

可展开的卡，分"键位""设置""画面""声音""改键""许可"页（许可页含版本说明），先显示当前模式的键位图；打开时才建、关闭即释放；开始页也能打开。卡底有 **返回标题**（先保存再经加载界面回开始页）和 **退出**（先写设置再保存，保存不成也直接退出，SYS-SAVE-FLOW §1.4）；"键位"页底有 [打开日志目录] 与 [导出诊断…]（确认框里"附带存档"默认不勾，不联网，ENG-RELEASE §6）。

- **存储**：界面设置存 `user://settings.json` 的 `ui` 节，改键存 `input` 节，画面和声音各有自己的节；整份是档案级，不进存档，读写规则以 SYS-SAVE-FORMAT §3 为准。
- **画面页**：分组列出 SYS-GRAPHICS §3 的单项，页首是预设分段（均衡、精致、极致、自定义）；每行是"名称｜控件｜生效标签"，无标签即时生效，"加载""重启"各有标签；悬停或聚焦一行时底部注释栏显示说明与负载标签（GPU、显存、CPU 的大中小），加载类配两张对比小图；即时类直接看身后实景，画面页只占左侧约 1/3，不压暗；有加载类改动待生效时"应用"才亮，未应用的改动跨开关保留。"界面缩放""大页磨砂""降低透明度""界面主题"不是画面单项，留在"设置"页。**声音页**按 SYS-AUDIO §7；**许可页**与开始页的"制作人员与许可"是同一个组件（ENG-RELEASE §7.1）。另有只读两行：本机缓存与烘焙进度（附 [清除缓存]）。
- **设置项**的取值与默认以 `game/hud/HudSettings.cs` 为准。设计要求：有**单键快捷键总开关**（WCAG 2.1.4）；减少动态效果和语言默认跟随系统；跳转后自动应用推荐状态默认关；界面缩放 75–150%；显示性能信息默认关。

### 3.6 临时提示

漫游态下只允许这些，2 秒内淡出，同时 1 条，一律不配提示音（样式 UI-VISUAL-COMPONENTS §4.2）：

- 速度档位、时间（按 `.`）、季节、模式切换、到达标题、小地图开关；天气（"小雨 · 按住 Y 自动"）；换季替换天气（"冬季 · 雨转为雪"）；点禁用的雷雨格（"春夏才有雷雨 · J 换季"）；画质推荐变化（主线之后；提示一次，不自动改观者的选择）；
- 阻挡："前方暂未开放"（旁观飞到可达空间边缘，SYS-BORDER §3.1），同一处 60 秒内不重复；
- 共享单车的借还与不能骑行、下不了车、停放点已满；另一个窗口在运行（本窗口不保存）只提示一次；照片存好提示"已保存照片"和所在文件夹，没存下提示"照片没存下"，纯净模式下也提示（照片本身不含界面）；保存失败只记日志，不提示（SYS-SAVE-FLOW §1.5）。

### 3.7 天气签条

清单、季节约束、强度档与自动天气规则以 SYS-WEATHER §1、SYS-WEATHER-PROCESS §1 为准；外观与图标见 UI-VISUAL-COMPONENTS §3、§4.4。

- **格**：时间卡展开时，签条从卡的左侧抽出；8 格加"自动"：晴、少云、多云、阴、雾、降水、雷雨、初晴。雷雨在秋冬禁用，但可聚焦并读出原因，点它只出提示，不替观者换季。
- **自动与手动**：默认自动，天气由种子与世界时间求出；点任意格进入手动（`SetWeather`），手动天气不随时间变；点"自动"（`SetWeatherAuto`）平滑回到自动天气。
- **强度**：三档方块（轻、中、重），只在雾、降水、雷雨下出现，点一枚就转为手动；不做连续滑杆，强度不设快捷键。
- **Y 键**：单击切到下一种天气并进入手动，只在本季可选的格里循环、跳过禁用格；按住 0.6 秒回到自动。
- **预报行**：展开时底部一行，对未来 24 小时的自动天气求值：只说粗时段（稍后、今夜、明晨），最多三个词，不给钟点、概率和种子，只在自动天气下显示；不做"将转雨"的临时提示。

## 4 输入

### 4.1 Esc 与单键快捷键

- **Esc**（固定，不能改键，不暂停世界）：漫游态进界面态；界面态有面板时先关面板，没有则回漫游态；大地图打开时先关传送卡或浮层再关大地图；传送的加载界面出现之前按 Esc 取消传送。暂停流逝用 P。
- **G / T / H / M**：漫游态直接切到界面态并开对应面板，界面态开关面板；M 关闭大地图时回到打开前的状态。**N** 两种状态下都切换小地图。
- **开始页与加载界面期间**（SYS-TITLE §3）：单键快捷键全部无效；开始页只认菜单键，主菜单上按 Esc 什么也不做；加载界面不接受输入。

### 4.2 关键键位

动作表在 `game/project.godot` 的输入映射里，按物理键位绑定；除 Esc 外都可改键，一个物理键只绑一个动作，冲突时提示并拒绝。关键键位：

| 键 | 作用 |
| --- | --- |
| Esc | 漫游态与界面态切换 |
| 1–9 / 0；`[` `]` | 飞到 P01–P09 / P00 全景；上一个 / 下一个点位（锚点不进轮转） |
| M / G / N | 大地图 / 大地图目录页 / 小地图显隐 |
| T / H / U | 时间卡 / 操作说明 / 纯净模式 |
| . / P / J / Y | 时间 +1 小时 / 暂停流逝 / 下一季 / 下一种天气 |
| F / R | 切换旁观与行走 / 按住 0.6 秒回到最近的安全点（行走） |
| V / B | 第一人称与第三人称（第三人称开放前只在开发构建起作用）/ 共享单车借还与上下车 |
| F12 | 游玩中把当前画面存成照片（不含界面），存到用户目录的 photos 文件夹；同名不覆盖，加后缀 |

- 疾跑默认按住 Ctrl，双击 W 同时保留，设置可改为切换。骑行时 W 蹬车、S 制动、A D 转向。
- 大地图打开期间只认 M、G、N、Esc 和地图内的键（WASD 与方向键平移；传送卡上 F 是【飞过去】（T 是【追踪】，主线之后））。
- 单键快捷键都受总开关约束。

### 4.3 输入优先级

同一时刻只有最上面一层接键盘和鼠标，下层收不到：

| 层 | 何时 | 接什么 | 下层 |
| --- | --- | --- | --- |
| 1 确认与改键 | 确认框打开；改键等新键 | 对话框：Tab、方向键、Enter、空格，Esc 等于取消；改键：下一个按键，Esc 取消 | 移动、视角与全部单键快捷键无效 |
| 2 大页 | 设置卡、存档页、数据手册、大地图 | 页内焦点键和本页的键；Esc 先关浮层再关页；打开本页的键再按关页 | 移动与其余单键快捷键无效（大地图见 SYS-ATLAS-UI §3.6） |
| 3 普通界面 | 界面态，无大页和对话框 | 有控件持焦点时，方向键、Enter、空格给它 | 移动键与单键快捷键照常 |
| 4 漫游 | 漫游态 | 全部 | — |

- 第 1、2 层经 `LockInput` 占用观者输入，只挡输入，世界照常运行。相机和行走不直接轮询按键，由 相机与输入（SYS-VIEW） 按本表过滤。
- 单键快捷键在第 1、2 层不响应（打开当前大页的那个键除外），所以确认框背后不会换季，改键时按下的键不会触发动作。

## 5 无障碍与语言

读屏用引擎内置的 AccessKit（实验性，判据尽力而为）。对比度、焦点环、不只靠颜色、闪烁、降低透明度和主题锁定见 UI-VISUAL-MOTION §2.2。

- **键盘可达**：Tab 顺序即视觉阅读顺序（左上、右上、左下、右下，区内从左到右、从上到下），由界面树的顺序决定，不手连焦点邻接（D-245）；大页或确认框打开时，下层整棵界面不可聚焦、不接鼠标；淡出的件不可聚焦。时间环声明为滑杆，方向键只有"增大"方向有效；禁用的雷雨格可聚焦并读出原因。大地图只用键盘完成一次传送：G、方向键、Enter、Enter（G14）；开始页、存档页、确认框、设置卡都能键盘走完。
- **读屏**：每个可获得焦点的控件有可读的名字，图标钮必须写读屏名；到达点位或传送到达时实时区域朗读"已到达：图书馆正门"，加载界面的进度同样写入。界面不会在键盘和读屏用户手里消失（§2）。
- **语言**：中文为主，提供英文，默认按系统语言选择；点位名在目录页中英双行显示。
- **文本约定**（所有写界面文字的包照此写）：
  - **稳定键**：界面文字一律写键 `<域>.<对象>.<用途>`，如 `hud.toast.save_failed`；发布过的键不改名、不复用，意思变了换新键；存档和日志只记键。
  - **整句加具名占位**：一句话一条翻译，变量写 `{place}`、`{key:menu}` 这样的具名占位，不拼句。
  - **地名只有一个来源**：区域与地点名在 `atlas/labels.json`，点位名在 `waypoints.json`，锚点与标记名在 `atlas/markers.json`，图名在 `map.json`；别处只存 ID，CSV 里不手写地名。
  - **回退**：系统语言以 `zh` 开头取中文，其余取英文；缺键回退中文。G2 检查中英两张表键齐全、占位名一致。
