# PRD-INDEX · 作品总纲

> **范围**：本文是作品域的入口：本域管作品是什么、做什么不做什么，以及观光规则集的硬约束；列出本域通用的原则和本域全部文档的上下级。
> **不在本文**：各主题的规则与设计（在下面列出的文档里）；全项目的核心准则与信息地图（CORE-INDEX）。
> **查阅**：先读 §0；要找文档看 §1，按标题挑要读的那份，再读它的 §0 与接入要点

## 0 结论

1. **只写长期不变的取舍与约束**：作品是什么、取舍与范围在 PRD-SCOPE，硬约束在 PRD-INVARIANTS；会随开发改的设计与数值写在各域文档里，本域只给方向并指过去。
2. **约束对主线版同样生效**：INV-1–INV-12 对所有工作包生效，主线版也要满足；放宽哪些由 ENG-ROADMAP 登记，登记前一条不放松（WF-RULE §8）。
3. **"当前范围"指本阶段的观光规则集**：PRD-SCOPE §2 列的"不做"现在不施工，别的文档也不为它写前瞻；RPG 规则集的扩展只在 ENG-ROADMAP 登记。
4. **默认状态是"落金初灯"**（秋 17:30，晴）：作品的开场与各文档取值、验收样张的基准，取值见 PRD-SCOPE §1。

### 0.1 接入要点

- **加或删一项范围、改一条不变量**：先在 REG-DECISIONS 登记，再改本域和受影响的文档。
- **在本域新增文档**：主题文档文件头写 `parent: PRD-INDEX`，在 §1 加一行；子文档写 `parent: <主题文档编码>`，列进主题文档的 §0 和本总纲 §1 那个主题下（STD-DOC §5.1、§7）。
