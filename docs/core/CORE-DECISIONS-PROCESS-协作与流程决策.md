> **范围**：本卷登记协作与流程领域的决策，每条一句结论，附适用范围、细则所在的小节和状态。
> **不在本卷**：用法、编号规则、状态含义和归卷规则在 CORE-DECISIONS §0；数值与规则的细则以"细则所在"指向的文档为准；其他领域的决策在 CORE-DECISIONS 列出的别的卷。
