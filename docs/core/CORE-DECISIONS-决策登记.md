# CORE-DECISIONS · 决策登记

> **范围**：本文登记全项目已经定下的决策，每条一句结论，附适用范围、细则所在的小节和状态。需要确认一件事定了没有、定成什么样、细则去哪里看时，按 D 编号或关键词查本文，不必开工前通读。
> **不在本文**：数值、规则、契约与验收的细则，以"细则所在"指向的文档为准；决策的来由与过程不写进文档，需要留背景与取舍的重大决策另写 ADR（WF-DOC §3）；术语见 CORE-GLOSSARY，约定见 CORE-CONVENTIONS，RPG 扩展路线见 ENG-ROADMAP。
> **新增决策**：由主会话登记进本文，再改相关文档；子代理只读本文，发现细则文档与本文不一致时报主会话，不自行改动。
> **查阅**：先读 §0；按 D 编号 grep；按领域找：作品与范围看 §1，世界与地图看 §2，时间季节天气看 §3，美术看 §4，界面看 §5，存档看 §6，音频看 §7，性能与画面设置看 §8，工程看 §9，流程看 §10

## 0 用法

- **编号**：D-001 起全文连续，编号不改、不复用。决策有变时改写原行，只写现行决定。
- **状态**：
  - 生效：按细则文档施工；
  - 待原型验证：方向已定，数值或做法以 P0 原型、看图、听评或实测为准；验证前按细则文档里的初值施工。
- **细则所在**：写"编码 §x.y"，例如"SYS-WEATHER §6.4"；不变量写"INV-6"。决策与细则文档有出入时以决策为准；发现者报主会话，由主会话同批改细则文档。

### 0.1 接入要点

- **想知道一件事定了没有**：按 D 编号或关键词 grep 本文；数值与做法以"细则所在"指向的文档为准，二者有出入以本文为准（§0）。
- **发现细则文档与本文不一致**：以本文为准，报主会话，不自行改动（§0）。
- **需要一个新决定**：在回报里提出，由主会话登记进本文，再改相关文档（WF-DOC）。
