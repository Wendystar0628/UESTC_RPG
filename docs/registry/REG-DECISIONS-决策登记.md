# REG-DECISIONS · 决策登记

> **范围**：本文是全项目已定决策登记的入口，规定编号、状态、"细则所在"写法、归卷规则和新增决策的登记方式；决策本体分三卷，每条一句结论，附适用范围、细则所在的小节和状态。需要确认一件事定了没有、定成什么样、细则去哪里看时，按 D 编号或关键词查三卷，不必开工前通读。
> **不在本文**：各条决策的内容在三卷；数值、规则、契约与验收的细则，以"细则所在"指向的文档为准；决策的来由与过程不写进文档；术语见 REG-GLOSSARY，约定见 STD-CONVENTIONS，RPG 扩展路线见 ENG-ROADMAP。
> **查阅**：先读 §0；按 D 编号或关键词 grep 三卷；归卷规则和三卷目录都在 §0

## 0 用法

- **编号**：D-001 起全文连续，编号不改、不复用。决策有变时改写原行，只写现行决定。
- **状态**：
  - 生效：按细则文档施工；
  - 待原型验证：方向已定，数值或做法以原型、看图、听评或实测为准；验证前按细则文档里的初值施工；验证完立即改成生效。
- **细则所在**：写"编码 §x.y"，例如"SYS-WEATHER-PROCESS §1.4"；不变量写"INV-6"。决策与细则文档有出入时以决策为准；发现者报主会话，由主会话同批改细则文档。
- **新增决策**：主会话登记进所属卷（见下"归卷"），再改相关文档；子代理只读本文与三卷，发现细则文档与决策不一致时报主会话，不自行改动。
- **归卷**：按"细则所在"第一份文档所在的域归卷；INV-n 按作品域算，代码路径和 CORE-INDEX 不计。新决策追加到所属卷的对应节；查最大号用 `grep -ohE "^\| D-[0-9]+" docs/registry/REG-DECISIONS*.md | sort | tail -1`。

| 卷 | 归入的域（文档编码前缀） | 节 |
| --- | --- | --- |
| REG-DECISIONS-WORLD 世界与画面决策 | 作品 PRD、画面 ART、世界 WLD、地图 MAP | 作品定位与范围、世界与地图、美术风格 |
| REG-DECISIONS-SYSTEMS 系统与工程决策 | 系统 SYS、界面 UI、工程 ENG | 界面、存档、音频、性能与画面设置、工程、地图与行走、时间季节天气 |
| REG-DECISIONS-PROCESS 协作与流程决策 | 计划 PLAN、协作 WF、规范 STD、登记 REG | 流程 |

### 0.1 接入要点

- **想知道一件事定了没有**：按 D 编号或关键词 grep 三卷；数值与做法以"细则所在"指向的文档为准，二者有出入以决策为准（§0）。
- **发现细则文档与决策不一致**：以决策为准，报主会话，不自行改动（§0）。
- **需要一个新决策**：在回报里提出，由主会话登记进所属卷，再改相关文档（§0，STD-DOC §8）。
